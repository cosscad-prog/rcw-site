01

Pname Milling 신규 화면 변경

Pname · PPI

단면에 이름·단중·추가 길이·Block 정보를 넣는 그 창입니다. 여기에 Milling 탭이 새로 생겼고, Additional Length 가 Start 한 칸으로 줄었습니다.

새로 생긴 것 — Milling 탭

  • 프로파일 바를 폴리라인 모양으로 깎습니다.단면과 같은 평면에 닫힌 폴리라인을 그리고 Mill 1 버튼으로 고릅니다. 한 프로파일에 Mill 1~Mill 4 네 칸.
  • Cut Type — 깎기만 / 깎고 절삭체 사본 남기기사본은 Subtract_Block 레이어에 남아 위치를 눈으로 확인할 수 있습니다.
  • Location — By Brep(바 실제 양 끝) / By Line(중심선 양 끝)
  • 등간격은 Block Insert 와 같은 뜻입니다 — 양 끝에 하나씩 놓고 사이를 값을 넘지 않는 가장 적은 개수로 나눕니다. 자투리가 없습니다.
구간입력결과
1250mm등간격 100간격 96.15mm · 14 개
1200mm등간격 200간격 200mm 그대로 · 7 개

바뀐 것 — Additional Length

  • Mullion · Transom 두 칸이 Start 한 칸으로.한 단면은 멀리언이거나 트랜섬이지 둘 다일 수 없어 늘 한쪽만 쓰였습니다.
  • 기존 도면은 그대로 열립니다 — 한 번 저장하면 옛 두 값이 하나로 정리됩니다.
  • 두 탭의 배치를 맞춰 탭을 바꿔도 항목이 움직이지 않습니다. 이름 칸을 누르면 모델에 번호 점이 찍힙니다.
한 마디 전에는 슬롯·홈을 넣으려면 형상을 따로 만들어 빼야 했습니다. 이제 단면에 그린 폴리라인 하나면 UMD 가 알아서 깎습니다. 간격 규칙도 블록과 같아 새로 외울 것이 없습니다.
02

Properties 패널의 단면 정보 신규

명령 아님 — Properties 패널 안의 탭

Rhino Properties 패널 안에 RCW 탭이 생겼습니다. 객체를 고르고 P 아이콘을 누르면 그것이 어떤 부재인지 바로 나옵니다. 단면 group 안의 선 하나를 골라도 됩니다.

화면 구성

ObjectRhino 기본 Object 페이지와 같은 줄 — Type · Name · Description · Layer · Display Color
Section DataMaterial · Profile · Fab · Group · Alloy — 번호가 아니라 뜻으로(1. Mullion)
Add LengthTop/Left · Bot/Right 두 줄
More details그 객체로 Pname 창을 바로 엽니다

알아 둘 것

  • Name 을 고치면 단면 이름(P_name)도 함께 바뀝니다 — 확인창이 먼저 뜹니다.
  • 여러 개를 고르면 편집이 꺼집니다.
  • ID 를 바꿔도 이미 만든 모델·도면은 그대로입니다 — SSP 재등록 + UMD 재실행이 필요합니다.
  • 단면 data 는 Undo 로 되돌아가지 않습니다. Rhino 7 에서도 나오고, 탭 아이콘만 Rhino 8 전용입니다.
한 마디 전에는 "이 선이 어느 프로파일인가"를 알려면 Pname 을 열어야 했습니다. 이제 클릭 한 번입니다.
03

SSP — 등록 전에 먼저 걸러 준다 사전검사 신규

SSP

SSP 는 단면 group 을 골라 등록하는 명령입니다. 여기에 등록 전 검사가 들어갔습니다 — 그대로 등록하면 한참 뒤 UMD 에서야 터지던 것들을, 이제 등록하는 그 자리에서 알려줍니다.

새로 검사하는 것 — 셋

  • data 가 없는 단면 SurfacePname 을 넣지 않은 단면입니다. 등록을 중단하고, 그 단면 한가운데에 빨간 No_Data 표시를 세웁니다.
  • 복사로 어긋난 Block ID — 다시 찾아 줍니다단면 group 을 복사하면 등록된 블록 ID 가 원본 group 의 블록을 그대로 가리킵니다. group 안에서 같은 이름 · 같은 거리의 블록을 찾아 스스로 고쳐 씁니다. 하나로 좁혀지지 않으면 고치지 않고 알립니다.
  • 형상이 깨진 단면 Surface닫히지 않은 구멍 선, 겹쳐 그린 선 — 잘못된 Surface 라고 알리고 Bad_Shape 표시를 세웁니다.

알아 둘 것

  • 한 창에 모아서 보여줍니다.단면 문제와 블록 문제가 섞여 있어도 나누지 않습니다 — 같은 유닛의 줄이 나란히 떠야 한 번에 고칩니다.
  • 찾아가기 쉽게 — 문제 객체는 선택된 채로 남고, 표시는 No_Data Layer 에 모입니다.SSP 를 다시 돌리면 지난 표시는 지웁니다. 자세한 이유는 명령창에 한 줄씩 남습니다.
  • 중단이면 등록은 하지 않습니다.반쪽짜리 단면이 Multi_set 에 들어가지 않게 합니다. 고친 뒤 SSP 를 다시 실행하면 됩니다.
한 마디 전에는 UMD 가 죽고 나서야 어느 단면이 문제인지 되짚어야 했습니다. 이제 SSP 가 그 단면을 집어서 보여줍니다.
04

FDwg — 입면에 홀 깊이가 보인다

FDwg · FDDS

FDwg 는 FDDS 와 같은 가공도를 만들되, 입면도에도 홀 정보를 함께 표시하고 홀이 자재를 얼마나 관통하는지를 점선으로 보여 줍니다.

입면 홀 깊이 표현

  • 홀이 자재를 통과하는 구간을 점선(Hidden Line)으로 그립니다 — 위치와 관통 깊이를 동시에 봅니다.
  • 홀과 같은 깊이의 선만 골라냅니다.홀의 Bounding Box 깊이와 2D 투영이 계산한 가려진 선의 깊이가 맞는 것만 씁니다 — 반대편 벽 같은 무관한 선은 빠집니다.
  • 선별된 선은 Shape_Hidden 레이어에 들어갑니다.
  • FR · TO · BO · TB · BB 모든 입면 View에 적용되며, 프로파일 방향에 따라 알맞은 View 에 자동으로 나타납니다.
  • 홀 중심선 · 단면 해치 · 홀 포인트 등 기존 표기는 그대로 두고 그 위에 더합니다.

옵션 우선순위

  • DdOpt 는 View 방향·거리·추가 치수·홀 인식 지름을, DsOpt 는 치수선 배치와 크기를 정합니다.
  • 재생 모드에서 해당 금형 행이 파일에 있으면 파일 값이 패널 값보다 우선합니다. 없으면 DdOpt 패널 값을 씁니다.
한 마디 입면만 보고도 홀이 어디까지 뚫렸는지 알 수 있습니다. 단면을 따로 찾아볼 일이 줄어듭니다.
04

FDstyle — 한 번 기록하면 다음부터 자동 명령 통합

FDstyle (구 FDP · FDwgStyle)

자주 쓰는 Profile 의 가공도 작업을 한 번 기록해 두면, 같은 Profile 의 가공도를 만들 때 같은 결과가 자동으로 재현됩니다.

기록되고 재현되는 것

  • DdOpt 옵션 전체
  • NC 데이터 테이블 (NC3~NC6)
  • FSC 도면 압축
  • 주석 · 지시선 · 라벨 이동직접 추가한 지시선·텍스트와 LeaderTextMove 로 옮긴 위치까지.
  • 부속자재 표(FabBomTable)의 위치
  • 부분 확대 3D(F3D)의 카메라 방향과 배율
  • 도면 양식(SFB/FFB)

보여 줄 것

  1. 기록 ON → DdOpt 맞추고 FDwg 실행
  2. F3D · 부속자재 표 · 지시선 추가
  3. 재생으로 되돌린 뒤 같은 Profile 을 다시 FDwg
한 마디 여기가 이번 변경의 중심입니다. 가공도를 "매번 다시 꾸미는 일"에서 "한 번 정해 두는 일"로 바꿉니다.
04

F3D — 3D 부분 확대 뷰 신규

F3D

복잡한 가공 부위나 브래킷 결합부를 원하는 각도의 3D 모습 그대로 도면에 넣습니다.

순서

  1. 부재를 고르면 별도 3D 창이 열립니다 — 그 부재만 격리되어 보입니다.
  2. 우버튼 드래그 회전 · 휠 확대 · 좌버튼 드래그 이동
  3. 확정 — 화면에 보이는 그대로(원근)가 숨은선 제거 2D 로 바뀝니다.
  4. 위치를 클릭하고 배율을 드래그로 정합니다(0.3 배부터).

알아 둘 것

  • 카메라 방향과 배율이 저장됩니다 — 재생 시 같은 방향·같은 배율로 자동 재현.
  • 부재(Brep)와 ProfileName 이 있어야 합니다 — 없으면 중단됩니다.
  • 출력은 항상 모델 실측 기준. 3D 창의 확대는 구도용일 뿐입니다.
한 마디 "이 부위는 말로 설명하기 어렵다" 싶을 때 씁니다. 한 번 각도를 잡아 두면 다음 도면에서도 같은 각도로 나옵니다.
04

FabBomTable — 부속자재 표 구 FBL

FabBomTable

가공도에 들어가는 부속자재 목록(BOM)을 마우스로 원하는 자리에 놓습니다. 내용은 이 명령이 만드는 것이 아니라 가공도를 만들 때 이미 모인 것입니다.

동작

  • 내용 — FDwg/FDDS 가 그룹의 브래킷·슬리브·부착물에서 자동 수집
  • 위치 지정 — 표 외곽과 행 구분선이 주황색 미리보기로 보입니다
  • 크기는 자재 종수와 글자 크기에 따라 자동 결정
  • 같은 Profile 에 표가 있으면 지우고 새로 그립니다
  • 위치는 도면 기준점 상대좌표로 저장 → 재생 시 같은 자리

안 될 때

  • "수집된 부속자재가 없습니다" — 부속자재가 포함된 그룹으로 FDwg/FDDS 를 먼저 실행해야 합니다.
  • ProfileName 태그가 없는 객체는 대상이 아닙니다.
  • FabTable(제작 번호 표)과는 다른 표입니다.
한 마디 표를 어디에 둘지만 정하면 됩니다. 그 자리를 기억했다가 다음 도면에서도 같은 자리에 놓습니다.
04

LeaderTextMove — 화살표는 두고 글자만 옮긴다 구 LM

LeaderTextMove · LeaderMove

지시선의 화살표는 부속에 고정한 채 텍스트(꼬리)만 옮깁니다. 일반 Move 는 화살표까지 움직여 지시 대상이 흔들립니다.

동작

  • 고정 / 이동 — 시작점(화살표)은 그대로, 마지막 점(꼬리)만 이동
  • 미리보기가 실제 지시선과 같은 DimStyle 로 그려져, 클릭 위치가 결과와 일치합니다
  • 여러 라벨을 이어서 옮길 수 있습니다 — Enter 로 종료
  • Annotation(지시선)만 선택됩니다

쓰는 자리

  • 단면 라벨이 서로 겹치거나 도면 밖으로 나갈 때
  • 기록 모드에서 옮기면 그 위치가 저장되어 재생 시 그대로 재현됩니다
  • 라벨 전체를 옮기려면 LeaderMove
한 마디 도면 손질 중 가장 잦은 것이 겹친 라벨 정리입니다. 그 손질까지 기록되니 다시 뽑아도 정리된 상태로 나옵니다.
05

WebV · ToWebFile — 브라우저에서 보고, 파일 하나로 보낸다 Standard

WebV · ToWebFile

모델을 Rhino 없이 볼 수 있게 만듭니다. WebV 는 지금 바로 브라우저로 열고, ToWebFile 은 HTML 파일 하나로 저장해 그대로 전달합니다.

뷰어에서 할 수 있는 것

  • Orbit · Pan · Zoom · Reset · Fit — 상단 툴바
  • Ghost 반투명 · Grid · Section 절단(X/Y/Z 축과 위치)
  • Explode — 슬라이더로 요소를 벌려 조립 관계 확인
  • Projection — Persp / Ortho (기본 Ortho)
  • Zoom Window — W → Space, 영역 드래그
  • 뷰 단축키 — TV · FV · RV · LV · SE/SW · ZX 전체보기

공통

  • 폴리곤 감소율을 물어봅니다 — Enter 면 원본. 값이 작을수록 가볍습니다.
  • 레이어·색상·블록 색상 상속과 텍스트까지 함께 넘어갑니다.
한 마디 현장이나 발주처에 모델을 그대로 보여 주는 가장 빠른 길입니다. 받는 사람은 프로그램을 깔 필요가 없습니다.
06

Bmt · Udt — 부재를 하나씩 만든다 신규 Standard

Bmt · Udt

UMD 는 와이어프레임 group 을 완전하게 준비하고 골라야 결과가 나옵니다. Bmt 는 같은 규칙을 부재 하나 단위로 줍니다 — 선 하나를 짚으면 그 부재가 바로 생깁니다.

작업 순서

  1. Mullion 이나 Transom 프로파일 group 하나를 고릅니다.
  2. 선 하나를 짚습니다.
  3. 미리보고 그 부재를 바로 만듭니다.
  4. 뒤 부재를 같은 와이어프레임 셋에 이어서 더합니다.
  5. 두 종류가 다 있으면 Udt 로 셋을 다시 지어 부재 간 절단이 보이게 합니다.

알아 둘 것

  • 생성물은 와이어프레임 셋 단위로 묶입니다.선택이 단순해지고, 관계없는 유닛의 프로파일이 함께 갱신되지 않습니다.
  • 프로파일 방향은 원본 group 에 저장되어, 나중에 갱신해도 지금의 뷰나 선택 방향에 좌우되지 않습니다.
  • 한 유닛은 한 방식만 씁니다 — BMT/UDT 아니면 SSP/UMD.
  • 단면 data 가 없는 프로파일은 옛 기본 연장값을 씁니다 — Brep·curve 50, 원본 Surface 0.
  • 도움말에 Bmt/Udt 페이지가 있습니다 — 04 Frame Modeling 의 UMD 다음.
한 마디 처음 배우는 사람과 한두 부재만 고쳐야 하는 상황을 위한 길입니다. 전체를 다시 돌리지 않고 필요한 것만 만들 수 있습니다.

System Default — 내 기본값을 저장한다 신규

DdOpt · DsOpt 의 D 버튼 · Fablist SaveAsDefault

자주 쓰는 설정을 기본값으로 저장해 두면 다음부터 그 값으로 시작합니다. 파일 하나에 모이고 설치 PC 단위라, 사람마다 다른 기본값을 가질 수 있습니다.

어떻게 저장하나

DdOpt패널 위쪽의 작은 D 버튼. 누르면 파랗게 바뀌고, 값을 하나라도 바꾸면 원래 색으로 돌아옵니다.

Fablist옵션 SaveAsDefault=On 으로 실행하면 LabelType·LabelFontScale 가 저장됩니다.

알아 둘 것

  • 저장 위치는 System_Default.dat 한 파일입니다 — 전체 경로는 저장할 때 명령창에 찍힙니다.
  • 여러 기능이 같은 파일을 공유하되 자기 항목만 갱신하고 다른 값은 그대로 둡니다.
  • 메모장으로 직접 고칠 수 있습니다 — key=value 한 줄에 하나.
  • 설치 PC 단위입니다 — 다른 PC 로 옮기려면 이 파일을 복사하십시오.
한 마디 매번 같은 체크박스를 다시 맞추던 일이 없어집니다. 회사 표준을 정했다면 그 파일 하나를 나눠 주면 됩니다.

CDPlg — 추가 길이만 옮긴다 신규

CDPlg

기준 단면의 Additional Length 상자만 다른 단면들에 복사합니다. 이름·단중·ID·Block 데이터는 손대지 않습니다.

작업 순서

  1. 기준이 될 단면 하나를 고릅니다.
  2. 값을 받을 단면들을 고릅니다 — 여러 개를 한꺼번에.
  3. 상자 안 다섯 칸이 그대로 넘어갑니다 — Start · Length · 간격 · 수량 · 대칭, 위·아래 두 줄이니 열두 칸입니다.

알아 둘 것

  • 멀리언과 트랜섬 사이에도 값이 그대로 갑니다.화면에 보이는 두 값(위/아래)으로 옮기므로 어느 쪽으로 쓰이든 뜻이 유지됩니다.
  • 상자 밖은 건드리지 않습니다 — Material·Profile·Fab·Group·Alloy ID 는 대상 것 그대로.
  • 단면 data 가 없던 대상에는 새로 만들어 넣습니다 — 이름이 지워지지 않습니다.
  • CDP 는 단면 data 를 통째로 덮습니다. 추가 길이만 맞추려면 CDPlg 입니다.
한 마디 추가 길이 하나 맞추자고 단면 data 를 통째로 덮던 것이 없어졌습니다. 바꾸고 싶은 것만 바꿉니다.

도움말 검색 — 목차를 훑지 않는다 신규

RcwHelp

도움말 왼쪽 위에 검색창이 생겼습니다. 명령 이름뿐 아니라 본문까지 찾습니다.

찾아 주는 것

  • 명령 이름 — FDwg, SSAngle 처럼.
  • 본문 글자 — "각도", "허용오차" 처럼 설명 안의 말로도 찾습니다.
  • 결과마다 어느 폴더의 무슨 명령인지 함께 보여 줍니다.

알아 둘 것

  • 한국어·영어 각각 찾습니다 — 지금 보고 있는 언어의 문서에서.
  • 도움말을 새로 받으면 검색 내용도 함께 갱신됩니다.
한 마디 "그 옵션 이름이 뭐였더라" 를 목차에서 찾지 않아도 됩니다. 기억나는 낱말 하나면 그 페이지로 갑니다.

정리

세 문장으로

하나

한 번 정해 두면 다시 정하지 않습니다.
가공도 방식(FDstyle) · 라벨 방식(FabList) · 옵션 기본값(System Default) 이 모두 저장되고 다음부터 자동으로 적용됩니다.

둘

확인이 빨라집니다.
선 하나를 클릭하면 무슨 부재인지 나오고(Properties), 여러 단면을 한 표에서 비교하고(Dtable), 입면에서 홀 깊이까지 보입니다(FDwg).
