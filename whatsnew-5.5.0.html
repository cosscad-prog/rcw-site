What's New 5.5.0

가장 큰 변화는 판재(Sheet) 명령입니다. 유리 자리에 들어가는 접힌 금속 판재를 만들고 가공도까지 냅니다. 함께 유리 · 백패널, 블록(RBB · SSP), 단면 패널의 여러 문제를 고쳤습니다.

유리 · 백패널

중심선의 어느 쪽인지로 고릅니다 · 선이 둘이면 알립니다

가공도

BpFd · GsFd

예전 버전으로 만든 판 · 유리도 그리고, 멈추면 이유를 알립니다

블록

RBB 가 등록을 망가뜨리던 것 · 평면 밖 블록을 SSP 가 고칩니다

먼저 보실 것 판재 명령은 Core 와 Standard 모두에 들어 있습니다. 판재가 붙는 단면에는 S_Center1 레이어의 선이 필요합니다 — 도움말 09 Sheet Modeling → Making Sheet Section 에 그림과 함께 있습니다.
01

판재 만들기 새 명령

ShMD · Sht

유리 자리에 들어가는 접힌 금속 판재를 만듭니다. 단면에 그려 둔 S_Center1 선이 판재의 가장자리 자리를 정합니다.

순서

준비단면 group 에 S_Center1 선 → SSP → WVector
1. ShMD유닛을 고르면 판재가 들어갈 칸에만 칸 면이 생깁니다
2. Sht칸 면을 고르고 창에서 모양을 정하면 판재와 붙는 프로파일이 만들어집니다

Sht 창에서 정하는 것

  • 두께(1.2 · 2 · 3 · 4 …)와 가장자리 모양 — 평판 · 접힘 · 안쪽 되접기 · 바깥쪽 되접기.
  • 변마다의 깊이(위 · 아래 · 왼쪽 · 오른쪽)와 되접는 길이.
  • 붙이는 프로파일 — 전체 길이 45° 맞댐 · 전체 길이 직각 · 조각(여유 · 간격 · 개수).
  • 스크류 구멍 — 지름과 개수 · 간격 · 끝 여유.
한 마디 창은 열어 둔 채 Rhino 에서 치수를 잴 수 있습니다. OK 를 누르면 접고, 닫으면 칸 면이 그대로 돌아옵니다.
02

번호 · 목록 · 가공도 새 명령

ShNo · ShList · ShTable · ShFd

유리 · 백패널과 같은 흐름입니다 — 번호 → 목록 → 가공 표 → 가공도.

명령

ShNo같은 판재에 같은 번호를 매깁니다
ShList수량 목록 — 폭 · 높이 · 면적 · 두께 · 가장자리 · 깊이 · 구멍, 붙인 프로파일은 이름 · 길이별로. Excel 로도 냅니다
ShTable두께마다 한 줄, 번호마다 한 칸에 판재를 정면으로 놓습니다
ShFd표의 판재를 골라 가공도를 그립니다

ShFd 가 그리는 것

  • 정면도 — 판의 크기, 붙인 프로파일과 구멍의 연속 치수. 기운 변은 실제 길이로.
  • 단면(가운데 높이 · 가운데 폭)과 ISO.
  • 전개도 — 모델을 그대로 펴서 그립니다. 접는 선은 따로 표시합니다.
  • 붙인 프로파일 표 — 이름 · 가공 모양(절단 각도) · 길이 · 수량.
알아 두실 것 전개도는 굽힘 여유를 넣지 않은 치수입니다. 프로파일의 길이는 가장 긴 변 기준입니다(45° 절단 포함).
03

유리 · 백패널이 선을 고르는 방식 바뀜

GS1~ · BP1~BP5

단면의 유리선(G_Center1) · 백패널 선(BP_Center1)이 중심선의 어느 쪽에 있는지를 보고, 칸이 있는 쪽의 선을 씁니다.

달라진 것

  • 아주 좁은 칸(약 110mm 미만)에서 선이 있는데도 못 찾던 것을 고쳤습니다.
  • 칸 쪽에 선이 둘 이상이면 중심선에 가장 가까운 것을 쓰고, 선의 수와 거리를 명령창에 알립니다.
  • 칸 쪽에 선이 없으면 어느 선(레이어)이 없는지 알리고, 만들다 만 면을 남기지 않습니다.

함께 고친 것

  • 멀리언 이음이 칸 안에 있을 때(위아래 유닛이 만나는 자리 등) 유리 · 백패널이 빠지던 것.
  • 도움말 08 BackPanel Modeling → Making BackPanel Section — BP_Center1 선이 정하는 것과 BpOpt 가 정하는 것을 그림으로.
주의 한쪽에 선을 둘 그려 둔 단면은 전과 다른 선을 씁니다(전에는 알림 없이 먼 쪽). 알림이 뜨면 단면을 확인해 주십시오.
04

BpFd · GsFd 고침

BpFd · GsFd

예전 버전으로 만든 백패널에 BpFd 를 돌리면 정면 선만 그리고 아무 말 없이 끝났습니다.

이제

  • 판의 면에서 꼭짓점을 구해 치수 · 단면 · 전개도까지 그립니다. 그렇게 했다고 명령창에 알립니다.
  • GsFd(유리 가공도)도 같습니다.

멈추면 알립니다

  • 한 장을 그리다 멈추면 어느 판에서 왜 멈췄는지 알리고 다음 장으로 넘어갑니다.
  • 그 판의 3D 복사본은 지우지 않으므로 다시 돌릴 수 있습니다.
  • GsFd 진행 표시의 유리 번호가 늘 0 이던 것을 고쳤습니다.
한 마디 지금 버전으로 만든 판 · 유리는 전과 똑같이 그려집니다.
05

블록 다시 잇기와 단면 등록 고침

RBB · SSP · BBC4 · BC12 · DBB · PPlist

RBB 가 블록 등록을 고치는 것이 아니라 망가뜨리고 있었습니다. 등록 값이 뒤바뀌어 저장되고, 합성 · FabG · 밀링 값이 지워졌습니다.

RBB

  • 이제 블록 등록만 고치고 나머지 값은 그대로 둡니다.
  • 블록 하나에 슬롯 하나만 잇고, 같은 거리의 블록은 기준점으로 가립니다.
  • 블록 복사 · 삭제 명령(BC12 · DBB · BBC4 등)과 PPlist 도 단면의 다른 값을 지우지 않습니다.
  • 블록 없는 새 단면에 BBC4 로 값만 복사한 뒤에는 SSP · RBB 가 블록을 다시 잇거나 못 찾은 슬롯을 알립니다.

SSP

  • 예전 RBB 가 뒤바꿔 놓은 단면을 경고로 알립니다. Pname · PPI 는 그런 단면도 바로잡아 읽습니다.
  • 삽입점이 단면 평면 밖에 있는 블록을 평면 위로 옮기고 '평면 밖 → 고침' 으로 알립니다.
하실 일 전에 RBB 를 돌린 단면이 있다면, SSP 가 경고할 때 RBB 를 한 번 다시 돌려 주십시오. 그것으로 고쳐집니다.
06

단면 패널과 표 고침

Pname · PPI · ComP · FabTable · Dtable

단면을 여는 길을 하나로 맞췄습니다 — PPI, Profile Manager 의 그림 클릭, RCW Section 탭의 More details 가 Pname 과 똑같이 엽니다.

단면 · 합성

  • 그림을 누른 뒤 단면을 클릭해도 골라지지 않던 것을 고쳤습니다.
  • ComP 가 ComP_이름 group 을 만듭니다 — 합성을 통째로 고르고 복사할 수 있습니다.
  • 복사한 합성은 Pname 으로 여는 순간 새 합성으로 등록되고, 미리보기에 원본이 섞이지 않습니다.
  • RCW Section 탭의 Name · Description · Additional Length 칸이 저장됩니다(칸을 벗어나거나 Enter).

표

  • FabTable — 칸 높이를 폭의 0.8배로, 긴 Profile Name 은 글자를 줄여 칸 안에.
  • Dtable — Profile Name 으로 정렬해도 합성마다 자기 구성원이 바로 아래에 모입니다.
한 마디 도움말의 판재는 09 Sheet Modeling, Xtract Modeling 은 13 번으로 옮겼습니다.
