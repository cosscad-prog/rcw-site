RCW V5 · CUSTOMER QUICK START

설치 및 라이선스 활성화 안내

Core · Standard · Trial | 설치 전 확인부터 도움말 실행까지

먼저 확인: 구매한 에디션(Core 또는 Standard), Rhino 버전(7 또는 8), 언어(한국어 또는 English)에 맞는 설치 파일 하나를 선택하십시오. 설치 중에는 Rhino를 종료하십시오. 설치가 끝나면 이 안내서가 자동으로 열립니다.

1. 설치

설치 중 경고가 나타날 수 있습니다 — 정상입니다.
“Windows의 PC 보호” 파란 창 → 추가 정보 를 누른 뒤 실행
백신 검사 창 → 검사가 끝난 뒤 실행을 허용하는 항목 선택 (버튼 이름은 제품마다 다릅니다: 실행 허용 / 예외 처리 후 실행 / 신뢰하는 프로그램으로 등록)
설치 파일에 코드 서명 인증서가 아직 적용되지 않아 나타나는 안내이며, 파일에 문제가 있다는 뜻은 아닙니다. 그래도 설치되지 않으면 사용 중인 백신 이름과 함께 연락 주십시오.
  1. 받은 RCW V5 설치 파일(.exe)을 실행합니다.
  2. Windows에서 관리자 권한을 요청하면 승인하고 설치를 마칩니다.
  3. Rhino를 실행합니다. Trial은 이 첫 정상 실행일부터 90일 동안 사용할 수 있습니다.
Core기본 명령 범위의 영구 상용 라이선스 제품
Standard전체 일반 명령 범위의 영구 상용 라이선스 제품
TrialCore 범위의 90일 평가판. 별도 라이선스 파일이 필요하지 않습니다.

2. Core / Standard 라이선스 활성화

라이선스는 고객 페이지에서 직접 받으십시오. 담당자에게 연락하실 필요가 없습니다.

  1. 라이선스 파일이 없는 상태로 Rhino를 처음 실행하면 머신코드가 명령창에 자동 표시되고 클립보드에 복사됩니다. 필요하면 RCWMachineCode를 직접 실행할 수도 있습니다.
  2. 고객 페이지 rcw-site.vercel.app/customer 에 접속해 안내받으신 라이선스 코드(V5KO- 로 시작)를 입력합니다.
  3. 화면 아래 라이선스 칸의 머신코드 입력란에 1번의 코드를 붙여넣고 [라이선스 요청] 을 누릅니다.
  4. 보통 1분 안에 같은 자리에 [라이선스 내려받기] 버튼이 나타납니다. 화면은 저절로 바뀌므로 새로고침하지 않으셔도 됩니다.
  5. 내려받은 라이선스 파일(.lic)을 안전한 위치에 저장합니다.
  6. Rhino 명령창에 RCWLicense를 입력하고 그 .lic 파일을 선택합니다.
  7. 가져오기 성공 메시지를 확인한 뒤 Rhino를 다시 시작합니다.
코드가 두 가지입니다. 헷갈리지 마십시오.
라이선스 코드 — V5KO-... · 안내 메일로 받으신 값. 고객 페이지에 로그인할 때 씁니다.
머신코드 — RCW5-CO-... 또는 RCW5-ST-... · Rhino가 알려주는 값. 로그인한 뒤 라이선스를 요청할 때 씁니다.
중요: 라이선스 파일을 Program Files 폴더에 직접 복사하지 마십시오. 반드시 RCWLicense 명령으로 가져와야 합니다. 라이선스는 PC 한 대당 하나씩 발급됩니다. PC 교체 또는 머신코드 변경 시에는 새 라이선스 발급이 필요하며, 이 경우에는 고객 페이지에서 요청하신 뒤 담당자 확인을 거칩니다.

3. Trial 사용

  • Trial은 Core 기능 범위로 동작합니다.
  • 기간은 최초 정상 실행일부터 90일이며, 같은 Windows 사용자 계정에서 재설치해도 최초 시작일을 유지합니다.
  • 기간 종료 후에는 Core 또는 Standard를 구매하고 위 활성화 절차를 진행하십시오.

4. 도움말과 지원

  • Rhino 명령창에서 RcwHelp를 실행하면 설치된 로컬 도움말이 열립니다.
  • 한국어/영문 설치본을 변경하는 경우에는 같은 .lic 파일을 RCWLicense로 다시 가져오십시오.
  • 지원 요청 시 설치 파일명, Rhino 버전, Windows 사용자 이름, 오류 메시지 또는 화면 캡처를 함께 보내십시오.
