RCW V5 · CUSTOMER QUICK START

설치 및 라이선스 활성화 안내

Core · Standard · Trial | 설치 전 확인부터 도움말 실행까지

먼저 확인: 구매한 에디션(Core 또는 Standard), Rhino 버전(7 또는 8), 언어(한국어 또는 English)에 맞는 설치 파일 하나를 선택하십시오. 설치 중에는 Rhino를 종료하십시오. 설치가 끝나면 이 안내서가 자동으로 열립니다.

1. 설치

  1. 받은 RCW V5 설치 파일(.exe)을 실행합니다.
  2. Windows에서 관리자 권한을 요청하면 승인하고 설치를 마칩니다.
  3. Rhino를 실행합니다. Trial은 이 첫 정상 실행일부터 90일 동안 사용할 수 있습니다.
Core기본 명령 범위의 영구 상용 라이선스 제품
Standard전체 일반 명령 범위의 영구 상용 라이선스 제품
TrialCore 범위의 90일 평가판. 별도 라이선스 파일이 필요하지 않습니다.

2. Core / Standard 라이선스 활성화

  1. 라이선스 파일이 없는 상태로 Rhino를 처음 실행하면 기기 코드가 명령창에 자동 표시되고 이 안내서가 열립니다. 필요하면 RCWMachineCode를 직접 실행할 수도 있습니다.
  2. 표시되고 클립보드에 복사된 기기 코드를 판매처 또는 지원 담당자에게 보냅니다.
  3. 받은 개별 라이선스 파일(.lic)을 안전한 위치에 저장합니다.
  4. Rhino 명령창에 RCWLicense를 입력하고 받은 .lic 파일을 선택합니다.
  5. 가져오기 성공 메시지를 확인한 뒤 Rhino를 다시 시작합니다.

중요: 라이선스 파일을 Program Files 폴더에 직접 복사하지 마십시오. 반드시 RCWLicense 명령으로 가져와야 합니다. PC 교체 또는 기기 코드 변경 시에는 새 라이선스 발급이 필요합니다.

3. Trial 사용

  • Trial은 Core 기능 범위로 동작합니다.
  • 기간은 최초 정상 실행일부터 90일이며, 같은 Windows 사용자 계정에서 재설치해도 최초 시작일을 유지합니다.
  • 기간 종료 후에는 Core 또는 Standard를 구매하고 위 활성화 절차를 진행하십시오.

4. 도움말과 지원

  • Rhino 명령창에서 RcwHelp를 실행하면 설치된 로컬 도움말이 열립니다.
  • 한국어/영문 설치본을 변경하는 경우에는 같은 .lic 파일을 RCWLicense로 다시 가져오십시오.
  • 지원 요청 시 설치 파일명, Rhino 버전, Windows 사용자 이름, 오류 메시지 또는 화면 캡처를 함께 보내십시오.
