01

설치 파일이 하나로 새 방식

RCW5.exe

전에는 에디션과 Rhino 버전마다 설치 파일이 따로 있어 8가지 중 맞는 것을 골라 받으셔야 했습니다. 이제 RCW5.exe 하나를 받고, 설치 화면에서 고르십시오.

설치 화면 순서

1. RhinoRhino 7 또는 Rhino 8. 이 PC 에 없는 버전은 고를 수 없습니다
2. 에디션정식판 — 고객 코드를 넣으면 에디션이 정해집니다
평가판 — Core · Standard 중에서 고릅니다
3. 설치Rhino 가 켜져 있으면 닫아도 되는지 묻고, 끝나면 다시 엽니다

알아 두실 것

  • RCW 는 한 번에 하나의 Rhino 에만 설치됩니다.
  • 고객 코드의 하이픈 · 공백 · 소문자는 상관없습니다. 머신코드(RCW5-)를 넣으시면 알려 드립니다.
  • 인터넷이 없으면 이 PC 의 라이선스에 적힌 에디션으로 설치합니다. 평가판은 인터넷 없이도 됩니다.
  • 고객 코드를 모르시면 Beimptech@gmail.com 으로 연락 주십시오.
한 마디 설치 파일은 어느 PC 에서나 같은 파일입니다. 무엇을 설치할지는 받을 때가 아니라 설치할 때 정합니다.
02

쓰던 RCW 에서 넘어오기 자동 정리

RCWUpdate

5.3.2 를 쓰고 계시면 새 버전 알림에서 [예] 를 누르십시오. 새 설치 파일을 받아 실행하고, 쓰던 설정이 채워진 채로 설치 화면이 열립니다.

알림에서 올리기

  • 설치 화면에 쓰던 Rhino 버전과 에디션이 미리 골라져 있습니다.
  • 정식판은 저장된 고객 코드가 채워져 있어 [다음] 만 누르시면 됩니다.
  • 고객 코드 칸이 비어 있으면 안내 메일의 코드를 한 번 넣어 주십시오.
  • 알림을 끄셨다면 RCWUpdate 명령으로 직접 확인하실 수 있습니다.

옛 설치는 정리됩니다

  • 전에 설치한 RCW 는 새 설치가 넘겨받아 지웁니다. 제어판에는 RCW5 하나만 남습니다.
  • Rhino 7 과 8 모두에 깔려 있었다면, 고르지 않은 쪽의 RCW 는 제거됩니다.
  • 라이선스 · 고객 코드 · 설정은 그대로입니다. 제어판에서 RCW5 를 지워도 남습니다.
한 마디 다시 설치하셔도 라이선스를 새로 받으실 필요가 없습니다. 같은 PC 라면 설치 전과 같은 상태로 돌아옵니다.
03

RCW 가 보내는 정보 알려 드립니다

이 버전부터 RCW 는 설치와 사용 현황을 파악하기 위해 아래 정보만 보냅니다. 도면이나 파일의 내용은 보내지 않습니다.

하루 한 번
RCW 를 켤 때		무작위로 만든 설치 번호 · RCW 버전 · 에디션 · Rhino 버전 · 화면 언어

한 마디 새 버전이 있는지 확인하는 일은 전처럼 하루 한 번이고, Rhino 가 다 켜진 뒤에 뒤에서 돕니다.
04

유리 종류와 유리 목록 새 두께

GsOpt · GsList

GsOpt 에 PVB 0.76 접합유리가 들어왔고, 유리 종류를 만들고 고치는 창을 쓰기 편하게 바꿨습니다. GsList 는 NBlock 으로 만든 unit 의 유리도 셉니다.

GsOpt

  • 1st · 3rd Pane 에 8.76 (4+0.76+4) · 10.76 (5+0.76+5) · 12.76 (6+0.76+6). 가공도에서 판 두 장으로 그립니다.
  • 강도(Hardness)를 고르지 않아도 Description 이 만들어집니다. 고르면 /CL 등이 붙습니다.
  • 목록에서 줄을 고르고 Del 키로 지웁니다(여러 줄 한 번에). 버튼은 SAVE 가운데 · Add List 오른쪽.
  • 맨 아래 안내 글이 잘리지 않습니다. 3rd Pane 을 다시 열면 2nd Pane 값이 들어가던 것 · 삼복층 가공도의 가운데 유리가 6mm 뒤에 그려지던 것을 고쳤습니다.

GsList — NBlock 도

  • 유리 group 을 포함해 만든 NBlock 을 골라도 유리 목록이 나옵니다. 수량은 배치한 NBlock 수만큼 곱해집니다.
  • 유리 solid 와 NBlock 을 함께 고르면 한 표로 합칩니다 — Molist 와 같습니다.
  • NBlock 에 담긴 유리 정보는 NBlock 을 만든 때의 것입니다. GsNo 뒤에 NBlock 을 만드시고, 유리를 바꿨으면 NBlock 을 다시 실행하십시오.
주의 NBlock 은 원본을 지우지 않습니다. 원본 유리와 그것으로 만든 NBlock 을 함께 고르면 두 번 셉니다.
05

FDstyle 은 필요할 때 바뀜

FDwg · DDOpt · FDstyle

FDwg 를 실행해도 FDstyle 창이 저절로 뜨지 않습니다. 가공도 설정을 기록할 때만 여십시오.

여는 곳

  • DDOpt 패널 맨 왼쪽 위의 [FDstyle] 버튼 — 옛 Apply File Data 체크박스 자리입니다.
  • 또는 FDstyle 명령.

재생 · 기록 버튼

둘 다 꺼짐
(처음)		DDOpt 패널값으로 그립니다
[재생모드 시작]
파랑		기록된 설정으로 그립니다 — 옛 Apply File Data 체크와 같습니다
[기록모드 시작]
빨강		패널값으로 그리면서 기록합니다. 다시 누르면 끝나고, 손으로 옮긴 표·지시선까지 저장합니다
한 마디 버튼마다 켜고 끕니다. 켜진 버튼을 다시 누르면 꺼지고, 다른 쪽을 누르면 넘어갑니다.
06

Dtable 바뀜

Dtable

프로파일이 어느 단면 group 의 것인지 보이고, 창을 열어 둔 채 Rhino 를 계속 쓸 수 있습니다.

맨 앞 Section 칸

  • 단면 group 이름(MC1 · TC2 …) — 이름이 같은 프로파일도 어느 group 의 것인지 가릅니다.
  • 머리글을 누르면 Section 순으로 정렬(Section 이 없는 줄은 맨 뒤).

열어 둔 채 작업

  • Pname 처럼 창 뒤의 Rhino 를 고르고 명령을 쓸 수 있습니다.
  • Save All 은 표에서 고친 칸만 저장 — 그동안 Pname 등으로 고친 값은 되돌리지 않습니다.
한 마디 표는 연 때의 값을 보여 줍니다. 밖에서 고친 값을 보려면 Dtable 을 다시 여십시오.
