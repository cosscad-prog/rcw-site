AutoCAD · BricsCAD 용 RCW 유틸리티.

오랫동안 AutoCAD · BricsCAD 안에서 쓰이던 커튼월 유틸리티입니다 — 치수, NC 데이터, 컷팅 리스트, 레이어 · 블록 도구. 기존 국내 사용자에게 무상으로 제공하며 인증 코드가 필요 없습니다.

i

이것은 Rhino 용 RCW V5 와 별개입니다. 설치 프로그램이 아니라 CAD 안에서 NETLOAD 로 불러 쓰는 플러그인입니다. Rhino 용 RCW 를 함께 쓰신다면 같은 설정 폴더를 씁니다.

!

받으신 뒤 가장 먼저 — 차단 해제
인터넷에서 받은 파일에는 Windows 가 “다른 컴퓨터에서 온 파일” 표시를 붙입니다. 이 표시가 남아 있으면 플러그인을 불러오지 못합니다.
ZIP 우클릭 → 속성 → 아래쪽 [차단 해제] 체크 → 확인 → 그 다음에 압축 풀기. 설치가 안 되는 경우 대부분이 이것입니다.

쓰시는 CAD 에 맞는 파일 하나만 받으시면 됩니다

각 ZIP 에는 DLL 하나, Data 폴더, 그리고 읽어보기.txt 가 들어 있습니다 — 차단 해제, 설치, 고치는 파일이 어디 있는지(RCWFolder), 잘 안 될 때까지 적혀 있습니다.

설치

  1. 위 안내대로 차단 해제한 뒤, 계속 둘 폴더에 압축을 푸세요.
  2. CAD 를 실행하고 NETLOAD 를 친 뒤, 그 폴더의 DLL 을 고르세요.
  3. AutoCAD 는 보안 경고가 뜰 수 있습니다 — [Load] 를 누르세요.
  4. Acmd 를 치면 버전이 나옵니다. 나오면 성공입니다.

BricsCAD 는 Areg 를 한 번 실행해 두시면 다음부터 자동으로 불러옵니다(Aunreg 로 해제). AutoCAD 는 지금은 켤 때마다 NETLOAD 가 필요합니다.

내가 고치는 파일

명령창에 RCWFolder 를 치면 고쳐서 쓰는 파일이 모여 있는 폴더가 열리고, 각 파일을 지금 어디서 읽고 있는지도 함께 나옵니다. Rhino 용 RCW 에도 같은 이름의 명령이 있고 같은 폴더를 엽니다 — 한 번만 고치면 양쪽이 같은 값을 씁니다.
