RCW for Rhino · 5.4.6 에서 달라진 것

What's New 5.4.6

메인보드 같은 PC 부품을 바꾸면 평가판이 막히던 문제를 고쳤습니다. 백패널에는 뒤쪽에만 판이 있는 Type F 를 더했습니다.

먼저 보실 것 부품을 바꾼 뒤 평가판이 "다른 컴퓨터에서 생성된 라이선스" 로 막혔다면, 5.4.6 을 설치하면 남은 기간으로 다시 열립니다. 시작일은 바뀌지 않습니다.

01 평가판 고침

Core 평가판 · Standard 평가판

  • 평가 기간 중에 메인보드 같은 부품을 바꾸어도 평가판이 막히지 않습니다. 시작일과 남은 기간은 그대로 이어지고, 부품이 바뀐 것은 명령창에 한 줄로 알립니다.
  • 이제 평가판이 막히는 것은 평가 기간이 끝났을 때와 PC 날짜가 평가 시작일보다 하루 넘게 이를 때뿐입니다.
  • PC 날짜가 시작일보다 이르면, 시작일을 보여 주며 Windows 의 날짜와 시간을 맞추라고 알립니다.

02 백패널 Type F 새 종류

BpOpt · 백패널 명령

  • 뒤쪽(유리 반대쪽)에만 판이 있고 벽이 유리 쪽으로 서는 종류입니다. Type A 를 앞뒤로 뒤집은 꼴입니다.
  • BpOpt 의 Back Panel 탭에서 Type A 바로 아래 줄에서 고릅니다.
  • Panel 은 벽 깊이(판 뒷면에서 벽 앞 끝까지), Insulation 은 백패널 앞면에서 판 뒷면까지(판 포함)입니다.
  • Inside length 는 Type A 와 같이 0 이면 접기만 합니다. 단열재도 Type A 와 같은 식으로 들어갑니다.
  • Type F 에는 아직 나사 구멍(Screw Holes)이 없습니다.
