설치 파일을 실행하면 Windows 경고가 표시됩니다

RCW V5는 현재 트라이얼 배포 단계로, 설치 파일에 코드 서명 인증서가 아직 적용되지 않았습니다. Windows SmartScreen은 서명이 없는 설치 파일에 대해 내용과 무관하게 경고를 표시하므로, 파일 자체에 문제가 있다는 뜻은 아닙니다. 정식 출시 시에는 인증서를 적용할 예정입니다.

“Windows의 PC 보호” 창이 나타나면 추가 정보 를 누른 뒤 실행 을 선택하시면 설치가 진행됩니다.

파일을 직접 확인하고 싶으시면 릴리스 페이지에 공개된 SHA-256 값과 대조해 보실 수 있습니다. PowerShell에서 Get-FileHash 파일이름.exe 를 실행하면 됩니다.
