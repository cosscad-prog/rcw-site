모델이 곧
서류입니다.

정확한 유닛이 만들어지면 RCW가 그것을 읽습니다. 프로파일마다 이름과 번호가 붙고, 같은 원본에서 가공도·표·리스트·기계 데이터가 작성됩니다. 모델은 하나, 기준도 하나입니다.

산출물 목록 보기 모델링으로 돌아가기
입력이 아니라 생성
이름 + 번호모든 프로파일에 식별자 — FabNo · GsNo
도면가공도 · 입면도 · 유닛 2D
물량BOM · 컷팅리스트 · 바리스트
기계 데이터NC3~NC6 홀·가공 데이터

산출물

공장과 현장이 받게 되는 것

모두 모델에서 읽어낸 것이므로 서로 어긋나지 않습니다. 모델을 고치면 변경이 전파되며, 여러 파일을 쫓아다니며 맞출 필요가 없습니다.

FDwg · FDDS

가공도

프로파일마다 입면·단면·홀 위치·가공 표기를 담은 도면을 자사 양식에 맞춰 작성합니다.

FDstyle

가공도 기록·재생

한 장의 구성을 기록해 나머지에 재생함으로써 도면 세트 전체의 형식을 일정하게 유지합니다.

FabTable

부재 표

모델에서 생성되는 프로파일별 제작 표. 길이·절단·가공 정보가 한 장에 정리됩니다.

FabBomTable

부속자재 BOM

하드웨어·앵커·브라켓·볼트·스크류·가스켓·폴리아미드를 모델에 실제로 들어간 대로 집계합니다.

U2D · UF2D · F2d · S2d

2D 입면·단면

3D 유닛에서 그대로 뽑아낸 조립 입면도·유닛 정면도·단면도입니다.

4:3 이미지 자리 — 컷팅리스트·물량 표.
Cuttinglist · Molist · PMolist

컷팅리스트·물량

프로파일별 물량과 함께 최적화된 컷팅·바 리스트를 공장에 바로 넘길 수 있는 형태로 만듭니다.

4:3 이미지 자리 — NC 홀·가공 좌표 테이블.
NC3 ~ NC6

NC 가공 데이터

절단·가공 센터로 넘길 홀 및 가공 좌표 데이터를 내보냅니다.

16:10 이미지 자리 — Fablist 라벨: 입면번호형·텍스트박스형.
Fablist · TextBoxLeaderMove

제작 리스트·라벨

입면 번호와 연결된 제작 리스트. 라벨을 옮길 수 있어 도면 가독성이 유지됩니다.

16:10 이미지 자리 — 브라우저 웹뷰어 / BIM 데이터 내보내기.
WebV · ToWebFile · FLdata

웹뷰어·BIM 데이터

유닛을 브라우저로 공유해 검토하고, BIM 워크플로용 데이터를 내보냅니다. (BIM 데이터는 Standard)

한 장에 전부

스스로 완성되는 가공도 한 장

한 장의 FDwg·FDDS에는 입면, 단면, 홀 치수, 노치·장공 표기, NC 콜아웃, BOM, 그리고 타이틀 블록이 함께 들어갑니다. 각 요소는 손으로 그리는 것이 아니라 모델 데이터에서 배치됩니다. 이후 FDstyle이 이 구성을 나머지 프로파일에 그대로 재생합니다.

  • 한 뷰에 입면 + 단면 + 홀 치수
  • 노치·장공·NC 표기 자동 배치
  • 자사 타이틀 블록·양식 그대로
  • FDstyle로 프로젝트 전체에 재생
4:3 · ★★ 가장 임팩트 큰 이미지 — 완성된 가공도 풀샷(입면+단면+홀+NC+BOM+양식). 이 한 장이 여러 GIF보다 강력합니다.

정확도

실수가 숨을 자리를 줄입니다

수작업 산출물은 서류끼리 어긋나는 지점에서 무너집니다. 도면과 맞지 않는 컷팅 길이, 아무도 세지 않은 부속자재 같은 것들입니다. 모든 것이 하나의 모델에서 파생되면 이런 종류의 오류는 대부분 사라집니다.

CHECK 프로파일 데이터 검증

CheckPfData가 데이터가 없거나 어긋난 프로파일을 도면 작성 전에 잡아냅니다.

SEE 눈으로 확인

조립 상태를 상상하는 것이 아니라 실제로 보고 있습니다. 잘못된 부분이 눈에 보입니다.

SYNC 하나의 원본, 여러 서류

도면·표·리스트·NC가 모두 같은 모델에서 나오므로 조용히 어긋나는 일이 없습니다.

효과

실무에서 무엇이 달라지는가

01

시간이 설계로 돌아옵니다

도면을 그리고 부품을 세던 시간이 디테일 검토와 조정, 정말 판단이 필요한 일에 다시 쓰입니다.

02

비용은 만회가 아니라 예방

화면에서 발견한 오류는 몇 분이면 끝납니다. 같은 오류를 현장에서 발견하면 인력 대기·장비 유휴·일정 지연이 따라옵니다.

03

예측 가능한 조립 단위

유닛이 명시적으로 모델링되므로 현장에 무엇이 어떤 단위로 도착할지 미리 알 수 있습니다. 단위가 명확할수록 시공은 빠르고 안전해집니다.
