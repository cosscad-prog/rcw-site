Rhino 7 · 8 커튼월 자동화

단면을 그리면,
가공도가 나옵니다.

RCW(Rhino Curtainwall Plugin)는 커튼월 설계·제작을 위한 라이노 플러그인입니다. 와이어프레임과 단면만으로 3D 모델을 만들고, 그 모델을 컴퓨터가 읽어 가공도·부품리스트·컷팅리스트·NC 데이터를 자동으로 만들어 냅니다.

① 모델링이 얼마나 쉬운가 ② 무엇을 만드는가

Core · Standard 영구 라이선스 · 90일 트라이얼 · Rhino 7·8

입력은 단 2가지
자동 도면 · BOM · NC

왜 중요한가

부품 하나가 틀리면 현장 전체가 멈춥니다.

커튼월 한 세트는 서로 맞물린 수천 개의 부품입니다. 지금도 대부분은 머릿속으로 3차원을 그려가며 손으로 도면을 그리고 물량을 셉니다. 느리고, 단 한 번의 실수가 인력 대기·장비 유휴·일정 지연으로 이어집니다.

01

돌아오지 않는 시간

실수하면 안 되기에 한 장 한 장 신중히 그리고 두 번 확인합니다. 신중함은 필요하지만, 수작업은 필요하지 않습니다.

02

머릿속에서 생기는 오류

2D를 그리며 3D 조립을 상상해야 하는 지점에서 대부분의 실수가 시작됩니다. 모델을 눈으로 보면 추측이 사라집니다.

03

부품 하나에 수천 달러

잘못된 부재가 현장에 도착하면 인력은 대기하고 장비는 놀며 일정은 밀립니다. 그 전부가 실비용입니다.

RCW의 구성

단면 → 모델링 → 산출물. 하나로 이어진 흐름.

RCW는 서로 무관한 도구 모음이 아닙니다. 하나의 파이프라인입니다. 평소 그리던 입력을 넣으면 모델을 만들고, 그 모델을 다시 읽어 공장과 현장에 필요한 모든 것을 뽑아냅니다.

Input · 01

단면 · 와이어프레임

멀리언·트랜섬 라인과, 평소 2D로 그리던 프로파일 단면. 새로 배울 것이 없습니다.

상세 페이지 1

3D 모델링은 더 이상 어렵지 않습니다

실무자는 3D 모델링의 비용을 압니다. RCW는 그 공포를 없앱니다. 와이어프레임을 넣으면 유닛이 나오고, 틀렸다면 선 하나만 고쳐 다시 만들면 됩니다.

모델링 과정 보기
상세 페이지 2

공장과 현장이 요구하는 모든 것

홀·NC가 포함된 가공도, 부속자재 BOM, 컷팅·바 리스트, 조립 입면도, 유닛 2D, 웹뷰어까지 모두 같은 모델에서 나옵니다.

버전 비교

어떤 버전이 필요하신가요?

Core는 프레임과 유리의 전체 흐름 — 모델링·번호·리스트·가공도·2D·NC — 을 모두 담습니다. Standard는 여기에 창호·그릴·백패널·추출·BIM 데이터와 AutoCAD 유틸리티를 더합니다. Professional에서는 트랜섬 곡선 모델링이 추가될 예정입니다.
