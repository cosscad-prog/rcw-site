왜 RCW인가

도입하면 무엇이 달라지나

반복적인 도면·물량 작업을 자동화해 인력과 시간을 절감하고, 사람이 만들던 오류를 구조적으로 제거합니다. 설계 변경이 가공 데이터까지 일관되게 반영됩니다.

⚡

제작 준비 시간 단축

모델 한 번으로 입면·단면·치수·홀 정보가 담긴 제작 가공도를 자동 생성. 수작업 작도 대비 대폭 단축됩니다.

✓

도면 오류 감소

치수·홀·물량을 모델에서 직접 산출하므로 옮겨 적다 생기는 실수가 사라지고 도면 일관성이 유지됩니다.

🔗

설계–가공 데이터 연결

NC 홀 좌표, 컷팅·물량 리스트, BIM 데이터, 웹뷰어까지 같은 모델에서 추출해 후공정으로 끊김 없이 전달합니다.

🔄

변경에 강함

설계가 바뀌어도 재모델링 후 가공도를 다시 생성하면 저장된 스타일이 그대로 재현됩니다. 변경분만 반영됩니다.

🧩

기존 워크플로우와 호환

Rhino 결과를 AutoCAD/BricsCAD 작업과 연계. 현장에서 쓰던 CAD 환경을 그대로 활용합니다.

📈

반복 품목에 강함

유닛·멀리언·트랜섬·유리·벤트·그릴·백패널을 규칙으로 모델링해 물량이 많은 프로젝트일수록 효과가 커집니다.

핵심 기능

설계자·가공 담당자를 위한 실무 기능

실제 제작 현장의 흐름에 맞춰 설계된 기능들입니다. 각 기능을 “문제 → 해결”로 보여줍니다.

  • 설계 변경 시 일괄 반영, 오류 시 RollBack
  • 각 구성요소마다 번호·리스트·테이블 자동 연동

제작 가공도 자동화

문제 — 같은 단면의 부재마다 도면 스타일을 매번 다시 잡는다.

한 번 만들면, 나머지는 자동 재현

가공도를 한 번 원하는 형태로 완성해 두면(기록), 같은 단면의 다른 부재에 같은 구성·스타일이 그대로 재현됩니다(재생). 첫 도면에만 공들이면 됩니다.

  • View별 2D·단면·치수·Fab No, 홀 관통 깊이 Hidden Line 표시
  • NC 홀 테이블 · 부속 자재(BOM) 표 · 회사 도면 양식까지 한 장에
  • 치수·주석·부속 라벨 위치까지 저장해 다른 부재에 자동 재현

  • 입면 제작 리스트 라벨 — 입면 번호 또는 TextBox 리더 선택

제작 리스트 라벨

문제 — 입면 자재 표기 방식이 회사·담당자마다 다르다.

입면에 맞는 표기를 선택 — 입면 번호 / TextBox 리더

Fablist는 도면 세트용 제작 리스트 표를 만들고, 입면에는 두 가지 라벨 방식 중 선호하는 것을 표시합니다. 기본값으로 저장하면 이후 자동 적용됩니다.

  • 입면 번호(TypeA) — 솔리드마다 원+번호 지시선, 표의 NO와 1:1 대응
  • TextBox 리더(TypeB) — 멤버별 ProfileName·Fab번호·수량 미니 테이블
  • 글자 크기와 함께 기본값으로 저장 → 이후 자동 적용
