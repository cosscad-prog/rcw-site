RCW V5는 어떤 프로그램입니까

Rhino 7 · Rhino 8 에서 동작하는 커튼월 전용 플러그인입니다(Windows). 단독 프로그램이 아니라 Rhino 안에서 도는 도구라, Rhino 가 설치되어 있어야 합니다.

하는 일은 하나입니다 — 커튼월 단면과 와이어프레임을 실제 제작용 3D 모델로 바꾸고, 그 모델 하나에서 공장이 필요로 하는 자료를 자동으로 뽑아냅니다.

  • 프레임(멀리언 · 트랜섬) · 유리 · 백패널 모델링
  • 부재 자동 번호
  • 가공도 — 홀 · 장공 · 노치 치수까지
  • 부재표 · 부속표 · 컷팅리스트 · 물량
  • 2D 도면과 NC 가공 데이터

3D 모델링 자체가 목적이 아니라, 그 뒤의 도면과 물량을 위한 도구입니다.

어느 버전이 필요한지는 형상이 정합니다

기능 목록보다 이 기준이 먼저입니다. 형상이 감당되지 않으면 뒤의 기능은 쓸 일이 없기 때문입니다.

프로젝트 형상필요한 버전
평면 스틱(Stick) 타입 Core해당
유닛(Unit) 타입 · 삼각형 등 평면이 아닌 유닛 Standard
곡선(커브)이 있는 형상 · 판재(Sheet) 가공 Professional

말씀하신 범위라면 Core 로 충분합니다

평면 스틱 타입 위주라면 모델링부터 가공도 · 물량까지 Core 안에서 전부 끝납니다. 지금 쓰지 않으실 기능에 비용을 들이실 이유는 없습니다.

Core 로 하실 수 있는 것

  • 프레임(멀리언 · 트랜섬) 유닛 모델링
  • 유리 · 백패널 모델링과 번호 · 리스트
  • 가공도, 부재표 · 부속표, 컷팅리스트, 물량 산출
  • 2D 도면과 NC 데이터
  • 레이어 · 블록 · 치수 유틸리티

Core 에 없는 것 (Standard 이상)

  • 창호(Vent) · 그릴(Grill) 모델링
  • 유닛 타입 모델링과 유닛 리스트 · 유닛 표
  • BIM 데이터 산출
  • 웹뷰어 — Rhino 가 없는 분께 3D 모델을 링크로 열어 보여 주는 기능
  • 사용자 바리스트, 서피스 · 각도 · 실린더 도구
한 가지만 미리 말씀드립니다. 앞으로 유닛 타입이나 삼각형처럼 평면이 아닌 형상, 또는 창호가 포함된 프로젝트를 맡으실 예정이라면 처음부터 Standard 를 보시는 편이 낫습니다. 나중에 올리실 수도 있지만, 프로젝트가 진행되는 중에 바꾸는 것은 번거롭습니다.

미리 아셔야 할 점

  • Rhino 7 또는 Rhino 8(Windows)이 따로 필요합니다. RCW 가격에 포함되지 않으며, 맥에서는 동작하지 않습니다.
  • 처음에 준비 작업이 있습니다. 회사에서 쓰시는 단면을 한 번 등록해 두어야 그 뒤가 자동으로 흘러갑니다. 이 작업이 끝나기 전에는 손으로 그리는 것보다 빠르지 않습니다. 《도입 초기에 이 부분을 함께 봐 드립니다》
  • 라이선스는 PC 1대 기준입니다. PC를 바꾸시면 홈페이지에서 재발급을 요청하시면 되고, 비용은 없습니다.
