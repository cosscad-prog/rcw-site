  받으신 파일을 실행해 설치하신 뒤 Rhino를 다시 시작해 주십시오.
  설치 안내 : https://rcw-site.vercel.app/guide-ko

  Rhino 명령창에 RCWMachineCode 를 입력하시면 기기 코드가 나옵니다.
  (RCW5- 로 시작하는 긴 문자열입니다)

  그 코드를 이 메일로 회신해 주시면, 라이선스 파일(.lic)을 보내드립니다.
  받으신 파일은 Rhino 명령창에 RCWLicense 를 입력해 선택하시면 적용됩니다.

    수정이 필요합니다.

  · 기존 버전은 그대로 두셔도 됩니다. V5는 Rhino 7과 8을 모두 지원합니다.

select company, name, license_id
  from public.customers
 where info_confirmed_at is null
   and note like '마이그레이션%'
 order by company;
