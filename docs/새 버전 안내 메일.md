# 고객 새 버전 안내 메일 문안 (2026-08-28 작성)

새 판을 낼 때마다 **기존 고객**에게 손으로 보낸다.
트라이얼과 달리 **자동 발송이 없다** — 트라이얼은 `.github/workflows/trial-notice.yml` 이 보내지만
고객 명단으로는 그 워크플로가 돌지 않는다.

`《 》` 부분만 고객마다 바꿔 넣는다. 고객 코드는 `/admin` 고객 탭에서 그 고객의 것 하나만.

## 왜 이 판은 따로 알리는가

버전마다 보내는 것이 아니다. 이번 판은 **동작이 바뀐 것이 있어** 알리지 않으면 문의가 온다.

- **FDDS 가 폐기됐다.** 누르면 "더이상 사용하지 않는 명령어 입니다. FDwg 사용하십시요" 한 줄만 나온다.
  쓰던 분이 미리 모르면 **고장으로 읽는다.** 이 메일의 존재 이유 절반이 이것이다.
- 그 밖은 전부 더해진 것이라 몰라도 손해는 없지만, 양이 많아 **한 번 보시게 할 값어치가 있다.**

## ★ 덱 링크가 본론이다

바뀐 것을 글로 나열하지 않는다. 스물한 가지를 메일에 적으면 아무도 안 읽는다.
**화면으로 보여 주는 덱**(`/whatsnew`)에 링크 하나만 걸고, 메일에는 **동작이 바뀐 것 하나**만 적는다.

⚠️ 덱과 새 설치 파일은 **같이 올린다.** 덱이 먼저 공개되면 아직 없는 기능을 보고 문의가 온다.

## ⚠️ 버전 뒤에 조사를 바로 붙이지 말 것

끝자리 발음에 따라 갈린다(5.1.3 **이** / 5.1.2 **가**). **5.2.0 은 "영" 으로 끝나 받침이 있다 — "5.2.0 을 올렸습니다".**
제목·본문 모두 버전 뒤는 공백이나 다른 말로 끊는다.

## 제목

```
[RCW] 새 버전 5.2.0 안내 — 이번에 달라진 것을 화면으로 보실 수 있습니다
```

## 본문

```
《회사명》 《담당자님》 안녕하십니까.

RCW를 사용해 주셔서 감사합니다.
새 버전 5.2.0 을 올렸습니다. 그동안 판 중 가장 많이 손본 판입니다.


■ 이번에 달라진 것

  https://rcw-site.vercel.app/whatsnew

  스물한 가지 변경을 화면으로 정리했습니다. 새로 생긴 명령, 바뀐 창,
  그리고 무엇이 없어졌는지를 실제 화면으로 보실 수 있습니다.
  로그인 없이 바로 열립니다.


■ 하나만 미리 알아 두십시오 — FDDS

  가공도 명령이 FDwg 하나로 정리되었습니다.
  FDDS 를 실행하시면 이제 안내 문구만 나옵니다.

    "더이상 사용하지 않는 명령어 입니다. FDwg 사용하십시요"

  고장이 아닙니다. FDDS 로 하시던 작업은 FDwg 으로 하시면 됩니다.
  전에 FDDS 로 뽑아 두신 도면은 그대로 열리고 그대로 쓰실 수 있습니다.


■ 받으시는 방법

  다운로드 페이지 : https://rcw-site.vercel.app/customer
  고객 코드       : 《RCW-XXXX-XXXX-XXXX》

  코드를 넣고 로그인하시면 설치 파일이 나옵니다.
  설치 중에는 Rhino 를 종료해 주십시오.


■ 라이선스는 그대로입니다

  덮어 설치하셔도 라이선스는 남습니다. 다시 등록하지 않으셔도 됩니다.
  머신코드도 바뀌지 않으므로 새로 발급받으실 필요가 없습니다.

  참고로 이번 판부터 고객 코드를 Rhino 에 적어 두실 수 있습니다.
  RCWCustomerCode 명령으로 한 번 넣어 두시면, 나중에 RCWVersion 으로
  언제든 다시 보실 수 있습니다. 이 메일을 못 찾으셔도 됩니다.

문의는 이 메일로 회신해 주시면 됩니다.

감사합니다.
```

## 보내기 전 점검

- [ ] 새 설치 파일이 **이미 올라가 있는가** (`publish-customer.ps1`)
- [ ] `releases.json` 에 이번 판 항목이 들어갔는가 — 안 넣으면 발행 자체가 막힌다
- [ ] `/whatsnew` 가 열리는가, 그림·영상이 다 나오는가
- [ ] 고객마다 **자기 코드**가 들어갔는가 (남의 코드가 가면 사고다)
- [ ] 버전 번호를 제목·본문 두 곳 모두 고쳤는가 (이번 판은 **5.2.0**, 조사는 **을**)

## 안 받아 가면

`/admin` 고객 탭에서 다운로드 기록을 본다. 며칠 뒤에도 비어 있으면
트라이얼과 같은 방식으로 카카오톡 1:1 로 한 번 더 안내한다.
⚠️ 할인·구매 권유 문구를 더하지 않는다 — 받은 동의는 제품 안내까지다.
