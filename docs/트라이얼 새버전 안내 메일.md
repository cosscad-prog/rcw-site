# 트라이얼 새 버전 안내 메일 (5.1.3) — 2026-08-24

기존 트라이얼 신청자에게 **다시 받으라고** 안내하는 문안. 사람마다 **개인 링크**가 다르다.

## 1. 개인 링크 뽑기

Supabase → SQL Editor:

```sql
select name, company, email,
       'https://rcw-site.vercel.app/trial?r=' || id as 링크
  from public.trial_requests
 order by created_at desc;
```

이 링크를 누르면 **신청 폼이 안 나오고 바로 다운로드 칸**이 뜬다.
링크를 잃은 사람은 페이지의 *"이미 신청하신 분"* 에 메일 주소만 넣으면 같다.

⚠️ 링크에는 신청 번호가 들어 있다. 남에게 넘어가면 **그 사람 이름으로 다운로드 기록이 쌓인다**
(받는 것 자체는 원래 공개다). 단체 메일 참조로 돌리지 말고 **한 사람씩** 보낼 것.

## 2. 제목

```
[RCW] 트라이얼 5.1.3 - 다시 받으실 수 있습니다 (입력 없이 바로)
```

## 3. 본문

```
《회사명》 《담당자님》 안녕하십니까.

RCW 트라이얼을 사용해 주셔서 감사합니다.
새 버전 5.1.3 이 나와 안내드립니다.


■ 이번 버전에서 바뀐 것

  · 단면 정보를 Rhino 속성창에서 바로 볼 수 있습니다
    선택한 형상의 이름·재질·가공 정보가 별도 창을 열지 않고 보입니다.

  · 단면의 추가 길이 입력이 하나로 합쳐졌습니다
    같은 값을 두 번 넣으실 필요가 없습니다.

  · 겹쳐 그린 선이 있는 단면을 미리 잡아냅니다
    눈에 보이지 않는 두께 0 형상 때문에 빼기 작업이 조용히 실패하던 것을
    작업 전에 경고로 알려 드립니다.


■ 받으시는 곳 — 아래 링크만 누르시면 됩니다

  《https://rcw-site.vercel.app/trial?r=신청번호》

  정보를 다시 입력하지 않으셔도 됩니다. 링크를 누르시면 바로 받으실 수 있습니다.
  기존 버전 위에 그대로 설치하시면 되고, 따로 지우지 않으셔도 됩니다.


■ 체험 기간은 그대로입니다

  새로 설치하셔도 체험 기간이 다시 시작되지는 않습니다.
  남으신 기간을 그대로 이어서 사용하시게 됩니다.


불편하신 점이나 궁금하신 것이 있으시면 이 메일로 회신해 주십시오.

감사합니다.
```

## 4. 보낸 뒤 확인

`/admin` → 트라이얼 탭. 받아 가면 **신청 표의 받아 갔나 칸**이 `Core 8` 처럼 바뀌고,
위 다운로드 표에 `2회차` 로 쌓인다. 신청 수는 늘지 않는다(같은 신청에 붙는다).

⚠️ 지금 네 분은 `받아 감 · 기록 없음 · 확인함` 으로 되어 있다. 새로 받아 가면
그 자리에 실제 버전이 찍히므로, 누가 5.1.3 으로 옮겼는지 그때부터 정확히 보인다.
