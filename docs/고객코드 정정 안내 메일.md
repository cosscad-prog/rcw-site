# 고객 코드 정정 안내 메일 문안 (2026-08-24)

이전에 **"임시코드"** 라고 안내드렸던 코드가 실은 **계속 쓰는 고객 코드**라는 것을 바로잡는 메일이다.
`《 》` 부분만 고객마다 바꿔 넣는다.

## 왜 보내는가

- 이전 안내에서 그 코드를 **임시**라고 말씀드려, 고객이 버리거나 "다른 코드가 따로 오겠지" 하고
  기다릴 수 있다.
- 일부 고객께는 **라이선스 파일(`.lic`)의 이름으로 로그인**하시라고 안내가 나갔다.
  그 이름은 **발급할 때마다 바뀌는 번호**라, PC 를 바꾸시면 더 이상 맞지 않는다.
- 고객 페이지 문구도 2026-08-23 에 **"고객 코드"** 로 바꿨다. 화면과 안내를 맞춰 둔다.

## 제목

```
[RCW] 고객 코드 안내 정정 — 처음 보내 드린 코드를 계속 사용하시면 됩니다
```

## 본문

```
《회사명》 《담당자님》 안녕하십니까.

RCW를 사용해 주셔서 감사합니다.
앞서 안내드린 코드에 대해 한 가지 바로잡아 드립니다.


■ 처음 보내 드린 코드는 임시가 아닙니다

  고객 코드 : 《V5KO-XXXXXXXXXXXX》

  이 코드가 앞으로도 계속 쓰시는 고객 코드입니다.
  전에 "임시코드"라고 말씀드린 적이 있는데, 그렇지 않습니다.
  기간 제한도 없고 다른 코드로 바뀌지도 않습니다.

  - 다운로드 페이지 로그인
  - 라이선스 요청

  두 가지 모두 이 코드 하나로 하시면 됩니다.
  PC를 바꾸시거나 새 버전이 나와도 같은 코드를 그대로 쓰십니다.


■ 라이선스 파일(.lic) 이름은 로그인 코드가 아닙니다

  받으신 라이선스 파일의 이름도 V5KO- 로 시작해 헷갈리기 쉽습니다.
  그 이름은 발급할 때마다 새로 붙는 번호라, PC를 바꾸시면 달라집니다.
  로그인에는 위의 고객 코드를 사용해 주십시오.


■ 코드를 못 찾으시겠으면

  알려 주시면 바로 다시 보내 드립니다. 재발급이 아니라 같은 코드입니다.

  다운로드 페이지 : https://rcw-site.vercel.app/customer

번거롭게 해 드려 죄송합니다.
문의는 이 메일로 회신해 주시면 됩니다.

감사합니다.
```

## 보낼 대상

명부(`/admin` → CSV 내려받기)의 **실고객 전부**. 시험용 줄(`베임테크 회사com1·com2`)과
개발용(`jcs`)은 제외한다.

⚠️ **중앙알텍 안찬식 님은 예외** — 그분은 처음에 고객 코드를 따로 보내 드린 적이 없고,
명부의 코드가 `.lic` 번호(`V5KO-0C644F7998C8`)로 만들어져 있다. 그 값이 실제로 그분의
로그인 코드이므로 **그대로 쓰시면 된다**. 이 메일을 그대로 보내면 "그 이름은 로그인 코드가
아니다" 라는 문단이 그분에게는 틀린 말이 되므로, 그분께는 그 문단을 빼고
고객 코드 자리에 `V5KO-0C644F7998C8` 을 적어 보낼 것.
