RcwHelp  —  도움말 열기

RcwHelp

설치된 RCW 도움말을 기본 웹 브라우저로 엽니다. 지금 보고 있는 이 문서가 그 도움말입니다.

사용 방법

  1. Rhino 명령창에 RcwHelp 를 입력하고 Enter 를 누릅니다.
  2. 기본 웹 브라우저가 열리면서 도움말 첫 화면이 표시됩니다.
  3. 왼쪽 목차에서 기능군을 펼쳐 원하는 명령 문서를 선택합니다.

언어별로 열리는 문서

RCW 의 표시 언어 설정에 따라 열리는 파일이 달라집니다.

표시 언어열리는 파일
한국어플러그인 설치 폴더의 help\Help_index.html
그 외 언어플러그인 설치 폴더의 help\en\index.html (영문 도움말)

실행 결과

항목설명
도움말 창Rhino 창이 아니라 기본 웹 브라우저에서 열립니다. Rhino 작업을 계속하면서 옆에 두고 볼 수 있습니다.
모델 변경없습니다. 도면이나 모델을 바꾸지 않습니다.

관련 명령어

명령어설명
RCWLicense발급받은 라이선스 파일을 사용자 프로필로 가져옵니다.
RCWMachineCode라이선스 발급에 필요한 이 컴퓨터의 machine code 를 확인합니다.
RCWCustomerCode고객 페이지 로그인에 쓰는 고객 코드를 이 컴퓨터에 적어 둡니다.
RCWVersion지금 돌고 있는 빌드의 버전·에디션·빌드 날짜와 로드된 파일 경로를 명령창에 표시합니다.
RCWUpdate새 버전이 나왔는지 확인합니다. 시작할 때의 자동 확인을 켜고 끕니다.

위 다섯 명령의 자세한 설명은 목차의 A3 Rhino Modeling Tools > 19 License > License / Version 문서에 있습니다.

주의: 도움말 파일을 찾지 못하면 명령창에 찾으려던 경로가 표시되고 명령이 중단됩니다. 이 경우 설치 폴더의 help 폴더가 함께 설치되었는지 확인하십시오.
