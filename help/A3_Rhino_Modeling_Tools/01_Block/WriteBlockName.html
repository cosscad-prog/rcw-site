WriteBlockName

선택된 Block Object의 이름을 Block의 Insert Point 위치에 표시하는 명령입니다.

사용 목적

배치된 Block 인스턴스의 정의 이름을 모델 위에 직접 표시해, 화면상에서 각 부품이나 삽입 객체가 어떤 Block인지 빠르게 식별할 때 사용합니다.

사용 방법

  1. Rhino 명령창에 WriteBlockName를 입력하고 Enter를 누릅니다.
  2. 명령 프롬프트에 따라 대상 객체를 선택합니다.
  3. Enter를 눌러 명령을 완료하고 Rhino 화면 또는 명령창 결과를 확인합니다.
