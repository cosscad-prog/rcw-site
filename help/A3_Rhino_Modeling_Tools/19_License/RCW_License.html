License / Version  —  라이선스와 버전

RCWMachineCode RCWLicense RCWCustomerCode RCWVersion RCWUpdate

도면을 그리는 명령이 아니라 설치·인증·버전을 다루는 관리 명령들입니다. 모델과 도면을 전혀 바꾸지 않습니다. 성격이 같아 한 문서에 모았습니다.

이 문서가 다루는 것

이름하는 일
RCWMachineCode이 PC 의 머신코드를 보여 주고 클립보드에 복사합니다. 라이선스를 요청할 때 씁니다.
RCWLicense받은 라이선스 파일(.lic) 을 가져옵니다. 현재 라이선스 상태도 함께 보여 줍니다.
RCWCustomerCode안내 메일로 받은 고객 코드를 이 컴퓨터에 한 번 적어 둡니다. 그 뒤로는 RCWVersion 이 계속 알려 줍니다.
RCWVersion지금 돌고 있는 빌드의 버전·에디션·빌드 날짜와 파일 경로를 보여 줍니다. 적어 둔 고객 코드도 함께 나옵니다.
RCWUpdate새 버전이 나왔는지 확인합니다. 시작할 때의 자동 확인을 켜고 끕니다.
고객 코드고객 페이지에 로그인할 때 쓰는 코드로, 안내 메일로 받으십니다. 아래 코드가 두 가지입니다 절을 보십시오.

처음 활성화하는 순서 (Core · Standard)

  1. Rhino 를 실행합니다. 라이선스 파일이 없으면 머신코드가 명령창에 저절로 표시되고 클립보드에 복사됩니다. 놓쳤다면 RCWMachineCode 를 직접 실행하십시오.
  2. 고객 페이지 rcw-site.vercel.app/customer 에 접속해 고객 코드로 로그인합니다.
  3. 화면 아래 라이선스 칸의 머신코드 입력란에 1번의 코드를 붙여넣고 [라이선스 요청] 을 누릅니다.
  4. 보통 1분 안에 같은 자리에 [라이선스 내려받기] 버튼이 나타납니다. 화면이 저절로 바뀌므로 새로고침하지 않으셔도 됩니다.
  5. 내려받은 .lic 파일을 안전한 위치에 저장합니다.
  6. Rhino 명령창에 RCWLicense 를 입력하고 그 .lic 파일을 고릅니다.
  7. 가져오기 성공 메시지를 확인한 뒤 Rhino 를 다시 시작합니다.
  8. 가져오기가 끝나면 고객 코드를 적어 둘지 그 자리에서 물어봅니다. 2번에서 로그인에 쓰신 코드를 붙여넣으십시오 — 메일을 잃어버려도 다시 찾을 수 있습니다. 나중에 하려면 RCWCustomerCode.
라이선스 파일을 Program Files 폴더에 직접 복사하지 마십시오. 반드시 RCWLicense 명령으로 가져와야 합니다.

로그인이 안 될 때는 대개 두 코드를 바꿔 넣은 경우입니다. 로그인 칸에 들어가는 것은 RCW- 로 시작하는 고객 코드이고, RCW5- 로 시작하는 머신코드는 로그인한 다음 화면 아래에 넣습니다.
고객 코드가 기억나지 않으면 RCWVersion 을 실행하십시오 — 한 번 적어 두었다면 거기 나옵니다.

RCWMachineCode — 머신코드 확인

실행하면 머신코드를 명령창에 한 줄 찍고 클립보드에 복사합니다. 그대로 고객 페이지에 붙여넣으면 됩니다.

항목설명
언제 쓰나라이선스를 처음 받을 때, 그리고 PC 를 바꾸거나 머신코드가 달라져 재발급이 필요할 때.
값이 정해지는 방식Windows 가 그 PC 에 부여한 값에서 만들어집니다. 같은 PC 면 늘 같은 코드가 나옵니다.
에디션 표시앞의 CO·ST 가 Core·Standard 를 뜻합니다. 에디션이 다르면 코드도 다릅니다.
보낼 곳고객 페이지 또는 발급 담당자에게만 보내십시오.
머신코드를 못 만들면 Windows 의 MachineGuid 를 읽지 못했다는 메시지가 나오고 명령이 실패합니다. 이때는 화면을 캡처해 함께 보내 주십시오.

RCWLicense — 라이선스 파일 가져오기

  1. 명령을 실행하면 현재 라이선스 상태가 먼저 한 줄 나옵니다.
  2. 이어서 파일 열기 창이 뜹니다. 내려받은 .lic 파일을 고릅니다.
  3. 가져온 뒤 상태를 다시 한 줄 찍습니다. 성공이면 "RCW 라이선스 파일을 가져왔습니다".
  4. 적어 둔 고객 코드가 없으면 여기서 한 번 물어봅니다. 붙여넣거나 Enter 로 건너뛰십시오.
  5. Rhino 를 다시 시작하면 적용됩니다.
항목설명
파일 형식*.lic 한 개. 여러 개를 한꺼번에 고를 수 없습니다.
취소파일 창에서 취소를 눌러도 됩니다. 이미 있던 라이선스는 그대로입니다.
실패했을 때"가져오지 못했습니다" 가 나오면 다른 PC 의 파일이거나 기간이 지난 파일일 수 있습니다. 바로 위에 찍힌 상태 줄을 함께 보내 주십시오.
인터넷필요 없습니다. 라이선스 확인은 파일의 서명으로 오프라인에서 끝납니다.
고객 코드 물음가져오기가 성공했을 때, 그리고 적어 둔 코드가 없을 때만 묻습니다. 무엇을 하시든(건너뛰든, 형식이 틀리든) 라이선스 가져오기 결과는 바뀌지 않습니다.

RCWCustomerCode — 고객 코드 적어 두기

고객 코드는 안내 메일에만 있습니다. 라이선스 파일 안에도 없고 화면 어디에도 나오지 않습니다. 몇 달 뒤 PC 를 바꾸거나 설치 파일을 다시 받으려 할 때 그 메일을 못 찾는 일이 잦습니다. 라이선스 파일을 한 번 등록해 두듯이 코드도 한 번 적어 두십시오.

처음 등록하는 자리는 RCWLicense 입니다 — 라이선스를 가져오고 나면 그 자리에서 물어봅니다. 이 명령은 나중에 등록하거나, 바꾸거나, 지울 때 씁니다.

  1. RCWCustomerCode 를 실행합니다. 적어 둔 것이 있으면 먼저 보여 주고 클립보드에 복사합니다.
  2. 명령창이 코드를 묻습니다. 안내 메일의 코드를 붙여넣고 Enter 를 누릅니다.
  3. 저장했다는 메시지가 나오면 끝입니다. 그 뒤로는 RCWVersion 에 늘 함께 나옵니다.
조작결과
Enter 만 누르기아무것도 바꾸지 않습니다. 보기만 하고 나올 때 이렇게 하십시오.
새 코드 붙여넣기적어 둔 것을 바꿉니다.
Remove 옵션적어 둔 코드를 지웁니다. 코드 자체가 없어지는 것은 아닙니다 — 이 컴퓨터의 기록만 지웁니다.
항목설명
입력 형태하이픈이 있어도 없어도, 대소문자가 섞여도 받습니다. 저장은 대문자로 맞춰 둡니다.
받는 것RCW- 로 시작하는 코드. V5KO- 로 시작하는 옛 코드도 그대로 받습니다 — 고객 페이지도 아직 받습니다.
거절되는 경우접두사가 RCW-·V5KO- 가 아니거나, 영숫자가 8자 미만·40자 초과일 때. 거절되어도 이미 적어 둔 코드는 그대로 남습니다.
머신코드를 넣으면거절하고 이유를 말합니다. RCW5-CO-…·RCW5-ST-… 는 머신코드이지 고객 코드가 아닙니다. 한 글자 차이라 가장 흔한 실수입니다.
저장되는 곳라이선스 파일 옆입니다. 재설치해도 남고, 고객이 여는 편집 폴더가 아니라 실수로 지울 일이 적습니다.
인터넷쓰지 않습니다. 코드가 맞는지 확인하려고 어디에 물어보지 않습니다 — 모양만 봅니다.
이 코드는 고객 페이지에 로그인하는 열쇠입니다. 적어 두면 이 컴퓨터의 파일에 그대로 남으므로, 여러 사람이 함께 쓰는 Windows 계정에서는 적어 두지 않는 편이 낫습니다. RCWCustomerCode 의 Remove 로 언제든 지울 수 있습니다.

RCWVersion — 어느 빌드가 돌고 있나

지원을 요청하실 때 가장 먼저 필요한 정보입니다. 실행하면 두 줄이 나옵니다.

RCW V5 5.1.2 Standard net48 build 2026-08-14 C:\Program Files\...\RCW_V5.rhp 고객 코드: RCW-1A2B-3C4D-5E6F
값뜻
5.1.2버전 번호. 뒤에 -trial 같은 꼬리가 붙으면 그 빌드의 성격을 나타냅니다.
Standard에디션. Core · Standard · Internal 중 하나이며, 평가판이면 Trial 이 함께 표시됩니다.
net48돌고 있는 .NET 종류. Rhino 8 은 설정에 따라 다른 값이 나올 수 있습니다.
build …그 빌드를 만든 날짜.
두 번째 줄실제로 로드된 파일의 경로입니다. 옛 버전이 지워지지 않고 남아 있을 때 이 줄이 답을 줍니다.
세 번째 줄RCWCustomerCode 로 적어 둔 고객 코드입니다. 적어 둔 것이 없으면 등록하라는 안내가 대신 나옵니다.
같은 줄이 Rhino 를 켤 때도 한 번 명령창에 나옵니다. 명령을 실행하지 않아도 위로 스크롤하면 볼 수 있습니다.

RCWUpdate — 새 버전 확인

알리기만 합니다. 내려받거나 설치하지 않습니다.

조작결과
Enter지금 확인합니다. 최신이면 "최신 버전입니다", 새 버전이 있으면 새 버전과 설치된 버전을 알려 주고 다운로드 페이지를 열까요? 라고 묻습니다.
AutoCheck시작할 때의 자동 확인을 켜고 끕니다. 끄면 그 뒤로 아무것도 확인하지 않습니다.

자동 확인은 이렇게 동작합니다.

항목설명
횟수하루 한 번, Rhino 시작이 끝난 뒤에 조용히 확인합니다. 시작을 붙들지 않습니다.
보내는 정보없습니다. 홈페이지의 버전 목록 파일 하나를 읽어 올 뿐이며, 머신코드·라이선스·도면은 어디에도 보내지 않습니다.
실패했을 때아무 말도 하지 않습니다. 폐쇄망·방화벽 안에서도 경고가 뜨지 않습니다. 이유가 궁금하면 RCWUpdate 를 직접 실행하십시오 — 그때는 결과를 반드시 답합니다.
같은 창 반복같은 새 버전으로 창을 두 번 띄우지 않습니다. 명령창 줄은 계속 남습니다.
설치하려면 Rhino 를 닫아야 합니다. 돌고 있는 동안에는 플러그인 파일이 잠겨 덮어쓸 수 없습니다.

PC 를 바꾸거나 다시 설치할 때

상황해야 할 일
같은 PC 에 다시 설치머신코드가 그대로이므로 가지고 계신 .lic 을 RCWLicense 로 다시 가져오면 됩니다.
도움말 언어를 바꾸려고 다시 설치같은 설치 파일로 다른 언어를 골라 설치한 뒤, 같은 .lic 을 다시 가져오십시오.
PC 교체 · 머신코드 변경새 라이선스가 필요합니다. 고객 페이지에서 요청하시면 담당자 확인을 거쳐 발급됩니다.
같은 회사의 다른 사람라이선스는 PC 한 대당 하나입니다. 사람마다 따로 받으셔야 합니다.

평가판(Trial)은 라이선스 파일이 필요 없습니다

Core Trial 은 Core 범위로 90일, Standard Trial 은 전체 명령 범위로 30일 동작합니다. 기간은 최초 정상 실행일부터 세며, 같은 Windows 사용자 계정에서 재설치해도 시작일이 되돌아가지 않습니다. 두 평가 기간은 서로 독립입니다.

평가판에는 RCWMachineCode · RCWLicense · RCWCustomerCode 가 들어 있지 않습니다. 라이선스 파일도 고객 코드도 쓰지 않기 때문입니다. RCWVersion 과 RCWUpdate 는 평가판에도 있습니다.

문제가 생겼을 때

증상확인할 것
고객 코드가 기억나지 않는다RCWVersion 을 실행하십시오. 한 번 적어 두었다면 마지막 줄에 나옵니다. 적어 둔 적이 없으면 안내 메일을 찾으셔야 합니다.
고객 페이지에 로그인이 안 된다RCW- 로 시작하는 고객 코드를 넣으셨는지. RCW5- 는 로그인 코드가 아닙니다.
라이선스를 가져왔는데 그대로다Rhino 를 다시 시작하셨는지.
명령이 없다고 나온다RCWVersion 으로 에디션을 확인하십시오. 평가판에는 라이선스 명령이 없고, Core 에는 Standard 전용 명령이 없습니다.
고친 줄 알았는데 옛날처럼 동작한다RCWVersion 의 두 번째 줄을 보십시오. 다른 폴더의 옛 빌드가 로드돼 있을 수 있습니다.

지원을 요청하실 때는 RCWVersion 의 두 줄, Rhino 버전, Windows 사용자 이름, 오류 메시지나 화면 캡처를 함께 보내 주십시오.
