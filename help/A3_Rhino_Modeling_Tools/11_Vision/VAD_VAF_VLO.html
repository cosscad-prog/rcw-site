VAD, VAF, VLO  —  11_Vision

VAD VAF VLO

객체의 Vision 상태를 직접 켜고 끄는 명령입니다. Layer 표시 상태와 별개로 객체 자체의 표시 속성을 바꾸며, 객체를 삭제하지 않고 숨김/표시 상태만 변경합니다.

사용 목적

선택 객체 단위로 표시/숨김 상태를 제어해 작업 중 필요한 객체만 남기거나 숨긴 객체를 다시 표시할 때 사용합니다.

명령어별 기능

명령어기능동작
VADSelected Object Vision On선택한 객체만 보이게 하고, 선택되지 않은 나머지 객체를 숨깁니다.
VAFSelected Object Vision Off선택한 객체만 숨깁니다.
VLOAll Object Vision On숨겨진 객체를 포함해 문서의 객체 표시 속성을 다시 켭니다.

사용 방법

  1. VAD를 실행하면 숨기지 않을 오브젝트를 선택하세요 프롬프트가 표시됩니다. 남길 객체를 하나 이상 선택하면 선택되지 않은 객체들이 숨겨집니다.
  2. VAF를 실행하면 Select Group objects 프롬프트가 표시됩니다. 숨길 객체를 하나 이상 선택하면 선택 객체의 표시 속성이 꺼집니다.
  3. VLO를 실행하면 별도 선택 없이 숨겨진 객체들의 표시 속성을 다시 켜고 화면을 갱신합니다.

코드 기준 동작

항목설명
VAD 선택 방식GetObject로 모든 타입의 객체(ObjectType.AnyObject)를 하나 이상 선택합니다. 선택 객체의 ID를 저장한 뒤, 문서 전체 객체를 순회하며 선택되지 않았고 현재 숨겨져 있지 않은 객체를 doc.Objects.Hide로 숨깁니다.
VAF 선택 방식기존 선택을 모두 해제한 뒤 새로 객체를 선택합니다. PreSelect는 비활성화되어 있어 명령 실행 후 선택한 객체만 처리합니다. 선택된 객체의 Attributes.Visible 값을 false로 바꾸고 변경을 저장합니다.
VLO 복원 방식ObjectEnumeratorSettings에서 Hidden, Locked, Reference 객체까지 포함해 객체 목록을 가져온 뒤 각 객체의 Attributes.Visible 값을 true로 바꿉니다.
Layer와의 관계Layer를 끄거나 켜는 명령이 아닙니다. 객체 자체의 표시/숨김 속성을 바꾸므로 Layer 상태와 별개로 작동합니다.
화면 갱신각 명령은 처리 후 Rhino View를 다시 그립니다.

주의 사항

항목설명
삭제 아님객체는 삭제되지 않습니다. 숨김 상태만 변경됩니다.
VAD 결과선택하지 않은 객체를 모두 숨기므로, 작업 범위를 좁혀 특정 객체만 확인할 때 사용합니다.
VAF 결과선택 객체만 숨기므로, 임시로 방해되는 객체를 제거해 보이는 상태를 만들 때 사용합니다.
VLO 결과Vision Off 상태의 객체를 다시 보이게 합니다. 코드상 숨김/잠김/참조 객체까지 열거 대상으로 포함합니다.
참고: VAD 실행 후 명령창에는 숨긴 객체 수가 출력됩니다. 다시 전체 객체를 보려면 VLO를 실행하세요.
