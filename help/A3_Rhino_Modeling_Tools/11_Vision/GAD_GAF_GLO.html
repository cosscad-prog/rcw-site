GAD, GAF, GLO  —  11_Vision

GAD GAF GLO

Group 단위로 객체의 Vision 상태를 켜고 끄는 명령입니다. Layer 표시 상태와 별개로 객체의 표시 속성을 바꾸며, 객체를 삭제하지 않고 숨김/표시 상태만 변경합니다.

사용 목적

Group 단위로 객체를 숨기거나 다시 표시해 복잡한 모델에서 특정 부품군만 집중 검토할 때 사용합니다. Layer를 끄지 않고 객체 표시 속성만 조정합니다.

명령어별 기능

명령어기능동작
GADSelected Group Object Vision On선택한 Group만 보이게 하고, 다른 Group 객체는 숨깁니다.
GAFSelected Group Object Vision Off선택한 Group에 속한 객체만 숨깁니다.
GLOAll Group Object Vision On숨겨진 객체를 포함해 객체 표시 속성을 다시 켭니다.

사용 방법

  1. GAD를 실행하면 Select Group objects 프롬프트가 표시됩니다. 보이게 유지할 Group 객체를 하나 이상 선택합니다.
  2. GAF를 실행하면 Select Group objects 프롬프트가 표시됩니다. 숨길 Group 객체를 하나 이상 선택합니다.
  3. GLO를 실행하면 별도 선택 없이 숨겨진 객체들의 표시 속성을 다시 켜고 화면을 갱신합니다.

코드 기준 동작

항목설명
Group 선택GetObject에서 GroupSelect = true를 사용합니다. 명령 실행 전 기존 선택은 해제되고, PreSelect는 비활성화되어 명령 실행 후 새로 선택한 Group만 처리합니다.
Group 인덱스 수집선택된 객체의 Attributes.GetGroupList()에서 첫 번째 Group Index를 가져오고, 중복 없이 선택 Group 목록을 만듭니다.
GAD 처리문서의 모든 Group을 순회합니다. 선택 Group에 속한 객체는 Visible = true, 선택되지 않은 Group에 속한 객체는 Visible = false로 바꿉니다.
GAF 처리선택된 Group Index마다 doc.Objects.FindByGroup(index)로 Group 객체를 찾고, 해당 객체의 Visible 값을 false로 바꿉니다.
GLO 처리코드상 Hidden, Locked, Reference 객체까지 포함해 문서 객체 목록을 가져온 뒤 각 객체의 Visible 값을 true로 바꿉니다.
Layer와의 관계Layer를 끄거나 켜는 명령이 아닙니다. 객체 자체의 표시/숨김 속성을 바꾸므로 Layer 상태와 별개로 작동합니다.
화면 갱신각 명령은 처리 후 Rhino View를 다시 그립니다.

주의 사항

항목설명
삭제 아님객체는 삭제되지 않습니다. 숨김 상태만 변경됩니다.
GAD 결과선택하지 않은 Group 객체를 숨기므로, 특정 Group만 확인할 때 사용합니다.
GAF 결과선택한 Group에 속한 모든 객체가 숨겨집니다. Group 안의 일부 객체만 숨기는 명령이 아닙니다.
GLO 결과참조 문서상 Group Object Vision On 명령이지만, 현재 코드 구현은 Group 필터 없이 문서 객체의 표시 속성을 전체적으로 켭니다.
참고: GAD/GAF는 Group에 속한 객체를 기준으로 동작합니다. Group이 없는 객체를 선택하면 선택 Group 목록에 포함되지 않아 의도한 결과가 나오지 않을 수 있습니다.
