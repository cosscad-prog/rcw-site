3CSrf

선택한 3개의 Curve를 경계로 하여 평면 Surface를 생성하는 명령입니다.

사용 목적

항목설명
Curve 기준 Surface3개의 Curve를 결합하여 닫힌 경계를 만들고 Surface를 생성합니다.
레이어 기준 필터첫 번째 선택 객체와 같은 레이어의 Curve만 Surface 작성 대상으로 사용합니다.
경계 보정결합된 Curve가 닫혀 있지 않으면 허용오차 기준으로 닫은 뒤 Planar Brep을 생성합니다.

사용 방법

  1. Rhino 명령창에 3CSrf를 입력하고 Enter를 누릅니다.
  2. Surface 경계로 사용할 Curve 객체를 선택합니다.
  3. 같은 레이어에 있는 3개의 Curve가 선택 대상에 포함되도록 합니다.
  4. 선택을 완료하면 3개 Curve가 닫힌 경계로 결합되어 생성된 Surface를 확인합니다.

실행 결과

항목설명
처리 결과선택된 3개 Curve의 경계 안에 평면 Surface가 생성됩니다.
확인 위치Rhino 화면에서 Curve 경계 내부에 생성된 Surface 객체를 확인합니다.
참고: 첫 번째로 선택한 Curve의 레이어와 같은 레이어에 있는 Curve만 사용하며, 정확히 3개가 모였을 때만 Surface를 생성합니다. 열린 경계는 허용오차 기준으로 닫기를 시도한 뒤 Planar Brep를 만듭니다.
