SVec

선택한 Surface에 X/Y/Z 방향 Vector 정보를 강제로 할당하는 명령입니다.

사용 목적

항목설명
방향성 할당선택된 Surface에 원하는 X/Y/Z 방향 Vector 정보를 저장합니다.
FabTable 준비외부 Modeling 데이터를 이용해 FabTable을 만들 때 필요한 면 방향성을 보완합니다.
평판 방향 정리Glass Panel, BackPanel 등 평판의 방향을 강제로 정리할 때 사용합니다.

사용 방법

  1. Rhino 명령창에 SVec를 입력하고 Enter를 누릅니다.
  2. Vector 정보를 할당할 Surface를 선택합니다.
  3. 명령 프롬프트에 따라 방향을 지정합니다.
  4. 할당된 Surface Vector 방향을 Rhino 화면에서 확인합니다.

주요 내용

항목설명
대상 객체Vector 정보를 지정할 Surface
색상 기준Red: X 방향축, Blue: Y 방향축, Green: Z 방향축

실행 결과

항목설명
처리 결과선택 Surface에 방향 Vector 정보가 할당됩니다.
확인 위치Rhino 화면의 Vector 표시와 Surface 내부 방향 정보를 확인합니다.
참고: 면 중심에서 한 점을 추가로 찍어 X 방향을 정하고, 면 노멀을 Z 방향으로 저장합니다. Y 방향은 Z와 X의 Cross Product로 계산되므로, X 방향 점을 잘못 찍으면 이후 Fab/Panel 방향 해석도 함께 틀어질 수 있습니다.
