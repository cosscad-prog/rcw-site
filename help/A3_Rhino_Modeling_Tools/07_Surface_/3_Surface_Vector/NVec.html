NVec

선택한 Surface의 Normal Vector 방향을 화면에 표시하는 명령입니다.

사용 목적

항목설명
Normal 확인선택 Surface의 Normal Vector 방향을 시각적으로 표시합니다.
방향 검토Surface 방향이 뒤집혀 있는지, 후속 Offset/Plane/Vector 작업 기준이 올바른지 확인합니다.
작업 보조Surface 기준 방향을 확인해야 하는 모델링, 검토, 절단 기준면 작업 전에 사용합니다.

사용 방법

  1. Rhino 명령창에 NVec를 입력하고 Enter를 누릅니다.
  2. Normal 방향을 확인할 Surface를 선택합니다.
  3. 명령 프롬프트에 따라 필요한 표시 크기 값을 입력합니다.
  4. Rhino 화면에 표시된 Surface Normal Vector 방향을 확인합니다.
