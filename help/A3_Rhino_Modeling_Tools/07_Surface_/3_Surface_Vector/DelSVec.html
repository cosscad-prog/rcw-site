DelSVec

Surface에 이미 할당된 SVec 방향 Vector 정보를 삭제하는 명령입니다.

사용 목적

항목설명
Vector 삭제선택 Surface에 저장된 SVec 방향 정보를 지웁니다.
오류 수정잘못된 방향이나 불필요한 Vector 정보가 할당된 경우 정리합니다.
재할당 준비기존 방향 정보를 삭제한 뒤 SVec로 새 방향을 다시 지정할 수 있습니다.

사용 방법

  1. Rhino 명령창에 DelSVec를 입력하고 Enter를 누릅니다.
  2. SVec 정보를 삭제할 Surface를 선택합니다.
  3. 선택을 완료합니다.
  4. 잘못 할당된 방향 정보가 삭제되었는지 확인합니다.
