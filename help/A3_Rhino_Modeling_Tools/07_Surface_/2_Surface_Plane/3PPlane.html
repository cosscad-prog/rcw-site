3PPlane

선택한 3개의 Point를 기준으로 4각형 Plane Surface를 생성하는 명령입니다.

사용 목적

항목설명
Plane 작성3개의 Point로 Plane 방향을 정의하고 4각형 Plane Surface를 만듭니다.
3PSrf와 차이3PSrf와 비슷하지만 삼각 Surface가 아니라 4각형 면을 생성합니다.
절단 기준면주로 특정 Solid를 잘라낼 때 사용할 Plane Surface 기준면을 만들기 위해 사용합니다.

사용 방법

  1. Rhino 명령창에 3PPlane를 입력하고 Enter를 누릅니다.
  2. Plane Surface를 만들 기준 Point 3개를 순서대로 지정합니다.
  3. 지정한 3개 Point로 정의되는 Plane 방향을 확인합니다.
  4. 생성된 4각형 Plane Surface를 Rhino 화면에서 확인합니다.

주요 내용

항목설명
입력Plane 방향을 정의하는 3개의 Point
생성 객체지정한 Plane 기준의 4각형 Plane Surface

실행 결과

항목설명
처리 결과3개 Point로 정의한 방향에 맞춰 4각형 Plane Surface가 생성됩니다.
확인 위치Rhino 화면에서 새로 생성된 Plane Surface 객체를 확인합니다.
참고: 세 점으로 만든 삼각 평면 Face를 Surf 레이어에 생성합니다. Plane 방향은 점을 찍은 순서로 결정되므로, 이후 Offset이나 Vector 확인에 쓸 기준면이라면 점 선택 순서를 일정하게 유지하십시오.
