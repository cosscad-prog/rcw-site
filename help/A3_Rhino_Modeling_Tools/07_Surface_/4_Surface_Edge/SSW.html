SSW

선택한 Surface의 Edge Line을 추출하고 그룹으로 묶는 명령입니다.

사용 목적

항목설명
Edge 추출선택 Surface의 Edge Line을 추출합니다.
ExtractWireframe 차이Rhino 기본 ExtractWireframe처럼 Edge Line을 만들지만, 면 기준으로 추출하고 결과를 Group으로 묶습니다.
부분 면 처리Solid의 일부 면을 기준으로 Edge를 추출할 때 사용합니다.

사용 방법

  1. Rhino 명령창에 SSW를 입력하고 Enter를 누릅니다.
  2. Edge를 추출할 Surface를 선택합니다.
  3. 선택을 완료합니다.
  4. Surface 기준으로 추출된 Edge Line과 Group 상태를 확인합니다.

실행 예시

주요 내용

항목설명
대상 객체Edge를 추출할 Surface
생성 객체Surface Edge에서 추출된 Line 객체 그룹

실행 결과

항목설명
처리 결과선택 Surface의 Edge Line이 추출되고 Group으로 정리됩니다.
확인 위치Rhino 화면에서 추출된 Edge Line과 Group 상태를 확인합니다.
참고: 선택 Surface의 모든 Edge Curve를 먼저 생성한 뒤 Join을 시도합니다. 닫힌 PolyCurve로 결합되면 개별 Edge Curve는 지우고 닫힌 경계선만 남기므로, 면 외곽선을 한 덩어리로 얻을 때 유용합니다.
