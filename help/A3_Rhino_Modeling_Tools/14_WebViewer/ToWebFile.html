ToWebFile

선택한 Rhino 모델을 GLB 데이터가 내장된 단일 HTML 파일로 저장하는 명령입니다. 저장된 HTML 파일은 Rhino 없이 더블클릭해 Web Browser에서 열 수 있으며, 다른 사용자에게 전달해 모델을 공유할 수 있습니다.

사용 목적

선택 모델을 웹에서 볼 수 있는 파일과 HTML 뷰어 형태로 내보내 외부 검토나 공유용 3D 미리보기를 만들 때 사용합니다.

사용 방법

  1. Rhino 명령창에 ToWebFile을 입력하고 Enter를 누릅니다.
  2. ToWeb: HTML로 저장할 오브젝트를 선택하세요 프롬프트에서 HTML로 내보낼 객체를 선택합니다.
  3. 폴리곤 감소율 (0.1~1.0, Enter=원본) 프롬프트에서 Reduce 비율을 입력합니다. Enter만 누르면 원본 비율 1.0을 사용합니다.
  4. KHR_mesh_quantization 압축 사용? (Y/N, Enter=N) 프롬프트에서 압축 옵션을 선택합니다. 기본값은 N입니다.
  5. 저장 대화상자에서 HTML 파일 이름과 위치를 지정합니다.
  6. 저장이 완료되면 생성된 HTML 파일이 기본 브라우저에서 바로 열립니다.

실행 예시

코드 기준 동작

항목설명
선택 대상ObjectType.AnyObject를 선택할 수 있으며, GroupSelect = true로 그룹 선택도 허용합니다. SubObject 선택은 사용하지 않습니다.
Reduce 비율0.1부터 1.0까지 입력할 수 있습니다. 값이 작을수록 폴리곤을 줄여 파일 크기를 줄이지만 형상이 단순화될 수 있습니다.
QuantizationY 또는 YES를 입력하면 KHR_mesh_quantization 압축을 사용합니다. 기본값은 사용하지 않음입니다.
GLB 변환RhinoMeshExporterGLB가 선택 객체를 GLB로 변환합니다. 색상, 레이어, 블록 색상 상속과 Text 변환 등 WebViewer 표시용 데이터를 포함합니다.
HTML 저장GLB 바이너리를 Base64 데이터로 변환해 HTML 안에 EMBEDDED_GLB 변수로 내장합니다. 대용량 모델에서도 메모리 부담을 줄이기 위해 3MB 단위로 스트리밍 저장합니다.
기본 저장 위치Rhino 문서가 저장되어 있으면 같은 폴더와 같은 파일명을 기본값으로 사용합니다. 문서 경로가 없으면 바탕화면과 rhino-model.html을 기본값으로 사용합니다.

WebV와 차이

명령차이점
WebV선택 모델을 임시 GLB로 변환해 현재 PC의 localhost:8765 WebViewer에서 바로 확인합니다. 파일 저장이 목적이 아닙니다.
ToWebFileGLB가 내장된 standalone HTML 파일을 저장합니다. 저장된 HTML은 더블클릭으로 열 수 있고, 다른 사용자에게 전달해 공유할 수 있습니다.

저장된 HTML 사용법

  1. 저장된 .html 파일을 더블클릭합니다.
  2. 브라우저에서 Rhino Web Viewer가 열리고 내장된 모델이 로드됩니다.
  3. 파일 안에 모델 데이터가 포함되어 있으므로 별도의 GLB 파일이나 로컬 서버가 필요하지 않습니다.
  4. 다른 사용자에게 공유할 때는 생성된 HTML 파일 하나만 전달하면 됩니다.

웹 뷰어 기본 조작

조작설명
Orbit상단 툴바의 Orbit 버튼을 선택한 상태에서 마우스 오른쪽 버튼을 드래그하면 모델을 회전합니다.
Pan상단 툴바의 Pan 버튼을 선택한 상태에서 마우스 오른쪽 버튼을 드래그하면 화면을 평행 이동합니다.
Zoom마우스 휠을 굴려 확대/축소합니다.
Reset카메라 방향을 초기 Isometric 상태로 되돌리고 전체 모델을 화면에 맞춥니다.
Fit현재 모델 전체가 보이도록 Zoom Extents를 실행합니다.
도움말WebViewer 안의 조작 단축키 안내 패널을 엽니다.

Zoom Window 사용법

  1. 브라우저 화면에서 키보드 W를 누릅니다.
  2. 이어서 Space 또는 Enter를 누르면 Zoom Window 모드가 켜집니다.
  3. 확대하고 싶은 영역을 마우스 왼쪽 버튼으로 드래그해 사각형으로 지정합니다.
  4. 마우스 버튼을 놓으면 지정한 영역 중심으로 화면이 확대됩니다.
  5. 도중에 취소하려면 Esc를 누릅니다.

키보드 단축키

단축키동작

W + Space/EnterZoom Window 모드를 켭니다.
TV, FV, RV, LV + Space/EnterTop, Front, Right, Left View로 전환합니다.
SE, SW + Space/EnterSouth-East 또는 South-West Isometric View로 전환합니다.
Esc입력 중인 단축키, Zoom Window 모드, 도움말 패널을 취소/닫습니다.
