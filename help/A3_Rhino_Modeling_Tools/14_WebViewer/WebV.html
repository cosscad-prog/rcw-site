WebV

선택한 Rhino 모델을 Web Browser에서 확인할 수 있도록 GLB로 변환하고, 로컬 WebViewer를 자동으로 여는 명령입니다.

사용 목적

현재 모델 또는 내보낸 웹 뷰어 결과를 로컬 웹 서버로 열어 브라우저에서 3D 상태를 확인할 때 사용합니다.

사용 방법

  1. Rhino 명령창에 WebV를 입력하고 Enter를 누릅니다.
  2. WebViewer(커스텀GLB)로 볼 오브젝트를 선택하세요 프롬프트에서 웹 뷰어로 볼 객체를 선택합니다.
  3. 폴리곤 감소율 (0.5~1.0, Enter=원본) 프롬프트에서 Reduce 비율을 입력합니다. Enter만 누르면 원본 비율 1.0을 사용합니다.
  4. 선택 모델이 GLB 데이터로 변환되고, 브라우저에서 http://localhost:8765/glb 주소가 열립니다.

실행 예시

코드 기준 동작

항목설명
선택 대상ObjectType.AnyObject를 선택할 수 있으며, GroupSelect = true로 그룹 선택도 허용합니다. SubObject 선택은 사용하지 않습니다.
Reduce 비율0.5부터 1.0까지 입력할 수 있습니다. 기본값은 1.0이며, 값이 작을수록 폴리곤을 줄여 웹 표시 데이터를 가볍게 만듭니다.
GLB 변환RhinoMeshExporterGLB가 선택 객체를 레이어별 Progressive GLB 청크로 변환합니다. 렌더 메시 캐시, Smooth Normal, 색상/레이어/블록 색상 상속, Mesh Quantization을 사용합니다.
전송 방식변환된 GLB 청크는 로컬 HTTP 서버에 등록되고, 브라우저 요청 시 gzip 압축으로 전송됩니다.
로컬 서버WebViewerServer가 localhost:8765에서 실행됩니다. /glb는 Viewer HTML, /model/count와 /model/{index}는 GLB 청크를 제공합니다.
브라우저 실행변환이 끝나면 기본 브라우저를 열어 http://localhost:8765/glb로 이동합니다.

웹 뷰어 기본 조작

조작설명
Orbit상단 툴바의 Orbit 버튼을 선택한 상태에서 마우스 오른쪽 버튼을 드래그하면 모델을 회전합니다.
Pan상단 툴바의 Pan 버튼을 선택한 상태에서 마우스 오른쪽 버튼을 드래그하면 화면을 평행 이동합니다.
Zoom마우스 휠을 굴려 확대/축소합니다. 마우스 위치를 기준으로 카메라가 이동합니다.
Reset상단 툴바의 Reset 버튼은 카메라 방향을 초기 Isometric 상태로 되돌리고 전체 모델을 화면에 맞춥니다.
Fit상단 툴바의 Fit 버튼은 현재 모델 전체가 보이도록 Zoom Extents를 실행합니다.
도움말상단 툴바의 도움말 버튼을 누르면 WebViewer 안의 조작 단축키 안내 패널이 열립니다.

Zoom Window 사용법

  1. 브라우저 화면에서 키보드 W를 누릅니다.
  2. 이어서 Space 또는 Enter를 누르면 Zoom Window 모드가 켜지고 커서가 십자 모양으로 바뀝니다.
  3. 확대하고 싶은 영역을 마우스 왼쪽 버튼으로 드래그해 사각형으로 지정합니다.
  4. 마우스 버튼을 놓으면 지정한 영역 중심으로 화면이 확대됩니다.
  5. 도중에 취소하려면 Esc를 누릅니다.

키보드 단축키

단축키동작
ZX + Space/Enter전체 보기(Zoom Extents)를 실행합니다. 툴바의 Fit과 같은 용도입니다.
W + Space/EnterZoom Window 모드를 켭니다.
TV + Space/EnterTop View로 전환하고 전체 모델을 화면에 맞춥니다.
FV + Space/EnterFront View로 전환하고 전체 모델을 화면에 맞춥니다.
RV + Space/EnterRight View로 전환하고 전체 모델을 화면에 맞춥니다.
LV + Space/EnterLeft View로 전환하고 전체 모델을 화면에 맞춥니다.
SE + Space/EnterSouth-East Isometric View로 전환합니다.
SW + Space/EnterSouth-West Isometric View로 전환합니다.
Esc입력 중인 단축키, Zoom Window 모드, 도움말 패널을 취소/닫습니다.

표시 옵션

옵션설명
Shaded모델의 Shaded 표시를 켜고 끕니다.
Ghost모델을 반투명 표시로 전환해 내부나 뒤쪽 객체를 확인하기 쉽게 합니다.
Grid기준 Grid 표시를 켜고 끕니다.
SectionSection Cut을 켜고 끕니다. Panel에서 X/Y/Z 절단축과 절단 위치를 조정할 수 있습니다.
Save현재 WebViewer 모델을 독립 실행 가능한 웹 파일로 저장합니다.
Panel오른쪽 Display Control 패널을 열고 닫습니다. 패널 상단을 드래그해 위치를 이동할 수 있습니다.

Display Control 패널

항목설명
Background웹 뷰어 배경색을 변경합니다.
Ambient장면의 Ambient Light 강도를 조정합니다.
ProjectionPersp와 Ortho 투영 방식을 전환합니다. 기본은 Ortho입니다.
Explode슬라이더로 모델 요소를 벌려서 조립 관계를 확인합니다.
Section CutX/Y/Z 축을 선택하고 슬라이더로 절단 위치를 조정합니다. 툴바의 Section이 켜져 있어야 절단 결과가 보입니다.

실행 결과

항목설명
명령창 출력선택 객체 수, 변환 시간, GLB 청크 수, 총 용량, 브라우저 URL이 출력됩니다.
웹 뷰어브라우저에서 선택 모델을 회전/확대/축소하며 확인할 수 있는 WebViewer가 열립니다.
파일 저장 여부WebV는 즉시 웹 브라우저로 보는 명령입니다. 웹 파일로 내보내는 작업은 ToWebFile 명령을 사용합니다.
참고: WebV는 선택한 객체를 임시 GLB 데이터로 변환해 로컬 서버에서 보여주는 방식입니다. 외부 인터넷 서버로 업로드하지 않고, 현재 PC의 localhost 주소를 사용합니다.
