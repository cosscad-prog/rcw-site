CPP  —  10_View

CPP

선택한 Surface의 법선 방향과 선택한 Edge Line의 방향을 함께 사용해 현재 활성 뷰포트의 작업 평면(CPlane)을 설정하는 명령입니다.

사용 목적

두 Surface 또는 기준 객체 관계를 이용해 CPlane을 더 명확하게 잡아야 할 때 사용하는 보조 작업평면 설정 명령입니다. 단일 면 기준 CP로 방향이 부족할 때 활용합니다.

사용 방법

  1. Rhino 명령창에 CPP를 입력하고 Enter를 누릅니다.
  2. Select Surface Brep Objects 프롬프트에서 CPlane의 면 방향 기준이 될 Surface를 선택합니다.
  3. Select Edge Line 프롬프트에서 CPlane의 원점과 X축 기준이 될 Edge를 선택합니다.
  4. 선택 Surface와 Edge 기준으로 활성 뷰포트의 CPlane이 변경됩니다.

동작 기준

항목설명
Surface 선택선택한 Surface의 면적 중심점을 구하고, 중심점에서 가장 가까운 UV 위치의 Normal을 CPlane의 Z 방향 기준으로 사용합니다.
Edge 선택선택한 Edge Curve의 시작점을 CPlane 원점으로 사용합니다.
X축 기준선택한 Edge Curve의 시작점 Tangent 방향을 CPlane X축으로 사용합니다.
Y축 기준Surface Normal 방향과 Edge X축 방향의 외적(Z_Vec x X_Vec)으로 Y축을 계산합니다.
적용 범위현재 활성 뷰포트의 Construction Plane만 변경합니다.
View 변경화면 View 방향은 변경하지 않습니다. 작업 평면만 변경합니다.

실행 결과

항목설명
처리 결과선택 Edge의 시작점을 원점으로 하고, Edge 방향을 X축으로 하는 CPlane이 활성 뷰포트에 적용됩니다.
Grid 설정명령 내부에서 CPlane Grid Line Count는 10, Grid Spacing은 10으로 설정합니다.
참고: Surface와 Edge를 모두 올바르게 선택해야 의도한 CPlane이 만들어집니다. Edge의 시작점 방향이 원점과 X축을 결정하므로, 반대 방향이 필요하면 반대 방향의 Edge를 선택하세요.
