CP

선택한 Surface의 방향을 기준으로 현재 활성 뷰포트의 작업 평면(CPlane)을 설정하는 명령입니다.

사용 목적

선택한 Surface의 중심과 법선 방향을 기준으로 현재 뷰포트의 CPlane만 맞출 때 사용합니다. View 방향은 유지한 채 작업 평면만 면에 붙이고 싶을 때 적합합니다.

사용 방법

  1. Rhino 명령창에 CP를 입력하고 Enter를 누릅니다.
  2. Select Surface Brep Objects 프롬프트에서 기준이 될 Surface를 선택합니다.
  3. 선택한 Surface의 중심과 법선 방향을 기준으로 활성 뷰포트의 CPlane이 변경됩니다.

동작 기준

항목설명
선택 대상Surface/Brep Face를 선택합니다.
CPlane 원점선택한 Surface의 면적 중심점(AreaMassProperties.Centroid)을 사용합니다.
CPlane 방향Surface 중심점에서 가장 가까운 UV 위치를 찾고, 그 위치의 Surface Normal을 CPlane의 법선 방향으로 사용합니다.
적용 범위현재 활성 뷰포트의 Construction Plane만 변경합니다.
View 변경화면 View 방향은 변경하지 않습니다. 작업 평면만 변경합니다.

실행 결과

항목설명
처리 결과선택 Surface에 맞는 CPlane이 활성 뷰포트에 적용되고 화면이 다시 그려집니다.
Grid 설정명령 내부에서 CPlane Grid Line Count는 10, Grid Spacing은 10으로 설정합니다.
참고: Surface 선택이 취소되거나 Surface 중심/법선 계산에 실패하면 코드의 기본 Plane 값이 사용될 수 있습니다. 정확한 결과를 위해 유효한 Surface Face를 선택하세요.
