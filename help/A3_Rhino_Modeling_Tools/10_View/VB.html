VB

선택한 Curve 또는 Line의 시작점과 끝점 방향을 기준으로 현재 활성 뷰포트의 작업 평면(CPlane)을 설정하는 명령입니다.

사용 목적

선택 객체의 BoundingBox나 배치 상태를 기준으로 보기 방향 또는 작업 기준을 빠르게 맞춰, 모델 검토와 후속 작업을 편하게 할 때 사용합니다.

사용 방법

  1. Rhino 명령창에 VB를 입력하고 Enter를 누릅니다.
  2. CPlane 기준으로 사용할 사선을 선택하세요 프롬프트에서 기준 Curve를 선택합니다.
  3. 선택한 Curve의 시작점이 CPlane 원점이 되고, 시작점에서 끝점으로 향하는 방향이 CPlane X축이 됩니다.

동작 기준

항목설명
선택 대상Curve 객체를 선택합니다. 직선이 아니어도 선택할 수 있지만, 실제 기준은 Curve의 시작점과 끝점을 잇는 방향입니다.
CPlane 원점선택 Curve의 시작점(PointAtStart)을 사용합니다.
X축 기준선택 Curve의 시작점에서 끝점(PointAtEnd)으로 향하는 단위 벡터를 사용합니다.
Y축 기준World Z축과 X축의 외적(WorldZ x XAxis)으로 Top View에서 X축에 수직인 방향을 계산합니다.
Z축 평행 예외선택한 선이 World Z축과 평행해 Y축을 계산할 수 없으면 World Y축을 Y축으로 대체합니다.
적용 범위현재 활성 뷰포트의 Construction Plane만 변경합니다.

실행 결과

항목설명
처리 결과선택 Curve 시작점을 원점으로 하고, 시작점에서 끝점 방향을 X축으로 하는 CPlane이 활성 뷰포트에 적용됩니다.
View 변경화면 View 방향은 변경하지 않습니다. 작업 평면만 변경하고 화면을 다시 그립니다.
명령창 출력성공 시 CPlane 원점, X축, Y축 정보가 명령창에 출력됩니다.
주의: 시작점과 끝점이 같은 Curve는 CPlane을 만들 수 없습니다. 또한 곡선을 선택한 경우 곡선의 실제 접선이 아니라 시작점과 끝점을 잇는 방향이 X축으로 사용됩니다.
