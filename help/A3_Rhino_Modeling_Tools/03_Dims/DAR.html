DAR  —  03_Dims

DAR

Rhino의 Linear Dimension 입력을 호출하여 일반 선형 치수를 작성하는 명령입니다. 코드 주석상 DR과 같은 성격의 치수 명령입니다.

사용 목적

사용자가 직접 두 점과 치수 위치를 지정해 Linear Dimension을 만들 때 사용합니다. 자동 치수 기준점이 준비되지 않은 임시 측정이나 수동 보정 치수에 적합합니다.

사용 방법

  1. Rhino 명령창에 DAR를 입력합니다.
  2. Rhino Linear Dimension 방식으로 첫 점, 두 번째 점, 치수선 위치를 지정합니다.
  3. 지정한 위치에 Linear Dimension이 생성됩니다.

주요 내용

항목설명
기능사용자가 지정한 점과 위치로 Linear Dimension을 생성합니다.
생성 Layer명령 실행 시 DIMS Layer를 준비합니다.
참조 차이참조 폴더의 1.DArc.htm은 Delete Arc 설명이며, 현재 코드의 DAR 동작과 다릅니다. 이 문서는 코드 동작을 기준으로 정리했습니다.
참고: DST/DSR/DSL/DSB처럼 Dim_Points 기반 자동 치수를 만들 때와 달리, DAR은 사용자가 직접 치수 위치를 지정합니다.
