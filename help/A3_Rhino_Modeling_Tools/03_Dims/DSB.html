DSB

Dim_Points Layer의 Point를 선택하여 Bottom 방향 Linear Dimension을 생성하는 명령입니다.

사용 목적

Dim_Points 레이어에 준비된 기준점을 이용해 하단 방향 치수를 자동 생성할 때 사용합니다. 패널이나 부재의 아래쪽 기준 치수를 반복 작성할 때 유용합니다.

사용 방법

  1. PP 또는 HPP로 Dim_Points Point를 준비합니다.
  2. DSB를 실행하고 치수에 사용할 Point 객체들을 선택합니다.
  3. 선택된 Point 중 가장 아래쪽 Z 위치를 기준으로 Bottom 방향 치수가 생성됩니다.
