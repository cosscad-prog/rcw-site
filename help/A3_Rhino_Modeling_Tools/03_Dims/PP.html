PP

마우스로 지정한 위치에 Dim_Points Layer의 Point를 하나 생성하는 명령입니다.

사용 목적

사용자가 직접 찍은 위치에 Dim_Points 레이어 Point를 추가해 자동 치수 기준점을 보완할 때 사용합니다. HPP로 잡히지 않는 임의 기준점 추가에 적합합니다.

사용 방법

  1. Rhino 명령창에 PP를 입력합니다.
  2. Click for new point 프롬프트에서 치수 기준점 위치를 클릭합니다.
  3. 클릭한 위치에 Dim_Points Layer Point가 생성됩니다.

주요 내용

항목설명
기능Dim_Points Layer Point를 직접 생성합니다.
사용 목적DST, DSR, DSL, DSB 실행 시 사용할 치수 기준점을 준비합니다.
가공도 활용FDwg 등 가공도 작성 시 필요한 위치에 미리 추가하면 치수 생성이 편리합니다.
참고: 여러 점을 자동 생성하려면 객체의 끝점, Node, 중심점을 읽는 HPP를 함께 사용합니다.
