HPP  —  03_Dims

HPP

선택한 선, Polyline, Circle, Arc의 주요 위치에 Dim_Points Layer Point를 자동 생성하는 명령입니다.

사용 목적

선택 객체의 끝점, 노드, 중심점 등 치수에 필요한 후보 위치를 Dim_Points 레이어 Point로 자동 생성할 때 사용합니다. 방향별 자동 치수 명령을 실행하기 전 기준점을 준비하는 명령입니다.

사용 방법

  1. Rhino 명령창에 HPP를 입력합니다.
  2. 치수 기준점을 만들 객체를 선택합니다.
  3. 객체 종류에 따라 끝점, Node, 중심점에 Dim_Points가 생성됩니다.

실행 예시

생성 기준

객체생성 위치
Line시작점과 끝점에 Dim_Points를 생성합니다.
PolyLine각 Node 위치에 Dim_Points를 생성합니다.
Circle원의 중심점에 Dim_Points를 생성합니다.
ArcArc의 중심점에 Dim_Points를 생성합니다.

주요 내용

항목설명
사용 목적DST, DSR, DSL, DSB에서 사용할 치수 기준점을 빠르게 준비합니다.
가공도 활용FDwg 등 가공도 작성에 필요한 치수점을 미리 추가할 때 유용합니다.
참고: 원하는 임의 위치에 Point 하나만 찍을 때는 PP를 사용합니다.
