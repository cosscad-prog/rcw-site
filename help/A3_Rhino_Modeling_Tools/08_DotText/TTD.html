TTD  —  08_DotText

TTD

선택한 일반 Text를 DotText 객체로 변환하는 명령입니다.

사용 목적

항목설명
DotText 변환선택된 일반 Text를 DotText로 변환합니다.
표시 크기DotText 크기는 TTS 명령으로 조절합니다.
기준 표기번호, 기준점, 반복 DotText 작업에 사용할 Text를 DotText 형식으로 바꿀 때 사용합니다.

사용 방법

  1. Rhino 명령창에 TTD를 입력하고 Enter를 누릅니다.
  2. DotText로 변환할 Text를 선택합니다.
  3. 선택을 완료합니다.
  4. 변환된 DotText 객체를 Rhino 화면에서 확인합니다.

실행 예시

주요 내용

항목설명
입력일반 Text 객체
출력DotText 객체

실행 결과

항목설명
처리 결과선택 Text가 DotText로 변환됩니다.
확인 위치Rhino 화면에서 변환된 DotText 객체를 확인합니다.
참고: 선택한 일반 Text의 PlainText를 읽어 BoundingBox 중심에 TextDot을 만들고, 변환이 성공하면 원래 Text는 삭제합니다. Text 서식은 보존되지 않고 문자열만 DotText로 옮겨집니다.
