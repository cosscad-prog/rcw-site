Dotlist

선택한 DotText를 이름별 수량 List로 정리해 표시하는 명령입니다.

사용 목적

항목설명
수량 목록선택 DotText를 이름별로 집계하여 수량 List를 작성합니다.
표시 크기List Text 크기는 TTS 명령으로 조절합니다.
검토 보조DotText 번호나 이름별 개수를 빠르게 확인할 때 사용합니다.

사용 방법

  1. Rhino 명령창에 Dotlist를 입력하고 Enter를 누릅니다.
  2. 목록으로 정리할 DotText들을 선택합니다.
  3. 선택을 완료합니다.
  4. 이름별 수량으로 작성된 DotText List를 확인합니다.
