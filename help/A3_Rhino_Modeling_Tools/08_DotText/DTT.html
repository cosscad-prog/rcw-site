DTT  —  08_DotText

DTT

선택한 DotText를 일반 Text 객체로 변환하는 명령입니다.

사용 목적

항목설명
Text 변환선택된 DotText를 일반 Text로 변환합니다.
표시 크기변환 Text 크기는 TTS 명령으로 조절합니다.
후속 편집DotText가 아닌 일반 Text로 편집하거나 출력해야 할 때 사용합니다.

사용 방법

  1. Rhino 명령창에 DTT를 입력하고 Enter를 누릅니다.
  2. Text로 변환할 DotText를 선택합니다.
  3. 선택을 완료합니다.
  4. 변환된 일반 Text 객체를 Rhino 화면에서 확인합니다.

실행 예시

주요 내용

항목설명
입력DotText 객체
출력일반 Text 객체

실행 결과

항목설명
처리 결과선택 DotText가 일반 Text로 변환됩니다.
확인 위치Rhino 화면에서 변환된 Text 객체를 확인합니다.
참고: 변환 후 원래 TextDot은 삭제되고, 같은 중심 위치에 일반 Text가 생성됩니다. 문자 크기는 현재 DimStyle의 TextHeight를 사용하되 10보다 작으면 10으로 보정합니다.
