DotDist

선택한 정수 DotText 사이의 거리를 산출하는 명령입니다.

사용 목적

항목설명
거리 산출선택된 정수 DotText 간의 거리를 계산합니다.
표시 크기결과 Text 크기는 TTS 명령으로 조절합니다.
검토 보조DotText 기준점 사이의 간격 확인이 필요할 때 사용합니다.

사용 방법

  1. Rhino 명령창에 DotDist를 입력하고 Enter를 누릅니다.
  2. 거리 산출에 사용할 정수 DotText들을 선택합니다.
  3. 선택을 완료합니다.
  4. DotText 간 거리 산출 결과를 Rhino 화면에서 확인합니다.

실행 예시

주요 내용

항목설명
대상 객체정수 값을 가진 DotText
출력 내용선택한 DotText 간 거리 값

실행 결과

항목설명
처리 결과선택한 DotText 사이의 거리가 산출됩니다.
확인 위치Rhino 화면에 표시된 거리 Text를 확인합니다.
참고: DotText의 문자값이 1, 2처럼 순번일 때 그 번호쌍의 거리를 계산합니다. 거리가 0.5 이하인 쌍은 제외하고, 결과 표는 선택한 위치에서 Text 레이어에 작성됩니다.
