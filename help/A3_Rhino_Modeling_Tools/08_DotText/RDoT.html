RDoT  —  08_DotText

RDoT

DotText 문자를 정수 번호로 반복 생성하는 명령입니다.

사용 목적

항목설명
반복 생성DotText 문자를 정수 번호로 반복해서 생성합니다.
시작 번호Option에서 시작 번호를 지정하여 번호 체계를 정합니다.
번호 배치여러 위치에 순차 번호 DotText를 빠르게 배치할 때 사용합니다.

사용 방법

  1. Rhino 명령창에 RDoT를 입력하고 Enter를 누릅니다.
  2. Option에서 시작 번호를 지정합니다.
  3. DotText를 배치할 위치를 순서대로 지정합니다.
  4. 반복 생성된 정수 DotText를 Rhino 화면에서 확인합니다.

입력시작 번호와 DotText 배치 위치
생성 객체순차 정수 DotText

실행 결과

참고: 클릭할 때마다 1부터 Repeat_Number까지 반복되는 TextDot을 생성합니다. 번호 카운터는 명령 실행 중 유지되며, 반복 수를 넘으면 다시 1부터 시작합니다.
