InterPt

선택한 Surface와 Line이 서로 만나는 위치에 Point를 생성하는 명령입니다.

사용 목적

항목설명
교차점 확인Surface와 Line의 교차 위치를 Point로 표시합니다.
기준점 작성후속 모델링이나 검토 작업에서 사용할 교차 기준점을 생성합니다.
검토 보조Line이 Surface와 실제로 만나는 위치를 화면에서 직접 확인할 수 있습니다.

사용 방법

  1. Rhino 명령창에 InterPt를 입력하고 Enter를 누릅니다.
  2. 교차 위치를 찾을 Surface를 선택합니다.
  3. Surface와 만나는 Line을 선택합니다.
  4. Surface와 Line이 만나는 위치에 생성된 Point를 Rhino 화면에서 확인합니다.
