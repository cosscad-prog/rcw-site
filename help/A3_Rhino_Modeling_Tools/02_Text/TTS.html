TTS

RCW 명령들이 생성하는 Text의 기준 크기 값을 저장하는 명령입니다. CCText, Tlist 등 Text를 새로 만드는 명령에서 이 값을 사용합니다.

사용 목적

선택한 Text의 크기를 한 번에 조정해 도면 표기 크기를 통일할 때 사용합니다. 출력 전 TextHeight를 정리하는 용도에 적합합니다.

사용 방법

  1. Rhino 명령창에 TTS를 입력합니다.
  2. Enter Text Size 프롬프트에서 사용할 Text Size 값을 입력합니다.
  3. Enter를 누르면 입력한 값이 현재 세션의 Text Size로 저장됩니다.

주요 내용

항목설명
기능TextSize 변수를 입력한 값으로 저장합니다.
기본값현재 저장된 Text Size가 프롬프트의 기본값으로 표시됩니다.
DimStyle 기준일부 Text 생성 명령은 TTS 값과 현재 DimStyle의 TextHeight × DimensionScale 값을 비교하여 더 큰 값을 사용합니다.

적용되는 명령

명령설명
CCText원문자 번호의 Text 크기에 사용됩니다.
TlistText 수량 List의 Table/Text 크기에 사용됩니다.
기타 Text 명령RCW 내부에서 TextSize_CurrentDim을 사용하는 Text 작성 명령에 적용됩니다.
참고: 문자 크기 변경은 선택 Text의 내용이 아니라 TextEntity의 높이 값을 조정하는 작업입니다. 이후 DTT로 일반 Text를 만들 때도 현재 DimStyle 문자 높이가 함께 영향을 줍니다.
