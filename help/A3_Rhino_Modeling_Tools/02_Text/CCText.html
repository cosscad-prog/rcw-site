CCText

원 안에 번호가 들어간 Circle Text를 연속으로 생성하는 명령입니다. 시작 번호를 입력하면 점을 찍을 때마다 번호가 1씩 증가합니다.

사용 목적

원형 표식과 Text를 함께 만들어 번호표, 위치표식, 가공도 표기처럼 시각적으로 구분되는 문자 마커를 빠르게 배치할 때 사용합니다.

사용 방법

  1. Rhino 명령창에 CCText를 입력합니다.
  2. 시작할 번호를 입력합니다. 기본값은 1입니다.
  3. 화면에서 위치를 클릭하면 해당 번호의 원문자가 생성됩니다.
  4. 다음 위치를 계속 클릭하면 번호가 순차적으로 증가합니다.
  5. Enter 또는 취소로 명령을 종료합니다.

주요 내용

항목설명
기능숫자가 들어간 Circle Text를 생성합니다.
번호 증가한 번 클릭할 때마다 현재 번호로 Text를 만들고, 다음 번호로 자동 증가합니다.
Text 크기TTS 명령으로 저장한 Text Size를 사용합니다. 현재 DimStyle TextHeight와 DimensionScale보다 작으면 DimStyle 기준 크기가 우선됩니다.
참고: 원형 번호 표식은 현재 문자 크기와 선택 위치를 기준으로 만들어집니다. 여러 표식을 같은 스타일로 배치하려면 먼저 DimStyle의 TextHeight를 맞춘 뒤 실행하는 것이 좋습니다.
