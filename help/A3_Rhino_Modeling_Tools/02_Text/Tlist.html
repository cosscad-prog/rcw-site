Tlist

선택된 Text의 내용을 이름별로 집계하여 수량 List를 만드는 명령입니다. 같은 Text 문자열을 모아 개수를 계산하고 Rhino 화면에 표 형태로 작성합니다.

사용 목적

선택한 Text 문자열을 화면에 리스트로 작성해 동일 표기의 수량이나 표기 누락 여부를 빠르게 검토할 때 사용합니다.

사용 방법

  1. Rhino 명령창에 Tlist를 입력합니다.
  2. List로 만들 Text Annotation들을 선택합니다.
  3. 명령 프롬프트에 따라 List를 배치할 위치를 지정합니다.
  4. 선택한 Text의 이름별 수량 List가 화면에 생성됩니다.
