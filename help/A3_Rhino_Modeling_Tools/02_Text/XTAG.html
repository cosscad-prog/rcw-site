XTAG

텍스트 생성, 정렬, 크기 변경, 텍스트 리스트 작성을 위한 도구 명령입니다.

사용 목적

Text 객체의 X 위치를 기준으로 표기를 정렬해, 수직 방향으로 나열된 도면 문자나 태그 위치를 깔끔하게 맞출 때 사용합니다.

사용 방법

  1. Rhino 명령창에 XTAG를 입력하고 Enter를 누릅니다.
  2. 명령 프롬프트에 따라 대상 객체를 선택합니다.
  3. Enter를 눌러 명령을 완료하고 Rhino 화면 또는 명령창 결과를 확인합니다.
참고: XTAG는 Text의 X 위치를 기준으로 정렬하는 보조 명령입니다. 문자 내용은 바꾸지 않고 배치 좌표만 정리하므로, 정렬 전에 기준이 될 Text 위치를 먼저 확인하십시오.
