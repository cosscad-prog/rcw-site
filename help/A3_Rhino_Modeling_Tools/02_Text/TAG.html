TAG

선택한 Text들을 한 줄 간격으로 정렬하는 명령입니다. Front View 기준에서는 Z 방향으로, Top View 기준에서는 Y 방향으로 정리합니다.

사용 목적

흩어져 있는 Text 객체를 일정한 기준으로 정렬해 도면 표기를 보기 좋게 정리할 때 사용합니다. 문자 내용은 유지하고 배치 상태만 정돈합니다.

사용 방법

  1. 정렬할 Text Annotation들을 선택할 수 있는 View에서 TAG를 실행합니다.
  2. 정렬할 Text 객체들을 선택합니다.
  3. 선택한 Text 중 가장 낮은 위치의 Text를 기준으로 일정 간격으로 재배치됩니다.

주요 내용

항목설명
기능선택된 Text Annotation을 위치 기준으로 정렬합니다.
정렬 간격첫 번째 기준 Text의 높이를 기준으로 약 1.6배 간격을 적용합니다.
View 기준Front View에서는 Z 방향으로, Top View에서는 Y 방향으로 정렬됩니다.
참고: Text 정렬 계열 명령은 객체 내용을 수정하지 않고 위치를 재배치합니다. 표기 순서가 중요한 경우 정렬 전에 기준 Text와 선택 범위를 먼저 정리해 두십시오.
