HoleCylinder

선택한 Solid Object에 Hole이 있으면, Hole 위치에 직경과 길이를 조정한 새 Cylinder를 생성하는 명령입니다.

사용 목적

항목설명
Hole 검출선택된 Solid Object의 Hole 위치를 기준으로 Cylinder를 만듭니다.
직경 변경기존 Hole 직경을 변경하거나 가공 기준 Cylinder를 다시 만들 때 사용합니다.
길이 조정Hole 위치마다 필요한 길이의 Cylinder를 생성하여 후속 모델링 기준으로 사용합니다.

사용 방법

  1. Rhino 명령창에 HoleCylinder를 입력하고 Enter를 누릅니다.
  2. Hole을 포함한 Solid Object를 선택합니다.
  3. 명령 프롬프트에 따라 Cylinder 생성에 필요한 값을 입력합니다.
  4. Hole 위치에 생성된 Cylinder의 직경과 길이를 Rhino 화면에서 확인합니다.

주요 내용

항목설명
대상 객체Hole을 포함한 Solid Object
생성 객체Hole 위치에 생성되는 새 Cylinder

실행 결과

항목설명
처리 결과선택된 Solid Object의 Hole 위치에 직경과 길이가 조정된 Cylinder가 생성됩니다.
확인 위치Rhino 화면에서 Hole 위치에 생성된 Cylinder 객체를 확인합니다.
참고: 원통 Face의 축과 중심을 읽어 별도 Cylinder Brep를 생성합니다. Cylinder_Diameter와 Cylinder_Length 옵션은 생성될 표시용 실린더 크기이며, 원래 구멍 반지름을 그대로 복사하는 방식은 아닙니다.
