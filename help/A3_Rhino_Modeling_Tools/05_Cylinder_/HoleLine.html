HoleLine

선택한 Solid Object에 Hole이 있으면, 각 Hole의 Center Line을 생성하는 명령입니다.

사용 목적

항목설명
Hole 검출선택된 Solid Object의 Hole 위치를 기준으로 Center Line을 찾습니다.
중심선 작성각 Hole의 중심 방향을 나타내는 Line을 생성합니다.
후속 기준Hole 위치 확인, 가공 기준선 작성, Cylinder 생성 전후 검토에 사용할 수 있습니다.

사용 방법

  1. Rhino 명령창에 HoleLine를 입력하고 Enter를 누릅니다.
  2. Hole을 포함한 Solid Object를 선택합니다.
  3. 명령 프롬프트에 따라 선택을 완료합니다.
  4. 각 Hole 중심에 생성된 Center Line을 Rhino 화면에서 확인합니다.

실행 예시

주요 내용

항목설명
대상 객체Hole을 포함한 Solid Object
생성 객체Hole 중심을 지나는 Center Line

실행 결과

항목설명
처리 결과선택된 Solid Object의 Hole마다 Center Line이 생성됩니다.
확인 위치Rhino 화면에서 Hole 중심을 지나는 Line 객체를 확인합니다.
참고: 선택 Brep 안에서 원통면으로 인식되는 Face만 처리합니다. 같은 구멍의 양쪽 원통면처럼 중심이 0.2 이내로 겹치는 경우는 중복 생성을 막기 위해 하나의 중심선만 만듭니다.
