Strim  —  09_Trim

Strim

선택한 Solid 또는 Brep 객체를 Surface/Brep 기준으로 Trim하고, 열린 절단면을 Cap 처리하여 Closed PolySurface 형태로 정리하는 명령입니다.

사용 목적

커튼월 부재, 패널, 브래킷 등 솔리드 모델을 기준 Surface 방향으로 잘라 필요한 쪽의 형상만 남길 때 사용합니다. 절단 후 가능한 경우 Fill Cap을 수행하여 Open PolySurface가 Solid 상태로 유지되도록 보정합니다.

사용 방법

  1. Rhino 명령창에 Strim를 입력하고 Enter를 누릅니다.
  2. Select Cutted Brep Objects 프롬프트에서 절단할 대상 Brep 또는 Solid 객체를 하나 이상 선택합니다.
  3. Select Cutting Surface Brep Object 프롬프트에서 절단 기준이 되는 Surface 또는 Brep를 선택합니다.
  4. Surface 기준으로 절단할 때 표시되는 빨간 방향 화살표를 확인합니다. 기본 방향을 사용할 경우 Enter를 누르고, 반대 방향으로 처리하려면 R 옵션을 선택합니다.
  5. 절단 결과와 명령창의 Brep_Count, Sucess_Count 메시지를 확인합니다.

주요 내용

항목설명
절단 대상Trim할 Brep 또는 Solid 객체를 다중 선택할 수 있습니다.
절단 기준Surface 객체를 기준 Plane으로 사용하거나, Brep Surface 자체를 기준으로 Trim합니다.
방향 옵션R 옵션으로 Org_Directon과 Reverse_Directon을 전환하여 남길 방향을 조정합니다.
Arrow_Length절단 Surface의 방향 화살표 표시 길이를 조정하는 옵션입니다.
데이터 유지Section, Vector, Profile, Bracket ID 사용자 데이터와 객체 속성을 새 Brep에 복사합니다.

실행 결과

항목설명
처리 결과선택 객체가 기준 Surface/Brep에 의해 Trim되며, 열린 절단면은 가능한 경우 CapPlanarHoles로 닫힌 Solid로 변환됩니다.
객체 처리새 Trim 결과 객체가 생성되고 원본 대상 Brep는 삭제됩니다. 새 객체는 원본 레이어와 속성을 이어받습니다.
확인 위치Rhino 화면의 절단 결과 형상과 명령창의 Trim By Surface, CapPlanarHoles Success, 처리 개수 메시지에서 확인합니다.
참고: 절단 기준 Surface의 노멀 방향에 따라 남는 형상이 달라질 수 있으므로, 실행 중 표시되는 방향 화살표를 확인한 뒤 필요하면 R 옵션으로 방향을 바꾸십시오.
