SFB  —  18_Insert_Frame

SFB

프레임 양식(Frame Form) 블록을 선택하여 메모리에 저장하는 Rhino 명령입니다.
이후 FFB 실행 시 이 Frame Form을 기준으로 선택 도면에 맞는 스케일과 위치에 자동 삽입합니다.

사용 목적

회사별 프레임 양식 블록을 미리 선택해 두면, 이후 FFB가 도면 크기에 맞는 스케일을 자동으로 계산하여 Frame Form을 삽입합니다. SFB는 Form 선택만 담당하며, 선택된 블록·텍스트 플레이스홀더·폴리라인 정보를 현재 Rhino 세션의 메모리에 저장합니다.

Frame Form 내에 필요한 구성 요소

구성 요소역할
Block Instance도면 양식 블록 본체입니다. SFB 선택 범위에 포함해야 합니다.
Point 2개 (블록 정의 내부)도면이 들어갈 내부 영역의 최소/최대 기준점입니다. 없으면 블록 BoundingBox 전체를 기준으로 사용합니다.
Text — DWG_NO, DWG-NO, DWGNO도면 번호 표기 플레이스홀더입니다. FFB가 도면 이름 텍스트로 교체합니다.
Text — Scale 레이어 또는 내용이 SCALE스케일 표기 플레이스홀더입니다. FFB가 자동 계산한 스케일 문자열(1 / N)로 교체합니다.
Text — Qnt 레이어 또는 내용이 QNT수량 표기 플레이스홀더입니다. FFB가 도면에서 읽은 수량 텍스트로 교체합니다.
Text — SIZE_W, SIZE_H, PAD_W, PAD_H, LENGTH패널 크기, 패드 크기, 길이 값을 자동 기입할 플레이스홀더입니다.
PolylineCurve프레임 경계 폴리라인입니다. 닫힌 폴리라인을 우선 저장하며, FFB가 Form과 함께 복사하여 배치합니다.

사용 방법

  1. Rhino 파일에 Frame Form 블록과 텍스트 플레이스홀더, 폴리라인이 배치되어 있는지 확인합니다.
  2. Rhino 명령창에 SFB를 입력하고 Enter를 누릅니다.
  3. "SFB: Frame Form을 선택하세요 (블록, 폴리라인, 텍스트 포함)" 프롬프트에서 Form 블록·텍스트·폴리라인을 모두 포함하여 선택하고 Enter를 누릅니다.
  4. 선택된 Frame Form 정보가 메모리에 저장됩니다. 이후 FFB로 도면에 Frame Form을 삽입합니다.

외부 3dm 파일로 양식 등록 (FDstyle 패널 [도면양식] 버튼)

화면에서 직접 선택하는 SFB 외에, FDstyle 패널의 [도면양식] 버튼으로 미리 만들어 둔 외부 3dm 양식 파일을 등록할 수도 있습니다. 같은 Frame Form 메커니즘이며 양식의 출처만 다릅니다.

단계동작
파일 선택파일 대화상자에서 양식 3dm 파일을 고르면 현재 문서로 가져옵니다(import).
사전 검사가져온 양식의 블록 이름이 기존 양식과 충돌하는지 미리 검사해, 문제가 있으면 알려줍니다.
자동 고유 이름블록 이름이 겹치면 자동으로 고유 이름을 부여해, 서로 다른 양식(예: Profile_A용·Profile_B용)이 섞이지 않게 합니다.
화면 격리등록된 양식 템플릿은 숨김 처리되어 화면을 어지럽히지 않습니다. (삽입된 양식은 정상 표시)
참고: 외부 파일로 등록한 양식도 문서(.3dm)에 함께 저장되어, 다시 열어도 자동 복원됩니다. 서로 다른 양식 파일을 여러 개 등록하면 각각 고유 이름으로 공존합니다.

주요 내용

항목설명
선택 대상Annotation, Curve, InstanceReference를 선택합니다. 블록, 텍스트, 폴리라인을 함께 선택해야 합니다.
저장 내용블록 이름, 블록 위치, 블록 배율, 텍스트 플레이스홀더 ID, 폴리라인 ID를 메모리에 보관합니다.
폴리라인 선택선택 객체 중 닫힌 PolylineCurve가 있으면 우선 저장하고, 없으면 첫 번째 PolylineCurve를 저장합니다.
기타 텍스트위 플레이스홀더에 해당하지 않는 텍스트는 내용 그대로 복사되는 속성 텍스트로 저장합니다.
적용 환경Rhino
참고: SFB는 Frame Form 정보를 저장만 하며 도면에 새 객체를 삽입하지 않습니다. 실제 Frame Form 삽입은 FFB(또는 FDstyle 패널의 [양식삽입])로 수행합니다. 양식 정보는 현재 문서(.3dm)에 함께 저장되어, 파일을 닫았다 다시 열어도 자동으로 복원됩니다 — 같은 파일에서는 다시 등록할 필요가 없습니다. (단, 등록된 양식 템플릿 객체를 삭제하면 다시 등록해야 합니다.)
주의: Frame Form 블록 안에 필요한 텍스트 플레이스홀더가 없으면 FFB 실행 시 해당 항목이 채워지지 않습니다.
