FLOpt

FLdata로 입력된 층 Data와 일정 Data를 층/Block 단위로 정리해 보여주는 Floor Data 패널을 여는 명령입니다. 패널에서 표시 상태를 제어하고, Block 행을 더블클릭해 BIM 데이터를 수정할 수 있습니다.

사용 목적

BIM/Floor 데이터 입력과 관리에 필요한 기본 옵션을 설정해, FLData 작업 전에 데이터 입력 기준을 정리할 때 사용합니다.

사용 방법

  1. Rhino 명령창에 FLOpt를 입력하고 Enter를 누릅니다.
  2. Floor Data 패널이 열리며, 현재 문서의 RCW_Floor UserString을 가진 객체를 스캔합니다.
  3. 상단의 새로고침 버튼으로 데이터를 다시 읽습니다.
  4. 상단 역할 버튼(관리자, 설계, 생산, 설치)을 눌러 표시할 일정 역할을 전환합니다.
  5. Block 행을 더블클릭하면 해당 층+Block 이름의 객체들을 대상으로 BIM 데이터 입력 창이 열립니다.

패널 구성

항목설명
On층 또는 Block의 표시/잠금 상태를 토글하는 아이콘 열입니다.
Floor / 기준고층 행에는 층 번호와 기준고가 표시됩니다. Block 행에는 Block/객체 표시 이름이 표시됩니다.
Qty층 행은 해당 층 전체 객체 수, Block 행은 해당 층+Block 이름에 속한 객체 수를 표시합니다.
Progress현재 선택된 역할 기준의 진행 상태를 색상 박스로 표시합니다.
계획완료일현재 선택된 역할의 계획 완료일을 표시합니다. 층 행은 자식 Block 중 가장 늦은 날짜를 대표값으로 표시합니다.
실제완료일현재 선택된 역할의 실제 완료일을 표시합니다. 층 행은 자식 Block 중 가장 늦은 날짜를 대표값으로 표시합니다.

진행 상태 색상

상태기준
Grey선택 역할의 계획 시작일이 없으면 Not Started로 표시됩니다.
Yellow계획 시작일이 있으면 In Progress로 표시됩니다.
Green실제 완료일이 있고 그 날짜가 오늘 이하이면 Done으로 표시됩니다.

코드 기준 동작

항목설명
패널 실행FLOpt 명령은 FLPanelControl.PanelId 패널을 엽니다.
데이터 스캔문서 객체 중 삭제/숨김 객체를 제외하고 RCW_Floor UserString이 있는 객체를 층별로 분류합니다.
Block 이름Block Instance는 Instance Definition 이름을 표시 이름으로 사용하고, 일반 객체는 객체 이름을 사용합니다.
일정 복원객체 UserString 값을 우선 사용하고, 값이 없으면 doc.Strings에 저장된 층+Block 이름 백업 데이터에서 복원합니다.
더블클릭 편집Block 행을 더블클릭하면 같은 층 번호와 같은 표시 이름을 가진 객체들을 모아 Dlg_BimData로 편집합니다.
On/Off 토글On 열을 클릭하면 해당 층 또는 Block의 객체를 Lock/Unlock합니다. 객체를 숨기거나 삭제하지 않고 잠금 상태로 제어합니다.
패널 닫기패널이 닫힐 때 FLOpt에서 잠금 처리한 객체를 다시 Unlock하고 내부 Off 상태를 초기화합니다.
참고: FLOpt는 입력된 데이터를 조회/정리/수정하는 패널입니다. 새 객체에 BIM 데이터를 처음 입력하려면 FLdata를 먼저 사용하세요.
