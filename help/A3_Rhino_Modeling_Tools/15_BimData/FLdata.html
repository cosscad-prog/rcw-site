FLdata

선택한 Group 또는 Block 객체에 층 정보와 역할별 일정 데이터를 입력하는 명령입니다.

사용 목적

선택 객체에 저장된 BIM/Floor 관련 데이터를 확인하거나 편집해, 모델 객체와 층/구역/속성 정보를 함께 관리할 때 사용합니다.

사용 방법

  1. Rhino 명령창에 FLdata를 입력하고 Enter를 누릅니다.
  2. BIM 데이터를 설정할 객체 선택 (Group/Block) 프롬프트에서 데이터를 적용할 객체를 하나 이상 선택합니다.
  3. BIM 데이터 입력 창에서 층 정보와 일정 정보를 입력합니다.
  4. 확인을 누르면 선택 객체의 UserString에 BIM 데이터가 저장됩니다.

실행 예시

입력 데이터

항목설명
층 번호RCW_Floor로 저장됩니다. 양수는 nF, 0은 Ground, 음수는 BnF로 표시됩니다.
기준고RCW_Elevation으로 저장됩니다. 층의 기준 높이(mm)를 입력합니다.
관리자관리자 역할의 계획 시작/완료, 실적 시작/완료, 진행률을 입력합니다.
설계설계 역할의 계획 시작/완료, 실적 시작/완료, 진행률을 입력합니다.
생산생산 역할의 계획 시작/완료, 실적 시작/완료, 진행률을 입력합니다.
설치설치 역할의 계획 시작/완료, 실적 시작/완료, 진행률을 입력합니다.

코드 기준 동작

항목설명
선택 대상ObjectType.AnyObject를 선택하며 GroupSelect = true로 Group 선택도 허용합니다. SubObject 선택은 사용하지 않습니다.
기존값 로드첫 번째 선택 객체의 기존 UserString을 읽어 입력 창의 초기값으로 사용합니다.
객체 저장입력된 값은 선택된 모든 객체의 Attributes UserString에 저장됩니다. 빈 값은 해당 UserString을 삭제합니다.
문서 백업 저장층 번호와 Block/객체 표시 이름이 있으면 doc.Strings에도 일정 데이터를 이중 저장합니다. 블록 재생성 후에도 같은 층+이름이면 FLOpt에서 복원할 수 있습니다.
저장 Key층은 RCW_Floor, 기준고는 RCW_Elevation, 일정은 RCW_Sched_{역할}_{필드} 형식으로 저장됩니다.
참고: FLdata는 데이터를 입력/저장하는 명령입니다. 입력된 데이터를 층별, 블록별로 확인하고 수정하려면 FLOpt 패널을 사용합니다.
