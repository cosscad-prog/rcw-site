Acad_Join  —  AutoCAD 식 결합

Acad_Join

고른 것을 한 번에 결합합니다. Rhino 내장 Join 처럼 하나씩 다시 묻지 않습니다. 곡선은 물론 서피스·폴리서피스도 받습니다.

사용 목적

Rhino 의 Join 은 명령을 먼저 실행하면 대상을 하나 찍은 뒤 다음 것을 다시 찍게 합니다. AutoCAD 의 JOIN 에 익숙하면 이 흐름이 번거롭습니다. Acad_Join 은 윈도우·크로싱으로 여러 개를 한꺼번에 잡고 Enter 로 끝냅니다. 선택을 먼저 하고 명령을 실행하는 기존 방식도 그대로 됩니다.

사용 방법

  1. Acad_Join 을 실행합니다. (명령창: 결합할 곡선·서피스·폴리서피스 선택)
  2. 결합할 것을 고릅니다 — 하나씩 찍어도, 윈도우·크로싱으로 쓸어 담아도 됩니다. 최소 2개가 필요합니다.
  3. Enter 로 확정합니다.
선택을 먼저 해 두고 Acad_Join 을 실행해도 됩니다.

알아 둘 것

항목설명
곡선과 면을 함께 골라도 됩니다 곡선과 서피스는 서로 붙지 않으므로 같은 종류끼리만 결합합니다. 한쪽만 결합되면 그쪽만 반영합니다.
받는 것곡선 · 서피스 · 폴리서피스 · 압출(Extrusion). 압출은 결합할 때 Brep 으로 바꿔 처리합니다 (Rhino 내장 Join 도 같은 자리에서 그렇게 합니다).
결과의 속성가장 먼저 고른 것의 레이어·색을 따릅니다. Rhino 내장 Join 과 같은 규칙입니다.
붙는 기준모델 허용오차 안에서 끝점(곡선)·모서리(면)가 만나야 붙습니다.
모서리·면(서브오브젝트)결합 대상이 아니라 고를 수 없습니다.

안 될 때

명령창에 나오는 말뜻
결합하려면 같은 종류의 객체가 2개 이상 필요합니다. 곡선 1개 + 서피스 1개처럼 종류별로는 하나씩만 골랐습니다.
모델 허용오차 안에서 만나는 곡선 끝점이 없어 곡선은 결합되지 않았습니다. 끝점이 떨어져 있습니다. 허용오차를 확인하거나 끝점을 맞추십시오.
모델 허용오차 안에서 만나는 서피스 모서리가 없어 서피스는 결합되지 않았습니다. 면들의 모서리가 맞닿아 있지 않습니다.
결합에 성공하면 몇 개를 몇 개로 합쳤는지 명령창에 나옵니다 — 곡선 5개를 1개로 결합했습니다 처럼.

명령어설명
