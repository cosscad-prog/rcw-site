MSU

여러 Solid/Brep 대상에서 여러 Cutting Solid를 한 번에 Boolean Difference 처리하는 명령입니다. Rhino 기본 BooleanDifference와 유사하지만 Cutting Solid는 삭제하지 않습니다.

사용 목적

여러 절단 또는 Boolean Subtract 작업을 반복 적용해야 할 때, 대상과 차감 객체를 한 번에 처리해 모델 정리 시간을 줄이는 유틸리티입니다.

사용 방법

  1. Rhino 명령창에 MSU를 입력하고 Enter를 누릅니다.
  2. Select Cutted Solid Object(자르는 대상) 프롬프트에서 잘릴 대상 Solid/Brep을 선택합니다.
  3. Select Cutting Solid Object(자르는 기준) 프롬프트에서 빼낼 기준 Solid/Brep을 선택합니다.
  4. 각 대상 객체에 대해 선택한 Cutting Solid 전체를 사용해 Boolean Difference를 수행합니다.

항목설명
선택 대상잘릴 대상과 자르는 기준 모두 ObjectType.Brep 객체를 여러 개 선택합니다.
Boolean 처리각 대상 Brep을 하나씩 Brep.CreateBooleanDifference로 처리합니다. Cutting Brep 목록은 모든 대상에 공통으로 적용됩니다.
대상 객체Boolean 결과가 생성되면 새 Brep을 추가하고 기존 대상 객체는 삭제합니다.
Cutting 객체자르는 기준 객체는 삭제하지 않습니다.
속성 유지새 결과 객체에는 원본 대상 객체의 Attribute와 UserData를 복사합니다.
Hole 체크결과 객체의 원통 Face 중 지름이 3.5인 Hole을 찾으면 중심축 방향의 선을 생성합니다.
Hole 표시 LayerHole 중심선은 Layer 12 레이어에 생성되며, 레이어 색상은 Red로 설정됩니다.
참고: Cutting Solid는 유지되지만, 잘리는 대상 객체는 Boolean 성공 시 결과 객체로 대체됩니다. 원본 대상 형상을 보존해야 한다면 실행 전에 별도 복사본을 만들어 두세요.
