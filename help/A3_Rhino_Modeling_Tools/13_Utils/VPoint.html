VPoint

선택한 Solid/Brep 객체의 Vertex 위치를 실제 Point 객체로 표시하는 명령입니다.

사용 목적

Brep의 꼭짓점 위치를 Point로 추출해 치수 기준점, 검토점, 후속 스냅 기준으로 활용할 때 사용합니다.

사용 방법

  1. Rhino 명령창에 VPoint를 입력하고 Enter를 누릅니다.
  2. Select Brep Object for All Vertex 프롬프트에서 Vertex를 확인할 Brep 객체를 하나 이상 선택합니다.
  3. 선택한 Brep의 각 Vertex 위치에 Point 객체가 생성됩니다.

실행 예시

코드 기준 동작

항목설명
선택 대상ObjectType.Brep 객체를 여러 개 선택합니다.
Vertex 추출각 Brep의 Vertices 목록을 순회하며 BrepVertex.Location 값을 가져옵니다.
Point 생성각 Vertex 위치에 Rhino Point 객체를 추가합니다.
명령창 출력생성한 Vertex Point 수를 BrepVertex Count로 출력합니다.
주의: Rhino 기본 명령 SolidPtOn처럼 형상을 편집하는 제어점을 켜는 명령이 아닙니다. VPoint는 Vertex 위치 확인용 Point 객체를 생성할 뿐이며, 생성된 Point를 움직여도 원본 Solid/Brep 형상은 수정되지 않습니다.
