Erase  —  AutoCAD 식 지우기

Erase

객체를 지웁니다. AutoCAD 의 ERASE 와 같은 조작감으로, 명령을 먼저 실행하든 객체를 먼저 고르든 둘 다 그대로 동작합니다.

사용 목적

AutoCAD 를 오래 쓰신 분은 E → 선택 → Enter 순서가 손에 배어 있습니다. Rhino 의 Delete 는 고른 뒤 눌러야 하므로 그 순서가 어긋납니다. Erase 는 두 순서를 다 받아 손버릇을 바꾸지 않아도 되게 합니다.

사용 방법

순서동작
명령 먼저
Erase → 선택 → Enter		 명령창에 삭제할 객체 선택 이 나옵니다. 하나씩 찍어도 되고 윈도우·크로싱으로 한꺼번에 잡아도 됩니다. Enter 로 확정하면 지워집니다.
선택 먼저
선택 → Erase		 이미 골라 둔 것이 그대로 대상이 됩니다. 다시 고를 필요가 없습니다.

알아 둘 것

항목설명
지울 수 있는 것모든 종류의 객체입니다. 커브·서피스·솔리드·블록·치수·텍스트 가리지 않습니다.
groupgroup 에 묶인 것을 찍으면 group 전체가 잡힙니다.
모서리·면(서브오브젝트)고를 수 없습니다. 모서리나 면만 따로 지울 수는 없기 때문에 처음부터 막아 두었습니다.
되돌리기Undo 로 되돌아갑니다. Rhino 의 보통 삭제와 같습니다.
아무것도 고르지 않고 Enter 를 누르면 아무 일도 하지 않고 끝납니다. 잘못 실행했을 때는 Esc 로 빠져나오십시오.

관련 명령어

명령어설명
