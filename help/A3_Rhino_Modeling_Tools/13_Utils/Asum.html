Asum

선택한 Surface/Brep의 평면 Face 면적을 합산하고, 합계 값을 도면 위 Text로 작성하는 명령입니다.

사용 목적

선택한 Surface/Brep 면적을 합산해 패널, 유리, 백패널 등 면적 검토값을 빠르게 확인할 때 사용합니다.

사용 방법

  1. Rhino 명령창에 Asum을 입력하고 Enter를 누릅니다.
  2. Select Surface Object 프롬프트에서 면적을 합산할 Brep/Surface 객체를 하나 이상 선택합니다.
  3. 합계 Text를 작성할 위치를 찍습니다.
  4. 선택 객체의 면적 합계가 mm2와 M2 두 줄 Text로 작성됩니다.

실행 예시

코드 기준 동작

항목설명
선택 대상ObjectType.Brep 객체를 여러 개 선택합니다.
계산 대상각 Brep의 Face 중 현재 모델 허용오차 기준으로 IsPlanar인 평면 Face만 면적 합산에 포함합니다.
면적 출력명령창에는 객체 번호와 Face 번호별 면적이 SurFace Area 형식으로 출력됩니다.
도면 Text선택한 점을 기준으로 현재 CPlane에 맞춰 합계 mm2와 합계 M2 Text를 작성합니다.
LayerText는 Text 레이어에 작성됩니다. 레이어가 없으면 생성됩니다.
Text 크기현재 Dimension/Text 설정을 기준으로 Func.TextSize_CurrentDim()에서 가져옵니다.
참고: 비평면 Face는 합산에서 제외됩니다. 곡면까지 포함한 전체 Brep 면적 합계가 필요한 경우에는 Rhino 기본 면적 계산과 결과가 다를 수 있습니다.
