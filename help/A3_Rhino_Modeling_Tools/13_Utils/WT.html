WT

선택한 Surface의 단면 면적을 기준으로 재질별 단위 중량을 계산하고, 결과를 도면 위 Text로 작성하는 명령입니다.

사용 목적

선택 객체의 정보를 Text 형태로 화면에 작성해, 모델 안에서 이름이나 속성 정보를 직접 확인할 때 사용하는 보조 표기 명령입니다.

사용 방법

  1. Rhino 명령창에 WT를 입력하고 Enter를 누릅니다.
  2. Select surface 프롬프트에서 단위 중량을 계산할 Surface Face를 선택합니다.
  3. 결과 Text를 작성할 위치를 찍습니다.
  4. 면적과 재질별 단위 중량 Text가 선택 위치부터 아래 방향으로 작성됩니다.

실행 예시

계산 내용

항목설명
Area선택 Surface Face의 면적입니다. AreaMassProperties.Compute 결과를 사용합니다.
AL Weightarea * 2.71 * 0.001로 계산합니다.
Steel Weightarea * 7.86 * 0.001로 계산합니다.
PA Weightarea * 1.3 * 0.001로 계산합니다.
GA Weightarea * 1.15 * 0.001로 계산합니다.

코드 기준 동작

항목설명
선택 대상ObjectType.Surface로 Surface Face 하나를 선택합니다.
Text 작성Area, AL Weight, Steel Weight, PA Weight, GA Weight를 5줄 Text로 작성합니다.
LayerText는 Text 레이어에 작성됩니다. 레이어가 없으면 생성됩니다.
Text 크기현재 Dimension/Text 설정을 기준으로 Func.TextSize_CurrentDim()에서 가져옵니다.
배치 방식선택한 점에서 시작해 현재 CPlane 기준 Y 방향 아래로 줄 간격을 두고 Text를 배치합니다.
참고: 출력 단위 표기는 코드상 mm²와 Kg/m로 작성됩니다. 계산식은 선택 Surface의 모델 면적 값을 그대로 사용합니다.
