Mullion Line  —  Wire Frame 요소

MC1 ~ MCXX

Mullion Line은 Wire Frame에서 세로 방향 Mullion 기준선을 정의하는 요소입니다.
M_Center1부터 M_CenterXX까지의 레이어명을 사용해 Mullion 중심선을 구분합니다.

사용 목적

세로 부재(Mullion)의 중심선을 M_Center 레이어 체계로 정리해, 이후 단면 배치와 Unit 모델링(UMD)이 세로 기준선을 올바르게 인식하도록 준비할 때 사용합니다. Mullion 번호 순서와 아래→위 방향을 맞춰 두면 모델링 결과의 부재 순서가 정확해집니다.

사용 방법

  1. Rhino에서 Mullion 기준선으로 사용할 Line을 준비합니다.
  2. MC1 ~ MCXX 명령으로 선택한 선을 해당 M_Center 레이어로 지정합니다.
  3. Mullion Line의 방향이 아래에서 위 방향인지 확인합니다.
