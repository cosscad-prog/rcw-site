LineLayerDotText  —  선의 Layer 이름 표시

LineLayerDotText

고른 선의 가운데에 그 선의 Layer 이름을 점 글자(Dot)로 보여 줍니다. Wireframe 을 고칠 때 바꿔야 할 선이 어느 Layer 에 있는지 한눈에 찾을 수 있습니다.

WVector 와 달리 group 이 아닌 선에도 쓸 수 있고, group 으로 묶인 선이라도 클릭한 선 하나만 들어갑니다.

사용 방법

  1. Rhino 명령창에 LineLayerDotText를 입력하고 Enter를 누릅니다.
  2. Layer 이름을 볼 선을 고르고 Enter를 누릅니다. 미리 골라 두고 실행해도 됩니다.
  3. 고른 선마다 선 길이의 가운데에 Layer 이름이 나옵니다.
  4. 선을 더 보려면 LineLayerDotText를 다시 실행해 고릅니다. 앞에 고른 선에 더해집니다.
  5. 끄려면 LineLayerDotText를 실행하고 아무것도 고르지 않은 채 Enter를 누르거나, Off 옵션을 누릅니다.

실행 결과

항목설명
표시 위치선 길이의 가운데
표시 글자선의 Layer 이름(하위 Layer 는 마지막 이름만)
점 색그 Layer 의 색. 밝은 색에는 검은 글자, 어두운 색에는 흰 글자
Layer 를 바꾸면선의 Layer 를 바꾸거나 Layer 이름을 고치면 다시 실행하지 않아도 바로 새 이름으로 바뀝니다.
선을 옮기면점 글자도 선을 따라 옮겨집니다.
안 보이는 경우지운 선, 숨긴 선, 꺼진 Layer 의 선은 점 글자도 보이지 않습니다. 다시 보이면 점 글자도 돌아옵니다.
점 글자는 화면에만 그려집니다. 문서에 TextDot 개체를 만들지 않으므로 파일에 저장되지 않고, 인쇄되지 않으며, Undo 기록도 남지 않습니다. 그래서 DWVector 로 지울 필요가 없습니다.
고른 선을 복사해 만든 새 선은 목록에 없습니다. 새 선의 Layer 이름을 보려면 다시 골라야 합니다. 다른 파일을 열면 고른 목록은 비워집니다.
