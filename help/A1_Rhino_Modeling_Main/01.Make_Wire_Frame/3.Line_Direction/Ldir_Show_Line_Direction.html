Ldir  —  Line 방향 표시

Ldir

선택한 Line의 시작점과 끝점 방향을 표시합니다. 기준선 방향을 확인한 뒤 Section 작성이나 모델링 명령을 실행할 때 사용합니다.

사용 방법

  1. Rhino 명령창에 Ldir를 입력하고 Enter를 누릅니다.
  2. 방향을 확인할 Line 객체를 선택합니다.
  3. 선택한 Line 위에 방향 표시가 생성되는지 확인합니다.

관련 명령어

명령어설명
