MVOption  —  모델 보기 옵션

MVOption

MVOption은 모델링 과정에서 Mullion/Transom 결과와 Subtract 형상을 화면에 표시할지 정하는 전역 토글 명령입니다.

사용 목적

UMD 등 모델링이 만든 Mullion/Transom 결과와 차감(Subtract) 형상을 화면에 표시할지 결정할 때 사용합니다. 모델링 미리 보기 범위를 정하거나, 가공 형상을 확인하며 검토할 때 사용하는 전역 토글입니다.

사용 방법

  1. Rhino 명령창에 MVOption을 입력합니다.
  2. 명령 옵션에서 필요한 항목을 On/Off로 바꿉니다.
  3. Enter를 눌러 종료하면 이후 모델링 루틴에서 해당 보기 설정을 사용합니다.

옵션

옵션On일 때 결과
Mul_View_OnMullion 모델링 결과를 표시합니다.
Mul_subtract_View_OnMullion 차감/가공 확인용 형상을 표시합니다.
Trn_View_OnTransom 모델링 결과를 표시합니다.
Trn_subtract_View_OnTransom 차감/가공 확인용 형상을 표시합니다.

관련 명령어

UMD 실행 전 표시 결과를 조정할 때 함께 사용합니다.
