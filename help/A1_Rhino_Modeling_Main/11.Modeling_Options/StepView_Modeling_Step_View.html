StepView  —  모델링 단계 표시 옵션

StepView

StepView는 모델링 중간 단계 형상을 표시할지 제어하는 토글 명령입니다.

사용 목적

모델링 중간 단계의 보조 형상을 남길지 결정할 때 사용합니다. On이면 처리 과정을 더 많이 확인할 수 있어 디버그·검토에 유용하고, Off이면 최종 결과 중심으로 정리됩니다.

사용 방법

  1. Rhino 명령창에 StepView를 입력합니다.
  2. Step_View_On 옵션을 On/Off로 변경합니다.
  3. 모델링 명령을 실행해 중간 단계 표시 여부를 확인합니다.

옵션

옵션설명
Step_View_OnOn이면 모델링 중간 처리 단계의 보조 형상을 더 많이 남겨 확인할 수 있습니다. Off이면 결과 중심으로 정리합니다.

관련 명령어

UMD, MVOption과 함께 모델링 검토 시 사용합니다.
