DataView  —  모델링 데이터 표시 옵션

DataView

DataView는 Mullion/Transom 모델링 데이터 확인 표시를 켜고 끄는 보조 명령입니다.

사용 목적

Mullion/Transom 모델링이 만든 내부 데이터 표시를 화면에 켜고 끄며 검토할 때 사용합니다. 모델링 결과의 데이터가 올바른지 점검하거나, 표시가 번잡할 때 꺼서 화면을 정리하는 용도입니다.

사용 방법

  1. Rhino 명령창에 DataView를 입력합니다.
  2. Mul_data_View, Trn_data_View 옵션을 필요한 상태로 변경합니다.
  3. 모델링 결과에서 데이터 표시 여부를 확인합니다.

옵션

옵션On일 때 결과
Mul_data_ViewMullion 관련 데이터 확인 표시를 사용합니다.
Trn_data_ViewTransom 관련 데이터 확인 표시를 사용합니다.

관련 명령어

MVOption, StepView와 함께 모델링 디버그/검토용으로 사용합니다.
