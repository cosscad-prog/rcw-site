PNamechange  —  Profile 이름 변경

PNamechange

선택한 Surface의 Profile 이름(P_name)에 들어 있는 -(하이픈)를 _(언더스코어)로 바꾸고, 변경된 목록을 Rhino 명령창에 출력합니다.

사용 목적

Profile 이름에 포함된 -(하이픈)는 파일명·데이터 처리에서 문제를 일으킬 수 있으므로, 이를 _로 일괄 정리해 이름 규칙을 통일할 때 사용합니다. Surface의 UserData와 객체 이름을 함께 갱신하며, Section Data가 없는 객체에는 N_Error 표시가 나타납니다.

사용 방법

  1. Rhino 명령창에 PNamechange를 입력하고 Enter를 누릅니다.
  2. 변경할 Profile 또는 관련 객체를 선택합니다.
  3. 새 이름을 입력합니다.
  4. 명령창에 출력되는 변경 전/후 이름을 확인합니다.

실행 결과

항목설명
변경 데이터Profile 이름이 새 이름으로 변경됩니다.
출력 메시지변경 전 이름과 변경 후 이름이 Rhino 명령창에 표시됩니다.

관련 명령어

명령어설명
PnameSection Profile 이름과 속성 입력
SSP작성된 Section Profile 그룹 선택
SSCSection 선택 상태 초기화
