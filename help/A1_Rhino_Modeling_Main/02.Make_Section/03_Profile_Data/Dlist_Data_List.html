PDlist  —  Data 목록 확인

PDlist

PDlist는 선택한 Surface(단면) 객체의 Section Data를 도면 위에 표로 작성하는 명령입니다. 단면 형상 복사본과 함께 Material_ID·Profile_ID·Fab_ID·단중 등 입력된 단면 데이터를 항목별로 나열합니다.

사용 목적

단면(Surface)별로 입력된 모델링 데이터가 올바른지 확인할 때 사용합니다. 데이터 누락·중복·오입력을 표로 비교 점검해, 리스트·모델링 작업 전에 단면 정보를 검증하는 용도입니다.

사용 방법

  1. Rhino 명령창에 PDlist를 입력하고 Enter를 누릅니다.
  2. 확인할 Section 객체를 선택합니다.
  3. 저장된 데이터 목록을 확인합니다.
