BC11 ~ BC44  —  Block Data 복사

BC11 BC12 BC13 BC14 BC21 BC22 BC23 BC24 BC31 BC32 BC33 BC34 BC41 BC42 BC43 BC44

Section의 첫 번째 Block Data를 두 번째 Block Data 위치로 복사하는 4x4 명령어 묶음입니다. 명령어의 첫 번째 숫자는 복사할 원본 Block 번호, 두 번째 숫자는 복사될 대상 Block 번호를 의미합니다.

사용 목적

한 Section에 입력된 여러 Block Data 중 한 Block의 설정을 다른 Block 위치로 빠르게 복사할 때 사용합니다. 명령어 두 자리 숫자(원본→대상)로 복사 방향이 정해져 있어, 반복되는 Block 구성을 일일이 입력하지 않고 신속히 맞출 때 유용합니다.

명령어 번호 규칙

구분설명
첫 번째 숫자복사 원본 Block 번호입니다. 예: BC31은 Block-3 데이터를 원본으로 사용합니다.
두 번째 숫자복사 대상 Block 번호입니다. 예: BC31은 데이터를 Block-1 위치로 복사합니다.
명령어 형식BC + 원본번호 + 대상번호 형식입니다. 원본/대상 번호는 1~4를 사용합니다.

사용 방법

  1. 복사할 원본 Block 번호와 대상 Block 번호를 확인합니다.
  2. Rhino 명령창에 해당 조합의 명령어를 입력합니다. 예: Block-2 데이터를 Block-4로 복사하려면 BC24를 입력합니다.
  3. 명령 안내에 따라 기준 객체 또는 Section 객체를 선택합니다.
  4. 대상 Block 위치의 데이터가 복사 또는 갱신되었는지 확인합니다.
