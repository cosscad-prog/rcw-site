PBlist  —  Block 목록 확인

PBlist

PBlist는 선택한 Section 객체에 입력된 Block Data를 도면 위에 그래픽 표로 작성하는 명령입니다. 각 Profile 이름과 단면 형상 축소본, Block 1~4에 배치된 Block 형상과 데이터를 박스 단위로 나열합니다.

사용 목적

각 단면에 어떤 Block이 어떤 값으로 연결되어 있는지 한눈에 확인할 때 사용합니다. Pname에서 입력한 Block Data가 올바른지, 누락이나 잘못된 설정이 없는지 Unit 모델링(UMD) 전에 시각적으로 점검하는 용도입니다.

사용 방법

  1. Rhino 명령창에 PBlist를 입력하고 Enter를 누릅니다.
  2. 확인할 Section 또는 Block 관련 객체를 선택합니다.
  3. 연결된 Block 데이터 목록을 확인합니다.
