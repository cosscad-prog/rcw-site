PFList  —  Profile/Fab 목록 확인

PFList

PFList는 선택한 Section Profile 그룹을 단위로, 그룹 안의 Profile 구성 전체를 종합한 목록표를 도면 위에 작성하는 명령입니다. 개별 요소가 아니라 그룹 단위로 Profile·제작 데이터를 묶어 표시합니다.

사용 목적

완성된 단면 세트(Section Profile 그룹)별로 Profile·제작 데이터 구성을 한 번에 확인할 때 사용합니다. 그룹 단위로 묶어 보므로, 단면 세트가 제작 데이터까지 빠짐없이 갖춰졌는지 검토하는 용도입니다.

사용 방법

  1. Rhino 명령창에 PFList를 입력하고 Enter를 누릅니다.
  2. 목록을 확인할 객체를 선택합니다.
  3. Profile/Fab 관련 목록 정보를 확인합니다.
