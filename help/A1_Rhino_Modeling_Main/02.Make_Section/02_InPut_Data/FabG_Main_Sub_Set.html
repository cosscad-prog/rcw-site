FabG / XFabG  —  Main-Sub 세트

FabG XFabG

한 단면 group 안에서 선택된 Main 프로파일과 같이 가공도에 표시되기를 원하는 Sub 프로파일을 한 세트로 묶습니다.

언제 쓰는가

Main 프로파일의 가공도를 작성하면 Sub 프로파일들이 Main 프로파일의 Parts 로 가공도에 함께 나타내기를 원할 때 사용합니다. Sub 프로파일들은 FabBomTable 로 표시됩니다.

첫 번째 선택된 프로파일이 Main 프로파일이며, 이후 선택된 모든 프로파일이 Sub 프로파일입니다. Main 프로파일이나 Sub 프로파일에 연결된 Block 도 포함됩니다.

한 group 안에 Main-Sub 세트가 둘 이상이면 세트를 묶어 주어야 서로 섞이지 않습니다. 묶지 않으면 Sub 를 축(센터라인)으로만 찾기 때문에 두 Main 이 서로 남의 Sub 까지 가져갑니다.

사용 방법

  1. Rhino 명령창에 FabG 를 입력하고 Enter 를 누릅니다.
  2. Main 프로파일 단면을 하나 클릭합니다. group 전체가 아니라 클릭한 단면 하나만 잡힙니다.
  3. 그 Main 에 붙을 Sub 단면들을 하나씩 클릭하고 Enter 를 누릅니다. 단면(Surface)뿐 아니라 폴리라인(예: bracket 을 만드는 자르개 폴리라인)도 고를 수 있습니다.
  4. 명령창에 쓴 개수와 Sub 이름이 찍힙니다. 되읽어서 확인한 수입니다.
  5. 모델링(UMD) → FabNo → FabTable → FDwg 순서로 다시 실행하면 세트대로 나옵니다.
단면의 형상은 손대지 않습니다. FabG 는 단면에 세트 표시만 씁니다. 표시를 바꾼 뒤에는 모델링부터 다시 해야 결과에 반영됩니다.

항목내용
Main 의 Group IDMain 의 Group ID 가 1. Main-Group 이 아니면 1 로 맞춥니다. 가공도가 센터라인과 도면의 주 부재를 이 값으로 정하기 때문입니다. 바꾼 경우 명령창에 한 줄 알려 드립니다.
합성 프로파일(ComP)고른 Main 이나 Sub 가 합성의 구성원이면 그 합성의 구성원 전원에 같은 표시를 씁니다. 구성원 하나만 클릭하시면 됩니다.
Sub 를 나중에 더할 때Main 이 이미 세트를 갖고 있으면 그 세트를 그대로 이어 씁니다. 같은 Main 으로 다시 실행해 Sub 를 추가하십시오.
다른 세트에 있던 단면이 세트로 옮겨집니다. 몇 개가 옮겨졌는지 명령창에 알려 드립니다.

가공도에 어떻게 나오는가

  • Main 의 가공도에 자기 세트의 Sub 만 이름·가공번호와 함께 표시됩니다.
  • 부속자재 목록(FabBomTable)에도 자기 세트의 Sub 만 세어집니다.
  • Sub 에 달린 블록(studbolt 등) 중 모델에 블록으로 남는 종류는 Main 가공도에 위치가 표시되고 수량이 세어집니다. 모델에 남지 않고 보여 주기만 하는 블록은 가공도에 나오지 않습니다.

XFabG  —  세트 풀기

XFabG 를 실행하고 풀 단면(또는 폴리라인)을 고른 뒤 Enter 를 누르면 세트 표시가 지워집니다. 단면의 이름·데이터는 그대로입니다.

  • 합성 구성원을 하나 고르면 그 합성의 구성원 전원이 함께 풀립니다.
  • 같은 세트의 단면이 도면에 남아 있으면 Main·Sub 가 몇 개 남았는지 알려 드립니다. 자기 세트의 Main 이 없는 Sub 는 아무 데도 붙지 않습니다. 세트 전체를 풀거나 Main 도 함께 정리하십시오.

주의

고른 것 중 하나라도 묶을 수 없으면 아무것도 쓰지 않고 멈춥니다. 반쪽짜리 세트는 가공도까지 가서야 드러나기 때문입니다. 다음은 묶을 수 없습니다 — 단면 정보가 없는 것 · 이름이 비어 있는 단면(둘 다 Pname 을 먼저 하십시오) · 면이 여러 개인 단면.
걸린 자리에는 빨간 표시(TextDot)가 No_Data Layer 에 섭니다(No_Data · No_Name · Multi_Face · Not_Section). FabG 를 다시 실행하면 지워집니다.
Main 을 Sub 로도 골랐다면 그것은 빼고 진행합니다. Main 과 같은 합성의 구성원을 Sub 로 골라도 Main 으로 둡니다.
잘 묶였는지는 FabGList 로 확인하십시오. 세트마다 Main·Sub 목록을 그리고, Main 없음·Sub 없음 같은 문제를 빨간 글자로 알려 줍니다.

관련 명령어

명령어설명
FabGListFabG 세트만 모아 목록으로 그리고 잘못 묶인 것을 알려 줍니다.

UMD유닛을 모델링합니다. 세트 표시는 이때 부재에 실립니다.
FDwg가공도를 만듭니다. Main 가공도에 자기 세트의 Sub 가 나옵니다.
