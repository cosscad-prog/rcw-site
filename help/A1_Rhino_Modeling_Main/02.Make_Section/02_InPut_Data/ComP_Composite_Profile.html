ComP / XcomP  —  합성 프로파일

ComP XcomP

폴리아미드 단열바처럼 서로 붙어 한 부재로 쓰이는 프로파일 여러 개를 하나의 이름으로 묶습니다. 묶고 나면 가공도가 3~4장이 아니라 1장이 나오고, Molist·FabNo 도 1개로 셉니다.

사용 방법

  1. 묶을 단면 Surface 를 2개 이상 선택합니다.
  2. Rhino 명령창에 ComP 를 입력하고 Enter 를 누릅니다.
  3. 합성 프로파일 이름을 입력합니다. 이 이름이 가공도·리스트에 나오는 부재 이름이 됩니다.
  4. 모델링(UMD)을 실행하면 구성원들이 하나의 부재로 합쳐집니다.
단면의 형상은 손대지 않습니다. ComP 는 단면에 표시(태그)만 씁니다. 실제로 형상이 합쳐지는 것은 모델링 중 solid 단계 한 번뿐입니다. 그래서 묶은 뒤에도 구성원 단면을 따로 고칠 수 있습니다.

묶으면 무엇이 하나가 되는가

구분내용
하나로 나오는 것가공도(FDwg·FDDS) · FabNo 번호 · Molist · Cuttinglist · Fablist · FabTable · UnitList · IFC 내보내기 — 전부 합성 이름 한 줄로 잡힙니다.
구성원별로 남는 것각 구성원의 이름·단중·재질·색상은 그대로 보존됩니다. 알루미늄과 폴리아미드를 나누어 발주해야 하기 때문입니다. 이 기록은 합치는 순간 부재에 함께 저장됩니다.
합성의 단위중량은 구성원 중량의 합입니다. 직접 값을 적으면 그 값이 우선하고, 비워 두면 구성원 중량이 바뀔 때 따라서 바뀝니다.

데이터는 어디서 고치는가  —  Pname

합성 단면을 Pname 으로 열면 이름 칸 오른쪽에 구성원 목록이 나타나고, 그 옆에 구성원 수가 표시됩니다. 목록의 맨 위가 합성이고 그 아래 들여쓴 것이 구성원입니다.

어느 모드에서무엇을 고치나
합성(목록 맨 위)합성 이름 · Description · Unit Weight · Color Code · Material ID · Alloy
그리고 공용 항목 — Profile ID · Fab ID · Group ID · Additional Length
구성원(들여쓴 줄)그 구성원의 이름 · Description · Unit Weight · Color Code · Material ID · Alloy
공용 항목은 구성원 전부가 같은 값을 가져야 합니다. 그래서 구성원 모드에서는 잠기고, 합성 모드에서 한 번 고치면 구성원 전부에 적용됩니다.

표로 한 번에 보려면  —  Dtable

Dtable 에서도 합성은 합성 줄 + 들여쓴 구성원 줄로 나옵니다. 여러 합성을 한 화면에서 비교하며 고칠 때 씁니다. 자세한 것은 Dtable 도움말을 보십시오.

XcomP  —  묶음 풀기

합성 단면을 선택하고 XcomP 를 실행하면 표시가 지워져 보통 프로파일로 돌아갑니다.

항목풀면 어떻게 되나
이름(Profile Name)그대로입니다. 풀고 바로 쓸 수 있습니다.
가공(Block · Milling)안 돌아옵니다. 합성은 가공을 구성원 하나에만 담으므로, 원래 어느 바에 있었는지는 남아 있지 않습니다.
공용 항목(Profile ID · Fab ID · Group ID · 추가 길이)안 돌아옵니다. 이미 구성원 전부가 같은 값으로 맞춰진 뒤입니다.
Layer · 색안 돌아옵니다. ComP 가 구성원을 한 Layer 로 모으면서 색을 객체에 직접 넣습니다.
잘못 묶었으면 합성 모드로 저장하기 전에 푸십시오. 그 전에 풀면 잃는 것이 없습니다.
XcomP 은 고른 것만 풉니다. 같은 묶음의 단면이 도면에 남아 있으면 몇 개가 남았는지 알려 줍니다. 반쪽으로 남기지 않으려면 묶음 전체를 고르십시오.

주의

단면 group 을 복사했다면 SSP 를 먼저 돌리십시오. 단면을 복사하면 합성 표시까지 함께 복사되어 서로 다른 유닛이 같은 표시를 갖게 됩니다. 그 상태로 Pname 을 열면 합성으로 열지 않고 안내만 표시합니다. SSP 가 복사본에 새 표시를 발급합니다.
묶을 수 없는 단면이 하나라도 있으면 아무것도 쓰지 않고 멈춥니다. 반쪽짜리 합성이 생기면 모델링까지 가서야 드러나기 때문입니다. 다음은 묶을 수 없습니다 — 이름이 비어 있는 단면 · 면이 여러 개인 단면(그 경우 표시는 Pname 이 관리합니다).
합성 이름에 쉼표(,) 는 쓸 수 없습니다. 구성원 기록이 쉼표로 칸을 나누기 때문입니다.
구성원은 같은 Layer 에 모입니다. ComP 가 이름을 받은 뒤 자동으로 옮기며, 보이는 색은 그대로 유지됩니다. 서로 다른 Layer 에 있으면 불리언이 Layer 별로 돌아 구성원이 서로 다르게 잘리기 때문입니다.

관련 명령어

명령어설명
Pname합성과 구성원의 데이터를 고칩니다.
Dtable여러 단면을 표로 모아 한 번에 고칩니다. 합성은 합성 줄 + 구성원 줄로 나옵니다.
SSP단면 group 을 선택합니다. 복사된 합성 표시를 찾아 새로 발급합니다.
UMD유닛을 모델링합니다. 합성은 이때 하나의 부재로 합쳐집니다.
