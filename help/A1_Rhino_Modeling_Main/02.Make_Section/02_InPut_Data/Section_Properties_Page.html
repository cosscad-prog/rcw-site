RCW Section  —  Properties 패널의 단면 정보

Rhino Properties 패널 안에 붙는 페이지입니다. 명령이 아니라 탭 하나이므로 따로 실행하지 않습니다.

사용 목적

객체를 고르는 것만으로 이것이 어떤 부재인지 바로 보기 위한 화면입니다. 단면 Surface 는 물론, 단면 group 안의 Polyline 을 골라도 같은 값이 나옵니다 — 선 하나를 짚어 "이건 어느 프로파일인가"를 확인할 때 쓰십시오. 값은 고칠 수도 있습니다.

사용 방법

  1. Rhino 의 Properties 패널을 엽니다(없으면 Properties 명령).
  2. 단면 Surface·솔리드·커브를 선택합니다.
    group 에 묶여 있으면 Alt + 클릭 으로 그 안의 하나만 고릅니다 — 그냥 클릭하면 group 전체가 잡혀 편집이 잠깁니다. (아래 Alt + 클릭 절 참조)
  3. RCW Section 탭이 저절로 뜹니다 — 누를 것이 없습니다. 다른 탭을 보고 있었어도 넘어갑니다. (Properties 패널이 닫혀 있으면 열어 주지는 않습니다. 열려 있을 때 탭만 바뀝니다.)
  4. 값을 고치려면 칸에 입력하고 Enter 를 누르거나 다른 칸으로 넘어갑니다.

항목설명

여러 개를 골랐을 때첫 번째만 보여 주고 편집은 꺼집니다. 어디에 적히는지 알 수 없는 상태로 고치지 않기 위해서입니다.
group 을 클릭하면 바로 이 상태가 됩니다 — 아래 Alt + 클릭 으로 하나만 고르면 편집이 살아납니다.
ID 를 바꿔도이미 만든 모델·도면은 바뀌지 않습니다. SSP 재등록과 UMD 재실행이 필요합니다(Pname 으로 고칠 때와 같습니다).
되돌리기Layer·Display Color·Name 같은 객체 속성은 되돌아가지만, 단면 data 는 Undo 로 되돌아가지 않습니다.
화면 글자는 UI 언어와 상관없이 영문 한 벌입니다. 보여 주는 값(1. Alum. Profile 등)이 영문 목록이라 설명만 한글이면 오히려 읽기 나쁘기 때문입니다.
Rhino 7 에서도 이 페이지는 그대로 나옵니다. 다만 Profile Manager 패널 탭의 아이콘은 Rhino 8 에서만 보입니다.

Alt + 클릭  —  group 안의 하나만 골라 보기

뷰포트에서 Alt 를 누른 채 객체를 클릭하면 그 객체 하나만 선택되고 Properties 패널이 열립니다. group 에 묶여 있어도 group 을 깨지 않습니다.

왜 필요한가: group 을 그냥 클릭하면 여러 객체가 한꺼번에 잡히고, 그때는 어느 단면에 쓰이는지 알 수 없어 편집이 잠깁니다. Alt+클릭은 하나만 고르므로 바로 편집할 수 있습니다.
Rhino 기본 조작은 그대로입니다. Shift+클릭(더하기)·Ctrl+클릭(빼기)·Ctrl+Shift+클릭(부분선택)은 건드리지 않습니다. Alt 를 단독으로 누른 좌클릭일 때만 동작합니다. 빈 곳을 Alt+클릭하면 Rhino 가 하던 대로 선택이 해제됩니다.
탭은 저절로 바뀝니다. 단면 data 가 있는 것을 고르면 — Alt+클릭이든 그냥 클릭이든 — RCW Section 탭으로 넘어갑니다. Text 를 고르면 Text 창이 뜨는 것과 같은 느낌입니다.
손으로 Object 탭을 고르면 그 선택이 다음에 무언가를 다시 고를 때까지 유지됩니다 — 치수를 보다가 Layer 를 바꾸는 식의 작업이 끊기지 않도록 한 것입니다.
Ctrl+Shift+클릭과 무엇이 다른가: Rhino 기본 부분선택은 surface 를 찍으면 edge 인지 face 인지를 또 골라야 합니다. Alt+클릭은 객체 단위로만 잡아 그 번거로움이 없습니다.
