Surface Data Input

Surface Data는 Section Surface가 Mullion 또는 Transom 방향으로 어떻게 Extrusion될지, 어떤 자재/용도/가공 속성을 가질지 지정합니다.

사용 목적

Section Surface의 Extrusion 방향(Mullion/Transom)과 자재·용도·가공 속성을 지정할 때 사용합니다. Profile_ID로 Mullion·Transom·Sleeve·Bracket 등 생성 용도를, Material_ID로 자재 분류를, Additional Length로 Wire Frame 대비 길이 보정을 지정해 부재가 정확한 길이·속성으로 생성되도록 합니다.

사용 방법

  1. Surface 요소를 선택한 뒤 Pname을 실행합니다.
  2. Material_ID로 분류를 지정합니다.
  3. Profile_ID로 Mullion, Transom, Sleeve, Bracket 등 생성 용도를 지정합니다.
  4. Wire Frame보다 길이를 늘리거나 줄여야 하면 Additional Length 값을 입력합니다.

실행 예시

옵션

항목설명
Material_IDAlum.Profile, Steel, 부자재, Subtracter, Sheet 등 리스트 분류를 지정합니다.
Profile_IDMullion, Transom, End Cap, End Dam, Vent, Sleeve, Bracket 등 모델링 용도를 지정합니다.
Fab_IDLine Limit, Temp 등 특별 가공 용도를 지정합니다.
Additional LengthTop/Bot 또는 Left/Right 방향으로 연장, 축소, 지정 길이, 간격, 수량을 설정합니다.

리스트 결과Material_ID와 Profile_ID에 따라 리스트 분류에 반영됩니다.
