DArc  —  Arc 데이터 삭제

DArc

선택한 Arc 관련 데이터를 삭제합니다.

사용 방법

  1. Rhino 명령창에 DArc를 입력하고 Enter를 누릅니다.
  2. 삭제할 Arc 또는 관련 데이터를 선택합니다.
  3. 삭제 결과를 확인합니다.
