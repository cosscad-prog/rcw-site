MakeM  —  Mullion 데이터 작성

MakeM

선택한 Surface를 Profile_ID = 1 으로 교체하는 명령어 입니다.

사용 방법

  1. Rhino 명령창에 MakeM을 입력하고 Enter를 누릅니다.
  2. Mullion 데이터를 만들 Section 객체를 선택합니다.
  3. 생성 또는 갱신된 데이터를 확인합니다.
