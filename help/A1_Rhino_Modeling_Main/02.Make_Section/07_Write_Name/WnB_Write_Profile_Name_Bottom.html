WnB  —  Profile 이름 Bottom 위치 작성

WnB

Profile 이름을 Bottom 위치에 텍스트로 작성합니다.

사용 방법

  1. Rhino 명령창에 WnB를 입력하고 Enter를 누릅니다.
  2. 이름을 작성할 Profile 또는 Section 객체를 선택합니다.
  3. 지정 위치에 작성된 Profile 이름 텍스트를 확인합니다.
