RBB  —  Block Data 이름 재정리

RBB

Block Data 이름 또는 연결 정보를 재정리합니다.

사용 방법

  1. Rhino 명령창에 RBB를 입력하고 Enter를 누릅니다.
  2. 재정리할 Block Data 또는 관련 객체를 선택합니다.
  3. 변경된 Block Data 이름과 연결 상태를 확인합니다.

실행 결과

항목설명
변경 데이터Block Data 이름 또는 연결 정보가 재정리됩니다.
사용 목적잘못 연결되었거나 이름이 맞지 않는 Block Data를 정리합니다.

관련 명령어

명령어설명
PnameSection Profile 이름과 속성 입력
SSP작성된 Section Profile 그룹 선택
SSCSection 선택 상태 초기화
