BCXX  —  번호 입력 Block Data 복사

BCXX

사용자가 입력한 번호 조합을 기준으로 Block Data를 복사합니다.

사용 목적

BC11~BC44처럼 조합이 고정된 명령 대신, 복사할 원본 Block 번호와 대상 Block 번호를 직접 입력해 Block Data를 복사할 때 사용합니다. Block 번호가 4를 넘거나 고정 명령에 없는 조합이 필요할 때 유용합니다.

사용 방법

  1. Rhino 명령창에 BCXX를 입력하고 Enter를 누릅니다.
  2. 명령창 안내에 따라 복사할 번호 조합을 입력합니다.
  3. 기준 객체를 선택하고 복사 결과를 확인합니다.

실행 결과

항목설명
입력값복사 원본/대상 번호 조합을 사용자가 직접 입력합니다.
오류 조건번호 형식이 맞지 않으면 Number Error 메시지가 표시될 수 있습니다.

관련 명령어

명령어설명
PnameSection Profile 이름과 속성 입력
SSP작성된 Section Profile 그룹 선택
SSCSection 선택 상태 초기화
