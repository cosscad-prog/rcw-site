Sht  —  판재 모델링

Sht

판 면(Sheet_XX 또는 Glass_XX)을 골라 접힌 판재를 만듭니다. 두께, 접는 깊이, 끝 모양(평판 · 접기 · 안쪽 되접기 · 바깥쪽 되접기)을 정하고, 판 뒷면에 profile 을 붙이거나 스크류 구멍을 낼 수 있습니다.

사용 목적

유리 자리에 들어가는 금속 판재(백판 · 스팬드럴 판 등)를 모델링할 때 사용합니다. 만든 판재에는 크기와 가공 정보가 기록되어 번호(ShNo) · 수량표(ShList) · 가공도(ShFd)가 그 기록으로 만들어집니다.

작업 순서: WVector → SSP → ShMD → Sht → ShNo → ShList → ShTable → ShFd
판재 명령은 단면에 그려 둔 S_Center1 선과 등록된 단면(SSP), 방향이 기록된 와이어프레임(WVector)을 바탕으로 동작합니다.

사용 방법

  1. Rhino 명령창에 Sht 를 입력하고 Enter 를 누릅니다.
  2. 판 면(Sheet_XX · Glass_XX)을 하나 이상 선택하고 Enter 를 누릅니다.
  3. 옵션 창에서 두께 · 깊이 · 끝 모양 · 붙일 profile 을 정합니다. 창이 떠 있는 동안에도 Rhino 화면을 움직이거나 치수를 잴 수 있습니다.
  4. OK 를 누르면 판재가 만들어집니다. 창을 닫거나 Cancel 을 누르면 아무것도 바뀌지 않습니다.

배치 규칙 (조각 · 구멍 공통)

시작(Fr. Start) 쪽은 가로 변(위 · 아래)은 왼쪽, 세로 변(왼쪽 · 오른쪽)은 위입니다(판을 바깥에서 본 방향).

입력결과
Pitch 0 · Count 있음두 여유(Fr. Start · Fr. End) 사이에 Count 개를 등간격으로 놓습니다. Count 1 이면 시작 쪽에 하나.
Pitch 있음 · Count 있음시작 쪽 여유에서부터 Pitch 간격으로 Count 개. Fr. End 는 쓰지 않습니다(칸이 꺼집니다). 변 밖으로 나가는 것은 빼고 명령창에 알립니다.
Pitch 있음 · Count 0수량을 스스로 정합니다. 양 끝을 두 여유 자리에 놓고 그 사이를 Pitch 를 넘지 않게 고르게 나눕니다(Pname 의 블록 입력과 같은 방식). 예: 길이 920 · 여유 20 / 20 · Pitch 300 → 4개, 간격 293.3.
Pitch 0 · Count 0놓지 않습니다.

끝 모양 (Edge)

아래 그림은 끝 모양마다의 단면 약도입니다. 모양이 잘 보이도록 두께를 크게, 폭을 짧게 그렸습니다(실제 비율이 아닙니다). 아래쪽이 판재의 보이는 면입니다.

profile 은 접기만 한 변(Fold)과 Flat 인 변에만 붙습니다. 되접는 변(Inside · Outside)은 Attach Side 칸이 꺼집니다. 예: 왼쪽 · 위쪽은 Fold, 오른쪽 · 아래쪽은 Outside 로 하면 profile 은 왼쪽 · 위쪽에만 붙고, 스크류 구멍은 오른쪽 · 아래쪽의 되접힌 부분에 납니다.
바깥쪽 되접기의 날개는 코너에서 직각으로 끝나고, 안쪽 되접기의 날개는 코너에서 45°로 맞닿습니다. 끝 모양이 다른 두 변이 만나는 코너는 직각으로 끊깁니다. 이웃 변을 안쪽으로 되접었고 profile 이 그 되접힌 부분과 같은 깊이에 걸리면, 통으로 붙이는 profile 은 되접힌 부분의 끝에서 잘립니다(그만큼 짧아지고 명령창에 알립니다). 조각(Pieces)은 자리를 옮기지 않고, 겹치는 조각이 있으면 명령창에 경고만 나옵니다.
끝 모양이나 되접는 길이가 변마다 다른 판재는 ShNo 가 다른 번호로 가르고, ShList 의 Edge 칸에 T:Fold B:Out L:Fold R:Out, Return 칸에 T:17 R:20 처럼 변마다 적힙니다. ShFd 의 단면 · 전개도 · 구멍 치수도 변마다의 끝 모양을 따릅니다.

붙이는 profile

항목설명
profile 라이브러리%LOCALAPPDATA%\RCW_V5\5.0\Templates\SheetProfiles 폴더의 3dm 파일에서 읽습니다. 파일 안의 group 하나가 profile 하나입니다. 파일을 고쳐 저장하면 다음 실행부터 목록에 반영됩니다.
스크류 구멍 자리라이브러리 group 안에 Hole(또는 Hole_Center) 레이어로 그은 선이 구멍의 축입니다. 선이 없으면 창의 Hole Dist 로 정합니다 — 바깥으로 뻗은 다리의 끝에서 그 거리만큼 들어온 자리.
Flat 인 변에 붙이기Flat 인 변에도 profile 을 붙일 수 있습니다. 자리는 접힌 변과 같습니다(판 가장자리에서 두께만큼 안쪽).
길이막대의 길이는 가장 긴 쪽으로 기록됩니다(45°로 자른 막대는 바깥쪽이 더 깁니다).
