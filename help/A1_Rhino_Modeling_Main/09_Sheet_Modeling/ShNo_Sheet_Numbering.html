ShNo  —  판재 번호

ShNo

Sht 로 만든 판재에 번호(SH-001, SH-002 …)를 붙입니다. 같은 판재에는 같은 번호가 붙고, 번호 글자가 판재 위에 표시됩니다.

사용 목적

같은 모양의 판재를 한 번호로 묶어 수량을 세고, 수량표(ShList)와 가공도(ShTable · ShFd)를 만들 때 사용합니다.

작업 순서: WVector → SSP → ShMD → Sht → ShNo → ShList → ShTable → ShFd
판재 명령은 단면에 그려 둔 S_Center1 선과 등록된 단면(SSP), 방향이 기록된 와이어프레임(WVector)을 바탕으로 동작합니다.

사용 방법

  1. Rhino 명령창에 ShNo 를 입력하고 Enter 를 누릅니다.
  2. 번호를 붙일 판재를 선택하고 Enter 를 누릅니다. 아무것도 고르지 않고 Enter 를 누르면 문서의 판재 전체가 대상입니다.
  3. 판재마다 번호가 기록되고 번호 글자가 판 면 가운데에 놓입니다.

동작 규칙

항목설명
번호 차례두께 → 폭 → 높이 차례로 작은 것부터 매깁니다.
번호 형식SH-001 부터 빈틈 없이 이어집니다. 두께가 달라도 번호는 이어집니다.
번호 글자Sheet_No 레이어에 놓이고 판재와 같은 group 에 들어갑니다.
다시 실행판재를 더 만들거나 지운 뒤 다시 실행하면 번호를 새로 매깁니다. 앞서 놓은 번호 글자는 바뀝니다.
표의 복사본ShTable 이 도면에 놓은 복사본은 판재로 세지 않습니다.

관련 명령어

명령어설명
Sht판재 모델링 — 번호를 붙이기 전에 먼저 실행합니다.
ShList판재 수량표 — 번호별 수량을 표로 만듭니다.
ShTable판재 가공도 표 — 번호별 대표 판재를 도면에 늘어놓습니다.
