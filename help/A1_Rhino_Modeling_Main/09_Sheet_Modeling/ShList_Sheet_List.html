ShList  —  판재 수량표

ShList

번호가 붙은 판재를 번호별로 모아 수량표를 만듭니다. 판재 표 아래에는 붙인 profile 을 이름 · 길이별 수량으로 모은 표가 이어집니다. 화면에 표를 그리고, 원하면 Excel 파일로도 저장합니다.

사용 목적

판재와 붙이는 profile 의 발주 · 생산 수량을 정리할 때 사용합니다. 표의 양식은 BpList · GsList 와 같은 열 순서를 따릅니다.

작업 순서: WVector → SSP → ShMD → Sht → ShNo → ShList → ShTable → ShFd
판재 명령은 단면에 그려 둔 S_Center1 선과 등록된 단면(SSP), 방향이 기록된 와이어프레임(WVector)을 바탕으로 동작합니다.

사용 방법

  1. 먼저 ShNo 로 번호를 붙입니다.
  2. Rhino 명령창에 ShList 를 입력하고 Enter 를 누릅니다.
  3. Excel 파일이 필요하면 명령창의 Excel_File_On 옵션을 On 으로 바꿉니다.
  4. 목록에 넣을 판재를 선택하고 Enter 를 누릅니다. 아무것도 고르지 않고 Enter 를 누르면 문서의 판재 전체가 대상입니다.
  5. 표를 놓을 자리를 화면에서 클릭합니다.
NBlock: 판재를 포함해 만든 NBlock 도 선택할 수 있습니다. NBlock 만 골라도 되고(Block Mode), 판재와 NBlock 을 함께 고르면 한 표로 합칩니다(Mixed Mode). NBlock 안의 판재와 붙인 profile 은 배치 개수만큼 세며, 명령창에 어느 Mode 인지와 장수를 알려 줍니다. NBlock 안의 판재는 블록 안의 기록을 직접 읽으므로 NBlock 을 다시 만들 필요가 없습니다.
⚠ NBlock 은 원본을 지우지 않으므로, 원본 판재와 그것으로 만든 NBlock 을 함께 선택하면 두 번 셉니다. 아무것도 고르지 않고 Enter 를 누르면 문서의 판재만 세고 NBlock 은 넣지 않습니다. ShNo 뒤에 NBlock 을 만드십시오 — 번호가 없는 판재는 목록에서 빠집니다.

실행 예시

판재 표의 열

열설명
NO줄 번호.
Unit_No · Code다른 수량표와 열 자리를 맞추기 위한 칸입니다. 판재에는 해당 기록이 없어 - 로 나옵니다.
Fab_No판재 번호(예: SH-003).
Quantity그 번호의 판재 수량.
Width · Height판 면의 폭과 높이(mm).
Area폭 × 높이 × 수량(㎡). 접힌 부분은 포함하지 않습니다. 합계 줄에 전체 면적이 나옵니다.
Thickness판 두께(mm).
Edge끝 모양(Flat · Fold · Inside · Outside).
Depth T/B/L/R위 · 아래 · 왼쪽 · 오른쪽 접는 깊이.
Return · Holes되접는 길이와 되접힌 부분의 구멍 수.
Profile붙인 profile 이름.

profile 표의 열

열설명
Profile · Materialprofile 이름과 재질 번호.
Quantity같은 이름 · 길이 · 구멍 수인 막대의 수량(고른 판재 전체의 합).
Length막대 길이(mm). 가장 긴 쪽 기준입니다 — 45°로 자른 막대는 바깥쪽 길이입니다.
Holes막대 하나의 스크류 구멍 수.
번호가 없는 판재는 목록에서 빠지고, 빠진 수를 명령창에 알립니다. Excel 파일은 문서를 저장한 폴더에 만들어지므로 문서를 먼저 저장해야 합니다.

관련 명령어

명령어설명
ShNo판재 번호 — 수량표를 만들기 전에 실행합니다.
ShTable · ShFd판재 가공도 표와 가공도.
BpList · GsList백패널 · 유리 수량표 — 같은 양식입니다.
