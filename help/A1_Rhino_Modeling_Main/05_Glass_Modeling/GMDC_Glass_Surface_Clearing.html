GMDC  —  유리 면 초기화

GMDC

현재 문서에서 Glass_XX 레이어에 있는 모든 서피스를 삭제합니다.
유리 모델링을 처음부터 다시 시작할 때 사용합니다.

사용 목적

Glass_XX 레이어의 유리 서피스를 모두 지워 유리 모델링을 처음부터 다시 시작할 때 사용합니다. 유리 타입이나 분할을 바꿔 재모델링하기 전, 기존 결과를 깨끗이 정리하는 용도입니다.

사용 방법

  1. Rhino 명령창에 GMDC 를 입력하고 Enter 를 누릅니다.
  2. 별도의 선택 없이 즉시 실행됩니다.
  3. Glass_XX 레이어의 모든 서피스가 삭제되고 화면이 새로고침됩니다.

실행 예시

삭제 대상

항목 설명
삭제 레이어 Glass_XX 패턴의 모든 레이어에 포함된 서피스 객체
삭제 범위 현재 열려 있는 문서(doc) 전체 — 선택 여부와 무관하게 일괄 삭제됩니다.
삭제 제외 Glass_XX 레이어 이외의 객체는 영향을 받지 않습니다.
주의: 실행 즉시 모든 유리 서피스가 삭제됩니다. 되돌리려면 Rhino의 Undo(Ctrl+Z)를 사용하세요.

관련 명령어

명령어 설명
GsOpt 유리 타입 옵션 패널 열기 — 재모델링 전 타입을 재설정합니다.
Gmd 유리 면 모델링 — 삭제 후 다시 유리 서피스를 생성합니다.
