GRV  —  유리 반투명 표시

GRV

Glass* 레이어의 모든 서피스를 80% 투명도의 재질로 표시하거나 원래 상태로 되돌립니다.
명령을 반복 실행하면 반투명 ON / OFF 가 교대로 전환됩니다.

사용 목적

유리 면을 80% 반투명으로 표시해 뒤쪽 부재·구조를 함께 확인할 때 사용합니다. 명령을 반복하면 반투명 표시가 ON/OFF로 전환되어, 검토 시 유리에 가리지 않고 모델을 살펴볼 수 있습니다.

사용 방법

  1. Rhino 명령창에 GRV 를 입력하고 Enter 를 누릅니다.
  2. Glass* 레이어의 모든 객체가 반투명 재질로 전환됩니다.
  3. GRV 를 다시 실행하면 원래 레이어 재질로 복원됩니다.

실행 예시

토글 상태

ON (반투명 표시) 투명도 80% 재질 적용
레이어 색상을 밝게 보정하여 표시
Rendered 뷰 모드로 표시 전환
OFF (원래 표시) 레이어 재질로 복원
표시 모드 오버라이드 제거
객체 색상 소스를 레이어 기준으로 복원

적용 대상

항목 설명
대상 레이어 이름이 Glass 로 시작하는 모든 레이어 (대소문자 무관)
투명도 80% (MaterialTransparency = 0.8)
표시 모드 Rendered 뷰 모드 오버라이드 적용
색상 보정 레이어 색상에 흰색 50% 혼합 → 밝은 색조로 표시

관련 명령어

명령어 설명
Gmd 유리 면 모델링 — 반투명 표시할 유리 서피스를 생성합니다.
GsNo 유리 번호 부여 — 반투명 상태에서 번호 위치를 확인하기 편리합니다.
참고: Rendered 뷰 모드를 찾을 수 없는 환경에서는 실행이 취소됩니다.
