Gmd  —  유리 면 모델링

Gmd

선택한 Brep(솔리드 또는 서피스) 면을 기준으로 유리 서피스를 자동 생성합니다.
GsOpt 패널에서 설정된 유리 타입 정보를 바탕으로 Glass 레이어에 서피스를 배치합니다.

사용 목적

커튼월 면을 기준으로 유리 서피스를 자동 생성할 때 사용합니다. GsOpt에 설정된 유리 타입 정보를 적용해 Glass 레이어에 일괄 배치하므로, 유리 모델을 빠르게 구성하는 핵심 단계입니다.

사용 방법

  1. GsOpt 패널에서 적용할 유리 타입을 먼저 선택합니다.
  2. Rhino 명령창에 Gmd 를 입력하고 Enter 를 누릅니다.
  3. 유리를 생성할 Brep 면(서피스)을 선택합니다.
  4. 옵션으로 Distance(거리 기준) 또는 Section(단면 기준) 분할 방식을 선택할 수 있습니다.
  5. Enter 를 눌러 실행하면 Glass 레이어에 서피스가 생성됩니다.

실행 예시

옵션

옵션 설명
Distance 뮬리언 간 거리를 기준으로 유리 면을 분할합니다.
Section 단면 데이터를 기준으로 유리 면을 분할합니다.

실행 결과

항목 설명
레이어 Glass_XX 레이어에 서피스가 생성됩니다. (XX = 유리 타입 번호)
서피스 선택한 Brep 면을 기준으로 뮬리언에 맞춰 분할된 서피스가 배치됩니다.

관련 명령어

명령어 설명
GsOpt 유리 타입 옵션 패널 열기 — 실행 전 유리 타입을 설정합니다.
GMDC 유리 면 초기화 — 생성된 Glass_XX 레이어 서피스를 전체 삭제합니다.
GsNo 유리 번호 부여 — 생성된 유리 서피스에 번호를 자동 배치합니다.
GRV 유리 반투명 표시 — Glass 레이어 객체를 투명하게 토글합니다.
