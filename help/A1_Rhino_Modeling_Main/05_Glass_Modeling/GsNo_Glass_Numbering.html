GsNo  —  유리 번호 부여

GsNo

Gmd 명령으로 생성된 유리 서피스에 번호 텍스트를 자동으로 배치합니다.
각 유리 면의 중심점에 일련번호가 부여되며, 도면 주기 및 수량 집계에 활용됩니다.

사용 목적

Gmd로 생성된 유리 면에 일련번호를 자동 부여해 도면 주기와 수량 집계의 기준을 만들 때 사용합니다. 각 유리 면 중심에 번호가 표기되어 리스트·가공도와 번호를 일치시킬 수 있습니다.

사용 방법

  1. Gmd 명령으로 유리 서피스가 미리 생성되어 있어야 합니다.
  2. Rhino 명령창에 GsNo 를 입력하고 Enter 를 누릅니다.
  3. 별도의 선택 없이 즉시 실행됩니다.
  4. 각 유리 서피스의 중심에 번호 텍스트가 자동 배치됩니다.

실행 결과

항목 설명
번호 위치 각 유리 서피스의 중심점(Center Point)에 텍스트가 배치됩니다.
번호 형식 유리 타입 코드 + 일련번호 형식으로 자동 생성됩니다.
레이어 번호 텍스트는 별도의 번호 레이어에 배치됩니다.

관련 명령어

명령어 설명
Gmd 유리 면 모델링 — 번호 부여 전 먼저 실행합니다.
GMDC 유리 면 초기화 — 유리 서피스와 번호를 모두 삭제하고 재시작합니다.
GRV 유리 반투명 표시 — 번호 확인 시 유리를 투명하게 보여줍니다.
