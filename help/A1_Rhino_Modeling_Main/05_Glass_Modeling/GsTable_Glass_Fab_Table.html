GsTable  —  유리 제작 도면 테이블

GsTable

선택한 유리 Solid 객체들을 분석하여 Rhino 도면 안에 제작 도면 테이블을 자동 생성합니다.
유리 타입별로 형상을 복사·배치하고, 제작 번호·수량·면적 정보를 셀 안에 텍스트로 출력합니다.

사용 목적

유리 타입별 형상과 제작 번호·수량·면적을 도면 위 제작 테이블로 정리할 때 사용합니다. 제작도에 유리 일람표를 함께 배치해 생산·발주 검토에 활용하는 용도입니다.

사용 방법

  1. Rhino 명령창에 GsTable 을 입력하고 Enter 를 누릅니다.
  2. 테이블에 포함할 유리 Solid 객체를 선택하고 Enter 를 누릅니다.
  3. 분석이 완료되면 테이블 시작 위치를 화면에서 클릭합니다.
  4. 선택한 위치를 기준으로 유리 타입별 제작 도면 테이블이 아래 방향으로 생성됩니다.

실행 예시

테이블 셀 구성

유리 타입별로 하나의 행(Row)이 생성되며, 각 셀의 내용은 다음과 같습니다.

셀 항목 설명
타입명 (첫 번째 셀) 유리 타입 대표 이름. 행의 가장 왼쪽에 중앙 정렬로 표시됩니다.
Fab_No 제작 번호. [타입명] [접두사][번호] 형식으로 표시됩니다.
Qnt 해당 제작 번호의 수량.
Area 면적(㎡). 소수점 2자리로 표시됩니다.
유리 형상 원본 유리 Solid 를 Front View 평면 기준으로 복사하여 셀 중심에 배치합니다.

레이어 및 동작 특이사항

항목 설명
텍스트 레이어 생성된 텍스트는 Text 레이어에 배치됩니다.
번호/수량 레이어 Fab_No · 수량 텍스트는 Profile_No_Qnt 레이어에 배치됩니다.
Construction Plane 실행 시 활성 뷰포트의 CPlane Y 원점을 0 으로 자동 보정합니다.
테이블 방향 타입별 행이 클릭 위치에서 아래(-Z) 방향으로 순서대로 배치됩니다.
셀 크기 선택된 유리 중 최대 폭·높이를 기준으로 자동 계산됩니다.

관련 명령어

명령어 설명
Gmd 유리 면 모델링 — 테이블 생성 전 유리 서피스를 먼저 생성합니다.
GsNo 유리 번호 부여 — 테이블의 Fab_No 와 연동됩니다.
GsList 유리 수량 리스트 — 테이블과 함께 사용하면 수량 집계와 도면을 동시에 작성할 수 있습니다.
참고: 선택 객체는 Brep(솔리드) 형태여야 합니다.
