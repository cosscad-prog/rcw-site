GsFd  —  유리 가공도 생성

GsFd

선택한 유리 Solid 객체로부터 가공도(Fabrication Drawing)를 자동 생성합니다.
정면도·배면도·측면도·평면도의 2D 라인과 치수선을 자동으로 작성하며, 원본 3D 유리 객체는 가공도 생성 후 자동으로 삭제됩니다.

사용 목적

유리 부재의 가공도(정면·배면·측면·평면 2D와 치수)를 자동 생성할 때 사용합니다. 유리 제작용 도면화를 자동화하는 용도이며, 가공도 생성 후 원본 3D 유리 객체는 자동으로 삭제됩니다.

사용 방법

  1. Rhino 명령창에 GsFd 를 입력하고 Enter 를 누릅니다.
  2. 가공도를 생성할 유리 객체(Glass 레이어의 Brep)를 선택하고 Enter 를 누릅니다.
    그룹 선택이 가능합니다.
  3. 선택된 객체 수만큼 순서대로 가공도가 자동 생성됩니다.
    명령창에 진행 상황 N / 전체 Working on [타입명 Fab_No] 가 표시됩니다.
  4. 가공도가 완성된 원본 3D 객체는 자동으로 삭제됩니다.

실행 예시

생성되는 도면 내용

도면 요소 생성 조건 설명
정면도 (Front) 기본 생성 유리 정면 서피스를 2D로 투영하고 폭·높이 치수선을 자동 작성합니다.
배면도 (Back) 기본 생성 유리 배면 서피스를 2D로 투영합니다. Hidden 선 타입으로 표시됩니다.
측면도 (Right) 기본 생성 유리 우측면을 2D로 투영하고 두께 방향 치수선을 작성합니다.
평면도 (Top) 기본 생성 유리 상단면을 2D로 투영합니다. 유리 사양(두께 문자열)이 함께 표시됩니다.
치수선 현재 DimStyle 기준 현재 DimStyle 설정을 기준으로 정면도에 폭·높이·경사 치수를 자동 배치합니다.

생성 레이어

레이어 내용
Glass_Fab 가공도 2D 라인 (흰색, Continuous 선종)
Dims 치수선 (노란색)

실행 조건

조건 설명
대상 레이어 이름이 Glass 로 시작하는 레이어의 객체만 처리됩니다.
객체 형식 Brep(솔리드) 형태여야 하며, Glass 데이터(UserData)가 포함되어 있어야 합니다.
Glass 데이터가 없는 경우 ***** Glass Data 가 없습니다. 메시지가 표시되고 해당 객체는 건너뜁니다.
원본 삭제 가공도가 정상 생성된 객체는 자동으로 삭제됩니다. 되돌리려면 Undo(Ctrl+Z)를 사용하세요.

관련 명령어

명령어 설명
Gmd 유리 면 모델링 — 가공도 생성 전 유리 서피스를 먼저 생성합니다.
GsNo 유리 번호 부여 — 가공도의 Fab_No 와 연동됩니다.
GsTable 유리 제작 도면 테이블 — 가공도와 함께 타입별 테이블을 생성합니다.
GsList 유리 수량 리스트 — 가공도 작성 전 수량을 먼저 확인할 수 있습니다.
주의: 가공도가 생성된 원본 3D 유리 객체는 자동으로 삭제됩니다.
작업 전 파일을 저장하거나 백업해 두는 것을 권장합니다.
