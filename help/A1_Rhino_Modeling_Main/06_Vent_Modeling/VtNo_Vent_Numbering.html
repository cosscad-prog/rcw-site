VtNo  —  벤트 번호 부여

VtNo

VT1 ~ VT9 명령으로 생성된 벤트 그룹을 분석하여 벤트 제작 번호를 자동 부여합니다.
프로파일 형상 비교를 통해 내부 Fab No를 만들고, 그룹별 fingerprint를 저장하여 같은 형상끼리 같은 번호 체계로 정리합니다.

사용 목적

벤트 그룹에 제작 번호(Fab No)를 자동 부여해 같은 형상끼리 같은 번호로 묶을 때 사용합니다. 형상 비교(fingerprint) 기반이므로, 이후 벤트 리스트·제작 테이블·도면과 번호를 일치시키는 기준이 됩니다.

사용 방법

  1. VT1 ~ VT9 명령으로 벤트 그룹이 미리 생성되어 있어야 합니다.
  2. Rhino 명령창에 VtNo 를 입력하고 Enter 를 누릅니다.
  3. 명령 프롬프트 Select Vent Group objects 에서 번호를 부여할 벤트 그룹을 선택합니다.
  4. Fab 문자열을 입력하면 프로파일과 벤트 그룹 번호가 자동으로 계산됩니다.

실행 예시

실행 과정

단계설명
1/4선택한 Vent 그룹에서 Brep 프로파일을 수집합니다.
2/4프로파일 형상을 비교하여 내부 Fab No를 부여하고 Fab_No_Text 레이어에 기록합니다.
3/4벤트 그룹별 Fab No fingerprint를 생성하여 그룹 데이터에 저장합니다.
4/4fingerprint를 기준으로 Vent 번호를 부여합니다. 번호 prefix는 V를 사용합니다.

관련 명령어

명령어설명
VT1 ~ VT9벤트 모델링 — 번호 부여 전 먼저 실행합니다.

VtTable벤트 제작 도면 테이블 — 번호 확인 후 작성합니다.
