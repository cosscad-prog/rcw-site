VtTable  —  벤트 제작 도면 테이블

VtTable

선택한 벤트 그룹 객체들을 분석하여 Rhino 도면 안에 제작 도면 테이블을 자동 생성합니다.
벤트 타입별로 형상을 복사·배치하고, 제작 번호와 수량 정보를 함께 출력합니다.

사용 목적

벤트 타입별 형상과 제작 번호·수량을 도면 위 제작 테이블로 정리할 때 사용합니다. 제작도에 벤트 일람표를 함께 배치해 생산·발주 검토에 활용하는 용도입니다.

사용 방법

  1. Rhino 명령창에 VtTable 을 입력하고 Enter 를 누릅니다.
  2. 테이블에 포함할 벤트 그룹 객체를 선택하고 Enter 를 누릅니다.
  3. 분석이 완료되면 테이블 시작 위치를 화면에서 클릭합니다.
  4. 선택한 위치를 기준으로 벤트 타입별 제작 도면 테이블이 생성됩니다.

실행 예시

테이블 셀 구성

벤트 타입별 제작 셀이 생성되며, 각 셀의 내용은 다음과 같습니다.

셀 항목설명
타입명벤트 타입 이름. 제작 번호와 함께 셀 상단에 표시됩니다.
Fab_No제작 번호. [타입명] [접두사][번호] 형식으로 표시됩니다.
Qnt해당 제작 번호의 수량.
벤트 형상원본 벤트 형상을 제작 테이블 셀 중심에 복사하여 배치합니다.

레이어 및 동작 특이사항

항목설명
선택 방식그룹 선택(GroupSelect) 모드로 동작하므로 벤트 그룹을 클릭하면 전체 그룹이 선택됩니다.
텍스트 레이어생성된 텍스트는 Text 및 Profile_No_Qnt 레이어에 배치됩니다.
데이터 기준VtNo에서 저장한 그룹 데이터와 Fab No 정보를 기준으로 타입별 수량을 정리합니다.
Construction Plane실행 시 활성 뷰포트의 CPlane Y 원점을 0으로 자동 보정합니다.
배치 방식선택한 시작점에서 타입별 벤트 입면과 프로파일 가공 정보를 순차적으로 배치합니다.

관련 명령어

명령어설명
VT1 ~ VT9벤트 모델링 — 테이블 생성 전 먼저 실행합니다.
VtNo벤트 번호 부여 — 테이블의 Fab_No와 연동됩니다.
VtList벤트 수량 리스트 — 테이블과 함께 사용합니다.
