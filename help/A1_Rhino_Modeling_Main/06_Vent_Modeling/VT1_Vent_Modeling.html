VT1 ~ VT9  —  벤트 모델링

VT1 VT2 VT3 VT4 VT5 VT6 VT7 VT8 VT9

선택한 Brep 면을 기준으로 벤트 프레임 3D 솔리드를 자동 생성합니다.
VT1 ~ VT9 는 각각 VTOpt 패널에서 미리 설정해 둔 벤트 타입 1~9 번에 대응합니다.

사용 목적

VTOpt에 설정해 둔 벤트 타입 1~9를 골라 커튼월 면에 벤트(개폐창) 프레임 3D 솔리드를 즉시 생성할 때 사용합니다. 타입별 단축 명령이라 여러 사양의 벤트를 면마다 빠르게 배치할 수 있습니다.

사용 방법

  1. VTOpt 패널에서 적용할 벤트 타입과 섹션 데이터를 먼저 설정합니다.
  2. Rhino 명령창에 VT1 (또는 VT2~VT9) 을 입력하고 Enter 를 누릅니다.
  3. 명령 프롬프트 Select Vent Surface Object 에서 벤트를 생성할 Brep 면을 선택합니다.
  4. Enter 를 눌러 완료하면 선택 면 기준으로 벤트 프레임 솔리드가 그룹으로 생성됩니다.

실행 예시

VT 번호와 타입의 관계

명령어설명
VT1VTOpt 패널의 1번 타입 설정으로 벤트를 생성합니다.
VT2VTOpt 패널의 2번 타입 설정으로 벤트를 생성합니다.
VT3 ~ VT9VTOpt 패널의 3~9번 타입 설정으로 벤트를 생성합니다.

실행 결과

항목설명
생성 객체Left / Right / Top / Bottom 프레임 솔리드가 생성됩니다.
그룹생성된 솔리드가 하나의 Rhino 그룹으로 묶입니다.
데이터그룹에 Vent 타입 데이터가 저장되어 VtNo, VtList, VtTable에서 사용됩니다.
비직각 면4면이 90도가 아닌 경우 별도 로직으로 생성하며 Rhino 명령창에 안내 메시지를 출력합니다.

관련 명령어

명령어설명

VtList벤트 수량 리스트 생성
VtTable벤트 제작 도면 테이블 생성
