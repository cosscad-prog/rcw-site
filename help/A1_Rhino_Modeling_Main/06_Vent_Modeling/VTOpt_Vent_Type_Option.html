VTOpt  —  벤트 타입 옵션 패널

VTOpt

벤트 타입 옵션 패널(Vent Type Option Panel)을 열거나 닫습니다.
패널이 열려 있는 경우 명령어를 다시 실행하면 닫힙니다.

사용 목적

벤트 타입(사용 섹션·코드·설명 등)을 미리 정의·수정하는 옵션 패널을 열 때 사용합니다. 여기서 설정한 타입 1~9가 VT1~VT9 벤트 생성의 기준이 되므로, 벤트 모델링 전에 타입을 정리하는 용도입니다.

사용 방법

  1. Rhino 명령창에 VTOpt 를 입력하고 Enter 를 누릅니다.
  2. Glass / BackPanel / Vent / Grill 타입을 관리하는 공용 옵션 패널이 열립니다.
  3. Vent 타입에서 사용할 프레임 섹션, 코드, 설명, 추가 정보를 설정합니다.
  4. 패널을 닫으려면 VTOpt 를 다시 실행하거나 패널의 닫기 버튼을 누릅니다.

실행 예시

패널에서 설정하는 주요 항목

항목설명
명령어 타입VT1 ~ VT9 중 모델링에 사용할 Vent 타입 번호를 지정합니다.
프레임 섹션Left, Top, Right, Bottom 위치에 사용할 단면 그룹을 지정합니다.
코드/설명수량 리스트와 테이블에 출력될 Code, Description, Add1~Add3 정보를 입력합니다.
타입 데이터선택한 VT 번호와 연결되어 모델링, 번호 부여, 수량 리스트 작성에 사용됩니다.

관련 명령어

명령어설명
VT1 ~ VT9벤트 모델링 — 옵션 설정 후 실행합니다.
VtNo벤트 번호 부여
VtList벤트 수량 리스트 생성
