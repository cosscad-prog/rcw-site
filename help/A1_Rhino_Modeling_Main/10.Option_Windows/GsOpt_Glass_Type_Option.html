GsOpt  —  유리 타입 옵션 패널

GsOpt

유리 타입 옵션 패널(Glass Type Option Panel)을 열거나 닫습니다.
패널이 열려 있는 경우 명령어를 다시 실행하면 닫힙니다.

사용 목적

유리 타입(두께·구성·이름 등)을 미리 정의·수정하는 옵션 패널을 열 때 사용합니다. 여기서 설정한 타입 1~9가 Gmd·GS1~GS9 유리 생성의 기준이 되므로, 유리 모델링 전에 타입을 정리하는 용도입니다.

사용 방법

  1. Rhino 명령창에 GsOpt 를 입력하고 Enter 를 누릅니다.
  2. 유리 타입 옵션 패널이 열립니다.
  3. 패널을 닫으려면 GsOpt 를 다시 실행하거나 패널의 닫기(×) 버튼을 누릅니다.

실행 예시

패널 구성

패널은 유리(Glass) / 백패널(Back Panel) / 환기창(Vent) 탭으로 구성되어 있습니다.
유리 탭의 주요 항목은 다음과 같습니다.

No 항목 설명
1 유리 타입 목록 등록된 유리 타입을 표 형태로 표시합니다. 항목을 클릭하면 하단 설정 값이 자동으로 채워집니다.
2 명령어 (Command) 모델링 시 사용할 Glass 명령어를 선택합니다 (GS1 ~ GS9).
3 색상 (Color) 레이어 색상을 지정합니다. 색상 코드를 직접 입력하거나 색상 박스를 클릭해 선택합니다.
4 유리 코드 (Glass Code) Glass Code 와 Description(설명)을 입력합니다. 도면 주기 및 리스트 출력 시 사용됩니다.
5 유리 구성 (Group 1) 1번 유리 / 2번 유리 / 3번 유리 각각의 두께(Thickness), 강도(Hardness), 공간(Space) 을 설정합니다.
합계 두께(Total Thickness)는 자동으로 계산되어 표시됩니다.
6 추가 정보 (Group 3) Add 1 / Add 2 / Add 3 — 사용자 정의 부가 정보를 입력합니다.

관련 명령어

명령어 설명
Gmd 유리 면 모델링 — 선택한 Brep 면에 유리 서피스를 생성합니다.
GMDC 유리 면 초기화 — 생성된 Glass_XX 레이어 서피스를 전체 삭제합니다.
GsNo 유리 번호 부여 — 유리 서피스에 번호 텍스트를 자동으로 배치합니다.
GRV 유리 반투명 표시 — Glass 레이어 객체를 투명(80%)하게 토글합니다.
