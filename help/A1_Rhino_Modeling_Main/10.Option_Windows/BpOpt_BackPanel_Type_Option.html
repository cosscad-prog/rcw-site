BpOpt  —  백패널 타입 옵션 패널

BpOpt

백패널 타입 옵션 패널(BackPanel Type Option Panel)을 열거나 닫습니다.
패널에서 설정한 타입 정보는 BP1 ~ BP5 모델링, 번호 부여, 리스트, 제작 도면 작성에 사용됩니다.

사용 목적

백패널 타입(두께·이격거리·절곡 타입 등)을 미리 정의·수정하는 옵션 패널을 열 때 사용합니다. 여기서 설정한 타입 1~5가 BP1~BP5 모델링과 번호·리스트·제작 도면의 기준이 되므로, 백패널 작업 전에 타입을 정리하는 용도입니다.

사용 방법

  1. Rhino 명령창에 BpOpt 를 입력하고 Enter 를 누릅니다.
  2. 백패널 타입 옵션 패널이 열립니다. Glass / BackPanel / Vent 공용 패널 중 BackPanel 탭을 사용합니다.
  3. 새 타입을 입력하거나 기존 타입을 선택해 값을 수정합니다.
  4. 입력이 끝나면 Add List 버튼으로 타입 목록에 추가합니다.
  5. 계속 사용할 설정이면 Save 버튼으로 데이터 파일에 저장합니다.
  6. 패널을 닫으려면 BpOpt 를 다시 실행하거나 패널의 닫기 버튼을 누릅니다.

실행 예시

패널 구성

No항목설명
1 백패널 타입 목록 등록된 백패널 타입을 표 형태로 표시합니다. 항목을 선택하면 하단 입력 값이 해당 타입 값으로 채워집니다.
2 Command 실제 모델링에서 사용할 BackPanel 명령어를 지정합니다. 일반적으로 BP1 ~ BP5 타입 명령과 연결됩니다.
3 Color 백패널 모델이 생성될 레이어 색상을 지정합니다.
4 Code 각 백패널 타입에 적용할 코드를 입력합니다. 리스트, 테이블, 도면 표기에서 타입 식별 정보로 사용됩니다.
5 Description 백패널 사양에 대한 설명을 입력합니다. 제작 리스트와 도면 주기에서 사람이 읽는 사양 정보로 사용됩니다.
6 Dist from Glass 외부 유리 표면을 기준으로 백패널이 떨어지는 거리를 입력합니다. 모델링 시 유리 기준면에서 백패널 위치를 잡는 데 사용됩니다.
7 Add 1 / Add 2 / Add 3 위치, 순서, 프로젝트별 분류 등 사용자 정의 부가 정보를 입력합니다.

두께와 타입 설정

항목설명
Sheet Thk. BackPanel sheet 두께를 입력합니다.
Panel Thk. BackPanel 외부 sheet의 두께 또는 절곡 형상 기준 두께를 입력합니다. Type B All Outside가 아닌 경우 Flange 길이는 Insulation 두께와 같아야 합니다.
Insulation Thk. 백패널 내부 단열재 두께를 입력합니다.
Type A All Inside 모든 Flange가 내부를 향하는 타입입니다. 접히는 Flange 길이의 기본값은 15입니다.
Type B All Outside 모든 Flange가 외부를 향하는 타입입니다. 접히는 Flange 길이의 기본값은 10입니다.

저장과 적용

작업설명
Add List 현재 입력 값을 백패널 타입 목록에 추가합니다. 중복된 이름이 있으면 덮어쓰기 확인이 표시될 수 있습니다.
Save 현재 타입 목록을 RCWFolder 폴더의 BackPanelType_Data.dat 파일에 기록합니다. 나중에 같은 설정을 사용하려면 Save로 파일에 저장해야 합니다.
모델링 적용 BP1 ~ BP5 명령은 이 패널에 저장된 타입별 두께, 색상, 코드, 설명 값을 읽어 백패널 모델을 생성합니다.

관련 명령어

명령어설명
BP1 ~ BP5설정된 백패널 타입으로 백패널 솔리드를 생성합니다.
BpNo생성된 백패널에 번호를 부여합니다.
BpList백패널 수량 리스트를 생성합니다.
BpTable백패널 제작 도면 테이블을 생성합니다.
BpFd백패널 가공도를 생성합니다.
주의: Add List만 누르고 Save하지 않으면 다음 작업 환경에서 타입 데이터가 유지되지 않을 수 있습니다.
