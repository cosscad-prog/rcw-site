BpFd  —  백패널 가공도 생성

BpFd

선택한 백패널 Solid 객체로부터 가공도(Fabrication Drawing)를 자동 생성합니다.
정면도·배면도·측면도·평면도의 2D 라인과 치수선을 자동으로 작성하며, 원본 3D 백패널 객체는 가공도 생성 후 자동으로 삭제됩니다.

사용 목적

백패널 부재의 가공도(정면·배면·측면·평면 2D와 치수)를 자동 생성할 때 사용합니다. 백패널 제작용 도면화를 자동화하는 용도이며, 측면도·단면 표시·ISO 도면 출력 여부를 옵션으로 조절할 수 있고 가공도 생성 후 원본 3D 객체는 자동으로 삭제됩니다.

사용 방법

  1. Rhino 명령창에 BpFd 를 입력하고 Enter 를 누릅니다.
  2. 명령 옵션에서 Side_FabDwg_On, SectionLine_Mark_On, ISO_Dwg_On 등의 출력 여부를 설정합니다.
  3. 가공도를 생성할 백패널 그룹 객체를 선택하고 Enter 를 누릅니다.
  4. 선택된 객체 수만큼 순서대로 가공도가 자동 생성됩니다.
    명령창에 진행 상황 N / 전체 Working on [타입명 Fab_No] 가 표시됩니다.
  5. 가공도가 완성된 원본 3D 객체는 자동으로 삭제됩니다.

실행 예시

옵션

옵션On일 때 결과
Side_FabDwg_On 좌·우 측면 방향의 추가 가공도 View를 생성합니다.
SectionLine_Mark_On 정면도에 단면 위치 표시선과 A/B 같은 단면 마크를 표시하고, 단면도에도 대응 마크를 작성합니다.
ISO_Dwg_On 백패널 형상을 ISO 방향의 보조 2D 도면으로 추가 생성하고 ISO Dwg 텍스트를 표시합니다.
UnRoll_Dwg_On 백패널을 펼친 전개도(UnRoll Dwg)를 추가 생성하고 외곽 크기를 표기합니다.

생성되는 도면 내용

도면 요소생성 조건설명
정면/배면 2D 기본 생성 백패널 정면 형상을 기준으로 폭·높이 치수선을 작성하고, 배면 방향 Hidden선을 함께 표시합니다.
Top/Right 단면 기본 생성 상부와 우측 단면을 생성하고 단면 치수를 작성합니다. 단면 마크는 SectionLine_Mark_On 옵션에 따라 표시됩니다.
Side FabDwg Side_FabDwg_On = On 좌·우 측면 방향의 추가 View를 생성합니다.
Section Mark SectionLine_Mark_On = On 정면도에 단면 위치 표시선과 A/B 마크를 표시하고, 단면도에도 대응 마크를 작성합니다.
ISO Dwg ISO_Dwg_On = On ISO 방향 보조 2D 도면을 추가 생성하고 ISO Dwg 텍스트를 표시합니다.
UnRoll Dwg UnRoll_Dwg_On = On 백패널 전개도와 외곽 크기를 생성합니다.
