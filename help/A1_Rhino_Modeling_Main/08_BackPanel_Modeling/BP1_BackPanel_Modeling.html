BP1 ~ BP5  —  백패널 모델링

BP1 BP2 BP3 BP4 BP5

유리 면(Glass Surface)을 기준으로 백패널(Back Panel) 3D 솔리드를 자동 생성합니다.
BP1 ~ BP5 는 각각 BpOpt 패널에서 미리 설정해 둔 백패널 타입 1~5 번에 대응합니다.

사용 목적

BpOpt에 설정해 둔 백패널 타입 1~5를 골라 유리 면을 기준으로 백패널 3D 솔리드를 즉시 생성할 때 사용합니다. 타입별 단축 명령이라 여러 사양의 백패널(스팬드럴 패널)을 면마다 빠르게 배치할 수 있으며, Distance·Section 분할 방식을 선택할 수 있습니다.

사용 방법

  1. BpOpt 패널에서 적용할 백패널 타입(두께·이격거리·절곡 타입 등)을 먼저 설정합니다.
  2. Rhino 명령창에 BP1 (또는 BP2~BP5) 을 입력하고 Enter 를 누릅니다.
  3. 마우스로 유리 면 위를 클릭하여 백패널을 생성할 영역을 선택합니다.
  4. 옵션으로 Distance(거리 기준) 또는 Section(단면 기준) 분할 방식을 선택할 수 있습니다.
  5. Enter 를 눌러 완료하면 BackPanel 레이어에 솔리드가 생성됩니다.
