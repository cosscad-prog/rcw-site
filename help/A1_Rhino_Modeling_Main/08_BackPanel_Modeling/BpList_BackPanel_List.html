BpList  —  백패널 수량 리스트

BpList

선택한 백패널 Solid 객체들을 분석하여 백패널 수량 리스트를 생성합니다.
Rhino 화면에 텍스트 리스트를 출력하며, 옵션으로 Excel 파일(.xlsx)로도 저장할 수 있습니다.

사용 목적

선택한 백패널 부재의 수량을 집계해 리스트로 확인할 때 사용합니다. 화면 텍스트로 출력하며, Excel 저장 옵션으로 외부 발주·집계 자료와 연동할 수 있습니다.

사용 방법

  1. Rhino 명령창에 BpList 를 입력하고 Enter 를 누릅니다.
  2. Excel 파일 저장 여부를 옵션(Excel_File_On)으로 설정합니다.
    • Off (기본) — Rhino 화면에만 출력합니다.
    • On — 현재 .3dm 파일과 같은 폴더에 Excel 파일을 함께 저장합니다.
  3. 수량을 집계할 백패널 Solid 객체를 선택하고 Enter 를 누릅니다.
  4. 수량 리스트가 화면에 출력됩니다.

실행 예시

옵션

옵션설명
Excel_File_On Off — Rhino 화면 출력만 수행합니다.
On — 현재 .3dm 파일과 동일 폴더에 Excel 파일을 저장합니다.
파일명 형식: [문서이름]-BackPanelList.xlsx

출력 항목 (컬럼 순서)

순번컬럼명내용
1NO일련번호
2Unit_No유닛 번호
3Fab_No제작 번호 (타입명 + 번호)
4Quantity수량
5Width (mm)폭
6Height (mm)높이
7Code백패널 코드
8Description백패널 설명
9Add1추가 정보 1
10Add2추가 정보 2
11Add3추가 정보 3
12Angle경사각

마지막 행에 전체 수량 합계가 자동으로 추가됩니다.

관련 명령어

명령어설명
BP1 ~ BP5백패널 모델링 — 리스트 집계 전 먼저 생성합니다.
BpNo백패널 번호 부여 — 리스트의 Fab_No 와 연동됩니다.
BpTable백패널 제작 도면 테이블 — 수량 리스트와 함께 사용합니다.
참고: 선택 객체는 Brep(솔리드 또는 열린 폴리서피스) 형태여야 합니다.
