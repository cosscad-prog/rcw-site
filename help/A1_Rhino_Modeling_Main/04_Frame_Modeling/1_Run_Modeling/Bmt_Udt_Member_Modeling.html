Bmt/Udt  —  부재를 하나씩 만들기

Bmt   Udt

Bmt 는 선 하나를 짚어 그 부재 하나만 만듭니다. Udt 는 그렇게 만든 부재들을 한 셋으로 다시 지어 부재끼리 맞물리는 절단까지 반영합니다.

사용 목적

UMD 는 와이어프레임 group 을 완전하게 준비하고 골라야 결과가 나옵니다. Bmt 는 같은 모델링 규칙을 부재 하나 단위로 줍니다 — 처음 배우는 사람과 한두 부재만 고쳐야 하는 상황을 위한 길입니다. 전체를 다시 돌리지 않고 필요한 것만 만들 수 있습니다.

실행 예시

사용 방법

  1. Bmt 를 실행하고 Mullion 이나 Transom 프로파일 group 하나를 고릅니다. (명령창: Select profile group)
  2. 커서를 와이어 근처로 옮기면 그 선에 맞춘 미리보기가 나옵니다. 누르면 그 부재가 만들어집니다. (명령창: Move near a wire and click to create extrusion)
  3. 선을 옮겨 가며 계속 짚습니다. Enter 나 Esc 로 끝냅니다.
  4. 뒤 부재는 같은 와이어프레임 셋에 이어서 더하면 됩니다.
  5. Mullion 과 Transom 이 다 있으면 Udt 로 그 셋을 다시 지어 부재 간 절단이 보이게 합니다. (명령창: Select the BMT Wireframe group)

Udt  —  셋을 다시 짓기

Bmt 는 부재를 하나씩 세우므로, 아직 만들지 않은 이웃 부재와의 맞물림(절단)까지는 알 수 없습니다. Mullion 과 Transom 이 다 놓인 뒤 Udt 를 돌리면 그 와이어프레임 셋을 통째로 다시 지어 부재끼리 파고드는 자리와 브래킷 재가공까지 반영합니다.

언제 돌리나: 부재를 더 얹을 때마다 돌릴 필요는 없습니다. 그 셋이 어느 정도 갖춰졌을 때 한 번 돌리면 됩니다. 다시 돌리면 그 셋의 이전 산출물을 지우고 새로 만듭니다.

알아 둘 것

항목설명
셋 단위로 묶입니다만들어진 것은 와이어프레임 셋 단위로 묶입니다. 그래서 선택이 단순해지고, 관계없는 유닛의 프로파일이 함께 갱신되지 않습니다.
방향은 원본에 남습니다프로파일 방향은 원본 group 에 저장됩니다. 나중에 다시 만들어도 지금의 뷰나 선택 방향에 좌우되지 않습니다.
단면을 찾는 방법단면을 layer 이름이 아니라 선에 심어진 group 번호로 찾습니다. 그래서 같은 layer 에 서로 다른 단면을 둘 수 있습니다.
앵커(ANP) group고른 group 의 이름표가 ANP 로 시작하면 앵커 모드로 동작합니다 — 선이 아니라 AN_Point layer 의 점에 블록·단면을 놓습니다. 같은 점을 다시 고르면 바뀝니다.
단면 data 가 없으면옛 기본 연장값을 씁니다 — Brep·curve 는 50, 원본 Surface 는 0.
한 유닛은 한 방식만 씁니다. 같은 와이어프레임을 Bmt/Udt 로도 만들고 SSP/UMD 로도 만들 수는 없습니다. 섞으려 하면 그 유닛에서 멈추고 알립니다 (SSP/UMD 로 만든 유닛이라 이 부재는 만들지 않았습니다).
방식을 바꾸려면 확인창에서 그 유닛의 산출물을 지우고 전환하면 됩니다. 전용 명령은 없습니다.
⚠️ 이 규칙이 있는 이유: Udt 로 만든 유닛은 같은 layer 에 다른 단면을 둘 수 있어 UMD 로는 표현 자체가 안 됩니다. UMD 가 건드리면 반드시 틀린 형상이 나옵니다.

안 될 때

명령창에 나오는 말뜻
Selected profile object is not in a group.고른 것이 group 에 묶여 있지 않습니다.
Profile group must contain one valid curve on the Center1 layer. 그 group 에 Center1 곡선이 하나 있어야 합니다.
No Surface or Brep objects were found…group 안에 단면 Surface 나 Brep 이 없습니다.
No wire curves were found outside…짚을 와이어 선이 없습니다. 와이어프레임을 먼저 만드십시오.
단면 group 을 복사해서 쓰셨다면 주의하십시오. 복사본은 원본과 같은 group 번호를 갖게 되어 어느 단면을 써야 할지 가릴 수 없습니다. 이때는 아무것도 만들기 전에 멈추고 어느 group 들이 겹쳤는지 알려 줍니다.

관련 명령어

명령어설명
UMD와이어프레임 group 전체를 한 번에 모델링합니다. 같은 유닛에 섞어 쓸 수 없습니다.
SSP단면을 등록합니다. UMD 경로에서 씁니다.
Pname단면에 이름·단중·추가 길이를 넣습니다.
FabNo만들어진 부재에 제작 번호를 부여합니다.
에디션: Bmt·Udt 는 Standard 부터 들어 있습니다. Core 에는 없습니다.
