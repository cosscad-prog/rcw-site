UMD  —  Unit Frame 모델링

UMD

UMD는 선택한 Unit 그룹의 Mullion/Transom 기준선을 분석하여 프레임 솔리드와 관련 Block을 자동 모델링하는 명령입니다. 그룹 안의 Unit No TextDot을 읽어 진행 상태와 결과 그룹 정보를 함께 관리합니다.

사용 목적

Wire Frame(Mullion/Transom 기준선)과 Section 데이터가 준비된 Unit을 실제 프레임 3D 솔리드로 자동 생성할 때 사용합니다. RCW 모델링의 핵심 실행 단계로, 멀리언·트랜섬 모델링과 브라켓 재가공·그룹 정리를 한 번에 처리해 이후 번호 부여·리스트·도면 작업의 바탕이 되는 모델을 만듭니다.

사용 방법

  1. Wire Frame과 Section 데이터가 입력된 Unit 그룹을 준비합니다.
  2. Rhino 명령창에 UMD를 입력하고 Enter를 누릅니다.
  3. Select Group objects 프롬프트에서 모델링할 Unit 그룹을 선택합니다.
  4. Enter를 누르면 그룹별로 Mullion 모델링, Transom 모델링, 브라켓 재가공, 최종 그룹 정리가 순서대로 실행됩니다.

실행 예시

실행 흐름

단계설명
1. 그룹 선택GroupSelect 모드로 Unit 그룹을 선택합니다. 하위 객체 단독 선택보다 그룹 단위 선택을 전제로 합니다.
2. 객체 분류그룹 내부에서 Mullion Curve, Transom Curve, Attach Curve, Anchor Point를 분류합니다.
3. Mullion 생성Section/Profile 데이터를 이용해 Mullion 솔리드와 관련 Block을 생성합니다.
4. Transom 생성Mullion 결과와 브라켓 차감 정보를 반영해 Transom 솔리드를 생성합니다.
5. 재가공/그룹화Transom 브라켓 차감 형상이 있으면 Mullion을 재가공하고, 생성 결과를 Unit 그룹으로 정리합니다.

실행 조건

항목설명
Unit 그룹Wire Frame 작성 단계에서 만든 그룹과 Unit No TextDot이 있어야 작업 흐름을 추적하기 쉽습니다.
Section 데이터Pname, MakeM, MakeT 등으로 Mullion/Transom 데이터가 준비되어 있어야 합니다.
Attach 정보브라켓이나 부속 가공이 필요한 경우 관련 Attach Curve와 Anchor Point가 그룹 안에 포함되어야 합니다.

실행 결과

항목설명
Frame 솔리드Mullion/Transom ProfileData를 가진 Brep 객체가 생성됩니다.
Block브라켓이나 부속물이 필요한 경우 관련 Block 또는 차감 형상이 함께 생성됩니다.
그룹생성된 모델과 기준 객체가 Unit 단위로 다시 그룹화됩니다.

관련 명령어

명령어설명
FabNo생성된 프레임 솔리드에 제작 번호와 ProfileData를 부여합니다.
Molist모델링 결과의 수량 리스트를 작성합니다.
FDwg프레임 제작 가공도를 생성합니다.
주의: 그룹 내부 기준선이나 Section 데이터가 누락되면 일부 Mullion/Transom 모델이 생성되지 않거나 그룹 오류가 발생할 수 있습니다.
