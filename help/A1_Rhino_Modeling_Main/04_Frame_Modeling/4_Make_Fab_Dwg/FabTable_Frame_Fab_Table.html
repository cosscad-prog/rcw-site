FabTable  —  프레임 제작 번호 테이블

FabTable

FabTable은 선택한 프레임 ProfileData를 Profile 이름과 Fab No 기준으로 집계하고, 각 부재의 형상 복사본과 수량 정보를 테이블 형태로 배치하는 명령입니다.

사용 목적

Profile 이름과 Fab No를 기준으로 부재를 집계하고, 각 부재의 형상과 수량을 도면 위 테이블로 배치할 때 사용합니다. 제작도에 부재별 제작 번호 일람을 함께 표기해 생산·검토에 활용하는 용도입니다.

사용 방법

  1. FabNo로 제작 번호를 먼저 작성합니다.
  2. Rhino 명령창에 FabTable을 입력하고 Enter를 누릅니다.
  3. 필요하면 Unit_No_On 옵션을 On으로 변경합니다.
  4. 부자재를 뺀 테이블을 만들려면 Accessory 옵션을 Off로 변경합니다. (기본값 On)
  5. Select Group and/or NBlock Objects for FabTable 프롬프트에서 대상 Brep 또는 NBlock을 선택합니다.
  6. 테이블 시작 위치를 Pick하면 Profile별 테이블이 생성됩니다.

실행 예시

선택 모드

모드설명
Group Mode선택된 Brep에서 ProfileData를 직접 추출합니다. 일반 Block은 이 명령의 Group Mode에서 제외됩니다.
Block ModeNBlock 내부의 Brep와 중첩 Block 정보를 읽어 수량을 반영합니다.
Mixed ModeBrep 결과와 NBlock 내부 결과를 병합해 테이블을 만듭니다.

옵션

옵션On일 때 결과
Unit_No_On테이블의 부재명에 Unit No를 함께 표시합니다. 예: Profile-UnitNo F1
Accessory부자재(Pname의 Material ID가 3. 부자재인 부재)를 테이블에 포함합니다. 기본값은 On이며, Off로 두면 부자재 테이블이 통째로 생성되지 않습니다. Group / Block / Mixed 모드 모두에 적용됩니다. 주부재에 브라켓으로 부착되어 함께 복사되는 형상은 이 옵션의 영향을 받지 않습니다.

실행 결과

항목설명
테이블 외곽Profile별 칸을 만들고 Profile 이름, Fab No, 수량, Length를 표시합니다.
형상 복사본Profile Brep와 관련 중심선/브라켓을 테이블 위치로 복사해 배치합니다.
레이어텍스트는 주로 Text, 부재명/수량은 Profile_No_Qnt, 형상은 Profiles 레이어를 사용합니다.

관련 명령어

명령어설명
FabNo테이블 생성에 필요한 Fab No와 ProfileData를 작성합니다.
FDwg개별 부재의 제작 가공도를 생성합니다.
Molist수량/중량 리스트를 작성합니다.
참고: FabTable 실행 중 CPlane 원점의 Y값이 0이 아니면 명령이 Y=0으로 보정합니다.
