FDstyle  —  가공도 기록 / 재생 패널

FDstyle

FDstyle은 FDwg Pipeline 패널을 열고 닫는 명령입니다. 이 패널에서 가공도(FDDS / FDwg) 작업을 기록(ON) 하거나 재생(OFF, 기본) 하는 모드를 전환하고, 도면 양식 등록·삽입과 Profile별 작업 상태 확인을 한곳에서 처리합니다.

참고: 같은 명령을 다시 입력하면 패널이 닫힙니다(토글). 기록/재생 전환은 명령이 아니라 패널 상단의 배너 버튼으로 합니다. (구 FDP·FDwgStyle 명령은 FDstyle로 통합되었습니다.)

사용 목적

자주 쓰는 Profile의 가공도 작업(옵션·NC 테이블·압축·주석·부속자재 표·부분확대·도면 양식)을 한 번 기록해 두면, 이후 같은 Profile의 가공도를 만들 때 재생 모드로 동일한 결과를 자동으로 재현할 수 있습니다. 사용자별·프로젝트별 표준 가공도 양식을 일관되게 유지할 때 사용합니다.

패널 구성

구성 요소설명

[새로고침]Profile별 작업 상태 표를 다시 읽어 갱신합니다.
[도면양식]외부 3dm 양식 파일을 도면 양식으로 등록합니다. (SFB와 동일 역할)

상태 표Profile별로 각 단계의 완료 상태를 보여줍니다(아래 표 참조).
작업 로그하단에 작업 내용·시각이 누적 표시됩니다.

기록 / 재생 모드

모드동작
기록 (ON)FDwg / FDDS 를 실행하면 현재 옵션과 추가 작업 — NC 테이블, FSC 압축, 주석/지시선, 부속자재 표, 부분확대(F3D), 도면 양식 — 을 Profile별로 저장합니다. 기록 중 직접 추가한 지시선·텍스트·라벨 이동도 자동으로 함께 기록됩니다.
재생 (OFF, 기본)같은 Profile의 가공도를 만들 때 기록된 내용을 읽어 자동으로 재현합니다. 기록된 데이터가 없으면 현재 DdOpt 패널 설정값을 사용합니다.
참고: 파일 데이터 적용은 이 재생 모드가 담당합니다. 기록된 데이터가 없으면 DdOpt 패널의 현재 설정값을 사용하며, DdOpt의 현재 선택을 기본값으로 저장 기능으로 기본값을 미리 저장해 둘 수 있습니다.

기본 사용 방법

① 표준 가공도 기록

  1. FDstyle을 입력해 패널을 엽니다.
  2. 상단 배너를 클릭해 기록 모드(ON)로 전환합니다.
  3. DdOpt에서 원하는 옵션을 맞춘 뒤 FDwg로 가공도를 만듭니다.
  4. 필요하면 NC 테이블·부속자재 표·부분확대·양식 삽입·주석을 추가합니다. (기록 모드라 함께 저장됩니다)
  5. 작업이 끝나면 배너를 다시 눌러 기록을 종료합니다.

② 재생(자동 재현)

  1. 배너가 재생 모드(OFF)인지 확인합니다(기본값).
  2. 같은 Profile의 그룹을 선택해 FDwg를 실행합니다.
  3. 기록해 둔 NC·압축·주석·부속자재·부분확대·양식이 자동으로 재현됩니다.

실행예시

도면 양식 등록 / 삽입

버튼동작
[도면양식]외부 3dm 양식 파일을 골라 등록합니다. 가져온 양식은 화면에서 숨김 처리되고, 블록 이름이 기존 양식과 충돌하면 자동으로 고유 이름을 부여해 서로 다른 양식이 섞이지 않게 합니다.
[양식삽입]등록된 양식을 선택 Profile의 가공도에 도면 단위로 삽입합니다. 도면 크기에 맞춰 배율이 자동 계산됩니다. (기록 모드에서 삽입하면 양식 정보도 함께 기록되어 재생에서 재현됩니다.)
참고: 등록된 양식 정보는 현재 문서(.3dm)에 함께 저장되어, 파일을 닫았다 다시 열어도 자동 복원됩니다. 같은 파일에서는 다시 등록할 필요가 없습니다. (자세한 내용은 SFB 도움말 참고)

Profile 상태 표

각 Profile 행에 작업 단계의 완료 여부가 표시됩니다.

열의미
Profile대상 Profile 이름. 작업 중인 Profile은 강조 표시됩니다.
① 2D2D 가공도 생성 여부.
② NCNC 홀 좌표 테이블 작성 여부.
③ FSC긴 부재 중간 압축(FSC) 적용 여부.
④ 주석지시선/텍스트 등 주석 기록 여부.
⑤ 자재부속자재 표(BOM) 작성 여부.
⑥ 3D부분확대(F3D) 뷰 작성 여부.
⑦ 양식도면 양식 삽입 여부.
상태해당 Profile의 전체 진행 상태 요약.

관련 명령어

명령어설명
FDDS폐기된 명령입니다. 가공도는 FDwg 으로 만듭니다.
FDwg프레임 제작 가공도를 생성합니다. 입면 홀 깊이(Hidden Line)까지 그립니다. FDstyle 모드(기록/재생)를 따릅니다.
DdOpt가공도 Drawing 옵션 패널. 재생 데이터가 없을 때 이 값을 사용합니다.
SFB / FFB도면 양식 선택(SFB)·삽입(FFB). 패널의 [도면양식]·[양식삽입] 버튼과 같은 기능입니다.
주의: 기록 모드에서 같은 Profile의 가공도를 다시 만들면 그 Profile의 기존 기록(옵션·NC·주석·양식 등)은 새 작업 내용으로 교체됩니다. 보존이 필요하면 기록 전에 확인하세요.
