LeaderTextMove  —  라벨 텍스트(꼬리) 이동

LeaderTextMove

LeaderTextMove(구 LM)는 부속(브래킷) 라벨 지시선의 화살표는 고정한 채 텍스트(꼬리)만 옮기는 명령입니다. 라벨을 선택하고 새 텍스트 위치를 클릭하면, 지시선 시작점(화살표)은 부속에 그대로 붙어 있고 꼬리(텍스트)만 이동하며 지시선 라인이 그 위치로 따라옵니다.

사용 목적

일반 Move는 화살표까지 함께 움직여 지시 대상이 흔들립니다. 화살표(지시점)는 부속에 고정한 채 텍스트만 보기 좋은 위치로 옮기고 싶을 때 사용합니다. 단면 라벨이 서로 겹치거나 도면 밖으로 나갈 때 정리하는 용도입니다.

사용 방법

  1. Rhino 명령창에 LeaderTextMove를 입력합니다.
  2. "이동할 라벨(지시선)을 선택하세요" 프롬프트에서 부속 라벨(Leader)을 선택합니다.
  3. 새 텍스트 위치를 클릭합니다. 커서를 따라 실제 라벨 모양 그대로 미리보기가 표시됩니다.
  4. 여러 라벨을 이어서 옮길 수 있습니다. Enter를 누르면 종료합니다.

실행 예시

동작 방식

항목설명
고정 / 이동지시선의 시작점(화살표)은 고정, 마지막 점(텍스트 꼬리)만 이동합니다. 지시선 라인이 새 꼬리 위치로 다시 그려집니다.
미리보기실제 지시선과 같은 DimStyle로 미리보기가 그려져, 클릭 위치가 결과와 일치합니다.
대상Annotation(지시선, Leader)만 선택됩니다. 지시선이 아니면 안내 메시지가 나옵니다.
재생 재현FDstyle 기록 모드에서 옮기면 그 위치가 저장되어, FDwg/FDDS 재생 시 동일하게 재현됩니다.
참고: 화살표까지 라벨 전체를 옮기려면 LeaderMove를 사용하세요. LeaderTextMove는 화살표를 고정하고 꼬리만 옮깁니다.

관련 명령어

명령어설명
LeaderMove화살표를 포함한 라벨 전체를 새 위치로 옮깁니다.
FDstyle기록/재생 모드 패널. 기록 모드에서 옮긴 라벨 위치가 저장됩니다.
FDwg제작 가공도 생성. 재생 시 라벨 이동이 재현됩니다.
