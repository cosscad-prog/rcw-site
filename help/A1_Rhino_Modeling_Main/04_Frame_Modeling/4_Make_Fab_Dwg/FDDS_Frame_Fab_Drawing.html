FDDS  —  프레임 제작 가공도 생성

FDDS

폐기된 명령입니다  —  FDwg 을 쓰십시오.
FDDS 는 더 이상 가공도를 만들지 않습니다. 명령을 실행하면 "더이상 사용하지 않는 명령어 입니다. FDwg 사용하십시요" 안내만 나옵니다.
가공도는 FDwg 하나로 만듭니다. 아래 설명은 옛 도면을 살펴볼 때를 위해 남겨 둡니다.

FDDS는 선택한 프레임 그룹 객체를 분석하여 제작 가공도(Fab Drawing)를 자동 생성하는 명령입니다.
모델을 가공도 위치로 복사·정렬한 뒤, 선택된 View 별로 2D 선, 단면, 홀 지름, 외곽 치수, 중심선 치수, 각도 치수, Fab No / Quantity / Unit No 텍스트를 작성합니다.

사용 목적

선택한 프레임 부재의 제작 가공도(Fab Drawing)를 자동으로 생성할 때 사용합니다. 부재별 2D 외형·단면·홀 지름·치수·제작 번호를 한 번에 작성해 수작업 도면화를 자동화하는 용도이며, Fdds.dat의 Profile별 설정과 DsOpt/DdOpt 옵션에 따라 도면 표기가 정밀하게 맞춰집니다.

참고: 이때 DimStyle 은 [DsOpt] 에 적용된 DimStyle 을 따른다. Profile 별 자동화를 위해 Fdds.dat 이 필요하며,  Fdds.dat 에 Profile Name 및 해당 필요정보가 있어야 한다. Fdds.dat 해당 정보가 없다면 DdOpt 패널의 Drawing 옵션을 따른다.

기본 사용 방법

  1. DdOpt 명령으로 Drawing 옵션 패널을 열고 필요한 View, 치수, 거리 옵션을 설정합니다.
  2. 프레임 모델에 FabNo 등으로 ProfileData / Fab No 정보가 먼저 입력되어 있어야 합니다.
  3. Rhino 명령창에 FDDS 를 입력하고 Enter 를 누릅니다.
  4. 명령 프롬프트 Select Group objects 에서 제작 가공도를 만들 프레임 그룹을 선택합니다.
  5. Enter 를 누르면 그룹별로 가공도 모델과 치수가 생성됩니다.

실행 예시

FDwg 안내: 홀 정보를 단면 View뿐 아니라 Bar 입면도에도 표시하고, 홀의 관통 깊이를 Hidden Line으로 함께 보고 싶다면 FDwg 명령을 사용하세요. 기본 동작은 FDDS와 동일합니다.

DdOpt 옵션 창 샘플

DdOpt 패널은 View 생성 여부, 거리값, 추가 치수, 보조 3D 표시 여부를 한곳에서 조정합니다. 운영체제 테마나 화면 배율에 따라 패널 외형은 달라도 항목의 의미와 적용 순서는 동일합니다.

FDstyle 기록 / 재생 모드

FDDS 는 FDstyle 패널의 모드에 따라 동작합니다. 패널 상단 배너를 눌러 기록(ON) 과 재생(OFF, 기본) 을 전환합니다.

모드동작
기록 (ON)FDDS 로 만든 가공도의 옵션과 추가 작업 — NC 테이블, FSC 압축, 주석/지시선, 부속자재 표, 부분확대(F3D), 도면 양식 등 — 을 Profile별로 FDDS_Data.dat 등에 기록합니다.
재생 (OFF, 기본)기록된 데이터를 읽어, 같은 Profile 의 가공도에 NC 테이블·FSC 압축·주석·부속자재 표·부분확대·양식을 자동으로 재현합니다. 기록된 데이터가 없으면 현재 DdOpt 패널 설정값을 사용합니다.
참고: 파일 데이터 적용은 재생 모드에서 자동으로 이루어집니다(해당 Profile 행이 있을 때). 기록된 행이 없으면 DdOpt 패널의 현재 설정값을 사용합니다. 파일 포맷은 FDDS_Data.dat 도움말을 참고하세요.

옵션 적용 우선순위

조건적용 방식
재생 + 일치 행 있음FDDS_Data.dat를 읽고, 선택 그룹의 금형명(ProfileName 또는 객체 이름의 앞부분)과 일치하는 행이 있으면 파일 값을 우선 적용합니다.
일치 행 없음 / 기록 데이터 없음DdOpt 패널의 현재 체크박스·텍스트박스 값을 사용합니다.

정리: 같은 모델이라도 재생 모드에서 해당 금형 행이 존재하면, 패널에서 보이는 값과 다른 결과가 나올 수 있습니다. 반복 제작 품목은 기록해 둔 데이터(재생)를 쓰고, 일회성 확인 작업은 패널 값을 직접 조정하는 방식이 안전합니다.

DsOpt / DimStyle 치수 옵션과 FDDS의 관계

FDDS의 View 선택과 출력 여부는 주로 DdOpt에서 결정하지만, 실제 치수선이 모델에서 얼마나 떨어져 배치되는지, 치수선끼리 얼마나 간격을 두는지, 각도 치수가 어느 위치에 그려지는지는 DsOpt 패널의 값도 함께 사용합니다.

DsOpt / DimStyle 항목기본값FDDS에서의 역할값 변경 시 결과
First Dist50첫 번째 치수선이 도면 외곽에서 떨어지는 기본 거리입니다. FDDS 내부에서는 DSopt_Dim_First로 사용됩니다.값을 키우면 치수선이 모델에서 멀어져 여유가 생기고, 줄이면 도면이 조밀해지지만 치수와 형상이 겹칠 수 있습니다.
Dim Gap20여러 줄 치수 사이의 간격입니다. FDDS 내부에서는 DSopt_Dim_Gap로 사용됩니다.값을 키우면 치수줄 간격이 넓어지고 가독성이 좋아집니다. 너무 작으면 치수 문자와 선이 겹칩니다.
Angle Dist50각도 치수를 형상에서 얼마나 떨어뜨려 배치할지 결정합니다. FDDS 각도 모델 처리에서 DSopt_Angle_Dist를 사용합니다.값을 키우면 각도 치수가 외곽으로 밀려나고, 줄이면 각도 치수가 형상 가까이에 붙습니다.
LnR Dist20좌우 방향 치수 도구와 일부 2D 치수 명령에서 사용하는 좌우 여백 값입니다. FDDS 자체의 주요 치수 배치에는 First Dist / Dim Gap 영향이 더 큽니다.좌우 전용 치수 명령이나 관련 도면에서 좌우 치수 간격이 달라질 수 있습니다.
Top Max / Bottom Max / Left Max / Right MaxTop, Left 기본 On일부 2D/가공도 치수에서 방향별 최대 치수 표시 방식을 제어합니다. FDDS에서는 DdOpt의 View별 Max 옵션이 직접적으로 더 우선적인 역할을 합니다.다른 제작도/2D 도면 명령과 함께 쓰는 경우 방향별 최대 치수 표시가 달라집니다.
TextSize현재 설정값DimStyle 패널에서 텍스트 기준 크기를 조정합니다. FDDS의 Fab No / Qnt 텍스트는 현재 DimStyle의 TextHeight와 DimensionScale도 함께 반영합니다.값이 커지면 문자와 치수 가독성은 좋아지지만 도면 간격도 더 필요합니다.
DdOpt와 DsOpt의 차이: DdOpt는 “무엇을 만들지”를 정합니다. 예를 들어 Top View를 만들지, Side 치수를 넣을지, Unit No를 표시할지 결정합니다. DsOpt / DimStyle은 “치수를 어디에 얼마나 띄워 그릴지”를 정합니다. 즉, 같은 FDDS 옵션이라도 DsOpt 값이 다르면 치수선 위치와 가독성이 달라집니다.
실무 팁: 대형 프레임이나 View를 많이 켜는 작업에서는 DdOpt의 Dwg Distance만 키우는 것으로 부족할 수 있습니다. 치수끼리 겹치면 DsOpt의 First Dist와 Dim Gap도 함께 키워야 합니다.

주의할 점

해치 패턴: RCWFolder 폴더의 Hatch\acad.pat와 필수 해치 패턴이 없으면 FDDS가 중단되고 안내 메시지가 표시됩니다. Rhino의 Hatch 설정에서 acad.pat를 import해야 합니다.
그룹 데이터: FDDS는 선택 그룹에서 Profiles 레이어의 Shape 모델, ProfileData, Fab No, DimBox/DimBox1, 절단면 데이터를 찾습니다. FabNo 처리 전이거나 그룹 구조가 깨져 있으면 Group Model Error occurs, CutSurface Error 같은 오류가 날 수 있습니다.
재생 모드 데이터: 재생 모드에서 해당 Profile 행이 있으면 패널 값보다 FDDS_Data.dat의 금형별 값이 우선합니다. 예상과 다른 View나 치수가 나온다면 먼저 FDstyle 모드(기록/재생)와 해당 금형 행을 확인하세요.
거리 값: Fab Start Point, Dwg Distance, Fab No Distance가 너무 작으면 원본 모델, 여러 View, 단면, 텍스트, 치수가 서로 겹칩니다. 큰 프레임은 기본값보다 넉넉한 간격을 주는 것이 좋습니다.
홀 인식: 홀은 원통형 Brep face를 기준으로 찾고, 지름이 Min Dia 이상인 것만 표기합니다. 너무 작은 Min Dia는 불필요한 원형 면까지 잡을 수 있고, 너무 큰 Min Dia는 실제 홀을 누락할 수 있습니다.
