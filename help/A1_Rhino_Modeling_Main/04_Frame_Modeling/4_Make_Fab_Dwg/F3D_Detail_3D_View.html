F3D  —  3D 부분 확대 뷰

F3D

F3D는 선택한 부재(Brep)를 별도 3D 창에서 원하는 방향으로 돌려본 뒤, 화면에 보이는 그대로(원근) 숨은선 제거 2D로 변환하여 가공도에 부분 확대(상세) 뷰로 삽입하는 명령입니다. 복잡한 가공 부위나 브래킷 결합부를 입체적으로 보여줄 때 사용합니다.

사용 목적

2D 가공도만으로 이해하기 어려운 부위를, 원하는 각도의 3D 모습으로 도면에 함께 넣어 제작 이해를 돕습니다. 한 번 잡은 방향·배율은 저장되어 FDDS/FDwg 재생 시 동일하게 재현됩니다.

사용 방법

  1. Rhino 명령창에 F3D를 입력합니다.
  2. "3D 확대뷰로 넣을 부재를 선택하세요" 프롬프트에서 대상 부재(Brep)를 선택합니다.
  3. 별도 3D 미리보기 창이 열립니다. 이 창에서 방향을 잡습니다:
    •   우버튼 드래그 — 회전(Orbit)
    •   휠 — 확대/축소(Zoom)
    •   좌버튼 드래그 — 이동(Pan)
  4. 원하는 구도가 되면 [확정]을 누릅니다. 화면에 보이는 그대로(원근)가 숨은선 제거 2D로 변환됩니다.
  5. 도면에서 삽입 위치를 클릭합니다.
  6. 마우스를 움직여 배율을 드래그(시작 0.3 배, "x N.NN" 표시)로 정한 뒤 클릭해 확정합니다.

실행예시

동작 방식

항목설명
방향 잡기실제 Rhino 3D 뷰포트를 임베드한 별도 창에서 잡습니다. 선택한 부재만 격리되어 표시됩니다.
2D 변환잡은 카메라 그대로 숨은선 제거(원근 투영)로 2D 선을 만듭니다. 평면(직교) 변환이 아니라 화면에서 본 입체 모습 그대로입니다.
삽입위치 클릭 후 배율을 드래그로 정합니다. 결과에는 테두리 박스가 함께 그려집니다.
재생 재현카메라·배율 정보가 저장되어, FDstyle 재생 모드의 FDDS/FDwg에서 같은 부재를 동일한 방향·배율로 자동 재현합니다.
참고: 기록 모드에서 F3D로 삽입하면 그 부재의 부분확대 정보가 함께 기록되어, 이후 재생 시 자동으로 다시 그려집니다. (FDstyle 도움말 참고)
주의: 부재(Brep)와 ProfileName 정보가 있어야 합니다. ProfileName 을 찾지 못하면 명령이 중단됩니다. 출력은 항상 모델 실측 기준(scale 1)이며, 3D 창에서의 확대/축소는 보기·구도용입니다.

관련 명령어

명령어설명
FDwg제작 가공도 생성. 재생 모드에서 F3D 부분확대 뷰를 자동 재현합니다.
FDstyle기록/재생 모드 패널. 기록 모드에서 F3D 결과가 저장됩니다.
