FDwg  —  프레임 제작 가공도 생성 (입면 홀 표현)

FDwg

FDwg는 FDDS와 동일하게 선택한 프레임 그룹 객체를 분석하여 제작 가공도(Fab Drawing)를 자동 생성하는 명령입니다. 모델을 가공도 위치로 복사·정렬한 뒤, 선택된 View 별로 2D 선, 단면, 홀 지름, 외곽 치수, 중심선 치수, 각도 치수, Fab No / Quantity / Unit No 텍스트를 작성합니다.

 FDwg는 여기에 더해, Bar 입면도(Front / Top / Bottom 등)에도 홀 정보를 함께 표시하고 홀이 자재를 얼마나 관통하는지(깊이)를 Hidden Line으로 쉽게 파악할 수 있는 도면을 추가로 생성합니다.
FDDS → FDwg 핵심 차이:
  • Shape Curve 레이어를 OutLine Layer 로 표현합니다. 
  • 그 외 옵션·치수·텍스트·레이어 동작은 FDDS와 동일합니다.
참고: 이때 DimStyle 은 [DsOpt] 에 적용된 DimStyle 을 따른다. Profile 별 자동화를 위해 Fdds.dat 이 필요하며,  Fdds.dat 에 Profile Name 및 해당 필요정보가 있어야 한다. Fdds.dat 해당 정보가 없다면 DdOpt 패널의 Drawing 옵션을 따른다.
FDstyle 기록/재생: FDwg/FDDS 는 FDstyle 패널의 모드를 따릅니다 — 기록(ON) 모드에서 옵션·NC 테이블·FSC 압축·주석·부속자재 표·부분확대(F3D)·도면 양식을 Profile별로 기록하고, 재생(OFF, 기본) 모드에서 이를 자동 재현합니다. 자세한 내용은 FDDS 도움말의 "FDstyle 기록 / 재생 모드"를 참고하세요.

사용 목적

FDwg 는 선택한 프레임 그룹 객체를 분석하여 제작 가공도(Fab Drawing)를 자동 생성하고, 입면도에서도 홀 위치와 가공 깊이를 한눈에 확인할 수 있게 하는 명령입니다.

기본 사용 방법

  1. DdOpt 명령으로 Drawing 옵션 패널을 열고 필요한 View, 치수, 거리 옵션을 설정합니다.
  2. 프레임 모델에 FabNo 등으로 ProfileData / Fab No 정보가 먼저 입력되어 있어야 합니다.
  3. Rhino 명령창에 FDwg 를 입력하고 Enter 를 누릅니다.
  4. DdOpt · DsOpt 패널이 닫혀 있으면 FDwg 이 열어 준 뒤 "지금 그 패널에 보이는 값 그대로 계속할까요?" 라고 묻습니다. 예 는 그 값으로 그리고, 아니오 는 여기서 멈춥니다 — 값을 확인·수정한 뒤 FDwg 을 다시 실행하십시오. 두 패널이 이미 열려 있으면 묻지 않고 바로 진행합니다.
  5. 명령 프롬프트 Select Group objects 에서 제작 가공도를 만들 프레임 그룹을 선택합니다.
  6. Enter 를 누르면 그룹별로 가공도 모델과 치수가 생성되고, 입면도에 홀 깊이 Hidden Line이 함께 그려집니다.

실행 흐름

단계설명

4. 모델 정렬선택 그룹에서 Shape 모델, DimBox 모델, 절단면 정보를 찾고 가공도 위치로 복사·정렬합니다.
5. View 생성DdOpt에서 켜진 View만 생성합니다. Top Back, Top, Front, Bottom, Bottom Back을 개별적으로 만들 수 있습니다.
6. 치수/주기 작성각 View에 외곽 치수, 세부 치수, 홀 지름, 각도 치수, 단면, Fab No, 수량, Unit No를 옵션에 따라 작성합니다.
7. 입면 홀 깊이 표현 (FDwg 추가)2D 투영의 Hidden Line 중 홀과 같은 깊이의 선을 선별해 입면도에 점선으로 그립니다.

입면도 홀 깊이 표현 (FDwg 추가 기능)

FDwg는 가공도를 만들 때 Rhino의 2D 투영(HiddenLineDrawing)이 계산한 가려진 선(Hidden Line) 중, 홀과 같은 깊이(Z)에 위치한 선만 선별하여 입면도에 함께 그립니다.

항목설명
표현 방식홀이 자재를 통과하는 구간을 Hidden Line(점선) 으로 표시합니다. 입면도에서 홀의 위치와 관통 깊이를 동시에 확인할 수 있습니다.
기준 정보각 홀(HolePoint)의 Brep Bounding Box 깊이값과, 2D 투영으로 계산된 Hidden Line의 깊이값이 일치하는 것을 자동으로 골라냅니다. 반대편 벽 등 홀과 무관한 가려진 선은 제외됩니다.
표시 레이어선별된 홀 Hidden Line은 Shape_Hidden 레이어(Hidden 선종류)에 그려집니다. 강조용 선이 아니라 일반 가려진 선으로 처리됩니다.
적용 ViewFR / TO / BO / TB / BB 등 생성되는 모든 입면 View에 동일하게 적용되며, 프로파일 방향에 따라 알맞은 View에 자동으로 나타납니다.
기존 마커 유지홀 중심선(Hole_Center), 단면 해치(Hole_Hatch), 홀 포인트(Hole_Points) 등 기존 표기는 그대로 유지되고, 그 위에 깊이 Hidden Line이 추가됩니다.

DdOpt 옵션 창 샘플

FDwg도 FDDS와 동일하게 DdOpt 패널의 View 생성 여부, 거리값, 추가 치수, 보조 3D 표시 여부 설정을 그대로 사용합니다. 운영체제 테마나 화면 배율에 따라 패널 외형은 달라도 항목의 의미와 적용 순서는 동일합니다.

옵션 / 치수 설정

FDwg의 View 선택, 거리, 추가 치수, 보조 3D 표시, 그리고 DsOpt / DimStyle 치수 배치 옵션은 FDDS와 완전히 동일하게 동작합니다. 각 옵션의 상세 설명은 FDDS 도움말 문서를 참고하세요.

옵션 그룹요약
DdOpt Group 1 (View/Max Only/Side Dim)생성할 View 방향과 각 View의 치수 표기 방식을 지정합니다.
DdOpt Group 2 (거리/홀 크기)가공도 시작 위치, View 간격, Fab No 위치, 홀 인식 지름(Hole Dia Min)을 조정합니다.
DdOpt Group 3 (Extra Dim OnOff)90° Angle / Center / Hole / Unit No / P_Section / Attach 추가 정보를 켜고 끕니다.
DdOpt Group 4 (Model View)Shape / Dim / Angle 보조 모델을 도면에 남길지 결정합니다.
DsOpt / DimStyleFirst Dist, Dim Gap, Angle Dist, TextSize 등 치수선 배치/크기를 결정합니다.
옵션 적용 우선순위: 재생 모드에서 FDDS_Data.dat에 해당 금형 행이 있으면 파일 값이 패널 값보다 우선합니다. 행이 없거나 파일이 없으면 DdOpt 패널 값을 사용합니다.

주의할 점

해치 패턴: RCWFolder 폴더의 Hatch\acad.pat와 필수 해치 패턴이 없으면 FDwg가 중단되고 안내 메시지가 표시됩니다. Rhino의 Hatch 설정에서 acad.pat를 import해야 합니다.
그룹 데이터: FDwg는 선택 그룹에서 Profiles 레이어의 Shape 모델, ProfileData, Fab No, DimBox/DimBox1, 절단면 데이터를 찾습니다. FabNo 처리 전이거나 그룹 구조가 깨져 있으면 Group Model Error, CutSurface Error 같은 오류가 날 수 있습니다.
홀 인식: 홀은 원통형 Brep face를 기준으로 찾고, 지름이 Hole Dia Min 이상인 것만 표기합니다. 너무 작은 값은 불필요한 원형 면까지 잡고, 너무 큰 값은 실제 홀을 누락할 수 있습니다.
입면 홀 깊이 Hidden Line: 깊이 표현은 모델에 실제 가공된 형상에서 계산됩니다. 홀이 인식되지 않거나(원통형 face가 아님) 자재가 비정상 형상이면 Hidden Line이 나타나지 않을 수 있습니다. 점선이 과하거나 부족하면 모델의 홀/단면 형상을 먼저 확인하세요.

90° Angle Dim 옵션  —  90도 각도를 켜고 끕니다

DdOpt 의 90° Angle Dim 은 90도 각도만 가르는 스위치입니다. 45도 같은 나머지 각도는 옵션과 무관하게 언제나 그려집니다 — 사면 각도는 도면에서 읽어야 하는 값이기 때문입니다.

90° Angle Dim그려지는 각도
On90도까지 전부 그립니다
Off90도만 빠지고 나머지는 그대로 그립니다

예를 들어 FR 이 90도이고 TP 가 45도인 부재라면, 90° Angle Dim 을 끄면 90도만 사라지고 45도는 그대로 남습니다. [F] 각도(3D 실각도)도 같은 규칙을 따라 [F]90도만 빠집니다.

90도 판정 기준: 도면에 90 으로 찍힐 값을 90도로 봅니다(90도에서 0.05도 이내). 즉 89.96°·90.04° 는 90도로 보아 빠지고, 89.9°·90.1° 는 90도가 아니므로 그대로 그려집니다.
