UnitTable  —  Unit 입면 테이블

UnitTable

UnitTable은 선택한 NBlock unit들을 블록 이름별로 집계하여, 각 unit의 대표 입면을 가로로 나란히 배치하고 그 아래에 이름과 수량을 표기하는 명령입니다.

사용 목적

커튼월 unit(NBlock) 종류별로 입면 일람을 도면 위에 배치할 때 사용합니다. 각 입면 사이를 넉넉히 벌려 두므로, 이어서 UF2D를 실행해 입면 옆에 부재 fablist와 치수를 표기하는 작업으로 연결됩니다.

사용 방법

  1. NBlock으로 unit 블록을 먼저 만들어 둡니다.
  2. Rhino 명령창에 UnitTable을 입력하고 Enter를 누릅니다.
  3. NBlock unit 객체를 선택하세요 프롬프트에서 대상 NBlock들을 선택합니다.
  4. 테이블 시작 위치를 Pick하면 unit 종류별 입면이 배치됩니다.

실행 결과

항목설명
입면 배치블록 이름별로 대표 unit 1개를 복제해 가로로 나란히 배치합니다. unit 사이 간격은 그 unit 폭(BoundingBox X길이)의 4배로, UF2D로 입면 fablist·치수를 넣을 공간을 확보합니다.
이름·수량각 입면 아래에 블록 이름과 Qnt-수량을 표기합니다. 수량은 선택한 NBlock 중 같은 이름의 개수를 합산한 값입니다.
Profile 표만들지 않습니다. (VtTable과 달리 아래쪽 Profile 표가 없습니다.)
레이어이름·수량 텍스트는 Profile_No_Qnt 레이어를 사용합니다.

참고 사항

항목설명
unit 이름unit 이름은 NBlock 블록 정의 이름을 그대로 사용합니다(예: PL0, LT2). NBlock에는 Vent와 같은 별도의 Fab 번호가 없어 이름만 표기됩니다.
선택 대상Description이 NBlock:으로 시작하는 InstanceReference(NBlock)만 집계합니다. 일반 블록은 대상이 아닙니다.

관련 명령어

명령어설명
NBlock선택 객체로 이름이 붙은 unit 블록을 만듭니다.
UF2D배치된 unit 입면에 단면·치수·fablist를 자동 생성합니다.
UnitListunit 이름과 수량을 리스트 테이블로 출력합니다.
FabTableProfile별 형상과 수량을 테이블로 배치합니다.
참고: UnitTable 실행 중 CPlane 원점의 Y값이 0이 아니면 명령이 Y=0으로 보정합니다.
