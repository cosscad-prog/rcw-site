FabBomTable  —  부속자재 표

FabBomTable

FabBomTable(구 FBL)은 가공도에 부속자재 표(BOM)를 마우스로 원하는 위치에 배치하는 명령입니다. 표 내용은 FDwg / FDDS 가공도 생성 시 그룹에서 자동 수집된 부속자재(브래킷·슬리브·부착물 등)로 채워집니다.

사용 목적

가공도에 들어가는 부속자재 목록(종류·수량 등)을 표로 정리해 함께 표기할 때 사용합니다. 부속자재는 가공도를 만들 때 자동으로 모이며, 이 명령은 그 표를 어디에 둘지만 지정합니다. 지정한 위치는 도면 기준점(anchor) 상대좌표로 저장되어, FDDS 재생 시 같은 자리에 자동으로 다시 생성됩니다.

사용 방법

  1. Rhino 명령창에 FabBomTable을 입력합니다.
  2. "부속자재 표를 넣을 가공도를 선택하세요" 프롬프트에서 대상 가공도를 선택합니다. (FDwg/FDDS로 생성된 가공도여야 ProfileName 태그가 있습니다)
  3. 마우스를 움직이면 표 크기·행 구분선 미리보기(주황색)가 표시됩니다. 원하는 좌상단 위치를 클릭합니다.
  4. 해당 위치에 부속자재 표가 그려집니다. (기존 표가 있으면 교체됩니다)

실행 예시

동작 방식

항목설명
표 내용가공도 생성(FDwg/FDDS) 시 그룹의 브래킷·슬리브·부착물에서 자동 수집된 부속자재 데이터로 채워집니다.
위치 지정마우스 미리보기(표 외곽 + 행 구분선)로 좌상단을 클릭해 배치합니다. 표 크기는 자재 종수와 글자 크기에 따라 자동 결정됩니다.
교체같은 Profile에 이미 표가 있으면 지우고 새로 그립니다.
재생 재현배치 위치는 도면 원점 상대좌표로 저장되어, FDstyle 재생 모드의 FDDS에서 같은 자리에 자동 생성됩니다.
참고: 표 내용은 이 명령이 만드는 것이 아니라 가공도 생성 시 자동 수집된 것입니다. 수집된 부속자재가 없으면 "수집된 부속자재가 없습니다" 메시지가 나옵니다 — 먼저 부속자재가 포함된 그룹으로 FDwg/FDDS를 실행하세요.
주의: ProfileName 태그가 없는(=FDwg/FDDS로 만들지 않은) 객체를 선택하면 표를 만들 수 없습니다.

관련 명령어

명령어설명
FDwg가공도 생성. 부속자재를 자동 수집하고, 재생 시 표를 자동 재현합니다.
FDstyle기록/재생 모드 패널. 기록 모드에서 표 위치가 저장됩니다.
FabTable프레임 제작 번호/수량 테이블(부속자재 표와는 별개)을 작성합니다.
