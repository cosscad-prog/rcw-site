AddBrkdata  —  브라켓 데이터 추가

AddBrkdata

AddBrkdata는 선택한 브라켓 Brep에 SectionCustomData를 기록하고, 선택한 Mullion Brep의 BrkIDdata 목록에 브라켓 ID를 추가하는 보조 명령입니다.

사용 목적

AddBrkdata 는 선택한 브라켓 Brep에 SectionCustomData를 기록하고, 선택한 Mullion Brep의 BrkIDdata 목록에 브라켓 ID를 추가하는 보조 명령입니다.

사용 방법

  1. Rhino 명령창에 AddBrkdata를 입력하고 Enter를 누릅니다.
  2. Select Bracket Objects 프롬프트에서 Mullion에 연결할 브라켓 객체를 여러 개 선택합니다.
  3. Enter를 누른 뒤 Select Mullion Objects 프롬프트에서 기준 Mullion 객체 하나를 선택합니다.
  4. 명령이 브라켓 ID 목록을 정리하고 Mullion의 BrkIDdata에 추가합니다.

기록되는 데이터

항목설명
Bracket SectionCustomData브라켓 이름을 P_name에 기록하고, Profile_ID = 1, MnT_ID = 9로 설정합니다.
Mullion BrkIDdata기존 BrkIDdata가 있으면 유효한 ID만 남긴 뒤 새 브라켓 ID를 중복 없이 추가합니다.
완료 메시지추가된 브라켓 개수를 Rhino 명령창에 출력합니다.

관련 명령어

명령어설명
FabNo브라켓 위치까지 반영해 Fab No를 재분석할 때 사용합니다.
FDwg브라켓 부착 치수와 가공도 생성에 BrkIDdata를 참조할 수 있습니다.
CheckPfData데이터 누락 여부를 검사합니다.
주의: 선택한 브라켓 객체가 Brep가 아니거나 Mullion 객체에 Brep 데이터가 없으면 데이터가 정상적으로 기록되지 않을 수 있습니다.
