CheckPfData  —  ProfileData 검사

CheckPfData

CheckPfData는 선택한 Brep 객체에 ProfileData가 있는지 검사하는 명령입니다. 데이터가 없는 객체는 빨간 원과 No ProfileData 텍스트로 표시합니다. 
때때로 Solid 에 결함이 생겨 정상적으로 해석하지 못하는 Solid가 있는지를 확인한다.

사용 목적

프레임 Solid에 ProfileData가 정상적으로 들어 있는지 검사할 때 사용합니다. 데이터가 없거나 형상 결함으로 해석되지 않는 Solid를 빨간 원·No ProfileData 표시로 찾아내어, 자재 리스트·도면 작성 전에 문제 객체를 미리 점검하는 용도입니다.

사용 방법

  1. Rhino 명령창에 CheckPfData를 입력하고 Enter를 누릅니다.
  2. Select Objects 프롬프트에서 검사할 프레임 객체를 선택합니다.
  3. Enter를 누르면 Brep 객체별로 ProfileData 존재 여부를 확인합니다.
  4. 명령창에 정상 객체의 이름/Fab No/Length가 출력되고, 마지막에 누락 개수가 표시됩니다.

검사 결과

상태표시
ProfileData 있음명령창에 Name: ProfileName-FabNo Length 형식으로 정보를 출력합니다.
ProfileData 없음객체 중심에 빨간 원과 No ProfileData 텍스트를 Check 레이어에 작성합니다.
최종 요약[ Error_Count / Total_Count ] 개의 No ProfileData 형식으로 누락 수를 출력합니다.

관련 명령어

명령어설명
UMD프레임 모델을 생성합니다.
FabNoProfileData와 Fab No를 작성합니다.
FDwgProfileData를 사용해 제작 가공도를 생성합니다.
주의: 이 명령은 Brep 기준으로 검사합니다. Block 내부 객체를 검사하려면 필요한 객체를 분해하거나 내부 Brep를 선택할 수 있는 상태에서 확인해야 합니다.
참고: 표시 원과 텍스트 크기는 현재 DimStyle의 TextSize를 기준으로 합니다.
