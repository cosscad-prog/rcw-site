FabNo  —  프레임 제작 번호 부여

FabNo

FabNo는 선택한 프레임 Brep, 일반 Block, NBlock을 분석하여 ProfileData와 제작 번호를 작성하는 명령입니다. 같은 Profile 이름과 형상 조건을 비교해 동일 부재에는 같은 Fab No를 부여합니다.

사용 목적

모델링된 프레임 부재에 ProfileData와 제작 번호(Fab No)를 부여해 동일 부재를 같은 번호로 묶을 때 사용합니다. 이후 자재 리스트(Molist)·절단 리스트(Cuttinglist)·제작 테이블(FabTable)·제작 도면 작성의 기준 데이터가 되는 필수 선행 단계입니다.

사용 방법

  1. Rhino 명령창에 FabNo를 입력하고 Enter를 누릅니다.
  2. 필요하면 명령 옵션 Data_Option을 On/Off로 변경합니다.
  3. Select Brep, Block, NBlock objects for FabNo 프롬프트에서 대상 객체를 선택합니다.
  4. NBlock만 선택한 경우 가공도 앞 문자를 입력합니다. 기본값은 F입니다.
  5. Enter를 누르면 객체 분석 후 Fab_No_Text 레이어에 번호 텍스트가 작성됩니다.

실행 예시

선택 모드

모드설명
Group ModeBrep 또는 일반 Block을 선택한 경우입니다. 그룹 안의 Brep와 일반 Block을 분석합니다.
Block ModeDescription이 NBlock:으로 시작하는 NBlock만 선택한 경우입니다. NBlock 내부 Brep를 분석합니다.
Mixed ModeGroup 대상과 NBlock을 함께 선택한 경우입니다. 두 결과를 통합해서 처리합니다.

옵션

옵션On일 때 결과
Data_OptionFab No가 달라지는 지점을 확인하기 위한 비교 데이터 표를 지정 위치에 추가로 출력합니다.

실행 결과

항목설명
ProfileDataBrep에 Unit No, Profile Name, Fab No, 길이/형상 비교 데이터가 기록됩니다.
번호 텍스트Fab_No_Text 레이어에 ProfileName F1 같은 확인용 텍스트가 배치됩니다.
브라켓 번호브라켓 객체는 별도 하위 레이어에서 더 작은 텍스트로 표시될 수 있습니다.

관련 명령어

명령어설명
UMDFabNo를 부여할 프레임 모델을 생성합니다.
CheckPfDataProfileData 누락 객체를 검사합니다.
MolistFab No 기준으로 수량 리스트를 작성합니다.

주의: FabNo 실행 후에는 전체 PolySurface 수와 작성된 번호 텍스트 수를 비교해 누락 객체가 없는지 확인하는 것이 좋습니다.
