FabNo  —  프레임 제작 번호 부여

FabNo

FabNo는 선택한 프레임 Brep, 일반 Block, NBlock을 분석하여 ProfileData와 제작 번호를 작성하는 명령입니다. 같은 Profile 이름과 형상 조건을 비교해 동일 부재에는 같은 Fab No를 부여합니다.

사용 목적

모델링된 프레임 부재에 ProfileData와 제작 번호(Fab No)를 부여해 동일 부재를 같은 번호로 묶을 때 사용합니다. 이후 자재 리스트(Molist)·절단 리스트(Cuttinglist)·제작 테이블(FabTable)·제작 도면 작성의 기준 데이터가 되는 필수 선행 단계입니다.

사용 방법

  1. Rhino 명령창에 FabNo를 입력하고 Enter를 누릅니다.
  2. Select Brep, Block, NBlock objects for FabNo 프롬프트에서 대상 객체를 선택합니다.
  3. NBlock만 선택한 경우 가공도 앞 문자를 입력합니다. 기본값은 F입니다.
  4. Enter를 누르면 객체 분석 후 Fab_No_Text 레이어에 번호 텍스트가 작성됩니다.

Group ModeBrep 또는 일반 Block을 선택한 경우입니다. 그룹 안의 Brep와 일반 Block을 분석합니다.
Block ModeDescription이 NBlock:으로 시작하는 NBlock만 선택한 경우입니다. NBlock 내부 Brep를 분석합니다.

지운 번호 글자 다시 보기  —  FabNoShow

FabNoShow

FabNoShow는 FabNo가 화면에 쓴 번호 글자를 지웠을 때 그 글자를 다시 쓰는 명령입니다. 번호를 새로 매기지 않고, 부재에 저장되어 있는 번호를 읽어 글자만 씁니다. FabNo를 다시 실행하는 것보다 빠르고 번호가 바뀌지 않습니다.

  1. Rhino 명령창에 FabNoShow를 입력하고 Enter를 누릅니다.
  2. 번호를 다시 볼 Brep, 일반 Block, NBlock을 선택하고 Enter를 누릅니다.
항목설명
번호 글자FabNo가 썼던 것과 같은 글자(ProfileName F1)를 같은 자리에 같은 크기로 씁니다. 레이어는 FabNo의 마지막 실행 레이어(Fab_No_Text 아래)입니다.
블록 이름선택한 Block, NBlock의 이름도 FabNo처럼 삽입점에 빨간 글자로 다시 씁니다.
이미 있는 글자같은 글자가 같은 자리에 남아 있으면 다시 쓰지 않습니다. 숨겨져 있거나 레이어가 꺼져 있으면 보이게만 합니다. 여러 번 실행해도 글자가 겹치지 않습니다.
번호가 없는 부재FabNo를 한 번도 실행하지 않은 부재에는 글자를 쓰지 않고 그 개수를 명령창에 알립니다. 먼저 FabNo를 실행하십시오.

관련 명령어

명령어설명
