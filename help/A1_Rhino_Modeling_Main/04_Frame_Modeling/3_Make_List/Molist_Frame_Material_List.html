Molist  —  프레임 자재 리스트

Molist

Molist는 선택한 프레임 모델의 ProfileData와 Block 정보를 읽어 자재 수량 리스트를 생성하는 명령입니다. Group, NBlock, 혼합 선택을 자동으로 판별하고 결과를 하나의 리스트로 집계합니다.

사용 목적

프레임 모델 전체의 자재 수량과 중량을 한 리스트로 집계할 때 사용합니다. 절단 계획 전 전체 소요 자재를 파악하거나 발주 수량을 확인하는 용도이며, Excel_File_On 옵션으로 외부 집계와 연동할 수 있습니다.

사용 방법

  1. FabNo로 ProfileData와 Fab No를 먼저 작성합니다.
  2. Rhino 명령창에 Molist를 입력하고 Enter를 누릅니다.
  3. 필요하면 Excel_File_On 옵션을 On으로 바꿉니다.
  4. Select Brep, Block objects for Molist 프롬프트에서 대상 Brep, 일반 Block, NBlock을 선택합니다.
  5. Enter를 누르면 화면에 리스트가 작성되고, 옵션이 On이면 Excel 파일도 저장됩니다.

실행 예시

선택 모드

모드설명
Group ModeBrep와 일반 Block에서 ProfileData / InstanceInfo를 추출합니다.
Block ModeNBlock 내부 Brep와 중첩 Block 정보를 추출합니다.
Mixed ModeGroup Mode 결과와 Block Mode 결과를 합쳐서 집계합니다.

출력 항목

항목설명
Unit NoProfileData의 Unit 번호입니다.
SHAPE NameProfile 이름 또는 Block 이름입니다.
FAB NOFabNo에서 부여된 제작 번호입니다.
Cut Length / Quantity부재 절단 길이와 수량입니다.
Unit_Weight / Weight단중과 수량을 반영한 중량입니다.
DescriptionSectionCustomData 또는 Block Description에서 읽은 설명입니다.

관련 명령어

명령어설명
FabNoMolist 집계에 필요한 Fab No와 ProfileData를 생성합니다.
PMolistProfile 중심의 간단한 자재 리스트를 작성합니다.
Cuttinglist절단 계획과 장바 리스트를 생성합니다.
참고: 부분 선택하면 선택한 객체만 기준으로 부분 Molist가 작성됩니다.
