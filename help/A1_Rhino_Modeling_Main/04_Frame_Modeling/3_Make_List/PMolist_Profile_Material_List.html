PMolist  —  Profile 자재 리스트

PMolist

PMolist는 선택한 Brep 또는 Block에서 ProfileData를 읽어 Profile 중심의 수량/중량 리스트를 작성하는 명령입니다. Block 수량보다 Profile 부재 자체의 집계를 빠르게 확인할 때 사용합니다.

사용 목적

Block 단위 수량이 아니라 Profile 부재 자체를 중심으로 수량·중량을 집계할 때 사용합니다. 부재(프로파일) 단위 물량을 빠르게 확인하려는 경우에 적합하며, Molist가 모델 전체 집계인 데 비해 Profile 중심의 관점을 제공합니다.

사용 방법

  1. FabNo 처리된 프레임 솔리드를 준비합니다.
  2. Rhino 명령창에 PMolist를 입력하고 Enter를 누릅니다.
  3. 필요하면 Excel_File_On 옵션을 On으로 바꿉니다.
  4. Select Solid objects 프롬프트에서 Brep 또는 InstanceReference 객체를 선택합니다.
  5. Enter를 누르면 Profile별 수량 리스트가 화면에 작성됩니다.

실행 예시

옵션

옵션On일 때 결과
Excel_File_OnRhino 파일명 뒤에 PMolist 파일명을 붙여 Excel 파일로 저장합니다.

출력 항목

항목설명
Unit NoProfileData에 기록된 Unit 번호입니다.
SHAPE Name_FAB NOProfile 이름과 Fab No를 한 항목으로 표시합니다.
Cut Length / Quantity동일 Profile/Fab No 기준으로 집계된 절단 길이와 수량입니다.
Weight길이, 수량, 단중을 반영한 중량입니다.

PMolist와 Molist의 차이

명령어차이
PMolistProfile 부재 중심으로 간단히 집계합니다.
MolistProfileData와 Block 정보를 함께 통합해 더 넓은 자재 리스트를 작성합니다.
참고: ProfileData가 없는 Brep는 리스트에 포함되지 않습니다.
