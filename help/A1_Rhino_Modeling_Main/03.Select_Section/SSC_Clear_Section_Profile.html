SSC  —  Section 선택 상태 초기화

SSC

SSP로 저장한 Section Profile 선택 상태를 모두 초기화합니다.

사용 방법

  1. Rhino 명령창에 SSC를 입력하고 Enter를 누릅니다.
  2. 명령창에 Section Profile Selection Clear 메시지가 표시되는지 확인합니다.
  3. 필요하면 SSP로 작업할 Section을 다시 선택합니다.

실행 결과

항목설명
초기화 대상저장된 Section Profile 선택 목록이 비워집니다.
사용 목적잘못 선택된 Section 상태를 지우고 새 작업을 시작합니다.

관련 명령어

명령어설명
PnameSection Profile 이름과 속성 입력
SSPSection Profile 그룹 선택
SSCSection 선택 상태 초기화
