SSP  —  Section Profile 그룹 선택

SSP

Section Profile 그룹을 선택하고, 선택된 Section의 Profile 데이터와 그룹 정보를 현재 작업 상태로 저장합니다.

사용 목적

여러 단면 요소를 묶은 Section Profile 그룹을 현재 작업 대상으로 지정할 때 사용합니다. 이후 모델링·데이터 입력 명령이 이 선택 상태를 기준으로 동작하므로, 작업할 Section을 먼저 확정하는 단계입니다.

사용 방법

  1. Rhino 명령창에 SSP를 입력하고 Enter를 누릅니다.
  2. 작업할 Section Profile 그룹을 선택합니다.
  3. 필요하면 Check_Error 옵션을 On으로 두고 속성 오류를 함께 검사합니다.
  4. 선택이 완료되면 후속 모델링 명령에서 현재 Section 정보를 참조합니다.

저장 데이터선택된 Section Profile 그룹 정보가 내부 선택 목록에 저장됩니다.

오류 조건Unit_No 또는 Center1 Curve가 없으면 명령창에 오류 메시지가 표시될 수 있습니다.

복사한 group 자동 수선

단면 group 을 복사하면 단면 data 도 그대로 따라와, 블록·Milling 곡선·합성 태그가 원본 group 의 것을 계속 가리킵니다. 그대로 모델링하면 복사본의 구멍·절삭이 원본 자리에 생깁니다. SSP 는 선택한 group 마다 이것을 찾아 group 안의 짝으로 바꿉니다. 바꾼 것은 명령창에 한 줄씩 남습니다.

대상짝을 찾는 기준
Block같은 이름의 블록 중, 단면에서 같은 방향·같은 거리에 있는 것(단면 BBox 최소점 → 삽입점 벡터).
Milling 곡선group 안의 닫힌 곡선 중 길이가 같고 단면 중심에서 같은 방향·같은 거리에 있는 것. 단면 양옆에 대칭으로 놓인 같은 곡선도 방향으로 갈립니다.
합성 태그복사본에 새 합성 번호를 붙여 group 안에서 다시 묶습니다.
참고: 기준 자리는 원본 블록·곡선이 원본 단면에서 떨어진 지금 자리를 먼저 씁니다. 원본을 지웠으면 Pname·SSP 가 저장해 둔 자리를 씁니다(한 번이라도 SSP 를 거친 group 이면 저장돼 있습니다). 회전해서 복사한 group 은 방향이 달라지므로 거리만으로 한 번 더 찾고, 딱 하나일 때만 바꿉니다.
경고창 표시뜻과 조치
누락원본이 지워졌고 group 안에도 짝이 없습니다(또는 저장된 자리도 없습니다). Pname 에서 다시 고르십시오.
위치이름·길이는 맞는 후보가 있지만 같은 자리에 있는 것이 없습니다. 크기를 바꿔 복사했거나 곡선·블록을 옮긴 경우입니다.
중복같은 자리에 후보가 둘 이상이라 가릴 수 없습니다(예: 회전 복사 + 대칭 자리). Pname 에서 직접 고르십시오.
