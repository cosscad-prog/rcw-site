GrMolist  —  그릴 부재 리스트

GrMolist

선택한 그릴 그룹 안에 들어 있는 개별 프로파일 부재를 집계하여 부재 리스트(Molist)를 생성합니다.
프레임 등 다른 모델이 함께 선택되어도 그릴 그룹에 속한 부재만 골라서 집계하므로, 전체 모델을 한 번에 선택해도 됩니다.
Rhino 화면에 텍스트 표로 출력하며, 옵션으로 Excel 파일로도 저장할 수 있습니다.

사용 목적

그릴을 발주·가공 단위로 넘기려면 그릴 자체의 크기가 아니라 그릴을 구성하는 프로파일의 절단 길이와 수량이 필요합니다. GrMolist는 그릴 그룹을 풀어서 그 안의 프로파일을 형상명·절단길이별로 묶어 집계합니다.

프레임과 그릴은 보통 한 도면에 함께 있습니다. GrMolist는 선택 범위와 관계없이 그릴 그룹에 속한 부재만 남기므로, 프레임 부재를 일일이 피해서 선택할 필요 없이 전체 모델을 창 선택으로 한 번에 잡아도 그릴 리스트만 나옵니다.

GrList · Molist 와의 차이

명령어집계 단위
GrList그릴 그룹 1개 = 1행. 그릴의 폭·높이·코드 등 완제품 기준 수량 리스트입니다.
GrMolist그릴 그룹 안의 프로파일 부재 1종 = 1행. 형상명·절단길이·수량·중량 기준의 부재 리스트입니다.
그릴 그룹에 속한 부재만 집계합니다.
Molist같은 표 형식이지만 선택한 것을 모두 집계합니다. 프레임·그릴을 함께 선택하면 한 리스트에 섞여 나옵니다.

즉 Molist는 "선택한 전부", GrMolist는 "선택한 것 중 그릴만" 입니다. 같은 객체를 선택해도 결과가 다릅니다.

사용 방법

  1. Rhino 명령창에 GrMolist 를 입력하고 Enter 를 누릅니다.
  2. Excel 파일 저장 여부를 옵션(Excel_File_On)으로 설정합니다.
  3. 집계할 객체를 선택합니다. 그룹 선택이 켜져 있으므로 그룹 안의 객체를 하나만 클릭해도 그룹 전체가 선택됩니다.
    그릴만 골라서 선택할 필요는 없습니다. 프레임을 포함한 전체 모델을 창 선택으로 잡아도 됩니다.
  4. Enter 를 눌러 선택을 마칩니다.
  5. 그릴 그룹에 속하지 않은 객체는 자동으로 제외되고, 제외된 개수가 명령창에 표시됩니다.
    [GrMolist] Grill Group 에 속하지 않은 객체 99개를 제외했습니다. 남은 것 — Brep: 34개, …
  6. 부재 리스트가 현재 작업평면에 텍스트 표로 작성됩니다. 옵션이 On이면 저장할 파일 이름을 입력받아 Excel 파일도 저장합니다.

실행 예시

옵션

옵션설명
Excel_File_On Off — Rhino 화면 출력만 수행합니다.
On — 저장할 파일 이름을 명령창에서 입력받아 Excel 파일로 저장합니다.
저장 위치는 현재 .3dm 파일 경로 앞부분에 입력한 이름을 붙인 [문서경로]-[입력한 이름] 형식입니다.

선택 대상 — 무엇이 집계되고 무엇이 빠지나

선택한 것을 그대로 집계하지 않고, 그릴 그룹에 속하는지를 먼저 판정합니다.

대상처리
그릴 그룹의 Brep집계 — 프로파일 데이터를 읽어 형상명·절단길이별로 묶습니다.
그릴 그룹 밖의 Brep제외 — 프레임 프로파일 등은 그릴 그룹에 속하지 않으므로 리스트에 들어가지 않습니다.
Block (Instance)Description 이 NBlock: 으로 시작하면 Named Block 으로 인식합니다. 블록 안에 그릴이 들어 있으면 그 그릴 부재만 집계하고, 같은 블록 안의 프레임 부재는 제외합니다. 그릴이 없는 블록은 통째로 제외됩니다.

도면 위의 그릴 그룹과 블록 안의 그릴을 함께 선택하면 두 결과를 하나의 리스트로 합쳐 출력합니다.

그릴 그룹 판정 기준: GR1 ~ GR5 모델링이 그룹에 기록해 둔 그룹 정보를 읽어 판정합니다. 따라서 수동으로 묶은 그룹이나, 그릴 모델링을 거치지 않은 객체는 그릴로 인식되지 않습니다.
블록 안의 그릴은 NBlock 을 만들 때 함께 저장된 정보로 판정합니다. NBlock 기능이 들어오기 전에 만들어진 오래된 블록은 그 정보가 없어 그릴을 찾지 못할 수 있습니다 — 이 경우 블록을 다시 만드십시오.

출력 항목 (컬럼 순서)

순번컬럼명내용
1NO일련번호
2Unit No유닛 번호
3SHAPE Name프로파일 형상 이름
4FAB NO가공 번호 (Fab 문자 + 번호)
5Cut Length(L)절단 길이 (mm)
6Quantity수량
7FINISH표면 처리
8Unit_Weight(Kg/M)미터당 단위 중량
9Weight(Kg)절단길이 × 수량 × 단위중량으로 계산한 중량
10Description프로파일 설명

알루미늄 부재 다음에 Alum.Total 소계 행이 들어가고, 마지막에 전체 수량과 중량 합계 행이 추가됩니다.

관련 명령어

명령어설명
GR1 ~ GR5그릴 모델링 — 집계 전에 먼저 생성합니다.
GrNo그릴 번호 부여 — 리스트의 Unit No 와 연동됩니다.
GrList그릴 그룹 단위 수량 리스트 — 완제품 기준 집계입니다.
Molist프레임 부재 리스트 — 같은 출력 형식을 사용합니다.
VtMolist벤트 그룹의 부재 리스트 — 그릴과 같은 방식으로 동작합니다.
주의: 프로파일 데이터가 없는 객체는 집계되지 않습니다. 리스트가 비어 있으면 명령창의 메시지를 먼저 확인하십시오.
  • ProfileData 를 찾지 못했습니다 — 프로파일 데이터는 GrNo 가 기록합니다. GrNo 를 먼저 실행한 뒤 다시 실행하십시오.
  • Grill Group 에 속한 것이 없습니다 — 선택한 것 중 그릴이 없다는 뜻입니다. 그릴을 포함해 다시 선택하십시오.
그래도 비어 있으면 Pname 으로 단면 정보가 입력되었는지 확인하십시오.
