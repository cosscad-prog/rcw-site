GR1 ~ GR5  —  그릴 모델링

GR1 GR2 GR3 GR4 GR5

선택한 Brep 면을 기준으로 그릴 프레임과 블레이드 3D 솔리드를 자동 생성합니다.
GR1 ~ GR5 는 각각 GrOpt 패널에서 미리 설정해 둔 그릴 타입 1~5 번에 대응합니다.

사용 목적

GrOpt에 설정해 둔 그릴 타입 1~5를 골라 커튼월 면에 그릴 프레임과 블레이드 3D 솔리드를 즉시 생성할 때 사용합니다. 타입별 단축 명령이라 여러 사양의 그릴(루버)을 면마다 빠르게 배치할 수 있습니다.

사용 방법

  1. GrOpt 패널에서 적용할 그릴 타입과 섹션 데이터를 먼저 설정합니다.
  2. Rhino 명령창에 GR1 (또는 GR2~GR5) 을 입력하고 Enter 를 누릅니다.
  3. 명령 프롬프트 Select Grill Surface Object 에서 그릴을 생성할 Brep 면을 선택합니다.
  4. Enter 를 눌러 완료하면 선택 면 기준으로 프레임과 블레이드가 그룹으로 생성됩니다.

실행 결과

항목설명
생성 객체Left / Right / Top / Bottom 프레임과 내부 Blade 솔리드가 생성됩니다.
그룹생성된 솔리드와 GR 번호 텍스트가 하나의 Rhino 그룹으로 묶입니다.
데이터그룹에 Grill 타입 데이터가 저장되어 GrNo, GrList, GrTable에서 사용됩니다.
비직각 면4면이 90도가 아닌 경우 별도 로직으로 생성하며 Rhino 명령창에 안내 메시지를 출력합니다.
