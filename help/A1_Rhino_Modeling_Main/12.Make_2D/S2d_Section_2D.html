S2d, Sec2d  —  Section 2D

S2d Sec2d

S2d , Sec2d는 선택한 Solid Unit의 View 방향을 기준으로 Top/Right Section과 2D와 치수를 생성합니다.
완성된 Solid Model 을 이용하여 2D Section 을 만든다.   
           1. Profile Visual Line 과 Block Line이 생성된다. 
           2. Glass , BackPanel 이 있다면, 함께 나온다. 
           3. Center Line 을 따라 치수가 기입된다. (Current Dim style 을 따른다.)
           ▶ 단면을 형성할 위치에 라인이 있어야 한다. 

사용 목적

완성된 Solid Unit을 View 방향 기준 Top/Right 단면 2D와 치수로 만들 때 사용합니다. Glass·BackPanel이 있으면 함께 표현되며, 단면을 형성할 위치에 라인이 있어야 동작합니다.

사용 방법

  1. S2d 또는 Sec2d를 입력합니다.
  2. Make2D를 적용할 객체 선택 프롬프트에서 대상 3D 객체를 선택합니다.
  3. 필요 시 단면을 형성할 라인을 선택합니다.
  4. 생성된 Section 곡선과 치수를 확인합니다.

실행 예시

주의: 선택 Unit의 View 각도에 따라 Section을 만들기 때문에 복잡한 방향의 모델은 정확한 Section이 나오지 않을 수 있습니다.
