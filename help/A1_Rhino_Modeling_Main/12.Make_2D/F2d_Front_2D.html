F2d  —  Front 2D

F2d

F2d는 선택한 3D 객체를 Front View 기준으로 Make2D 처리해 입면 2D 곡선과 치수를 생성하는 명령입니다.
           1. Profile Visual Line 과 Block Line이 생성된다. 
           2. Profile 라인이 잘 보이도록 Glass Line은 생략된다.
           3. Center Line 을 따라 치수가 기입된다. (Current Dim style 을 따른다.)

사용 목적

선택한 3D 객체를 Front View 기준 입면 2D(곡선과 치수)로 만들 때 사용합니다. 입면 도면이 필요할 때 사용하며, Profile 라인이 잘 보이도록 Glass Line은 생략되고 Center Line을 따라 현재 DimStyle 기준으로 치수가 기입됩니다.

사용 방법

  1. Rhino에서 Front View가 존재하는지 확인합니다.
  2. F2d를 입력합니다.
  3. Make2D를 적용할 객체 선택 프롬프트에서 대상 객체를 선택합니다.
  4. Enter를 누르면 Front 기준 2D 결과가 생성됩니다.
