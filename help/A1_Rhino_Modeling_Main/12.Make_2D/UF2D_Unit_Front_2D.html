UF2D  —  Unit Front 2D

UF2D

UF2D는 선택한 Solid Unit의 Section 2D, Fablist, Front 입면 2D와 치수를 함께 생성하는 통합 명령입니다.
단면을 형성할 위치에 Point 를 찍어서 Cross Line 을 만든다. 2개점까지 가능하다.

사용 목적

U2D의 단면 2D·Fablist에 더해 Front 입면 2D와 치수까지 한 번에 만들 때 사용합니다. 단면과 입면 도면이 함께 필요한 Unit 도면화를 한 명령으로 끝낼 때 사용합니다.

사용 방법

  1. UF2D를 입력합니다.
  2. Make2D를 적용할 객체 선택 프롬프트에서 Unit 객체를 선택합니다.
  3. Enter를 누르면 Section 2D와 Fablist가 생성됩니다.
  4. 이어 Front 입면 2D와 치수가 생성됩니다.

관련 명령어
