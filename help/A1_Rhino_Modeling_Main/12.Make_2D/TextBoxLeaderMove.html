TextBoxLeaderMove  —  텍스트박스 지시선 이동

TextBoxLeaderMove

Fablist TypeB 라벨의 텍스트박스를 이동할 때 사용합니다.
박스(테두리·텍스트·구분선)가 새 위치로 이동하고, 지시선의 끝점(박스쪽)은 자동으로 갱신됩니다.
지시선의 시작점(멤버 중점)은 고정되어 움직이지 않습니다.

사용 목적

Fablist TypeB로 생성한 라인별 미니 테이블 라벨이 겹치거나 위치를 조정해야 할 때 사용합니다. 일반 Move 명령으로 텍스트박스만 이동하면 지시선이 따라오지 않지만, TextBoxLeaderMove를 사용하면 박스 이동에 맞춰 지시선 끝점이 자동으로 재계산됩니다.

사용 방법

  1. TextBoxLeaderMove를 입력합니다.
  2. FabList type_B 그룹 객체를 선택하세요 프롬프트에서 이동할 텍스트박스 그룹의 아무 객체(박스선, 텍스트, 구분선)를 클릭합니다.
  3. 박스 중심을 기준으로 오렌지색 미리보기(박스 외곽 + 지시선)가 표시됩니다. 새 위치를 클릭합니다.
  4. 박스와 텍스트가 이동하고 지시선 끝점이 자동 갱신됩니다.
  5. 계속해서 다른 박스를 선택하거나, Enter를 눌러 종료합니다.

실행 예시

텍스트박스 그룹 내 어느 객체(테두리 Polyline, 행 텍스트, 구분선)를 클릭해도 동일하게 동작합니다. 지시선(Leader) 자체를 클릭해도 선택됩니다.

동작 원리

항목설명
이동 기준점현재 박스 bbox의 중심. 클릭한 새 위치로 박스 중심이 이동합니다.
이동 대상테두리 Polyline, 행 TextEntity, 행 구분선 — 모두 동일한 변위로 이동합니다.
지시선 끝점 갱신이동된 박스 가장자리에서 멤버 중점(고정)에 가장 가까운 점으로 자동 재계산됩니다.
지시선 시작점멤버 중점 — 절대 변경되지 않습니다.

주의사항

Fablist TypeB 생성 이전 객체에는 적용 안 됨.
TextBoxLeaderMove는 Fablist TypeB로 생성된 객체에만 동작합니다(FablistGroupKey 태그 필요). 이전 버전 또는 수동으로 만든 박스+지시선에는 사용할 수 없습니다.
