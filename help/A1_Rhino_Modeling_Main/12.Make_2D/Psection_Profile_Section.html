Psection  —  Profile Section

Psection

Psection은 선택한 Profile 방향에 맞춰 단면을 생성하는 명령입니다.
Unit 안의 개별 Profile 단면 확인에 사용합니다.
            1. Profile Visual Line 이 생성된다. 
            2. Profile 라인이 잘 보이도록 Glass Line, BackPanel 은 생략된다.

사용 목적

Unit 안의 개별 Profile 단면을 그 Profile 방향에 맞춰 확인할 때 사용합니다. Profile 라인이 잘 보이도록 Glass·BackPanel 라인은 생략되며, 부재 단면을 개별적으로 검토하는 용도입니다.

사용 방법

  1. Psection을 입력합니다.
  2. 단면을 만들 Profile 또는 관련 3D 객체를 선택합니다.
  3. 단면 기준 위치를 지정합니다.
  4. 생성된 단면 곡선을 확인합니다.
