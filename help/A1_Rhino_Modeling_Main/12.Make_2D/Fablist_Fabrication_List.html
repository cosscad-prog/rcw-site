Flist, Fablist  —  제작 리스트

Flist Fablist

Flist와 Fablist는 같은 기능을 실행하는 동일 명령어입니다.
선택한 Brep, 일반 Block, NBlock을 분석하여 Unit 단위 제작 리스트와 번호 표시를 작성합니다.
         1. 입면에 프로파일 해당 번호를 만든다. 
         2. FabList 는 알루미늄 Profile, Steel Profile, 부자재 Profile, Block 순으로 정렬된다.  
         3. Text Size 는 Current Dim style 을 따른다.

사용 목적

선택한 Unit의 제작 리스트와 입면 번호 표시를 작성할 때 사용합니다. 알루미늄·스틸·부자재 Profile, Block 순으로 정렬된 제작 리스트가 필요할 때 사용하며, Flist와 동일한 명령입니다.

사용 방법

  1. Flist 또는 Fablist를 입력합니다.
  2. 필요하면 SubMaterial_No 옵션을 On/Off로 변경합니다.
  3. LabelType 옵션으로 입면 번호 표시 방식을 선택합니다 — TypeA(원+번호) 또는 TypeB(라인별 미니 테이블).
  4. 필요하면 LabelFontScale 로 라벨 글자 크기 배율을 조정합니다(기본 2.5).
  5. SaveAsDefault 를 On 으로 두고 실행하면 현재 LabelType·LabelFontScale 가 기본값으로 저장되어, 다음부터 자동 적용됩니다.
  6. Select Brep, Block, NBlock objects for Fablist 프롬프트에서 대상 객체를 선택합니다.
  7. Enter를 누르면 선택 객체를 분석해 제작 리스트를 작성합니다.

실행 예시

옵션

옵션설명
SubMaterial_NoOn 이면 부자재(Profile_ID 3) 번호 표시를 함께 생성합니다.
LabelType입면 번호 표시 방식. TypeA = 원+번호(기존), TypeB = 라인별 미니 테이블.
LabelFontScale라벨 글자 크기 배율. 표시 크기 = FontHeight × 이 값 × DimensionScale (기본 2.5).
SaveAsDefaultOn 으로 실행하면 현재 LabelType·LabelFontScale 를 기본값으로 저장합니다(System_Default.dat).

라벨 표시 방식 (TypeA / TypeB)

전체 제작 리스트 표는 두 방식 모두 동일하게 생성되며, 입면에 표시되는 라벨만 달라집니다.

방식설명
TypeA솔리드마다 원 + 번호를 지시선으로 표시합니다. 표의 NO 와 1:1 대응됩니다.
TypeB같은 센터라인(멤버)에 속한 솔리드들을 하나로 묶어, 그 라인의 ProfileName Fab번호 - 수량 행으로 구성된 미니 테이블을 만들고 멤버 중점에 지시선으로 연결합니다.
사용자마다 선호하는 방식이 다를 수 있습니다. SaveAsDefault=On 으로 한 번 실행해 두면, 이후 FabList 실행 시 저장된 방식·글자 크기가 자동으로 적용됩니다(설치 PC 단위로 저장).
