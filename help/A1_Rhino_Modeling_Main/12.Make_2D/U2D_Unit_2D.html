U2D  —  Unit 2D

U2D

U2D는 선택한 Solid Unit의 Section 2D와 Fablist를 함께 생성하는 통합 2D 명령입니다.
단면을 형성할 위치에 Point 를 찍어서 Cross Line 을 만든다. 2개점까지 가능하다. 

사용 목적

선택한 Unit Solid의 단면 2D와 제작 리스트(Fablist)를 한 번에 만들 때 사용합니다. 단면 위치에 점을 찍어 Cross Line 기준으로 Top/Right 단면과 치수를 생성하므로, Unit 도면화를 빠르게 처리하는 통합 명령입니다.

사용 방법

  1. U2D를 입력합니다.
  2. Make2D를 적용할 객체 선택 프롬프트에서 Unit 객체를 선택합니다.
  3. Enter를 누르면 Top/Right Section과 치수가 생성됩니다.
  4. 선택 Unit에 대한 Fablist가 함께 작성됩니다.
