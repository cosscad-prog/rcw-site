Y0, Z0  —  06_Move_Zero

Y0Z0

선택한 객체를 지정 축의 0 기준면으로 정리하는 단순 원점 정렬 명령 모음입니다.

사용 목적

Line, Point 등 선택 객체의 특정 좌표값을 0으로 맞춰 서로 다른 평면에 있는 객체를 기준면으로 빠르게 정리할 때 사용합니다.

명령어 정리

명령어0으로 맞추는 좌표Curve/Line 처리Point/Text 처리
Y0Y = 0XZ 평면으로 투영Y 좌표만 0으로 이동
Z0Z = 0XY 평면으로 투영Z 좌표만 0으로 이동

사용 방법

  1. AutoCAD 또는 BricsCAD 명령창에 Y0, Z0 중 필요한 명령을 입력합니다.
  2. 0 기준면으로 정리할 객체를 선택합니다.
  3. Enter를 누르면 선택 객체가 해당 축의 0 기준으로 정리됩니다.
참고: Rhino의 X0, Y0, Z0 문서와 같은 기준으로 정리한 문서입니다. AutoCAD / BricsCAD 항목에는 현재 Y0, Z0 명령만 포함되어 있습니다.
