CCL, CCN, CCS  —  Layer/Color 정리

CCLCCNCCS

현재 Layer, 선택 객체의 Layer, 객체 Color를 기준으로 작업 상태를 빠르게 정리하는 보조 명령 모음입니다.

사용 목적

선택 객체를 현재 Layer로 보내거나, 선택 객체의 Layer를 현재 Layer로 지정하거나, CAD Color Number로 객체 색상을 바꿔 작업 중인 객체의 분류와 표시 상태를 빠르게 맞출 때 사용합니다.

명령어 정리

명령어기능사용 상황
CCL선택 객체를 현재 Layer로 이동흩어진 객체를 지금 작업 중인 Current Layer로 모을 때 사용합니다.
CCS선택 객체의 Layer를 Current Layer로 설정기준 객체가 있는 Layer를 현재 Layer로 삼아 이후 생성 객체의 Layer 기준을 맞출 때 사용합니다.
CCN선택 객체 Color를 CAD Color Number로 변경Layer 이동 없이 객체 표시 색상만 빠르게 바꾸고 싶을 때 사용합니다.

사용 방법

  1. AutoCAD 또는 BricsCAD 명령창에 CCL, CCS, CCN 중 필요한 명령을 입력합니다.
  2. CCL과 CCS는 명령 프롬프트에 따라 기준 객체 또는 이동할 객체를 선택합니다.
  3. CCN은 CAD Color Number를 입력한 뒤 색상을 바꿀 객체를 선택합니다.
  4. 명령 완료 후 Layer와 객체 속성에서 Layer/Color 결과를 확인합니다.
