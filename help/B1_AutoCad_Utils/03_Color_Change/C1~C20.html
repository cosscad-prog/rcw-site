C1~C20  —  Object Color 변경

C1 ~ C20

선택한 객체의 Object Color를 CAD Color Number 기준으로 빠르게 바꾸는 명령 모음입니다.

사용 목적

Layer는 그대로 유지하면서 객체 표시 색상만 즉시 변경할 때 사용합니다. 검토 표시, 임시 강조, 도면 정리 과정에서 객체를 색상별로 구분하기 좋습니다.

명령어 정리

명령어동작
C1선택 객체의 Color를 1번 Color [CAD Color Number]로 변경합니다.
C2선택 객체의 Color를 2번 Color [CAD Color Number]로 변경합니다.
C3선택 객체의 Color를 3번 Color [CAD Color Number]로 변경합니다.
C4 ~ C17같은 방식으로 명령어 번호와 같은 CAD Color Number로 Object Color를 변경합니다.
C18선택 객체의 Color를 18번 Color [CAD Color Number]로 변경합니다.
C19선택 객체의 Color를 19번 Color [CAD Color Number]로 변경합니다.
C20선택 객체의 Color를 20번 Color [CAD Color Number]로 변경합니다.

사용 방법

  1. AutoCAD 또는 BricsCAD 명령창에 C1 ~ C20 중 필요한 색상 번호의 명령을 입력합니다.
  2. 색상을 변경할 객체를 선택합니다.
  3. Enter를 누르면 선택 객체의 Object Color가 지정 번호로 변경됩니다.

주요 내용

항목설명
대상 명령C1 ~ C20
변경 대상선택 객체의 Object Color
유지 항목객체 Layer는 변경하지 않습니다.
