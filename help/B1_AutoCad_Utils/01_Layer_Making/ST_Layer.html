ST1 ~ ST9, STL  —  01_Layer_Making

ST1 ~ ST9STL

Steel 계열 Layer를 AutoCAD / BricsCAD 도면에 빠르게 생성하는 명령 모음입니다.

사용 목적

Steel 관련 중심선이나 보강재 기준선을 Steel 계열 Layer로 나누어 관리할 때 사용합니다.

포함 명령어

명령어생성 LayerColor / 속성
STLSteel XX Layer를 만듭니다. 숫자, 문자 입력이 가능합니다.숫자 입력 시 해당 CAD Color Number
ST1Steel 1 Layer를 만듭니다.1번 Color [CAD Color Number]
ST2Steel 2 Layer를 만듭니다.2번 Color [CAD Color Number]
ST3 ~ ST8같은 방식으로 Steel 3 ~ Steel 8 Layer를 만듭니다.각 명령 번호와 같은 CAD Color Number
ST9Steel 9 Layer를 만듭니다.9번 Color [CAD Color Number]

사용 방법

  1. AutoCAD 또는 BricsCAD 명령창에 필요한 명령어를 입력하고 Enter를 누릅니다.
  2. *L 형식의 명령은 입력한 숫자 또는 문자를 기준 Layer 이름 뒤에 바로 붙여 Layer를 만듭니다.
  3. 숫자를 입력하는 경우 해당 숫자를 CAD Color Number로 사용합니다. 256보다 큰 숫자는 256으로 나눈 나머지 값을 Color Number로 사용합니다.
  4. Layer 목록에서 생성된 Layer 이름과 색상, Linetype을 확인합니다.
