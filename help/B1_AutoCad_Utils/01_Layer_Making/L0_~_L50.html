L0 ~ L50  —  01_Layer_Making

L0 ~ L50

Layer 00 ~ Layer 50 계열 Layer를 AutoCAD / BricsCAD 도면에 빠르게 생성하는 명령 모음입니다.

사용 목적

일반 작업 Layer를 번호 체계로 빠르게 생성해 임시선, 보조선, 검토용 객체를 색상별로 분리할 때 사용합니다.

포함 명령어

명령어생성 LayerColor / 속성
L0Layer 00 Layer를 만듭니다.7번 Color [CAD Color Number]
L1Layer 01 Layer를 만듭니다.1번 Color [CAD Color Number]
L2Layer 02 Layer를 만듭니다.2번 Color [CAD Color Number]
L3 ~ L49같은 방식으로 두 자리 번호의 Layer 03 ~ Layer 49를 만듭니다.각 명령 번호와 같은 CAD Color Number
L50Layer 50 Layer를 만듭니다.50번 Color [CAD Color Number]

사용 방법

  1. AutoCAD 또는 BricsCAD 명령창에 필요한 명령어를 입력하고 Enter를 누릅니다.
  2. *L 형식의 명령은 입력한 숫자 또는 문자를 기준 Layer 이름 뒤에 바로 붙여 Layer를 만듭니다.
  3. 숫자를 입력하는 경우 해당 숫자를 CAD Color Number로 사용합니다. 256보다 큰 숫자는 256으로 나눈 나머지 값을 Color Number로 사용합니다.
  4. L0은 Layer 00, L1은 Layer 01처럼 두 자리 번호 Layer를 만듭니다.
  5. Layer 목록에서 생성된 Layer 이름과 색상, Linetype을 확인합니다.
