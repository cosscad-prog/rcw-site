CT0 ~ CT5, CTL  —  01_Layer_Making

CT0 ~ CT5CTL

Center 계열 Layer를 AutoCAD / BricsCAD 도면에 빠르게 생성하는 명령 모음입니다.

사용 목적

단면 기준선이나 중심선을 Center 계열 Layer로 미리 만들고, 번호별 색상과 Center Linetype을 함께 맞출 때 사용합니다.

포함 명령어

명령어생성 LayerColor / 속성
CTLCenterXX Layer를 만듭니다. 숫자, 문자 입력이 가능합니다.숫자 입력 시 해당 CAD Color Number / Center Linetype
CT0Center0 Layer를 만듭니다.White Color / Center Linetype
CT1Center1 Layer를 만듭니다.1번 Color [CAD Color Number] / Center Linetype
CT2Center2 Layer를 만듭니다.2번 Color [CAD Color Number] / Center Linetype
CT3Center3 Layer를 만듭니다.3번 Color [CAD Color Number] / Center Linetype
CT4Center4 Layer를 만듭니다.4번 Color [CAD Color Number] / Center Linetype
CT5Center5 Layer를 만듭니다.5번 Color [CAD Color Number] / Center Linetype

사용 방법

  1. AutoCAD 또는 BricsCAD 명령창에 필요한 명령어를 입력하고 Enter를 누릅니다.
  2. *L 형식의 명령은 입력한 숫자 또는 문자를 기준 Layer 이름 뒤에 바로 붙여 Layer를 만듭니다.
  3. 숫자를 입력하는 경우 해당 숫자를 CAD Color Number로 사용합니다. 256보다 큰 숫자는 256으로 나눈 나머지 값을 Color Number로 사용합니다.
  4. Layer 목록에서 생성된 Layer 이름과 색상, Linetype을 확인합니다.

실행 결과 확인
