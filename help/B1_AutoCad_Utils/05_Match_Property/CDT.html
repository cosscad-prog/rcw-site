CDT  —  05_Match_Property

CDT

기준 Text의 내용이나 문자 속성을 다른 Text에 맞추는 문자 매칭 명령입니다.
문자 내용만 변경한다. Layer, Color,  크기 등은 변하지 않는다.

사용 목적

기준 Text의 내용이나 문자 속성을 대상 Text에 맞춰 도면 표기를 빠르게 통일할 때 사용합니다.

사용 방법

  1. Rhino 명령창에 CDT를 입력하고 Enter를 누릅니다.
  2. 명령 프롬프트에 따라 대상 객체를 선택합니다.
  3. Enter를 눌러 명령을 완료하고 Rhino 화면 또는 명령창 결과를 확인합니다.

실행 예시

참고: 기준 Text의 문자열 또는 Text 속성을 대상 Text에 맞추는 명령입니다. 도면 표기 내용을 일괄 정리할 때 사용합니다.
