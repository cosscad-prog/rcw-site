TTS

AutoCAD 시스템 변수 TEXTSIZE를 변경하는 명령입니다.
객체를 선택하지 않으며, 현재 값을 확인하고 새 값을 입력하는 방식으로 동작합니다. CCText 등 텍스트 크기에 영향을 받는 명령 실행 전에 미리 설정합니다.

사용 목적

AutoCAD의 TEXTSIZE 시스템 변수를 빠르게 변경하기 위한 단축 명령입니다. CCText(원문자 생성) 등 텍스트 관련 명령이 이 값을 참조하므로, 작업 전에 적절한 크기로 설정해 두면 일관된 크기의 텍스트를 만들 수 있습니다.

사용 방법

  1. 명령창에 TTS를 입력하고 Enter를 누릅니다.
  2. 명령창에 현재 TEXTSIZE 값이 표시됩니다.
    예: "TEXTSIZE 를 입력하시오[Current: 5]"
  3. 원하는 새 텍스트 크기(양의 정수)를 입력하고 Enter를 누릅니다.
  4. 명령창에서 변경된 값을 확인합니다.

주요 내용

항목설명
동작현재 TEXTSIZE 값을 명령창에 표시하고, 새 값을 입력받아 변경합니다.
객체 선택없음 — 숫자 입력만으로 동작합니다.
입력 제한양의 정수만 입력 가능합니다 (0 및 음수 불가).
적용 범위AutoCAD 세션 전체에 적용됩니다. 이후 생성되는 텍스트의 기본 크기가 변경됩니다.
적용 환경AutoCAD / BricsCAD
