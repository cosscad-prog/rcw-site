Tlist

선택된 Text 객체들의 내용을 이름별로 분류하여 수량을 집계하고, 화면에 테이블로 출력하는 명령입니다.
선택적으로 Excel 파일(.xls)로 저장할 수 있습니다.

사용 목적

도면에 흩어진 Text 객체들의 내용을 종류별로 분류하고 수량을 파악할 때 사용합니다. 부품 번호, 재료 이름, 규격 등 동일한 텍스트가 반복 사용되는 도면에서 항목별 수량 집계표를 빠르게 만들 수 있습니다.

사용 방법

  1. 명령창에 Tlist를 입력하고 Enter를 누릅니다.
  2. 수량을 집계할 Text 객체들을 선택하고 Enter를 누릅니다.
  3. 화면에서 테이블이 배치될 위치를 클릭합니다.
  4. 집계 결과가 화면 테이블과 명령창에 동시에 출력됩니다.
  5. "Enter Excel File Name :" 프롬프트에서:
    — 파일 이름을 입력하면 이름.xls로 저장됩니다.
    — 빈 채로 Enter를 누르면 저장하지 않고 종료됩니다.

주요 내용

항목설명
선택 대상TEXT, MTEXT, DBText 객체만 인식합니다. 다른 엔티티는 자동으로 필터링됩니다.
정렬 방식텍스트 내용을 알파벳(가나다) 순으로 정렬한 뒤 수량을 집계합니다.
화면 출력집계 결과를 화면에 테이블(No / 내용 / 수량 / Total)로 생성합니다.
명령창 출력각 항목과 수량이 명령창에도 출력됩니다.
Excel 저장파일 이름을 입력하면 .xls 형식으로 저장됩니다. 빈 이름 입력 시 저장하지 않습니다.
적용 환경AutoCAD / BricsCAD

실행 결과

항목설명
화면 테이블No / 텍스트 내용 / 수량 컬럼으로 구성된 테이블이 도면에 생성됩니다. 마지막 행에 Total 합계가 표시됩니다.
명령창각 항목과 수량이 명령창에 출력됩니다.
Excel 파일파일 이름 입력 시 동일 내용이 .xls 파일로 저장됩니다.
참고: 텍스트 내용이 완전히 동일한 경우에만 같은 항목으로 집계됩니다. 대소문자, 공백 차이가 있으면 별도 항목으로 처리됩니다.
