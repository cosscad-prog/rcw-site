CCText

지정한 시작 번호부터 순차적으로 번호가 있는 원문자(Circle + 번호 텍스트)를 클릭하는 위치마다 연속으로 생성하는 명령입니다.
텍스트 크기는 AutoCAD 시스템 변수 TEXTSIZE를 따르며, TTS 명령으로 미리 조절합니다.

사용 목적

도면의 여러 위치에 부품 번호, 상세 번호 등 원형으로 감싼 일련번호를 빠르게 배치할 때 사용합니다. 시작 번호를 지정하면 클릭할 때마다 번호가 자동으로 증가하므로, 다수의 위치에 연속 번호를 부여하는 작업에 적합합니다.

사용 방법

  1. 원문자 크기가 필요한 경우 먼저 TTS 명령으로 TEXTSIZE를 설정합니다.
  2. 명령창에 CCText를 입력하고 Enter를 누릅니다.
  3. "Enter Start number :" 프롬프트에 시작 번호(1 이상 정수)를 입력하고 Enter를 누릅니다.
  4. "Pick Point" 프롬프트에 따라 원문자를 배치할 위치를 클릭합니다.
    클릭할 때마다 번호가 1씩 증가하며 원문자가 생성됩니다.
  5. ESC 또는 Enter를 눌러 명령을 종료합니다.

주요 내용

항목설명
시작 번호명령 실행 후 시작 번호를 입력합니다. 이후 클릭할 때마다 1씩 증가합니다.
생성 방식클릭한 위치마다 원(Circle)과 번호 텍스트를 함께 생성합니다. ESC 또는 Enter로 종료합니다.
텍스트 크기AutoCAD 시스템 변수 TEXTSIZE를 사용합니다. 최솟값은 2입니다.
크기 조절TTS 명령으로 TEXTSIZE를 미리 변경한 뒤 실행합니다.
적용 환경AutoCAD / BricsCAD
