TAG

선택된 Text 객체들을 첫 번째 텍스트의 위치를 기준으로 수직 방향으로 균등 정렬하는 명령입니다.
X값도 첫 번째 텍스트에 맞춰 통일됩니다. X값을 유지하면서 정렬하려면 XTAG를 사용합니다.

사용 목적

흩어져 있는 Text 객체들을 세로 방향으로 일정 간격으로 정렬할 때 사용합니다. 첫 번째로 선택한 텍스트의 위치가 기준점이 되며, 나머지 텍스트들이 텍스트 높이(Height × 1.6) 간격으로 아래로 정렬됩니다.

사용 방법

  1. 명령창에 TAG를 입력하고 Enter를 누릅니다.
  2. 정렬할 Text 객체들을 선택합니다. (첫 번째 선택한 텍스트가 기준이 됩니다.)
  3. Enter를 눌러 선택을 완료합니다.
  4. 선택된 텍스트들이 첫 번째 텍스트 위치를 기준으로 수직 정렬됩니다.

주요 내용

항목설명
선택 대상TEXT, MTEXT, DBText 객체만 인식합니다. 다른 엔티티는 자동으로 필터링됩니다.
기준 위치첫 번째 선택한 텍스트의 위치를 기준으로 정렬합니다.
X값 처리모든 텍스트의 X값이 첫 번째 텍스트의 X값으로 통일됩니다.
정렬 간격첫 번째 텍스트의 Height × 1.6 값을 간격으로 사용합니다.
정렬 방향Front View(XZ 평면)에서는 Z축 방향, Top View(XY 평면)에서는 Y축 방향으로 정렬됩니다.
적용 환경AutoCAD / BricsCAD

TAG vs XTAG 차이

항목TAGXTAG
X값 처리첫 번째 텍스트 X값으로 모두 통일각 텍스트의 X값 개별 유지
Y/Z값 처리첫 번째 기준으로 균등 간격 정렬첫 번째 기준으로 균등 간격 정렬
사용 목적X축도 일렬로 정렬할 때각자의 X 위치는 유지하고 수직만 맞출 때
