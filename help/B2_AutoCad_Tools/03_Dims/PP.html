PP

화면에서 클릭한 위치에 Dim_Points 레이어 Point를 1개 생성하는 명령입니다.
객체를 선택하는 방식이 아니며, 직접 클릭(Pick Point)으로 원하는 위치에 Point를 배치합니다.

사용 목적

DST / DSB / DSL / DSR / DSA 치수 명령에서 기준으로 사용할 Dim_Points 레이어 Point를 원하는 위치에 직접 배치할 때 사용합니다. HPP가 엔티티에서 자동 추출하는 것과 달리, PP는 원하는 위치를 직접 지정합니다.

사용 방법

  1. 명령창에 PP를 입력하고 Enter를 누릅니다.
  2. "Point 위치 선택" 프롬프트에 따라 화면에서 Point를 배치할 위치를 클릭합니다.
  3. 클릭한 위치에 Dim_Points 레이어 Point가 생성됩니다.
  4. 이후 DST / DSB 등의 치수 명령으로 생성된 Point를 선택하여 치수를 기입합니다.

주요 내용

항목설명
동작 방식객체 선택 없음 — 화면을 클릭(Pick Point)하여 위치를 지정합니다.
생성 Point클릭한 위치에 Dim_Points 레이어 Point 1개가 생성됩니다.
레이어Dim_Points 레이어(색상 2)에 배치됩니다. 레이어가 없으면 자동 생성됩니다.
다음 단계생성된 Point를 DST / DSB / DSL / DSR / DSA 명령에서 선택하여 치수를 기입합니다.
적용 환경AutoCAD / BricsCAD (Rhino 포함)

HPP vs PP 차이

항목HPPPP
위치 지정엔티티 선택 → 특징점 자동 추출화면 직접 클릭(Pick Point)
생성 수량선택 엔티티 수에 따라 다수 생성클릭 1회 = Point 1개
사용 상황형상에서 자동으로 Point 추출할 때원하는 특정 위치에 Point를 추가할 때

실행 결과

항목설명
생성 Point클릭한 위치에 Point 1개가 생성됩니다.
레이어Dim_Points 레이어(색상 2)에 배치됩니다.
참고: 형상 엔티티(Line, Circle 등)의 끝점이나 중심점에서 Point를 자동 추출하려면 HPP를 사용하세요. PP는 형상과 무관하게 원하는 위치에 Point를 추가할 때 사용합니다.
