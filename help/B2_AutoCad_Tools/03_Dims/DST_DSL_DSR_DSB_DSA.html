DST / DSB / DSL / DSR / DSA  —  03_Dims

DST  DSB  DSL  DSR  DSA

Dim_Points 레이어의 Point 객체를 선택하면, DsOpt에서 설정한 변수를 이용하여 지정된 방향에 자동으로 치수를 기입하는 명령입니다.

사용 목적

도면의 형상 주요 위치에 PP 또는 HPP로 미리 배치한 Dim_Points 레이어 Point들을 기준으로, 원하는 방향(Top / Bottom / Left / Right / 4면 동시)에 일관된 치수를 자동 기입합니다. 수동으로 치수를 하나씩 작성하는 것보다 훨씬 빠르게 도면을 완성할 수 있습니다.

명령 목록

명령동작
DST객체 Top(위쪽)에 수평 치수를 기입합니다.
DSB객체 Bottom(아래쪽)에 수평 치수를 기입합니다.
DSL객체 Left(왼쪽)에 수직 치수를 기입합니다.
DSR객체 Right(오른쪽)에 수직 치수를 기입합니다.
DSATop / Bottom / Left / Right 4면 전체에 치수를 동시에 기입합니다.

사용 방법

  1. DsOpt를 실행하여 치수 변수(First Dist, Dim Gap 등)를 설정합니다.
  2. PP 또는 HPP로 치수 기준 Point(Dim_Points 레이어)를 배치합니다.
  3. 명령창에 원하는 방향의 명령(DST / DSB / DSL / DSR / DSA)을 입력합니다.
  4. "POINT을 선택하세요." 프롬프트에 따라 치수 기준으로 사용할 Point 객체를 선택합니다.
  5. Enter를 눌러 완료하면 지정된 방향에 자동으로 치수가 기입됩니다.

주요 내용

항목설명
선택 대상Dim_Points 레이어의 Point 객체만 인식합니다. 다른 객체는 필터링됩니다.
사전 준비PP 또는 HPP로 치수 기준이 될 Point를 먼저 배치해야 합니다.
치수 변수DsOpt 패널의 First Dist, Dim Gap, Top/Left/Right/Bottom Max 설정을 참조합니다.
레이어치수는 Dims 레이어에 생성됩니다.
적용 환경AutoCAD / BricsCAD

항목설명

실행 결과

항목설명
생성 치수선택한 Point들의 위치를 기준으로 지정 방향에 치수가 자동 기입됩니다.
치수선 거리First Dist(첫 치수선), Dim Gap(치수선 간격) 설정값을 사용합니다.
레이어생성된 치수는 Dims 레이어에 배치됩니다.
참고: 치수 기준이 되는 Point는 반드시 Dim_Points 레이어에 있어야 합니다. PP(클릭 위치 Point 생성) 또는 HPP(엔티티 기반 Point 자동 생성)를 먼저 실행하세요.
주의: DsOpt에서 설정한 변수가 치수선 위치와 크기에 직접 영향을 미칩니다. 치수 기입 전에 First Dist, Dim Gap 값을 확인하세요.
