HPP  —  03_Dims

HPP

선택한 엔티티(Line, PolyLine, Circle, Arc)에서 특징점을 자동으로 추출하여 Dim_Points 레이어에 Point를 생성하는 명령입니다.
DST / DSB / DSL / DSR / DSA 치수 명령 실행 전에 기준 Point를 빠르게 배치할 때 사용합니다.

사용 목적

형상 엔티티에서 치수 기준점(끝점, 중심점, Node점)을 일일이 클릭하지 않고 자동으로 추출하여 Dim_Points 레이어 Point를 생성합니다. 복잡한 도면에서 다수의 치수 기준점을 한 번에 만들 수 있습니다.

엔티티 종류별 Point 생성 위치

선택 엔티티Point 생성 위치
Line (선)시작점(StartPoint)과 끝점(EndPoint) 2개
PolyLine각 꼭짓점(Node) 위치마다 Point 생성
Circle (원)원의 중심점(Center) 1개
Arc (호)호의 중심점(Center) 1개

사용 방법

  1. 명령창에 HPP를 입력하고 Enter를 누릅니다.
  2. "Entity 을 선택하세요." 프롬프트에 따라 치수 기준점을 추출할 엔티티를 선택합니다.
    (Line, PolyLine, Circle, Arc 혼합 선택 가능)
  3. Enter를 눌러 완료합니다.
  4. 선택된 엔티티의 특징점 위치마다 Dim_Points 레이어 Point가 생성됩니다.
  5. 이후 DST / DSB 등의 치수 명령으로 생성된 Point를 선택하여 치수를 기입합니다.

주요 내용

항목설명
레이어생성된 Point는 Dim_Points 레이어(색상: 40)에 배치됩니다. 레이어가 없으면 자동 생성됩니다.
선택 대상Line, PolyLine, Circle, Arc 모두 선택 가능합니다. 혼합 선택도 지원합니다.
다음 단계생성된 Point를 DST / DSB / DSL / DSR / DSA 명령에서 선택하여 치수를 기입합니다.
적용 환경AutoCAD / BricsCAD (Rhino 포함)

실행 결과

항목설명
생성 Point각 엔티티의 특징점(끝점/중심점/Node)에 Point가 생성됩니다.
레이어Dim_Points 레이어(색상 40)에 배치됩니다.
참고: HPP는 형상에서 자동으로 특징점을 추출합니다. 특정 위치에 Point를 하나씩 직접 클릭해서 배치하려면 PP 명령을 사용하세요.
