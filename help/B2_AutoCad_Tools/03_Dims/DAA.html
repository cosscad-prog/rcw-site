DAA

서로 다른 각도의 Line 2개를 선택하면, 두 선 사이의 각도 치수를 자동으로 기입하는 명령입니다.
DsOpt의 Angle Dist 설정값을 치수 위치 거리로 사용합니다. Layer에 관계없이 Line 객체이면 선택 가능합니다.

사용 목적

두 선이 이루는 각도를 정확하게 도면에 표기할 때 사용합니다. 경사진 부재, 절곡 부위, 경사 치수 등 각도 정보가 필요한 위치에 빠르게 기입할 수 있습니다.

사용 방법

  1. DsOpt에서 Angle Dist 값을 확인하고 필요 시 조정합니다.
  2. 명령창에 DAA를 입력하고 Enter를 누릅니다.
  3. 각도를 기입할 Line 객체 2개를 선택하고 Enter를 누릅니다.
  4. 두 선 사이에 각도 치수가 자동으로 기입됩니다.

실행 결과

항목설명
생성 치수선택한 두 Line이 이루는 각도값이 치수호로 표시됩니다.
치수 위치Angle Dist 설정값만큼 교차점에서 떨어진 위치에 치수호가 그려집니다.
레이어생성된 치수는 Dims 레이어에 배치됩니다.
참고: 두 Line이 실제로 교차하거나 연장선이 교차해야 각도 치수가 올바르게 기입됩니다. 평행한 두 선을 선택하면 각도 치수를 만들 수 없습니다.
