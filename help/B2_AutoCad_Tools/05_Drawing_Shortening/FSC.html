FSC  —  05_Drawing_Shortening

FSC

2D 도면을 X축 방향으로만 자동으로 줄여(Drawing Shortening) 폼(Form)에 맞는 크기로 압축하는 명령입니다.
AutoScale.dat에 저장된 프로파일별 설정을 자동으로 읽어, 줄임 기준 치수·목표 치수·제외 구간 등을 적용합니다.

사용 목적

실제 형상 치수가 폼(Form)에 들어가는 최대 길이를 초과하는 경우, 지정 기준 이상의 구간만 선택적으로 압축하여 도면을 폼 크기에 맞게 줄입니다. 치수 텍스트는 실측값 고정 치수로 변환하여 줄인 후에도 원래 치수를 표시합니다.

동작 흐름

순서단계설명
1객체 선택도면 전체(형상, 치수, 텍스트, NC Point 등)를 선택합니다. 필터 없이 모든 객체를 선택할 수 있습니다.
2프로파일 인식선택된 MText 중 도면 번호 텍스트를 읽어 -·공백 앞 첫 단어를 프로파일 이름으로 사용합니다. AutoScale.dat에서 해당 프로파일의 설정 데이터를 로드합니다.
3범위 측정NC_BottomPoint 레이어 Point(좌측 기준)와 NC_TopPoint 레이어 Point(우측 기준)의 X 좌표로 도면 전체 폭(Max_distance)을 계산합니다.
4실행 조건 확인현재 폭(Max_distance)이 목표 치수(MinFabdist)보다 작으면 줄이기를 실행하지 않습니다.
5치수 고정 변환줄임 기준(min_ds) 이상의 구간에 있는 RotatedDimension을 실측값 고정 텍스트 치수로 변환합니다.
6제외 구간 선택AutoScale.dat의 excute=1인 경우: "제외 구간 Entity 을 선택하세요." 프롬프트에서 줄이지 않을 구간의 치수 객체를 선택합니다.
7최소값 입력AutoScale.dat의 Min_excute=1인 경우: 목표 최소 폭을 직접 입력합니다 (이전 입력값이 기본값으로 표시됨).
8구간별 스트레치줄임 기준 이상인 각 치수 구간 중심점에서 오른쪽을 X축으로 당겨 비율에 맞게 압축합니다.
9NC 데이터 테이블 이동NC4_data / NC3_data 레이어에서 도면 최대 X 오른쪽에 있는 객체(NC 데이터 테이블)를 총 줄인 거리만큼 왼쪽으로 이동합니다.

AutoScale.dat 설정 항목

열항목기본값(코드)설명
[0]Name—프로파일 이름. 도면 번호 첫 단어와 일치해야 자동 적용됩니다.
[1]줄임 기준 치수 (min_ds)250이 값 이상의 구간만 줄임 대상이 됩니다. (예: 250이면 구간 길이 ≥ 250인 경우만 압축)
[2]전체 줄임 치수 (MinFabdist)300줄인 후 도면의 목표 전체 폭입니다.
[3]제외구간 선택 (excute)11이면 제외 구간 선택 프롬프트를 표시합니다. 0이면 생략합니다.
[4]최소값 입력 (Min_excute)11이면 최소 폭 직접 입력 프롬프트를 표시합니다. 0이면 MinFabdist를 그대로 사용합니다.

사전 준비

항목설명
NC_BottomPoint 레이어 Point도면 좌측(X 최솟값) 기준점입니다. 없으면 형상 전체 범위로 대체됩니다.
NC_TopPoint 레이어 Point도면 우측(X 최댓값) 기준점입니다. 없으면 형상 전체 범위로 대체됩니다.
AutoScale.dat프로파일별 줄임 파라미터 파일입니다. 없거나 프로파일 이름이 없으면 기본값(min_ds=250, MinFabdist=300)이 사용됩니다.
도면 번호 MText선택 범위 안에 도면 번호 MText가 포함되어야 프로파일이 자동으로 인식됩니다.

사용 방법

  1. AutoScale.dat에 해당 프로파일의 파라미터가 올바르게 입력되어 있는지 확인합니다.
  2. 도면에 NC_BottomPoint / NC_TopPoint 레이어 Point가 배치되어 있는지 확인합니다.
  3. 명령창에 FSC를 입력하고 Enter를 누릅니다.
  4. "Entity 을 선택하세요." 프롬프트에서 형상, 치수, 도면 번호 텍스트, NC Point를 포함한 도면 전체를 선택하고 Enter를 누릅니다.
  5. (excute=1인 경우) "제외 구간 Entity 을 선택하세요." 프롬프트에서 줄이면 안 되는 구간의 치수 객체를 선택하고 Enter를 누릅니다. 없으면 Enter만 누릅니다.
  6. (Min_excute=1인 경우) 목표 최소 폭을 입력합니다. Enter만 누르면 이전 입력값 또는 AutoScale.dat의 MinFabdist가 사용됩니다.
  7. 도면이 X축 방향으로 자동 압축되고, 명령창에 Maximum_distance / Minimum_distance / 비율 / 실제 이동 거리가 출력됩니다.

실행 결과

항목설명
도면 압축줄임 기준 이상인 각 구간이 비율에 맞게 X축으로 당겨집니다.
치수 고정압축된 구간의 치수는 실측값 고정 텍스트로 변환되어, 줄인 후에도 원래 치수를 표시합니다.
NC 테이블 이동NC4_data / NC3_data 레이어의 NC 데이터 테이블이 총 줄인 거리만큼 자동으로 왼쪽으로 이동합니다.
참고: 현재 도면 폭(Max_distance)이 AutoScale.dat의 MinFabdist보다 이미 작거나 같으면 줄이기가 실행되지 않고 "Not Working" 메시지가 표시됩니다.
줄임 기준(min_ds) 미만인 구간은 압축하지 않으며 최소 압축 후 크기(Min_s=30)가 보장됩니다.
주의: 선택 범위에 도면 번호 MText가 포함되지 않으면 AutoScale.dat 프로파일을 인식하지 못하여 기본값으로 실행됩니다.
NC_BottomPoint / NC_TopPoint 레이어 Point가 없으면 도면 범위 계산이 부정확해질 수 있습니다.
