BB1 ~ BB8  —  01_Block

BB1  BB2  BB3  BB4  BB5  BB6  BB7  BB8

SSBlock으로 저장된 Block 목록에서 번호에 해당하는 Block을, 화면에서 선택한 Point 또는 Line 엔티티의 위치에 삽입하는 명령입니다.
선택한 객체가 없으면 직접 클릭(Pick Point)으로 대체되며, 삽입된 Block은 Explode하지 않고 Block Reference 상태를 유지합니다.

사용 목적

도면에 이미 배치된 Point 객체(DBPoint)나 Line의 끝점을 기준으로 Block을 정확한 위치에 반복 배치할 때 사용합니다. 좌표를 직접 입력하지 않고 기존 형상에서 삽입점을 자동으로 추출하므로, 다수의 위치에 동일한 Block을 빠르게 배치하는 작업에 적합합니다.

삽입 위치 결정 방식

선택 객체삽입 위치 결정 방법

사용 방법

  1. 먼저 SSBlock 명령으로 사용할 Block 객체들을 순서대로 선택하여 메모리에 저장합니다.
    선택 순서가 번호(1번, 2번 …)가 됩니다.
  2. AutoCAD 또는 BricsCAD 명령창에 삽입할 번호에 해당하는 명령(BB1 ~ BB8)을 입력하고 Enter를 누릅니다.
  3. 삽입 위치 기준으로 사용할 Point 또는 Line 객체를 선택하고 Enter를 누릅니다.
    — DBPoint를 선택하면 해당 점 위치에 삽입됩니다.
    — Line을 선택하면 가장 아래·왼쪽 끝점을 삽입점으로 사용합니다.
    — 객체를 선택하지 않으면 직접 클릭(Pick Point)으로 전환됩니다.
  4. Block이 지정된 위치에 Block Reference로 삽입됩니다.
