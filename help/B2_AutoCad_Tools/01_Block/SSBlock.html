SSBlock

B1~B8 / BB1~BB8 명령에서 사용할 Block 객체를 선택하여 메모리에 저장하는 명령입니다.
선택한 순서가 곧 번호가 됩니다 — 첫 번째로 선택한 Block이 1번(B1/BB1), 두 번째가 2번(B2/BB2), …

사용 목적

Block을 삽입하기 전에 사용할 Block 객체를 미리 등록해두는 준비 명령입니다. 여러 종류의 Block을 번호로 구분하여 관리할 수 있으며, 이후 B1~B8(Explode 삽입) 또는 BB1~BB8(Block Reference 삽입) 명령으로 등록된 Block을 빠르게 배치할 수 있습니다.

사용 방법

  1. AutoCAD 또는 BricsCAD 명령창에 SSBlock을 입력하고 Enter를 누릅니다.
  2. 삽입에 사용할 Block 객체를 순서대로 선택합니다.
    첫 번째 선택한 Block이 1번, 두 번째가 2번이 됩니다.
  3. Enter를 눌러 선택을 완료합니다.
  4. 명령창에서 선택된 Block 이름을 확인합니다.
  5. 이후 B1~B8 또는 BB1~BB8 명령으로 등록된 Block을 삽입합니다.

주요 내용

항목설명
선택 대상Block Reference 객체만 인식합니다. Line, Text, 치수 등 다른 엔티티는 선택해도 무시됩니다.
저장 방식선택된 Block의 이름(Definition Name)을 순서대로 메모리(BlockNameList)에 저장합니다.
번호 부여선택 순서대로 번호가 부여됩니다. 첫 번째 선택 = 1번, 두 번째 = 2번, … , 최대 8번.
명령창 출력선택된 각 Block의 이름이 명령창에 출력됩니다.
적용 환경AutoCAD / BricsCAD

실행 결과

항목설명
저장 목록선택된 Block 이름이 순서대로 BlockNameList에 저장됩니다.
명령창 출력각 Block의 이름이 명령창에 출력되어 등록 여부를 확인할 수 있습니다.
다음 단계B1~B8 또는 BB1~BB8 명령으로 등록된 Block을 삽입합니다.
주의: SSBlock을 다시 실행하면 이전에 저장된 목록이 완전히 덮어써집니다. 기존 등록 내용이 필요하다면 재실행 전에 확인하세요.
참고: Block Reference가 아닌 객체(Line, Text, 치수 등)는 선택해도 목록에 추가되지 않습니다. 반드시 도면에 삽입된 Block 인스턴스를 선택해야 합니다.
