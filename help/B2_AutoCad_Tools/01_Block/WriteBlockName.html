WriteBlockName

선택된 Block 객체의 이름을 해당 Block의 Insert Point 위치에 텍스트로 표시하는 명령입니다. 도면에 배치된 Block 인스턴스가 어떤 이름인지 화면에서 직접 확인할 때 사용합니다.

사용 목적

여러 종류의 Block이 혼재된 도면에서, 각 Block의 정의 이름을 삽입점 위치에 직접 표기하여 육안으로 빠르게 식별할 수 있게 합니다. Block 검수, 도면 정리, 수량 확인 전 사전 확인 작업에 유용합니다.

사용 방법

  1. AutoCAD 또는 BricsCAD 명령창에 WriteBlockName을 입력하고 Enter를 누릅니다.
  2. 이름을 표시할 Block 객체를 선택하고 Enter를 누릅니다.
  3. 각 Block의 Insert Point 위치에 Block 이름 텍스트가 생성됩니다.

주요 내용

항목설명
선택 대상Block Reference 객체만 처리합니다. Line, Text, 치수 등 다른 엔티티는 선택해도 무시됩니다.
텍스트 위치각 Block의 Insert Point 위치에 이름 텍스트를 생성합니다.
텍스트 정렬MiddleCenter(가운데 정렬)로 삽입됩니다.
적용 환경AutoCAD / BricsCAD

실행 결과

항목설명
생성 텍스트선택된 Block Reference의 정의 이름(Block Name)이 Insert Point에 텍스트로 생성됩니다.
텍스트 위치Block의 Insert Point(삽입점) 위치에 MiddleCenter 정렬로 배치됩니다.
참고: Block Reference가 아닌 객체(Line, Text, 치수 등)는 선택해도 처리되지 않습니다. 반드시 도면에 삽입된 Block 인스턴스를 선택하세요.
주의: 생성된 텍스트는 별도의 Text 엔티티로 추가됩니다. 이후 Block을 이동하거나 삭제해도 텍스트는 자동으로 따라가지 않습니다.
