B1 ~ B8  —  01_Block

B1  B2  B3  B4  B5  B6  B7  B8

SSBlock으로 저장된 Block 목록에서 번호에 해당하는 Block을 Pick Point(직접 클릭)한 위치에 삽입하고, 삽입 즉시 Explode하여 개별 엔티티로 분해하는 명령입니다.
▶ 삽입 후 Block 상태가 해제되어 더 이상 Block이 아닌 개별 객체로 변환됩니다.

사용 목적

SSBlock으로 미리 등록해 둔 Block 중 원하는 번호(1~8)의 Block을 화면의 특정 위치에 바로 배치할 때 사용합니다. 삽입과 동시에 Explode되므로, Block 정의를 유지하지 않고 구성 요소(선, 원 등)를 직접 편집해야 하는 작업에 적합합니다.

사용 방법

  1. 먼저 SSBlock 명령으로 사용할 Block 객체들을 순서대로 선택하여 메모리에 저장합니다.
    선택 순서가 번호(1번, 2번 …)가 됩니다.
  2. AutoCAD 또는 BricsCAD 명령창에 삽입할 번호에 해당하는 명령(B1 ~ B8)을 입력하고 Enter를 누릅니다.
  3. 명령 프롬프트 "위치를 선택 :"에 따라 삽입할 위치를 화면에서 클릭합니다.
  4. Block이 클릭한 위치에 삽입되고 즉시 Explode되어 개별 객체로 분해됩니다.

주의: 삽입 후 Explode되므로 원본 Block 정의는 영향을 받지 않으나, 삽입된 객체는 Block으로 재편집할 수 없습니다. Block 상태를 유지하며 삽입하려면 BB1~BB8을 사용하세요.
참고: SSBlock으로 저장된 Block이 없거나 지정 번호에 해당하는 Block이 없으면 명령이 동작하지 않습니다. 먼저 SSBlock을 실행하여 Block을 등록한 뒤 사용하세요.
