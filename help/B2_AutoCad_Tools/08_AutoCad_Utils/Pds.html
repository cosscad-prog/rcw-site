Pds

도면 내 모든 Point 객체의 표시 방향을 현재 뷰 방향으로 일괄 정렬하는 명령입니다.
사용자가 객체를 직접 선택할 필요 없이, 도면 전체의 Point를 자동으로 찾아 처리합니다.

사용 목적

뷰 방향이 변경된 후 도면에 배치된 Point(예: Dim_Points, NC_BottomPoint 등)가 이전 뷰 방향 기준으로 그려져 화면에 올바르게 표시되지 않을 때 사용합니다. 명령 실행 시 Point의 Normal 벡터를 현재 뷰 방향(ViewDirection)으로 일괄 갱신합니다.

사용 방법

  1. 뷰 방향을 원하는 상태로 설정합니다.
  2. 명령창에 Pds를 입력하고 Enter를 누릅니다.
  3. 별도의 선택 없이 도면 내 모든 Point가 자동으로 처리됩니다.
  4. 명령창에서 처리된 Point 수를 확인합니다.

주요 내용

항목설명
객체 선택 방식사용자 선택 없음. SelectAll로 도면 내 모든 Point(DBPoint) 객체를 자동으로 수집합니다.
처리 내용각 Point의 Normal 벡터를 현재 뷰의 ViewDirection으로 변경합니다.
시스템 변수 변경PDMODE = 35 (X 표식 + 원), PDsize = 1로 설정합니다.
반복 실행내부적으로 동일 처리를 2회 반복하여 안정적으로 적용합니다.
출력 메시지처리 완료 후 "Point N개를 변경하였습니다."와 "Re_Draw_Point_and_Overkill 완료."가 명령창에 출력됩니다.
적용 환경AutoCAD / BricsCAD

PDMODE 35 표시 형식

시스템 변수설명
PDMODE = 35Point를 X 표식과 원이 겹친 형태로 표시합니다 (3 + 32 = 35).
PDsize = 1Point 표시 크기를 화면 픽셀 단위 1로 설정합니다.

실행 결과

항목설명
Point Normal 갱신도면 내 모든 DBPoint의 Normal 벡터가 현재 뷰 방향으로 변경됩니다.
PDMODE / PDsize 변경Point 표시 형식이 X+원(PDMODE=35), 크기 1(PDsize=1)로 설정됩니다.
명령창 출력처리된 Point 개수와 완료 메시지가 출력됩니다.
참고: Pds는 도면의 모든 Point에 적용됩니다. 특정 레이어의 Point만 처리하고 싶은 경우에도 구분 없이 전체가 변경되므로 주의하세요.
PDMODE와 PDsize 시스템 변수가 변경되므로, 기존에 다른 Point 표시 형식을 사용하고 있었다면 이후 Point 생성 시에도 동일 형식이 적용됩니다.
