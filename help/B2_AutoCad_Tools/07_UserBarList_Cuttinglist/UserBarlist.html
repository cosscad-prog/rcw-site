UserBarlist  UBarlist

프로파일별 사용 장바 길이를 입력·저장하는 외부 옵션 창(Barlist_Option.exe)을 실행하는 명령입니다.
저장된 장바 데이터 파일은 Cuttinglist 명령의 User 모드에서 불러와 절단 리스트 산출에 사용합니다.

사용 목적

공장에서 실제 보유·발주하는 장바 규격이 AutoCAD 기본값(3000~6500mm)과 다를 때, 프로파일별로 사용할 장바 길이를 직접 지정하여 절단 최적화를 할 수 있습니다. UserBarlist로 장바 데이터를 저장해 두면, Cuttinglist 실행 시 User 모드를 선택하여 해당 파일을 불러올 수 있습니다.

UserBarlist → Cuttinglist 워크플로

단계설명
UserBarlistBarlist_Option.exe를 열어 프로파일별 장바 길이를 입력하고 .txt로 저장합니다.
Cuttinglist실행 시 [User]를 선택하면 파일 열기 창이 표시됩니다. 저장한 .txt를 선택하면 해당 장바로 절단 리스트가 산출됩니다.

사용 방법

  1. 명령창에 UserBarlist(또는 UBarlist)를 입력하고 Enter를 누릅니다.
  2. Barlist_Option.exe 창이 열립니다.
  3. 프로파일 이름별로 사용할 장바 길이(mm)를 입력합니다.
  4. 저장 버튼을 눌러 .txt 파일로 저장합니다.
  5. 이후 Cuttinglist 실행 시 [User]를 선택하고 저장한 파일을 불러옵니다.

주요 내용

항목설명
실행 방식AutoCAD API를 사용하지 않고, 외부 독립 실행 프로그램 Barlist_Option.exe를 시작합니다.
입력 내용프로파일 이름별로 사용 가능한 장바 길이(mm)를 하나 이상 입력합니다.
저장 형식입력한 데이터는 텍스트 파일(.txt)로 저장됩니다. 파일 형식은 프로파일명,길이1,길이2,... (콤마 구분)입니다.
연동 명령Cuttinglist 실행 시 [User] 모드를 선택하면 저장된 파일을 불러와 해당 프로파일에 맞는 장바로 절단 리스트를 산출합니다.
명령 별칭UBarlist도 동일한 동작을 합니다.
적용 환경AutoCAD / BricsCAD / Rhino (외부 EXE 실행이므로 플랫폼 무관)
참고: 프로파일 이름과 Line 레이어 이름이 정확히 일치해야 Cuttinglist에서 해당 장바가 적용됩니다. 파일에 프로파일 이름이 없으면 기본 장바 목록(3000, 4000, 5000, 6000, 6500)이 사용됩니다.
주의: Barlist_Option.exe 는 RCW 와 함께 설치됩니다. 지워졌다면 RCW 를 다시 설치하십시오. 해당 파일이 없으면 명령이 오류 없이 종료되지만 창이 열리지 않습니다.
