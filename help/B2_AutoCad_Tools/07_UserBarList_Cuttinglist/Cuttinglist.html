Cuttinglist

선택한 Line 객체의 레이어(프로파일명)와 길이(절단 치수)를 읽어 절단 리스트(Cutting List)와 장바 리스트(Long Bar List)를 도면과 Excel 파일로 자동 생성하는 명령입니다.
Line 필터 선택 → 장바 모드 전환 → 절단 최적화 → 도면 출력·Excel 저장까지 한 번에 처리합니다.

사용 목적

AutoCAD 도면에서 각 프로파일 부재를 Line으로 표현한 경우, 레이어 이름을 프로파일 명칭으로, 선 길이를 절단 치수로 사용하여 부재별 절단 리스트와 필요 장바 수량을 자동으로 산출합니다.

Line 데이터 읽기 규칙

Line 속성사용 방법
레이어 이름프로파일(부재) 이름으로 사용됩니다. 장바 모드가 User일 때 이 이름으로 장바 파일을 검색합니다.
선 길이절단 치수(mm, 정수 변환)로 사용됩니다. 소수점 이하는 버림합니다.

장바 모드 (Auto / User)

모드설명
Auto (기본)내장 장바 목록(3000~6500mm, 100mm 간격)을 모든 프로파일에 동일하게 적용합니다.
User파일 열기 창에서 UserBarlist로 저장한 .txt 파일을 선택합니다. 프로파일 이름과 일치하는 장바 목록을 사용하고, 일치 항목이 없으면 기본값(3000, 4000, 5000, 6000, 6500)을 사용합니다.

동작 흐름

순서단계설명
1모드 선택"Current Barlist <Auto/User>: Enter Key [Auto / User]:" 프롬프트에서 A 또는 U를 입력하여 장바 모드를 전환합니다. Enter만 누르면 이전 모드를 유지합니다.
2Line 선택"Select one or more lines:" 프롬프트에서 절단 치수 Line을 선택합니다. Line 객체만 필터링되며 다른 엔티티는 무시됩니다.
3User 파일 선택(User 모드 시) 파일 열기 창에서 UserBarlist로 저장한 .txt를 선택합니다.
4길이 검증절단 치수가 장바 최댓값 - 35mm 이상인 Line이 있으면 경고를 표시하고 처리를 중단합니다.
5절단 최적화프로파일·길이별 정렬 및 수량 집계 후, 각 장바 규격에 절단 치수를 최적 배분하여 필요 장바 수량·손실 길이·잔여 길이를 계산합니다.
6Excel 파일명 입력"Enter Excel File Name:" 프롬프트에서 저장할 Excel 파일 이름을 입력합니다.
7도면 출력 위치 선택"TList의 위치를 선택:" 프롬프트에서 테이블을 배치할 도면 위치를 클릭합니다.
8결과 출력Cutting List와 Long Bar List를 도면에 텍스트로 출력하고, Excel 파일로도 저장합니다.

사용 방법

  1. 프로파일 부재를 Line으로 그립니다. 이때 레이어 이름 = 프로파일 이름, 선 길이 = 절단 치수(mm)가 되도록 합니다.
  2. (User 모드를 사용할 경우) UserBarlist로 장바 데이터를 미리 저장합니다.
  3. 명령창에 Cuttinglist를 입력하고 Enter를 누릅니다.
  4. "[Auto / User]:" 프롬프트에서 모드를 선택합니다. Enter만 누르면 이전 모드를 유지합니다.
  5. 절단 치수 Line을 선택하고 Enter를 누릅니다.
  6. (User 모드 시) 파일 열기 창에서 장바 데이터 .txt 파일을 선택합니다.
  7. 절단 길이 검증을 통과하면, Excel 파일 이름을 입력합니다.
  8. 도면에서 테이블을 배치할 위치를 클릭합니다.
  9. Cutting List와 Long Bar List가 도면에 출력되고 Excel 파일이 저장됩니다.

주요 내용

항목설명
선택 필터LINE 객체만 인식합니다. PolyLine, Circle 등은 선택해도 무시됩니다.
Auto 장바 범위3000mm ~ 6500mm, 100mm 간격 (36개 규격)
절단 길이 한도장바 최댓값 - 35mm 이상의 절단 치수가 있으면 경고 후 중단됩니다.
도면 출력 내용① Cutting List (절단 치수·수량·장바 배정·손실·잔여) ② Long Bar List (장바 길이·수량) 순서로 출력됩니다.
Excel 출력Cutting List와 Long Bar List가 Excel 파일로 저장됩니다.
텍스트 크기현재 AutoCAD TEXTSIZE 시스템 변수를 사용합니다.
적용 환경AutoCAD / BricsCAD

실행 결과

항목설명
Cutting List (도면)프로파일별 절단 치수·수량·사용 장바 배정·손실·잔여가 도면 텍스트로 출력됩니다.
Long Bar List (도면)Cutting List 아래에 프로파일별 필요 장바 길이·수량이 출력됩니다.
Excel 파일입력한 이름의 Excel 파일에 Cutting List와 Long Bar List가 저장됩니다.
참고: 부분 선택도 가능합니다. 도면 전체가 아닌 일부 Line만 선택하면 선택된 범위에 대한 절단 리스트만 산출됩니다.
User 모드에서 프로파일 이름과 일치하는 항목이 없으면 기본 장바(3000, 4000, 5000, 6000, 6500)가 적용됩니다.
주의: 절단 치수가 장바 최댓값 - 35mm 이상인 Line이 하나라도 있으면 처리가 중단됩니다. 해당 Line의 레이어 이름과 길이가 명령창에 표시되므로 확인 후 수정하세요.
