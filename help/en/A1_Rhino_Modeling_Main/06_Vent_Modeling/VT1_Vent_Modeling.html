VT1 ~ VT9  —  Vent Modeling

VT1VT2VT3 VT4VT5VT6 VT7VT8VT9

Automatically creates vent frame 3D solids based on the selected Brep face. VT1 ~ VT9 each correspond to vent types 1–9 pre-configured in the VTOpt panel.

Purpose

Used to quickly create vent (operable window) frame 3D solids for any number of specifications via type shortcuts (VT1-VT9). Enables fast placement of varied vent types across multiple faces based on settings configured in VTOpt.

How to Use

  1. Set the vent type and section data to apply in the VTOpt panel first.
  2. Type VT1 (or VT2–VT9) in the Rhino command line and press Enter.
  3. At the Select Vent Surface Object prompt, select the Brep face on which to create the vent.
  4. Press Enter to finish — vent frame solids are created as a group based on the selected face.

Example

VT Number and Type Relationship

CommandDescription
VT1Creates vents using type 1 settings in the VTOpt panel.
VT2Creates vents using type 2 settings in the VTOpt panel.
VT3 ~ VT9Creates vents using types 3–9 settings in the VTOpt panel.

Result

ItemDescription
Created ObjectsLeft / Right / Top / Bottom frame solids are created.
GroupThe created solids are bundled into a single Rhino group.
DataVent type data is stored in the group and used by VtNo, VtList, and VtTable.
Non-orthogonal FaceIf the four sides are not at 90°, a separate logic is used and a guidance message is shown in the command line.
