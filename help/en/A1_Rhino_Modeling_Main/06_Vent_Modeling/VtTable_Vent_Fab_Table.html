VtTable  —  Vent Fabrication Drawing Table

VtTable

Analyzes selected vent group objects and automatically generates a fabrication drawing table within the Rhino drawing. Copies and places vent shapes per type, and outputs fabrication numbers and quantity information.

Purpose

Used to organize vent type shapes, fabrication numbers, and quantities into an on-drawing fabrication reference table. Supports production and ordering review by consolidating vent schedule information alongside shape copies.

How to Use

  1. Type VtTable in the Rhino command line and press Enter.
  2. Select the vent group objects to include in the table and press Enter.
  3. Once analysis is complete, click the table start position in the viewport.
  4. A per-vent-type fabrication drawing table is generated from the selected position.

Example

Table Cell Contents

Fabrication cells are created per vent type. The contents of each cell are as follows.

Cell ItemDescription
Type NameVent type name. Displayed at the top of the cell alongside the fabrication number.
Fab_NoFabrication number. Displayed as [TypeName] [Prefix][Number].
QntQuantity for that fabrication number.
Vent ShapeA copy of the original vent shape is placed at the cell center in the fabrication table.

Layer and Behavior Notes

ItemDescription
Selection ModeOperates in GroupSelect mode — clicking a vent group selects the entire group.
Text LayerGenerated text is placed on the Text and Profile_No_Qnt layers.
Data ReferenceTallies per-type quantities based on group data and Fab No information saved by VtNo.
Construction PlaneThe active viewport's CPlane Y origin is automatically corrected to 0 on execution.
Placement MethodVent elevation and profile machining information are placed sequentially from the selected start point.

Related Commands

CommandDescription
VT1 ~ VT9Vent modeling — run first before generating the table.
VtNoVent numbering — linked to the Fab_No in the table.
VtListVent quantity list — use together with the table.
