VtMolist  —  Vent Material List

VtMolist

Tallies the individual profile members contained in the selected vent groups and generates a material list (Molist).
Frames and other models may be selected along with the vents — only the members belonging to a vent group are tallied, so you can select the whole model at once.
The table is written into the Rhino viewport and can optionally be saved as an Excel file.

Purpose

Ordering and fabricating a vent needs the cut lengths and quantities of the profiles that make it up, not the overall size of the vent. VtMolist opens the vent group and aggregates the profiles inside it by shape name and cut length.

Frames and vents normally share one document. VtMolist keeps only the members that belong to a vent group, whatever the selection contains, so there is no need to pick around the frame profiles — a window selection over the whole model still produces a vent-only list.

Difference from VtList and Molist

CommandUnit of aggregation
VtListOne row per vent group. A finished-product quantity list with vent width, height and code.
VtMolistOne row per profile member inside the vent groups. A material list with shape name, cut length, quantity and weight.
Only members belonging to a vent group are tallied.
MolistSame table format, but tallies everything selected. Select frames and vents together and they are mixed into one list.

In short, Molist lists "everything selected" while VtMolist lists "only the vents among what was selected". The same selection gives different results.

How to Use

  1. Type VtMolist in the Rhino command line and press Enter.
  2. Set whether to save an Excel file using the Excel_File_On option.
  3. Select the objects to tally. Group selection is enabled, so clicking one object selects the whole group.
    There is no need to isolate the vents. A window selection over the whole model, frames included, is fine.
  4. Press Enter to finish the selection.
  5. Objects that do not belong to a vent group are dropped automatically, and the number excluded is reported in the command line.
    [VtMolist] Excluded 34 objects that are not in a Vent group. Remaining — Breps: 12, …
  6. The material list is written as a text table on the current construction plane. If the option is On, you are prompted for a file name and an Excel file is also saved.

Example

Options

OptionDescription
Excel_File_On Off — Rhino viewport output only.
On — prompts for a file name in the command line and saves an Excel file.
The file is saved as [DocumentPath]-[EnteredName], next to the current .3dm file.

Accepted Selection — What Is Tallied and What Is Dropped

The selection is not tallied as-is. Each object is first tested for membership in a vent group.

ObjectHandling
Brep in a vent groupTallied — its profile data is read and grouped by shape name and cut length.
Brep outside a vent groupDropped — frame profiles and the like do not belong to a vent group, so they never reach the list.
Block (instance)A block whose description starts with NBlock: is treated as a named block. If it holds a vent, only that vent's members are tallied; frame profiles in the same block are dropped. A block with no vent in it is skipped entirely.

Vent groups placed in the document and vents held inside blocks can be selected together; both results are merged into a single list.

How vent membership is decided: from the group information that VT1 – VT9 modeling wrote onto the group. A group assembled by hand, or an object that never went through vent modeling, is therefore not recognized as a vent.
A vent inside a block is decided from information stored when the NBlock was built. An older block created before that information existed carries none, and its vents cannot be found — rebuild such a block.

Output Columns

#ColumnContent
1NOSequential number
2Unit NoUnit number
3SHAPE NameProfile shape name
4FAB NOFabrication number (fab prefix + number)
5Cut Length(L)Cut length in mm
6QuantityQuantity
7FINISHSurface finish
8Unit_WeightUnit weight per meter
9WeightCut length x quantity x unit weight

An Alum.Total subtotal row follows the aluminum members, and a final row adds the total quantity and weight.

Note: this command was named VMolist in earlier versions. It was renamed to VtMolist to match the other vent commands (VtList, VtNo, VtTable). Its behavior is unchanged.
Caution: objects without profile data are not tallied. If the list comes out empty, read the command line message first.
  • No ProfileData was found — profile data is written by VtNo. Run VtNo first, then run this command again.
  • None of the selected objects belong to a Vent group — the selection contained no vents. Select again, including the vents.
If it is still empty, check that the section data was entered with Pname.
