VtList  —  Vent Quantity List

VtList

Analyzes selected vent group objects and generates a vent quantity list. Outputs a text list to the Rhino viewport and can optionally save as an Excel file (.xlsx).

Purpose

Used to tally vent component quantities for review. Displays a text summary on screen and can export to Excel for external ordering and consolidation workflows.

How to Use

  1. Type VtList in the Rhino command line and press Enter.
  2. Set whether to save an Excel file using the Vent_Excel_File_On option.
  3. Select the vent group objects to tally and press Enter.
  4. The quantity list is displayed on screen. If the option is On, an Excel file is also saved in the same folder as the current .3dm file.

Example

Options

OptionDescription
Vent_Excel_File_On Off — Rhino viewport output only.
On — saves an Excel file in the same folder as the current .3dm file.
Filename format: [DocumentName]-VentList.xlsx
