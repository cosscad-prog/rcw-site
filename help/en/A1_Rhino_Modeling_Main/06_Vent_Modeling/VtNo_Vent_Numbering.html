VtNo  —  Vent Numbering

VtNo

Analyzes vent groups created by VT1 ~ VT9 and automatically assigns vent fabrication numbers. Compares profile shapes to create internal Fab Nos, and saves a per-group fingerprint so identical shapes share the same numbering scheme.

Purpose

Used to automatically assign fabrication numbers (Fab No) to vent groups based on shape comparison (fingerprint). Identical shapes receive the same number scheme, serving as the reference basis for vent lists, fabrication tables, and drawings.

How to Use

  1. Vent groups must already be created with VT1 ~ VT9 commands.
  2. Type VtNo in the Rhino command line and press Enter.
  3. At the Select Vent Group objects prompt, select the vent groups to number.
  4. Enter the Fab prefix string — profile and vent group numbers are automatically calculated.

Example

Execution Steps

StepDescription
1/4Collects Brep profiles from the selected Vent groups.
2/4Compares profile shapes, assigns internal Fab Nos, and records them on the Fab_No_Text layer.
3/4Generates a Fab No fingerprint per vent group and saves it to group data.
4/4Assigns Vent numbers based on the fingerprint. Number prefix is V.
