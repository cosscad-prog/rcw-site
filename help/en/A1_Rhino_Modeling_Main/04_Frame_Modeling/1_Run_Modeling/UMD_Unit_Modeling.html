UMD  —  Unit Frame Modeling

UMD

UMD analyzes the Mullion/Transom centerlines of the selected Unit group and automatically models the frame solids and related Blocks. It reads the Unit No TextDot inside the group to track progress and manage result group information.

Purpose

Used to automatically generate frame 3D solids from Units with Wire Frame (Mullion/Transom reference lines) and Section data prepared. As the core execution step of RCW modeling, it processes Mullion/Transom modeling, bracket remachining, and group organization in one operation to create the foundation model for subsequent numbering, list, and drawing work.

How to Use

  1. Prepare a Unit group with Wire Frame and Section data already entered.
  2. Type UMD in the Rhino command line and press Enter.
  3. At the Select Group objects prompt, select the Unit group to model.
  4. Press Enter — Mullion modeling, Transom modeling, bracket remachining, and final grouping are executed in sequence for each group.

Example

Execution Flow

StepDescription
1. Group SelectionSelects Unit groups in GroupSelect mode. Processes groups as units rather than individual sub-objects.
2. Object ClassificationIdentifies Mullion Curves, Transom Curves, Attach Curves, and Anchor Points within the group.
3. Mullion GenerationCreates Mullion solids and related Blocks using Section/Profile data.
4. Transom GenerationCreates Transom solids incorporating Mullion results and bracket subtraction data.
5. Remachining / GroupingIf Transom bracket subtraction shapes exist, Mullion is remachined; results are organized into Unit groups.

Prerequisites

ItemDescription
Unit GroupA group created in the Wire Frame stage with a Unit No TextDot is recommended to easily track the workflow.
Section DataSection data must be prepared in advance with Pname. Whether a section is a mullion or a transom is decided by the program itself.
Attach InfoIf brackets or accessory machining are needed, the relevant Attach Curves and Anchor Points must be included in the group.

Result

ItemDescription
Frame SolidsBrep objects with Mullion/Transom ProfileData are created.
BlocksIf brackets or accessories are needed, related Blocks or subtract shapes are also created.
GroupsThe created models and reference objects are re-grouped by Unit.

Related Commands

CommandDescription
FabNoAssigns fabrication numbers and ProfileData to the created frame solids.
MolistCreates a quantity material list from the modeling result.
FDwgGenerates frame fabrication drawings.
Caution: If reference lines or Section data are missing inside the group, some Mullion/Transom models may not be created or group errors may occur.
