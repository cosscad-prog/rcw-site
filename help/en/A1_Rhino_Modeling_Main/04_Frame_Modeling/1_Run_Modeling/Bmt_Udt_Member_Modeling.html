Bmt/Udt  —  building members one at a time

Bmt   Udt

Bmt builds one member from one line you point at. Udt then rebuilds those members as a single set, so where they cut into one another shows.

Purpose

UMD gives you nothing until a wireframe group is complete and selected as a whole. Bmt offers the same modelling rules one member at a time - a way in for someone learning, and for fixing one or two members. You build what you need without running the whole thing again.

Example

How to Use

  1. Run Bmt and select one Mullion or Transom profile group. (prompt: Select profile group)
  2. Move the cursor near a wire and a preview appears, aligned to that line. Click and the member is built. (prompt: Move near a wire and click to create extrusion)
  3. Keep pointing at lines. Finish with Enter or Esc.
  4. Later members go on the same wireframe set.
  5. Once both Mullions and Transoms are there, run Udt to rebuild the set so that the cuts between members show. (prompt: Select the BMT Wireframe group)

Udt — rebuilding the set

Bmt raises members one at a time, so it cannot know how a member will meet a neighbour that does not exist yet. Once the Mullions and Transoms are in place, Udt rebuilds that whole wireframe set, working out where members cut into each other and redoing the bracket work.

When to run it: not after every member. Run it once the set is reasonably complete. Running it again clears that set's previous output and builds it afresh.

Worth knowing

ItemDescription
Grouped by setWhat you build is grouped per wireframe set. Selection stays simple, and profiles in unrelated units are not updated along with it.
Direction stays with the originalProfile orientation is stored on the original group, so a later rebuild does not depend on your current view or the direction you picked in.
How sections are foundBy the group number embedded in the line, not by layer name. That means different sections can live on the same layer.
Anchor (ANP) groupsIf the group's label starts with ANP it works in anchor mode - blocks and sections are placed on the points of the AN_Point layer rather than on lines. Picking the same point again replaces what is there.
With no section dataThe old default extensions are used - 50 for a Brep or curve, 0 for the original surface.
A unit uses one method only. The same wireframe cannot be built with Bmt/Udt and with SSP/UMD. Mixing them stops at that unit and says so.
To switch, confirm in the dialog that that unit's output is deleted and the method changes. There is no separate command.
⚠ Why the rule exists: a unit built with Udt may carry different sections on one layer, which UMD cannot represent at all. If UMD touched it, the shape would be wrong.

When it does not work

What the command line saysWhat it means
Selected profile object is not in a group.What you picked is not in a group.
Profile group must contain one valid curve on the Center1 layer. The group needs one curve on the Center1 layer.
No Surface or Brep objects were found…The group holds no section surface or Brep.
No wire curves were found outside…There are no wires to point at. Build the wireframe first.
If you copied a section group, take care. The copy carries the same group number as the original, so there is no telling which section to use. It stops before building anything and names the groups that clash.
