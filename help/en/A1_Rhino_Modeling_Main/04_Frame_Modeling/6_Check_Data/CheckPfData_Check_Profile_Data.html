CheckPfData

CheckPfData checks whether selected Brep objects have ProfileData. Objects without data are marked with a red circle and a "No ProfileData" text. It also identifies any solids with defects that cannot be interpreted normally.

Purpose

Used to verify that frame Solids have ProfileData correctly. Finds Solids with missing data or shape defects that cannot be interpreted by marking them with a red circle and No ProfileData label, allowing you to identify problem objects before creating material lists or drawings.

How to Use

  1. Type CheckPfData in the Rhino command line and press Enter.
  2. At the Select Objects prompt, select the frame objects to check.
  3. Press Enter — the existence of ProfileData is verified per Brep object.
  4. The command line outputs the name/Fab No/Length of valid objects, and shows the missing count at the end.

Example

Inspection Result

StateDisplay
ProfileData presentOutputs Name: ProfileName-FabNo Length format in the command line.
ProfileData missingWrites a red circle and No ProfileData text on the Check layer at the object center.
Final summaryOutputs [ Error_Count / Total_Count ] No ProfileData format showing the missing count.
