PMolist  —  Profile Material List

PMolist

PMolist reads ProfileData from selected Breps or Blocks and creates a Profile-centered quantity/weight list. Use this to quickly check the aggregate for Profile members themselves rather than Block quantities.

Purpose

Used to quickly generate a simplified Profile-centered material quantity list, aggregating members by Profile name and Fab No. Provides a fast overview of profile material requirements without Block information, useful for quick material checks or when Block details are not needed.

How to Use

  1. Prepare frame solids processed with FabNo.
  2. Type PMolist in the Rhino command line and press Enter.
  3. If needed, switch Excel_File_On to On.
  4. At the Select Solid objects prompt, select Brep or InstanceReference objects.
  5. Press Enter — a Profile quantity list is written to screen.

Example

Options

OptionResult when On

PMolist vs Molist

CommandDifference
PMolistSimple aggregate centered on Profile members.
MolistCreates a broader material list integrating both ProfileData and Block information.
Note: Breps without ProfileData are not included in the list.
