Molist  —  Frame Material List

Molist

Molist reads the ProfileData and Block information of selected frame models to generate a material quantity list. It automatically identifies Group, NBlock, and Mixed selections and tallies the results into a single list.

Purpose

Used to generate a comprehensive material quantity list from modeled frame members before cutting, checking total quantities and weights. Provides visibility into material requirements at the unit level, integrating both ProfileData and Block information for accurate material planning and cost estimation.

How to Use

  1. Use FabNo to write ProfileData and Fab No first.
  2. Type Molist in the Rhino command line and press Enter.
  3. If needed, switch Excel_File_On to On.
  4. At the Select Brep, Block objects for Molist prompt, select target Breps, standard Blocks, and NBlocks.
  5. Press Enter — the list is written to screen, and if the option is On, an Excel file is saved.

Example

Selection Modes

ModeDescription
Group ModeExtracts ProfileData / InstanceInfo from Breps and standard Blocks.
Block ModeExtracts Breps and nested Block information from inside NBlocks.
Mixed ModeMerges Group Mode and Block Mode results for combined tallying.

Output Items

ItemDescription
Unit NoUnit number from ProfileData.
SHAPE NameProfile name or Block name.
FAB NOFabrication number assigned by FabNo.
Cut Length / QuantityCutting length and quantity of the member.
Unit_Weight / WeightUnit weight and total weight incorporating quantity.
DescriptionDescription read from SectionCustomData or Block Description.

Related Commands

CommandDescription
FabNoGenerates Fab No and ProfileData needed for Molist tallying.
PMolistCreates a simple Profile-centered material list.
CuttinglistGenerates a cutting plan and bar list.
Note: If only a subset of objects is selected, a partial Molist is generated based only on the selected objects.
