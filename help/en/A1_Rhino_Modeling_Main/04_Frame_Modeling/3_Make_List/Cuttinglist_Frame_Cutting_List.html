Cuttinglist  —  Frame Cutting List

Cuttinglist

Cuttinglist tallies the selected frame ProfileData by cutting length, calculates bar lengths and losses, and generates a cutting plan. An additional list for the optimal 5 bar lengths is also provided. Supports Group, NBlock, and Mixed selection.

Purpose

Used to generate a cutting plan from modeled frame members by calculating bar lengths and cutting losses. Provides both a detailed cutting plan and an optimized bar list, enabling efficient material preparation and minimizing waste before fabrication.

Note: A CuttingList is generated for the selected objects. If only a subset is selected, a partial CuttingList is produced.

How to Use

  1. Prepare objects with ProfileData from FabNo or post-modeling.
  2. Type Cuttinglist in the Rhino command line and press Enter.
  3. Choose whether to use automatic bar list with the Auto_Barlist_On option.
  4. In auto mode, adjust Cut_Interval_Barlist, Cut_Min_Barlist, and Cut_Max_Barlist as needed.
  5. At the Select Group and/or NBlock objects for Cuttinglist prompt, select the target objects.
  6. Press Enter — the cutting plan and bar list are written to the screen.

Example

Options

OptionDescription
Auto_Barlist_OnOn: automatically generates the bar list from the Min–Max range and Interval. Off: uses bar data from a user-provided txt file.
Cut_Interval_BarlistAutomatic bar length interval. Default: 100.
Cut_Min_BarlistMinimum automatic bar length. Default: 3000.
Cut_Max_BarlistMaximum automatic bar length. Default: 6500.

Output Items

ItemDescription
Cutting PlanDisplays Profile Name, unit weight, cutting length, quantity, bar used, and production quantity.
Loss / StockCalculates loss length/quantity/weight and reusable stock length/quantity/weight.
Bar ListSeparately tallies bar length and quantity used per Profile, plus total weight.
Additional ExcelIf a Python comparison script is found, an additional Excel file can be generated in the same directory.

Related Commands

CommandDescription
MolistCheck total material quantities and weights before the cutting plan.
PMolistCreate a Profile-centered list.
FabNoGenerate ProfileData and Fab No.
Caution: If a cutting length exceeds the maximum bar length, calculation may stop or an error message may appear.
Note: If the user bar txt file has no die number, the default bar length list is applied.
