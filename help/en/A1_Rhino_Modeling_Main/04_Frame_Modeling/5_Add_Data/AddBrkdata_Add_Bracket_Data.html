AddBrkdata  —  Add Bracket Data

AddBrkdata

AddBrkdata is an auxiliary command that records SectionCustomData on selected bracket Breps and adds bracket IDs to the BrkIDdata list of the selected Mullion Brep.

Purpose

AddBrkdata records SectionCustomData on selected bracket Breps and adds bracket IDs to the BrkIDdata list of the selected Mullion Brep.

How to Use

  1. Type AddBrkdata in the Rhino command line and press Enter.
  2. At the Select Bracket Objects prompt, select multiple bracket objects to link to the Mullion.
  3. Press Enter, then at the Select Mullion Objects prompt, select one Mullion object.
  4. The command organises the bracket ID list and adds it to the Mullion's BrkIDdata.

Recorded Data

ItemDescription
Bracket SectionCustomDataRecords the bracket name in P_name and sets Profile_ID = 1, MnT_ID = 9.
Mullion BrkIDdataIf existing BrkIDdata is present, retains only valid IDs, then adds new bracket IDs without duplicates.
Completion MessageOutputs the number of added brackets to the Rhino command line.

Caution: If the selected bracket objects are not Breps, or the Mullion object has no Brep data, the data may not be recorded correctly.
