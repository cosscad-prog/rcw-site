FabNo  —  Frame Fabrication Numbering

FabNo

FabNo analyzes selected frame Breps, standard Blocks, and NBlocks to write ProfileData and fabrication numbers. It compares the same Profile name and shape conditions, assigning the same Fab No to identical members.

Purpose

Used to assign ProfileData and fabrication numbers (Fab No) to modeled frame members, grouping identical members under the same number. This is an essential preliminary step before creating material lists (Molist), cutting lists (Cuttinglist), fabrication tables (FabTable), and fabrication drawings, providing the reference data for all subsequent tasks.

How to Use

  1. Type FabNo in the Rhino command line and press Enter.
  2. If needed, toggle the Data_Option On or Off.
  3. At the Select Brep, Block, NBlock objects for FabNo prompt, select the target objects.
  4. If only NBlocks are selected, enter the drawing prefix character (default: F).
  5. Press Enter — after analysing objects, number text is written on the Fab_No_Text layer.

Example

Selection Modes

ModeDescription
Group ModeWhen Breps or standard Blocks are selected. Analyzes Breps and standard Blocks within the group.
Block ModeWhen only NBlocks (description starts with NBlock:) are selected. Analyzes Breps inside NBlocks.
Mixed ModeWhen Group and NBlock targets are selected together. Both results are processed and merged.

Options

OptionResult when On
Data_OptionOutputs an additional comparison data table at a specified location to identify where Fab No changes.

Result

ItemDescription
ProfileDataUnit No, Profile Name, Fab No, and length/shape comparison data are recorded on the Brep.
Number TextVerification text such as ProfileName F1 is placed on the Fab_No_Text layer.
Bracket NumbersBracket objects may be shown with smaller text on a separate sub-layer.

Related Commands

CommandDescription
UMDCreates the frame model to which FabNo will be assigned.
CheckPfDataChecks for objects missing ProfileData.
MolistCreates a quantity list based on Fab No.
