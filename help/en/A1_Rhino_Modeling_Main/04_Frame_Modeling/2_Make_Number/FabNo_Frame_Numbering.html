FabNo  —  Frame Fabrication Numbering

FabNo

FabNo analyzes selected frame Breps, standard Blocks, and NBlocks to write ProfileData and fabrication numbers. It compares the same Profile name and shape conditions, assigning the same Fab No to identical members.

Purpose

Used to assign ProfileData and fabrication numbers (Fab No) to modeled frame members, grouping identical members under the same number. This is an essential preliminary step before creating material lists (Molist), cutting lists (Cuttinglist), fabrication tables (FabTable), and fabrication drawings, providing the reference data for all subsequent tasks.

How to Use

  1. Type FabNo in the Rhino command line and press Enter.
  2. At the Select Brep, Block, NBlock objects for FabNo prompt, select the target objects.
  3. If only NBlocks are selected, enter the drawing prefix character (default: F).
  4. Press Enter — after analysing objects, number text is written on the Fab_No_Text layer.

Example

Selection Modes

ModeDescription
Group ModeWhen Breps or standard Blocks are selected. Analyzes Breps and standard Blocks within the group.
Block ModeWhen only NBlocks (description starts with NBlock:) are selected. Analyzes Breps inside NBlocks.
Mixed ModeWhen Group and NBlock targets are selected together. Both results are processed and merged.

Options

OptionResult when On
DiagnoseFor two Profiles with the same name that received different Fab No, marks the faces that differ in red and writes a Dot with the number and area on each face (for example F1 515.86). The marks are created on the FabNo_FaceDiff layer and disappear when that layer is deleted. Once turned on, it stays on until Rhino is closed.

Result

ItemDescription
ProfileDataUnit No, Profile Name, Fab No, and length/shape comparison data are recorded on the Brep.
Number TextVerification text such as ProfileName F1 is placed on the Fab_No_Text layer.
Bracket NumbersBracket objects may be shown with smaller text on a separate sub-layer.
Numbers of the same nameWhen one section name is used both for attached parts (brackets, parts attached by ATC) and for main members (mullions, transoms), the main members are numbered after the last number used by the attached parts (for example, F4 onward when the attached parts took F1 to F3). A line in the command window reports each such name. An attached part and a main member are not given the same number even if their shapes match.
Copied unitsFor units copied with Rhino's Copy, FabNo finds the parts attached to the copy (brackets and the like) again and numbers from them. Parts are grouped the same way as in the original, but the numbers themselves can differ from the original.
Rotated or mirrored partsParts rotated or mirrored after numbering cannot be handled correctly by FabNo. When there are such parts a warning is shown at the end of the command, and the number and sizes of a rotated part that already has a number are not rewritten. Please number before rotating. Copying and rotating numbered units to produce Fablist and Molist works as before.
In a document numbered in 5.4.3 or earlier where the same name was used for attached parts and for main members, numbers may overlap (Molist then differs with the selection). Run FabNo again, and because the numbers change, remake the lists, tables and fabrication drawings made from them. Re-running only part of a selection with the same prefix mixes old and new numbers, so select everything in one run.

Showing Deleted Number Text Again  —  FabNoShow

FabNoShow

FabNoShow writes the number text again after the text that FabNo placed on screen has been deleted. It does not renumber anything: it reads the number stored on each member and only writes the text. It is faster than running FabNo again, and the numbers do not change.

  1. Type FabNoShow in the Rhino command line and press Enter.
  2. Select the Breps, standard Blocks, and NBlocks whose numbers you want to see, then press Enter.
ItemDescription
Number TextThe same text that FabNo wrote (ProfileName F1) is written at the same position and size, on the layer of the last FabNo run (under Fab_No_Text).
Block NamesThe names of the selected Blocks and NBlocks are also written again in red at their insertion points, as FabNo does.
Existing TextIf the same text is still at the same position it is not written again. If it is hidden, or its layer is turned off, it is only made visible. Running the command several times does not stack text.
Members Without a NumberNo text is written for members on which FabNo has never been run; their count is reported in the command line. Run FabNo on them first.
