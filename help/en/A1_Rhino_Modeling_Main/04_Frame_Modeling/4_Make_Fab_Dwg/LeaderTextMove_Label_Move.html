LeaderTextMove  —  Label Text Move

LeaderTextMove

LeaderTextMove (formerly LM) is a command that moves only the text (tail) of an accessory label leader while keeping the arrow fixed. Select the label and click the new text position, and the leader start point (arrow) stays attached to the accessory while only the text tail moves, with the leader line following to the new position.

Purpose

Unlike standard Move, which moves the arrow too and loses the reference target, this command keeps the arrow (reference point) fixed to the accessory while moving only the text to a better viewing position. Use it to organize overlapping section labels or labels that extend beyond the drawing boundary.

How to Use

  1. Type LeaderTextMove in the Rhino command line.
  2. At the Select label (leader) to move prompt, select the accessory label (Leader).
  3. Click the new text position. A live preview showing the actual label appearance follows your cursor.
  4. Multiple labels can be moved in sequence. Press Enter to finish.

Execution Flow

ItemDescription
Fixed / MovedThe start point (arrow) of the leader stays fixed, while only the end point (text tail) moves. The leader line is redrawn to the new tail position.
PreviewPreview is drawn using the same DimStyle as the actual leader, so the click position matches the result exactly.
TargetOnly Annotation (leader) objects can be selected. A guidance message appears if a non-leader is selected.
Playback ReproductionIf moved in FDstyle Recording Mode, the position is saved and automatically reproduced in FDDS/FDwg Playback.
Note: To move the entire label including the arrow, use LeaderMove. LeaderTextMove keeps the arrow fixed and moves only the tail.
