FDwg  —  Frame Fab Drawing (Elevation Hole Representation)

FDwg

FDwg analyzes the selected frame group objects in the same way as FDDS to automatically generate a fabrication drawing (Fab Drawing). It copies/aligns the model to the drawing position, then for each selected View creates 2D lines, sections, hole diameters, overall dimensions, center-line dimensions, angle dimensions, and Fab No / Quantity / Unit No text.

Additionally, FDwg displays hole information on the Bar elevation views (Front / Top / Bottom, etc.) and generates a drawing where you can easily understand how deeply each hole penetrates through the material via Hidden Lines.
FDDS → FDwg key differences:
  • Shape Curve layer is represented as OutLine Layer.
  • All other options, dimensions, text, and layer operations are identical to FDDS.
Note: The DimStyle follows the DimStyle applied in [DsOpt]. For per-profile automation, Fdds.dat is required and must contain the Profile Name and needed information. If that information is missing, the Drawing options in the DdOpt panel are used.
FDstyle Record/Playback: FDwg/FDDS follows the mode of the FDstyle panel — in Record (ON) mode it records options, NC tables, FSC compression, annotations, supplementary material tables, partial enlargement (F3D), and drawing templates per profile, and in Playback (OFF, default) mode it automatically reproduces them. For details, see the "FDstyle Record / Playback Mode" section in the FDDS help documentation.

Purpose

FDwg analyzes the selected frame group objects to auto-generate a fabrication drawing and lets you confirm hole position and penetration depth at a glance on the elevation view as well.

Basic Usage

  1. Open the Drawing option panel with DdOpt and set the required View, dimension, and distance options.
  2. ProfileData / Fab No must first be assigned to the frame model (e.g. via FabNo).
  3. Type FDwg in the Rhino command line and press Enter.
  4. If the DdOpt or DsOpt panel is closed, FDwg opens it and then asks whether to continue with the values now shown there. Yes draws with those values; No stops — check or change them and run FDwg again. With both panels already open you are not asked.
  5. At the Select Group objects prompt, select the frame group to generate the fab drawing for.
  6. Press Enter to generate the drawing model and dimensions per group, with hole depth Hidden Lines drawn on the elevation.

Elevation Hole Depth Representation (FDwg Addition)

When building the drawing, FDwg uses Rhino's 2D projection (HiddenLineDrawing) and selects only those hidden lines located at the same depth (Z) as the holes, drawing them on the elevation.

ItemDescription
RepresentationThe section where the hole passes through the material is drawn as a Hidden Line (dashed). Hole position and penetration depth can be confirmed on the elevation at the same time.
Matching basisHidden lines whose depth value matches each hole's (HolePoint) Brep bounding-box depth are picked automatically. Hidden lines unrelated to the hole (e.g. the opposite wall) are excluded.
LayerThe selected hole hidden lines are drawn on the Shape_Hidden layer (Hidden linetype) — treated as ordinary hidden lines, not emphasized lines.
Applied viewsApplied identically to all generated elevation views (FR / TO / BO / TB / BB) and appears automatically on the appropriate view depending on profile orientation.
Existing markers keptExisting markers — hole center line (Hole_Center), section hatch (Hole_Hatch), hole points (Hole_Points) — are kept, and the depth Hidden Line is added on top.

Options / Dimension Settings

FDwg's View selection, distances, extra dimensions, auxiliary 3D display, and DsOpt / DimStyle dimension placement options behave exactly like FDDS. For detailed descriptions of each option, refer to the FDDS help document.

Option groupSummary
DdOpt Group 1 (View/Max Only/Side Dim)Specifies the View directions to generate and the dimension notation method for each View.
DdOpt Group 2 (Distance/Hole size)Adjusts the drawing start position, View spacing, Fab No position, and hole recognition diameter (Hole Dia Min).
DdOpt Group 3 (Extra Dim OnOff)Toggles the 90° Angle / Center / Hole / Unit No / P_Section / Attach extra information.
DdOpt Group 4 (Model View)Decides whether to leave the Shape / Dim / Angle auxiliary models in the drawing.
DsOpt / DimStyleDecides dimension-line placement/size such as First Dist, Dim Gap, Angle Dist, and TextSize.
Option priority: In Playback mode, if FDDS_Data.dat contains a matching die row, the file values take priority over the panel. If there is no row or no file, the DdOpt panel values are used.

Cautions

Hatch patterns: If Hatch\acad.pat, in the folder RCWFolder opens, and required patterns are missing, FDwg stops with a message. Import acad.pat in Rhino's Hatch settings.
Group data: FDwg looks for the Profiles-layer Shape model, ProfileData, Fab No, DimBox/DimBox1, and cut-face data in the selected group. If FabNo is not assigned or the group structure is broken, errors like Group Model Error or CutSurface Error may occur.
Hole recognition: Holes are found from cylindrical Brep faces, and only those with diameter ≥ Hole Dia Min are labeled. A value too small catches even unnecessary circular faces, while a value too large may miss actual holes.
Elevation hole depth Hidden Line: Depth is computed from the actually machined shape in the model. If a hole is not recognized (not a cylindrical face) or the material shape is abnormal, the Hidden Line may not appear. If dashed lines are excessive or missing, check the hole/section geometry of the model first.

The 90° Angle Dim option  —  it switches right angles on and off

90° Angle Dim in DdOpt governs the 90 degree angles only. Every other angle, 45 degrees for instance, is always drawn regardless of the option - a bevel angle is a value the drawing has to state.

90° Angle DimAngles drawn
OnAll of them, right angles included
OffOnly the 90 degree ones are left out; the rest are drawn as usual

So on a member where FR measures 90 and TP measures 45, turning 90° Angle Dim off removes the 90 and keeps the 45. [F] angles (true 3D angles) follow the same rule, so only [F]90 is left out.

What counts as 90: a value that would read 90 on the drawing (within 0.05 degrees of 90). So 89.96° and 90.04° count as right angles and are dropped, while 89.9° and 90.1° do not and are drawn.
