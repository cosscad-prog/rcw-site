FabBomTable  —  Accessory Table

FabBomTable

FabBomTable (formerly FBL) is a command to place an accessory (BOM) table at any desired position on a fabrication drawing by clicking. The table content is automatically collected from accessories (brackets, sleeves, attachments, etc.) when FDwg / FDDS generates the drawing.

Purpose

Used to organize and display a list of accessories used in the fabrication drawing (types, quantities, etc.). Accessories are automatically collected when the drawing is generated; this command only specifies where to place the collected table. The position is saved as relative coordinates to the drawing anchor, and is automatically regenerated at the same location when FDDS runs in Playback Mode.

How to Use

  1. Type FabBomTable in the Rhino command line.
  2. At the Select fabrication drawing for accessory table prompt, select the target drawing. (Must be a drawing created by FDwg/FDDS to have ProfileName tags.)
  3. As you move the mouse, a table size and row separator preview (orange) is displayed. Click the desired top-left position.
  4. The accessory table is drawn at that position. (If an existing table is present, it is replaced.)

Example

Execution Flow

ItemDescription
Table ContentFilled with accessory data automatically collected during drawing generation (FDwg/FDDS) from brackets, sleeves, and attachments in the group.
Position PlacementUse the mouse preview (table border + row separators) to click and place the top-left corner. Table size is automatically determined by the number of accessory types and text size.
ReplacementIf a table already exists for the same Profile, it is erased and redrawn.
Playback ReproductionThe placement position is saved as relative coordinates to the drawing origin and is automatically regenerated at the same location in FDDS during FDstyle Playback Mode.
Note: The table content is not created by this command but is automatically collected when the drawing is generated. If no accessories are collected, a message "No collected accessories" appears — first run FDwg/FDDS with a group containing accessories.
Caution: If you select an object without ProfileName tags (not created by FDwg/FDDS), the table cannot be created.
