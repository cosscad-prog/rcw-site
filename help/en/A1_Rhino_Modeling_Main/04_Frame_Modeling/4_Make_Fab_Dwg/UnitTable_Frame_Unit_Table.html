UnitTable  —  Unit Elevation Table

UnitTable

UnitTable aggregates the selected NBlock units by block name, then lays out one representative elevation per unit side by side with the name and quantity below each.

Purpose

Use it to place an elevation overview of the curtain-wall units (NBlocks) on the drawing. The elevations are spaced generously so you can follow up with UF2D to add the member fablist and dimensions beside each elevation.

How to Use

  1. Create the unit blocks first with NBlock.
  2. Type UnitTable in the Rhino command line and press Enter.
  3. At the Select NBlock unit objects prompt, select the target NBlocks.
  4. Pick the table start position — one elevation is placed per unit type.

Example

Result

ItemDescription
Elevation layoutDuplicates one representative unit per block name and places them side by side. The spacing between units is four times that unit's width (BoundingBox X length), leaving room for UF2D to lay out the fablist and dimensions.
Name & quantityWrites the block name and Qnt-N below each elevation. The quantity is the count of same-named units within the selection.
Profile tableNot created. (Unlike VtTable, there is no lower profile table.)
LayerName/quantity text uses the Profile_No_Qnt layer.

Notes

ItemDescription
Unit nameThe unit name is the NBlock block definition name as-is (e.g. PL0, LT2). NBlock has no separate Fab number like Vent, so only the name is shown.
SelectionOnly InstanceReferences whose Description starts with NBlock: (NBlocks) are aggregated. Regular blocks are ignored.

Related Commands

CommandDescription
NBlockCreates a named unit block from the selection.
UF2DAuto-generates sections, dimensions, and a fablist for the placed unit elevation.
UnitListOutputs unit names and quantities as a list table.
FabTableLays out per-profile shapes and quantities as a table.
Note: If the CPlane origin Y is not 0 while UnitTable runs, the command corrects it to Y=0.
