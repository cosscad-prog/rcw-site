FabTable  —  Frame Fabrication Number Table

FabTable

FabTable tallies selected frame ProfileData by Profile name and Fab No, then lays out a copy of each member's shape along with quantity information in table form.

Purpose

Used to create a fabrication reference table showing member shapes, quantities, and Fab No information. Provides a visual overview of all members to be fabricated, with shape copies and dimensions for quick reference during fabrication planning and verification.

How to Use

  1. Use FabNo to write fabrication numbers first.
  2. Type FabTable in the Rhino command line and press Enter.
  3. If needed, switch Unit_No_On to On.
  4. To build a table without accessories, switch Accessory to Off. (Default is On.)
  5. At the Select Group and/or NBlock Objects for FabTable prompt, select target Breps or NBlocks.
  6. Pick the table start position — a table is generated per Profile.

Example

Selection Modes

ModeDescription
Group ModeExtracts ProfileData directly from selected Breps. Standard Blocks are excluded from Group Mode in this command.
Block ModeReads Breps and nested Block information inside NBlocks to reflect quantities.
Mixed ModeMerges Brep results and NBlock internal results to build the table.

Options

OptionResult when On
Unit_No_OnDisplays the Unit No alongside the member name in the table. Example: Profile-UnitNo F1
AccessoryIncludes accessories (members whose Material ID in Pname is 3. Accessory) in the table. On by default; when Off, accessory tables are not generated at all. Applies to Group, Block, and Mixed modes alike. Shapes attached to a main member as brackets and copied along with it are not affected by this option.

Result

ItemDescription
Table FrameCreates a cell per Profile showing Profile name, Fab No, quantity, and Length.
Shape CopiesProfile Brep and related centerlines/brackets are copied and placed at the table position.
LayersText mainly uses Text; member name/quantity uses Profile_No_Qnt; shapes use the Profiles layer.

Related Commands

CommandDescription
FabNoWrites Fab No and ProfileData required for table generation.
FDwgGenerates individual member fabrication drawings.
MolistCreates a quantity/weight list.
Note: If the CPlane origin Y value is not 0 when FabTable runs, the command corrects it to Y=0.
