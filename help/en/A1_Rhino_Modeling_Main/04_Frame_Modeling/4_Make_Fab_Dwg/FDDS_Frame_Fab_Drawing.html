FDDS  —  Generate Frame Fabrication Drawing

FDDS

Retired command  —  use FDwg instead.
FDDS no longer produces a drawing. Running it prints only "This command is no longer used. Please use FDwg."
Fabrication drawings are made with FDwg alone. What follows is kept for reading older drawings.

FDDS analyzes selected frame group objects and automatically generates fabrication drawings (Fab Drawings). It copies and aligns the model to the drawing position, then writes 2D lines, cross-sections, hole diameters, overall dimensions, centerline dimensions, angle dimensions, and Fab No / Quantity / Unit No text for each selected View.

Purpose

Used to generate the fabrication drawing of the selected frame members automatically. It writes the 2D outline, cross-section, hole diameters, dimensions and fabrication number of each member in one pass instead of drawing them by hand, and the drawing follows the per-Profile settings in Fdds.dat together with the DsOpt / DdOpt options.

Note: The DimStyle applied in [DsOpt] is used. Fdds.dat is required for per-Profile automation; it must contain the Profile Name and required information. If the information is not in Fdds.dat, the Drawing options from the DdOpt panel are used.

How to Use

  1. Open the Drawing Options panel with DdOpt and set the required View, dimension, and distance options.
  2. Ensure ProfileData / Fab No have been entered on the frame model using FabNo first.
  3. Type FDDS in the Rhino command line and press Enter.
  4. At the Select Group objects prompt, select the frame groups for which to create fabrication drawings.
  5. Press Enter — drawing models and dimensions are generated per group.

Example

About FDwg: If you want hole information shown not only in the section View but also on the Bar elevation, with the hole penetration depth drawn as Hidden Lines, use the FDwg command. Its base behavior is identical to FDDS.

Execution Flow

StepDescription
1. Group SelectionSelects frame groups in GroupSelect mode. Processes group units rather than individual sub-objects.
2. Hatch Pattern CheckReads hatch patterns from Hatch\acad.pat, in the folder RCWFolder opens, and checks for ANGLE, ANSI31–ANSI38 patterns.
3. Layer PreparationUses layers: DIMS, Section_Curve, Dim_Point, Hole_Dia, Hole_Points, DimBox, Dim_Points, DIMS_Center, DIMS_Angle.
4. Model AlignmentFinds Shape models, DimBox models, and cut face information from the selected group; copies and aligns them to the drawing position.
5. View GenerationCreates only the Views turned on in DdOpt. Top Back, Top, Front, Bottom, and Bottom Back can each be generated individually.
6. Dimensions / AnnotationsWrites overall dimensions, detailed dimensions, hole diameters, angle dimensions, cross-sections, Fab No, quantity, and Unit No per View according to options.

DdOpt Panel Sample

The DdOpt panel controls View generation, distance values, additional dimensions, and auxiliary 3D display in one location. The panel layout may vary depending on OS theme or screen scaling, but the meaning and application order of items remain the same.

FDstyle Record / Playback Mode

FDDS follows the mode of the FDstyle panel. Click the banner at the top of the panel to switch between Record (ON) and Playback (OFF, default).

ModeWhat it does
Record (ON)Records the options and follow-up work of a fabrication drawing made with FDDS — NC table, FSC compression, annotations/leaders, accessory table, detail view (F3D), drawing template and so on — per Profile into FDDS_Data.dat and its companion files.
Playback (OFF, default)Reads the recorded data and reproduces automatically the NC table, FSC compression, annotations, accessory table, detail view and template on the fabrication drawing of the same Profile. When nothing has been recorded, the current DdOpt panel settings are used.
Note: File data is applied automatically in Playback mode (when a row for that Profile exists). If no row has been recorded, the current DdOpt panel settings are used. For the file format, see the FDDS_Data.dat help.

Option Priority

ConditionBehavior
Playback + matching row foundReads FDDS_Data.dat; if a row matching the selected group's die name (ProfileName or the leading part of the object name) is found, file values take priority.

DsOpt / DimStyle Dimension Options and Their Relation to FDDS

FDDS's View selection and output are mainly decided in DdOpt, but how far the actual dimension lines are placed from the model, how much spacing is left between dimension lines, and where angle dimensions are drawn also use the values of the DsOpt panel.

DsOpt / DimStyle itemDefaultRole in FDDSEffect of changing the value
First Dist50The default distance the first dimension line sits from the drawing edge. Used internally in FDDS as DSopt_Dim_First.Increasing it moves the dimension lines away from the model for more room; decreasing it makes the drawing denser but dimensions and geometry may overlap.
Dim Gap20The gap between multiple dimension lines. Used internally in FDDS as DSopt_Dim_Gap.Increasing it widens the spacing between dimension rows for better readability. Too small and the dimension text and lines overlap.
Angle Dist50Decides how far angle dimensions are placed from the geometry. FDDS angle-model processing uses DSopt_Angle_Dist.Increasing it pushes angle dimensions outward; decreasing it sticks angle dimensions close to the geometry.
LnR Dist20The left/right margin used by left-right dimension tools and some 2D dimension commands. For FDDS's own main dimension placement, First Dist / Dim Gap have more influence.The left/right dimension spacing may change in left-right dedicated dimension commands or related drawings.
Top Max / Bottom Max / Left Max / Right MaxTop, Left On by defaultControls how the per-direction maximum dimensions are shown in some 2D/fab dimensions. In FDDS, the per-View Max option in DdOpt plays a more directly prioritized role.When used with other fab/2D drawing commands, the per-direction maximum dimension display changes.
TextSizeCurrent settingAdjusts the base text size in the DimStyle panel. FDDS's Fab No / Qnt text also reflects the current DimStyle's TextHeight and DimensionScale.A larger value improves text and dimension readability but also requires more drawing spacing.
DdOpt vs DsOpt difference: DdOpt decides "what to create" — for example, whether to make a Top View, whether to add Side dimensions, whether to show Unit No. DsOpt / DimStyle decides "where and how far apart to draw the dimensions." That is, even with the same FDDS options, different DsOpt values change dimension-line position and readability.
Practical tip: For large frames or work with many Views on, increasing only DdOpt's Dwg Distance may not be enough. If dimensions overlap each other, also increase DsOpt's First Dist and Dim Gap.

Cautions

Hatch Pattern: FDDS stops and displays a message if Hatch\acad.pat, in the folder RCWFolder opens, or required hatch patterns are missing. Import acad.pat in Rhino's Hatch settings.
Group Data: FDDS finds the Shape model on the Profiles layer, ProfileData, Fab No, DimBox/DimBox1, and cut face data from the selected group. Errors such as Group Model Error occurs or CutSurface Error may occur if FabNo has not been run or the group structure is broken.
Playback mode data: In Playback mode, if a matching Profile row exists, die-specific values in FDDS_Data.dat take priority over panel values. If unexpected Views or dimensions appear, check the FDstyle mode (Record/Playback) and the relevant die row first.
Distance Values: If Fab Start Point, Dwg Distance, or Fab No Distance values are too small, the original model, multiple Views, sections, text, and dimensions may overlap. For large frames, use more generous spacing than the defaults.
Hole Detection: Holes are identified from cylindrical Brep faces; only those with diameter ≥ Min Dia are marked. A Min Dia that is too small may capture unintended circular faces; too large may miss actual holes.
