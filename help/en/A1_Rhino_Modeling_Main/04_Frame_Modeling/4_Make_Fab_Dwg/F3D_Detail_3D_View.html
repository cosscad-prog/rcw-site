F3D  —  Detail 3D View

F3D

F3D lets you rotate and view a selected member (Brep) in a separate 3D viewport at any angle, then converts the on-screen view (perspective) to 2D lines with Hidden Line Removal, and inserts the result as a detailed close-up view into the fabrication drawing. Use this to show complex machining areas or bracket connection points in three dimensions.

Purpose

Provides 3D detail views of areas difficult to understand from 2D drawings alone, allowing fabricators to see the spatial relationship and machining details at a chosen angle. Once captured, the viewing direction and scale are saved and automatically reproduced when drawings are regenerated via FDDS/FDwg playback.

How to Use

  1. Type F3D in the Rhino command line.
  2. At the Select member for detail 3D view prompt, select the target Brep.
  3. A separate 3D preview viewport opens. Adjust the viewing angle:
    •   Right-click drag — Rotate (Orbit)
    •   Wheel — Zoom In/Out
    •   Left-click drag — Pan
  4. When the desired view is set, click [Confirm]. The on-screen view (perspective) converts to 2D lines with Hidden Line Removal.
  5. Click the insertion point in the drawing.
  6. Drag the mouse to set the scale (starting at 0.3×, shown as "x N.NN"), then click to confirm.

Example

Execution Flow

ItemDescription
Angle AdjustmentPerformed in a separate viewport with an embedded actual Rhino 3D viewport. Only the selected member is isolated and displayed.
2D ConversionCreates 2D lines with Hidden Line Removal (perspective projection) from the captured camera angle. Output is perspective, not orthographic — exactly as it appears on screen in 3D.
InsertionAfter clicking the insertion point, drag to set scale. A border box is drawn around the result.
Playback ReproductionCamera and scale information are saved and automatically reproduced at the same angle and scale in FDDS/FDwg during FDstyle Playback Mode.
Note: When F3D is used in Recording Mode, the detail view information is recorded and automatically redrawn during playback. (See FDstyle help for details.)
Caution: The member (Brep) and ProfileName data must be present. If ProfileName is not found, the command will stop. Output is always at model scale (1:1); zoom in/out in the 3D viewport is for viewing and angle adjustment only.

Related Commands
