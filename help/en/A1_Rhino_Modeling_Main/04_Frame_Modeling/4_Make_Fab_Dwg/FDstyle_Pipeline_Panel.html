FDstyle  —  Fabrication Drawing Record / Playback Panel

FDstyle

FDstyle opens and closes the FDwg Pipeline panel. In this panel, you can switch between Recording (ON) and Playback (OFF, default) modes for fabrication drawing (FDDS / FDwg) work, and manage drawing template registration/insertion and per-Profile progress tracking all in one place.

Note: Entering the same command again closes the panel (toggle). Recording/Playback mode switching is done via the banner button at the top of the panel, not via command. (Legacy commands FDP and FDwgStyle have been consolidated into FDstyle.)

Purpose

Frequently-used Profile drawing operations (options, NC table, compression, annotations, accessory table, detail views, templates) can be recorded once, then automatically reproduced when creating drawings for the same Profile in Playback mode. Use this to maintain consistent standard fabrication drawing templates across users and projects.

Panel Composition

ComponentDescription
Top Banner (Toggle)Displays the current mode and can be clicked to switch: ● Recording Mode ON (red) ↔ ■ Playback Mode (gray, default).
[Refresh]Re-reads and updates the per-Profile work status table.
[Form Template]Registers an external 3dm template file as a drawing template. (Same role as SFB)
[Insert Form]Inserts the registered template into the selected Profile's fabrication drawing (drawing unit). Scale is automatically calculated to fit the drawing size.
Status TableShows completion status for each step per Profile (see table below).
Work LogWork details and timestamps accumulate and are displayed at the bottom.

Record / Playback Mode

ModeBehavior
Record (ON)When FDwg / FDDS runs, the current options and additional work — NC table, FSC compression, annotations/leaders, accessory table, detail views (F3D), templates — are saved per Profile. Additional leaders, text, and label moves made during recording are also automatically recorded together.
Playback (OFF, default)When creating a drawing for the same Profile, reads and automatically reproduces the recorded content. If no recorded data exists, uses the current DdOpt panel settings.
Note: File data application is handled by this Playback Mode. If no recorded data exists, the current DdOpt panel values are used. Default values can be saved in advance using the Save Current Selection as Default feature in DdOpt.

Basic Usage

① Recording Standard Fabrication Drawings

  1. Type FDstyle to open the panel.
  2. Click the top banner to switch to Record Mode (ON).
  3. Adjust desired options in DdOpt, then create a drawing with FDwg.
  4. If needed, add NC table, accessory table, detail views, template insertion, and annotations. (Recording mode saves them together.)
  5. When done, click the banner again to end recording.

② Playback (Automatic Reproduction)

  1. Verify the banner is in Playback Mode (OFF) (default).
  2. Select a group for the same Profile and run FDwg.
  3. Recorded NC, compression, annotations, accessories, detail views, and templates are automatically reproduced.

Example

Template Registration / Insertion

ButtonAction
[Form Template]Select an external 3dm template file to register. Imported templates are hidden from view, and block names are automatically made unique if they conflict with existing templates to prevent mixing different templates.
[Insert Form]Inserts the registered template into the selected Profile's drawing (drawing unit). Scale is automatically calculated to fit the drawing size. (If inserted in Recording mode, template info is also recorded and reproduced in Playback.)
Note: Registered template information is saved with the current document (.3dm) and automatically restored even after closing and reopening the file. No need to register again in the same file. (See SFB help for details.)

Related Commands

CommandDescription

DdOptFabrication drawing Drawing Options panel. Used when Playback has no recorded data.

Caution: If you create a drawing for the same Profile again while in Recording mode, the existing record for that Profile will be replaced with the new work contents. Confirm before recording if preservation is needed.
