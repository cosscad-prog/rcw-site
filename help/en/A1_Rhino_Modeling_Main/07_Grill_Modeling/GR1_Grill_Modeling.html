GR1 ~ GR5  —  Grill Modeling

GR1GR2GR3 GR4GR5

Automatically creates grill frame and blade 3D solids based on the selected Brep face. GR1 ~ GR5 each correspond to grill types 1–5 pre-configured in the GrOpt panel.

Purpose

Used to quickly create grill (louver) frame and blade 3D solids for any number of specifications via type shortcuts (GR1-GR5). Enables fast placement of varied grill types across multiple faces based on settings configured in GrOpt.

How to Use

  1. Set the grill type and section data to apply in the GrOpt panel first.
  2. Type GR1 (or GR2–GR5) in the Rhino command line and press Enter.
  3. At the Select Grill Surface Object prompt, select the Brep face on which to create the grill.
  4. Press Enter to finish — frame and blade solids are created as a group based on the selected face.

Result

ItemDescription
Created ObjectsLeft / Right / Top / Bottom frame solids and internal Blade solids are created.
GroupThe created solids and GR number text are bundled into a single Rhino group.
DataGrill type data is stored in the group and used by GrNo, GrList, and GrTable.
Non-orthogonal FaceIf the four sides are not at 90°, a separate logic is used and a guidance message is shown in the command line.
