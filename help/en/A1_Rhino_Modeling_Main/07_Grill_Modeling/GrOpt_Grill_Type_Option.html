GrOpt  —  Grill Type Option Panel

GrOpt

Opens or closes the Grill Type Option Panel. If the panel is already open, running the command again closes it.

Purpose

Used to define and modify grill types (frame section, blade configuration, code, description) before grill modeling. Types 1-5 configured here serve as the basis for grill generation by GR1-GR5 commands, so type setup should precede grill modeling.

How to Use

  1. Type GrOpt in the Rhino command line and press Enter.
  2. The shared option panel for managing Glass / BackPanel / Vent / Grill types opens.
  3. Set the member section, blade conditions, code, and description for the Grill type.
  4. To close the panel, run GrOpt again or click the close button on the panel.

Example

Key Panel Settings

ItemDescription
Command TypeSpecifies the Grill type number to use for modeling among GR1 ~ GR5.
Frame SectionSpecifies the section group to use for the Left, Top, Right, and Bottom positions.
Blade SectionSpecifies the blade section group to be placed repeatedly inside the Grill.
Code / DescriptionEnter Code, Description, and Add1~Add3 information to be output in quantity lists and tables.
