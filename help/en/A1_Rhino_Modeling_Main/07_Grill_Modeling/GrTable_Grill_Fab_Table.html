GrTable  —  Grill Fabrication Drawing Table

GrTable

Analyzes selected grill group objects and automatically generates a fabrication drawing table within the Rhino drawing. Copies and places grill shapes per type, and outputs fabrication numbers and quantity information.

Purpose

Used to organize grill type shapes, fabrication numbers, and quantities into an on-drawing fabrication reference table. Supports production and ordering review by consolidating grill schedule information alongside shape copies.

How to Use

  1. Type GrTable in the Rhino command line and press Enter.
  2. Select the grill group objects to include in the table and press Enter.
  3. Once analysis is complete, click the table start position in the viewport.
  4. A per-grill-type fabrication drawing table is generated from the selected position.

Example

Table Cell Contents

Fabrication cells are created per grill type. The contents of each cell are as follows.

Cell ItemDescription
Type NameGrill type name. Displayed at the top of the cell alongside the fabrication number.
Fab_NoFabrication number. Displayed as [TypeName] [Prefix][Number].
QntQuantity for that fabrication number.
Grill ShapeA copy of the original grill shape is placed at the cell center in the fabrication table.

Layer and Behavior Notes

ItemDescription
Selection ModeOperates in GroupSelect mode — clicking a grill group selects the entire group.
Text LayerGenerated text is placed on the Text and Profile_No_Qnt layers.
Data ReferenceTallies per-type quantities based on group data and Fab No information saved by GrNo.
Shared Table LogicUses the shared Vent/Grill table logic to lay out elevation and profile machining information.
Construction PlaneThe active viewport's CPlane Y origin is automatically corrected to 0 on execution.

Related Commands

CommandDescription
GR1 ~ GR5Grill modeling — run first before generating the table.
GrNoGrill numbering — linked to the Fab_No in the table.
GrListGrill quantity list — use together with the table.
