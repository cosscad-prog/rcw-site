GrNo  —  Grill Numbering

GrNo

Analyzes grill groups created by GR1 ~ GR5 and automatically assigns grill fabrication numbers. Compares profile shapes to create internal Fab Nos, and saves a per-group fingerprint so identical shapes share the same numbering scheme.

Purpose

Used to automatically assign fabrication numbers (Fab No) to grill groups based on shape comparison (fingerprint). Identical shapes receive the same number scheme, serving as the reference basis for grill lists, fabrication tables, and drawings.

How to Use

  1. Grill groups must already be created with GR1 ~ GR5 commands.
  2. Type GrNo in the Rhino command line and press Enter.
  3. At the Select Grill Group objects prompt, select the grill groups to number.
  4. Enter the Fab prefix string — profile and grill group numbers are automatically calculated.

Example

Execution Steps

StepDescription
1/4Collects Brep profiles from the selected Grill groups.
2/4Compares profile shapes, assigns internal Fab Nos, and records them on the Fab_No_Text layer.
3/4Generates a Fab No fingerprint per grill group and saves it to group data.
4/4Assigns Grill numbers based on the fingerprint. Number prefix is G.
