GrMolist  —  Grill Material List

GrMolist

Tallies the individual profile members contained in the selected grill groups and generates a material list (Molist).
Frames and other models may be selected along with the grills — only the members belonging to a grill group are tallied, so you can select the whole model at once.
The table is written into the Rhino viewport and can optionally be saved as an Excel file.

Purpose

Ordering and fabricating a grill needs the cut lengths and quantities of the profiles that make it up, not the overall size of the grill. GrMolist opens the grill group and aggregates the profiles inside it by shape name and cut length.

Frames and grills normally share one document. GrMolist keeps only the members that belong to a grill group, whatever the selection contains, so there is no need to pick around the frame profiles — a window selection over the whole model still produces a grill-only list.

Difference from GrList and Molist

CommandUnit of aggregation
GrListOne row per grill group. A finished-product quantity list with grill width, height and code.
GrMolistOne row per profile member inside the grill groups. A material list with shape name, cut length, quantity and weight.
Only members belonging to a grill group are tallied.
MolistSame table format, but tallies everything selected. Select frames and grills together and they are mixed into one list.

In short, Molist lists "everything selected" while GrMolist lists "only the grills among what was selected". The same selection gives different results.

How to Use

  1. Type GrMolist in the Rhino command line and press Enter.
  2. Set whether to save an Excel file using the Excel_File_On option.
  3. Select the objects to tally. Group selection is enabled, so clicking one object selects the whole group.
    There is no need to isolate the grills. A window selection over the whole model, frames included, is fine.
  4. Press Enter to finish the selection.
  5. Objects that do not belong to a grill group are dropped automatically, and the number excluded is reported in the command line.
    [GrMolist] Excluded 99 objects that are not in a Grill group. Remaining — Breps: 34, …
  6. The material list is written as a text table on the current construction plane. If the option is On, you are prompted for a file name and an Excel file is also saved.

Example

Options

OptionDescription
Excel_File_On Off — Rhino viewport output only.
On — prompts for a file name in the command line and saves an Excel file.
The file is saved as [DocumentPath]-[EnteredName], next to the current .3dm file.

Accepted Selection — What Is Tallied and What Is Dropped

The selection is not tallied as-is. Each object is first tested for membership in a grill group.

ObjectHandling
Brep in a grill groupTallied — its profile data is read and grouped by shape name and cut length.
Brep outside a grill groupDropped — frame profiles and the like do not belong to a grill group, so they never reach the list.
Block (instance)A block whose description starts with NBlock: is treated as a named block. If it holds a grill, only that grill's members are tallied; frame profiles in the same block are dropped. A block with no grill in it is skipped entirely.

Grill groups placed in the document and grills held inside blocks can be selected together; both results are merged into a single list.

How grill membership is decided: from the group information that GR1 – GR5 modeling wrote onto the group. A group assembled by hand, or an object that never went through grill modeling, is therefore not recognized as a grill.
A grill inside a block is decided from information stored when the NBlock was built. An older block created before that information existed carries none, and its grills cannot be found — rebuild such a block.

An Alum.Total subtotal row follows the aluminum members, and a final row adds the total quantity and weight.

Caution: objects without profile data are not tallied. If the list comes out empty, read the command line message first.
  • No ProfileData was found — profile data is written by GrNo. Run GrNo first, then run this command again.
  • None of the selected objects belong to a Grill group — the selection contained no grills. Select again, including the grills.
If it is still empty, check that the section data was entered with Pname.
