GRV  —  Glass Transparency Toggle

GRV

Toggles all surfaces on Glass* layers between 80% transparency material and the original state. Running the command repeatedly alternates between transparent ON and OFF.

Purpose

Used to display glass surfaces as 80% semi-transparent so you can see the underlying structural members and bracing without the glass blocking the view. Repeating the command toggles transparency ON/OFF for easy review during modeling.

How to Use

  1. Type GRV in the Rhino command line and press Enter.
  2. All objects on Glass* layers switch to a semi-transparent material.
  3. Run GRV again to restore the original layer material.

Example

Toggle States

ON (Semi-transparent) 80% transparency material applied
Layer colour brightened for display
Switches to Rendered viewport mode
OFF (Original display) Restored to layer material
Display mode override removed
Object colour source restored to layer

Target Objects

ItemDescription
Target LayersAll layers whose names start with Glass (case-insensitive)
Transparency80% (MaterialTransparency = 0.8)
Display ModeRendered viewport mode override applied
Colour AdjustmentLayer colour blended with 50% white → displayed in a lighter tint

Related Commands

CommandDescription

Note: Execution is cancelled if the Rendered viewport mode cannot be found in the current environment.
