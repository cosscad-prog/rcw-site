GS1 ~ GS9  —  Glass Modeling

GS1GS2GS3 GS4GS5GS6 GS7GS8GS9

Select a curtainwall Brep face to automatically create a glass 3D solid.
GS1 ~ GS9 each correspond to glass types 1–9 pre-configured in the GsOpt panel.
▶ A Section must also be selected via SSP, and a [ G_Center1 ] layer line must exist within that Section. Command: [GC1]

Note: A Section must be selected by SSP, and that Section must contain a [ G_Center1 ] layer line.

Purpose

Used to quickly create 3D glass solids for the chosen glass type (1-9) configured in GsOpt on curtainwall faces. Type-specific shortcuts allow fast placement of multiple glass specifications. Requires Section selection via SSP and a G_Center1 reference line within that Section.

How to Use

  1. Set the glass type (thickness, specification, code, etc.) in the GsOpt panel first.
  2. Select the Section with SSP and confirm that a G_Center1 layer reference line exists inside the Section.
  3. Type GS1 (or GS2–GS9) in the Rhino command line and press Enter.
  4. Select the curtainwall Brep face (surface) on which to create glass.
  5. Optionally choose Distance or Section as the split method.
  6. Press Enter to finish — glass solids are created on the Glass layer.

Example

GS Number and Type Relationship

CommandDescription
GS1Creates glass solids using type 1 settings in the GsOpt panel.
GS2Creates glass solids using type 2 settings in the GsOpt panel.
GS3 ~ GS9Creates glass solids using types 3–9 settings in the GsOpt panel.

Prerequisites

ItemDescription
Input ObjectSelect the Glass Face created by the Gmd command.
Section SelectionThe relevant Section must be selected using SSP.
Reference LineA reference line on the G_Center1 layer must exist inside the selected Section.

Options

OptionDescription
DistanceSplits glass faces based on the distance between Mullions.
SectionSplits glass faces based on Section data.

Result

ItemDescription
LayerGlass solid objects are created on the Glass_XX layer.
ShapeA 3D solid extruded to the thickness set in GsOpt is created based on the selected Brep face.

Gmd vs GS1~GS9

CommandDescription
GS1~GS9Creates a glass solid (3D). A volumetric model with thickness.
GmdCreates a glass surface (2D). A lightweight face-based model.
