GFace  —  Glass Position Surface

GFace

For each bay of a wireframe unit, creates a face at the position where the glass actually sits, using the glass lines drawn in the sections.
G_Center1 line → Glass_XX1 face, G_Center2 line → Glass_XX2 face … G_Center5 line → Glass_XX5 face (up to five glass positions).

Purpose

Use it to prepare the front faces of the glass before running GS1 ~ GS9. GMD makes Glass_XX, the bay face on the wireframe plane (member center lines), which back panels, vents, grills and sheets use. The faces made by GFace match the size and depth position of the glass.

Workflow: WVector → SSP → GFace → GS1 ~ GS9 → GsNo → GsList → GsTable → GsFd
If a unit mixes glass bays with back panel or sheet bays, use both: GFace for the glass bays and GMD for the others.

Preparation

For how to draw the glass line, see Making Glass Section.

ItemDescription
G_Center1 line in the sectionIn every section (mullion or transom) that holds glass, draw a line on the G_Center1 layer and add it to the section group.
Line position = edge of the glass, start point = front face of the glass. The rule is the same as the S_Center1 line for sheets.
G_Center2 ~ G_Center5 lines in the sectionDraw them only in sections that have a second to fifth glass position (make the layers with GC2 ~ GC5). Without the line, no face of that number (Glass_XX2 ~ Glass_XX5) is made and nothing is reported.
Sections with glass on both sidesFor a middle mullion with glass on both sides, draw two lines, one for each bay. Do the same for a transom with glass above and below.
Section registrationAfter adding the lines, register the sections again with SSP. GFace reads the registered sections, so lines added after registration are used only after SSP is run again.
WireframeThe mullion and transom lines must be one group and WVector must have been run.

How to Use

  1. Type GFace in the Rhino command line and press Enter.
  2. Select the wireframe unit (mullion and transom lines) and press Enter.
  3. A face is created on the Glass_XX1 (and Glass_XX2 ~ Glass_XX5) layer in every bay whose sides all have a glass line on that bay side.
  4. Run GS1 ~ GS9 next and pick the faces.

Rules

ItemDescription
Glass bayThe sections on all sides of the bay must have a glass line on that bay side. If even one side is missing, no face is made.
Bays without linesTreated as back panel or sheet bays and skipped. At the end the count is reported ("M of N bay(s) got no glass face"). Use GMD to make Glass_XX for those bays.
Lines on some sides onlyNo face is made, and the sides missing the line are reported in the command line. Add the line to that section and run SSP again.
Sections not registeredNo face is made, and you are asked to run SSP first.
Running againA bay that already has a face at the same position (within 1 mm) on the same layer does not get a second one.
Glass_XXGFace does not leave Glass_XX. It is used briefly to find the bays and then deleted.
Making glass with GSPick Glass_XX1 ~ Glass_XX5 faces and the glass is made at that position; the used face is deleted. The thickness comes from the glass type in GsOpt.
If the Glass_XX of the same bay is picked too, it is skipped so the glass is not made twice.
ClearingGMDC deletes Glass_XX1 ~ Glass_XX5 faces together with Glass_XX.

Related Commands

CommandDescription
GS1 ~ GS9Glass modeling — pick the faces made by GFace to make the glass.
GMDBay surface — makes Glass_XX on the wireframe plane, for back panel, vent, grill and sheet bays.
ShFaceSheet bay surface — makes panel faces the same way in bays with an S_Center1 line.
SSPSection registration — run it after adding the glass lines.
GsOptGlass type options — sets the glass thickness and more.
GMDCClear glass surfaces — deletes Glass_XX and Glass_XX1 ~ Glass_XX5 faces.
