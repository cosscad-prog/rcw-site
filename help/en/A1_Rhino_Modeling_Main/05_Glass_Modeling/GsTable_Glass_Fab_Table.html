GsTable  —  Glass Fabrication Drawing Table

GsTable

Analyzes selected glass Solid objects and automatically generates a fabrication drawing table within the Rhino drawing. Copies and places the shape per glass type, and outputs fabrication number, quantity, and area information as text inside each cell.

Purpose

Used to organize glass type shapes, fabrication numbers, quantities, and areas into an on-drawing fabrication reference table. Supports production and ordering review by consolidating glass schedule information alongside shape copies.

How to Use

  1. Type GsTable in the Rhino command line and press Enter.
  2. Select the glass Solid objects to include in the table and press Enter.
  3. Once analysis is complete, click the table start position in the viewport.
  4. A per-glass-type fabrication drawing table is generated downward from the selected position.

Example

Table Cell Contents

One row is created per glass type. The contents of each cell are as follows.

Cell ItemDescription
Type Name (first cell)The representative glass type name. Displayed center-aligned on the far left of the row.
Fab_NoFabrication number. Displayed as [TypeName] [Prefix][Number].
QntQuantity for that fabrication number.
AreaArea (m²). Displayed to 2 decimal places.
Glass ShapeA copy of the original glass Solid is placed at the cell center based on the Front View plane.

Layer and Behavior Notes

ItemDescription
Text LayerGenerated text is placed on the Text layer.
Number/Qty LayerFab_No and quantity text are placed on the Profile_No_Qnt layer.
Construction PlaneOn execution, the active viewport's CPlane Y origin is automatically corrected to 0.
Table DirectionPer-type rows are placed in order downward (−Z) from the clicked position.
Cell SizeAutomatically calculated based on the maximum width and height among the selected glass objects.

Related Commands

CommandDescription
GmdGlass surface modeling — create glass surfaces before generating the table.
GsNoGlass numbering — linked to the Fab_No in the table.
GsListGlass quantity list — use together to generate quantity totals and drawings simultaneously.
Note: Selected objects must be in Brep (solid) form.
