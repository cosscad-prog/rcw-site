Gmd  —  Glass Surface Modeling

Gmd

Automatically creates glass surfaces based on the selected Brep (solid or surface) face. Surfaces are placed on the Glass layer using the glass type information set in the GsOpt panel.

Purpose

Used to automatically generate glass surfaces based on curtainwall faces. Applies glass type information configured in GsOpt to quickly populate the Glass layer, making this a key step in constructing the glass model.

How to Use

  1. First select the glass type to apply in the GsOpt panel.
  2. Type Gmd in the Rhino command line and press Enter.
  3. Select the Brep face (surface) on which to create glass.
  4. Optionally choose the split method: Distance (distance-based) or Section (section-based).
  5. Press Enter to run — surfaces are created on the Glass layer.

Example

Options

OptionDescription
DistanceSplits glass faces based on the distance between Mullions.
SectionSplits glass faces based on Section data.

Result

ItemDescription
LayerSurfaces are created on the Glass_XX layer. (XX = glass type number)
SurfaceSurfaces split to match Mullions are placed based on the selected Brep face.

Related Commands

CommandDescription
GsOptGlass Type Option Panel — set the glass type before running.
GMDCClear glass surfaces — deletes all Glass_XX layer surfaces.
GsNoGlass numbering — automatically places numbers on the created glass surfaces.
GRVGlass transparency toggle — toggles Glass layer objects to transparent.
