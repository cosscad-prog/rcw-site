GsNo  —  Glass Numbering

GsNo

Assigns fabrication numbers to the glass solids created by the GS1 ~ GS9 commands. Glass of the same shape gets the same number, and that number is the reference for the quantity list, the fabrication table and the fabrication drawings.

Purpose

Used to number glass solids so drawing annotation and quantity tallying share one reference. The text written on each glass changes to its number, so GsList, GsTable and GsFd carry the same numbering.

How to Use

  1. Glass solids must already be created with the GS1 ~ GS9 commands. (The glass faces made by Gmd alone cannot be numbered.)
  2. Type GsNo in the Rhino command line and press Enter.
  3. At the Select Solid objects prompt, select the glass solids to number and press Enter. Only closed polysurfaces can be selected.
  4. Enter the fabrication text to put in front of the number. You can also just press Enter.
  5. The text on each glass changes to its number.

Example

Result

Item Description
Number Position The text created together with the glass solid changes to the number.
Number Format Glass type name + fabrication text + sequential number.
Same Number Glass of the same type is compared by shape. If two pieces coincide after moving or rotating, they get the same number; if they coincide only after flipping (mirror images), they get different numbers.

Related Commands

Command Description
GS1 ~ GS9 Glass modeling — run first before numbering.
GsList Glass quantity list — linked to the numbers.
GRV Glass transparency toggle — makes glass transparent to easily verify number positions.
