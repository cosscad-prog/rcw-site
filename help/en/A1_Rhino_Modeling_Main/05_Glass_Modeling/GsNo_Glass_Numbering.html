GsNo  —  Glass Numbering

GsNo

Automatically places number text on glass surfaces created by the Gmd command. A sequential number is assigned at the center point of each glass face and used for drawing annotations and quantity tallying.

Purpose

Used to assign sequential numbers automatically to the glass faces created by Gmd, giving drawing annotation and quantity tallying a common reference. A number is written at the center of each glass face so the lists and the fabrication drawings carry the same numbering.

How to Use

  1. Glass surfaces must already be created with the Gmd command.
  2. Type GsNo in the Rhino command line and press Enter.
  3. Executes immediately without any selection.
  4. Number text is automatically placed at the center of each glass surface.

Example

Result

Item Description
Number Position Text is placed at the center point of each glass surface.
Number Format Auto-generated as glass type code + sequential number.
Layer Number text is placed on a dedicated number layer.

Related Commands

Command Description
Gmd Glass surface modeling — run first before numbering.
GMDC Clear glass surfaces — deletes all glass surfaces and numbers to restart.
GRV Glass transparency toggle — makes glass transparent to easily verify number positions.
