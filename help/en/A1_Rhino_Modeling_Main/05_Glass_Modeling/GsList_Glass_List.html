GsList  —  Glass Quantity List

GsList

Analyzes selected glass Solid objects and generates a glass quantity list. Outputs a text list to the Rhino viewport, and can optionally save as an Excel file (.xlsx).

Purpose

Used to tally glass component quantities for review. Displays a text summary on screen and can export to Excel for external ordering and consolidation workflows.

How to Use

  1. Type GsList in the Rhino command line and press Enter.
  2. Set whether to save an Excel file using the Excel_File_On option:
    • Off (default) — output to Rhino viewport only.
    • On — also save an Excel file in the same folder as the current document.
  3. Select the glass Solid objects (closed polysurfaces) to tally and press Enter.
  4. The quantity list is displayed on screen.

Example

Options

OptionDescription

A total quantity and total area (m²) row is automatically added at the end.
