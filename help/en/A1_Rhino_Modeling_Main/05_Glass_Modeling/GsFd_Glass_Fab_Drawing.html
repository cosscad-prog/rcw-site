GsFd  —  Generate Glass Fabrication Drawing

GsFd

Automatically generates a fabrication drawing from selected glass Solid objects. Automatically creates 2D lines and dimensions for the front, back, side, and top views. The original 3D glass objects are automatically deleted after the drawing is generated.

Purpose

Used to automatically generate 2D fabrication drawings (front, back, side, top views with dimensions) from glass components. Automates the drawing process for glass manufacturing, with the 3D objects automatically deleted after drawing generation.

How to Use

  1. Type GsFd in the Rhino command line and press Enter.
  2. Select the glass objects (Breps on the Glass layer) to generate drawings for, then press Enter. Group selection is supported.
  3. Drawings are generated automatically in sequence for the number of selected objects. The command line shows progress as N / Total Working on [TypeName Fab_No].
  4. The original 3D objects for which drawings are completed are automatically deleted.

Example

Generated Drawing Content

Drawing ElementGeneration ConditionDescription
Front ViewAlways generatedProjects the glass front surface to 2D and automatically writes width and height dimensions.
Back ViewAlways generatedProjects the glass back surface to 2D. Displayed with Hidden line type.
Side View (Right)Always generatedProjects the glass right side to 2D and writes thickness-direction dimensions.
Top ViewAlways generatedProjects the glass top face to 2D. Glass specification (thickness string) is also displayed.
DimensionsBased on current DimStyleAutomatically places width, height, and inclination dimensions on the front view based on current DimStyle settings.

Generated Layers

LayerContent
Glass_FabFabrication drawing 2D lines (white, Continuous line type)
DimsDimension lines (yellow)

Prerequisites

ConditionDescription
Target LayerOnly objects on layers whose names start with Glass are processed.
Object TypeMust be a Brep (solid) containing Glass data (UserData). If Glass data is missing, a ***** No Glass Data. message appears and that object is skipped.
Original DeletionObjects for which fabrication drawings are successfully generated are automatically deleted. Use Undo (Ctrl+Z) to revert.

Related Commands

CommandDescription
GmdGlass surface modeling — create glass surfaces before generating drawings.
GsNoGlass numbering — linked to the Fab_No in the drawing.
GsTableGlass fabrication drawing table — create per-type tables alongside the drawings.
GsListGlass quantity list — check quantities before generating drawings.
Caution: The original 3D glass objects are automatically deleted after drawing generation. Save or back up the file before running.
