BpTable  —  BackPanel Fabrication Drawing Table

BpTable

Analyzes selected BackPanel group objects and automatically generates a fabrication drawing table within the Rhino drawing. Copies and places BackPanel shapes per type, and outputs fabrication number, quantity, and area information as text inside each cell.

Purpose

Used to organize BackPanel type shapes, fabrication numbers, quantities, and areas into an on-drawing fabrication reference table. Supports production and ordering review by consolidating BackPanel schedule information (including area in m²) alongside shape copies.

How to Use

  1. Type BpTable in the Rhino command line and press Enter.
  2. Select the BackPanel group objects to include in the table and press Enter.
  3. Once analysis is complete, click the table start position in the viewport.
  4. A per-BackPanel-type fabrication drawing table is generated downward from the selected position.

Example

Table Cell Contents

One row is created per BackPanel type. The contents of each cell are as follows.

Cell ItemDescription
Type Name (first cell)BackPanel type representative name. Displayed center-aligned on the far left of the row.
Fab_NoFabrication number. Displayed as [TypeName] [Prefix][Number].
QntQuantity for that fabrication number.
AreaArea (m²). Displayed to 2 decimal places.
BackPanel ShapeA copy of the original BackPanel shape is placed at the cell center in the fabrication table.

Layer and Behavior Notes

ItemDescription
Text LayerGenerated text is placed on the Text layer.
Number/Qty LayerFab_No and quantity text are placed on the Profile_No_Qnt layer.
Group SelectionOperates in GroupSelect mode — clicking a group object selects the entire group.
Construction PlaneThe active viewport's CPlane Y origin is automatically corrected to 0 on execution.
Table DirectionPer-type rows are placed in order downward (−Z) from the clicked position.
Cell SizeAutomatically calculated based on the maximum width and height among the selected BackPanels.

Related Commands

CommandDescription
BP1 ~ BP5BackPanel modeling — run first before generating the table.
BpNoBackPanel numbering — linked to the Fab_No in the table.
BpListBackPanel quantity list — use together with the table.
BpFdBackPanel fabrication drawing — complete the fabrication drawing set together with the table.
