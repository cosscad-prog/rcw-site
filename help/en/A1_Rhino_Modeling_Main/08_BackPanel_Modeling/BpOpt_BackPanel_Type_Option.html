BpOpt  —  BackPanel Type Option Panel

BpOpt

Opens or closes the BackPanel Type Option Panel. The type information set in the panel is used for BP1 ~ BP9 modeling, numbering, lists, and fabrication drawing creation.

Purpose

Used to define and modify BackPanel types (thickness, offset distance, bend method, code, description) before BackPanel modeling. Types 1-9 configured here serve as the basis for BackPanel generation by BP1-BP9 commands, so type setup should precede modeling.

How to Use

  1. Type BpOpt in the Rhino command line and press Enter.
  2. The BackPanel Type Option Panel opens. Use the BackPanel tab of the shared Glass / BackPanel / Vent panel.
  3. Enter a new type or select an existing type to edit its values.
  4. Click Add List to add the type to the type list.
  5. If the settings will be reused, click Save to save to the data file.
  6. To close the panel, run BpOpt again or click the close button on the panel.

Example

Panel Layout

NoItemDescription
1 BackPanel Type List Displays registered BackPanel types in a table. Selecting an item fills the input fields below with that type's values.
2 Command Specifies the BackPanel command to use in actual modeling. Generally linked to BP1 ~ BP9 type commands.
3 Color Specifies the layer color for the BackPanel model.
4 Code Enter the code for each BackPanel type. Used as type identification in lists, tables, and drawing annotations.
5 Description Enter a description of the BackPanel specification. Used as human-readable specification info in fabrication lists and drawing annotations.
6 Dist from Glass Enter the distance the BackPanel is offset from the outer glass surface. Used to position the BackPanel relative to the glass reference plane during modeling.
7 Add 1 / Add 2 / Add 3 Enter user-defined supplementary information such as position, sequence, or project-specific classification.

Thickness and Type Settings

ItemDescription
Sheet Thk. Enter the BackPanel sheet thickness.
Panel Thk. Enter the thickness of the BackPanel outer sheet or the bend-shape reference thickness. When not using Type B All Outside, the flange length must equal the insulation thickness. For Type F it is the wall depth (from the back of the sheet to the front end of the walls).
Insulation Thk. Enter the internal insulation thickness of the BackPanel. The value includes the sheet thickness - the insulation itself is this value minus two sheet thicknesses (for Type C, the sheet thickness and the 2nd Thickness). For Type F it is also the depth from the front of the BackPanel to the back of the sheet.
Type A, B, D, E Types made by folding a single sheet. Choose one of the four.
Type A - all four sides return inward (Inside).
Type B - all four sides return outward (Outside).
Type D - the top and bottom sides return outward, the left and right sides return inward.
Type E - the top and bottom sides return inward, the left and right sides return outward.
Type F A type with a sheet only at the back (the room side) - Type A turned front to back. The sheet face lies on the back of the BackPanel (Dist from Glass + Insulation Thk. from the glass), and the walls on all four sides fold toward the glass by Panel Thk. (wall depth = Panel Thk., sheet included). There is no sheet in front.
Panel Thk. must be more than the sheet thickness and not more than Insulation Thk. Otherwise no panel is made and the command line says why.
Inside length - the wing folded back from the front end of the wall toward the middle of the panel. As in Type A, 0 means fold only with no wing (no wing either when it is twice the sheet thickness or less). Choosing Type F puts 0 here.
The insulation is the same as in Type A: it lies from Dist from Glass + sheet thickness to Dist from Glass + Insulation Thk. - sheet thickness (the open front is left empty by one sheet thickness), one sheet thickness in from the panel edge on all four sides (the inside of the walls). When Insulation Thk. is more than Panel Thk., it reaches in front of the walls at the same width. There are no outside wings and no screw holes.
The type list stores it with the Inside length only, such as F0 (Inside 0) or F15 (Inside 15).
Inside length / Outside length The return lengths for the inward and outward folds. Type A and F use Inside length, Type B uses Outside length, and Type D and E use both (the two fields are shared by Type A, B, D, E and F). The defaults are 15 for Inside and 10 for Outside.
Type C A type made of two sheets. The first sheet is folded backward from the glass side and the second sheet forward from the back, so the folds of the two sheets overlap.
Inter Distance - the fold depth of the first sheet.
Overlap Length - the length over which the two folds overlap.
2nd Thickness - the thickness of the second sheet.
Overlap Gap - the gap between the two overlapping folds. Left empty, it is 3.
Screw Holes With Make Screw Holes checked, screw holes are made in the outside wings of Type B, D and E (not in Type A, C or F).
Diameter - the hole diameter. Hole Dist - the distance from the fold line to the hole center.
Fr. Start, Pitch, Fr. End, Count - the values that place the holes along a side, by the same rule as the holes of the sheet command Sht. With a Pitch and Count 0, the space between the two end margins is divided evenly without exceeding the pitch.
The holes are drawn in the unfold of BpFd as well. A hole that falls where the wing is cut away is not made, and the number of holes made is reported.
Type picture The picture on the right follows the chosen type and whether holes are on. The middle is the front view, the bottom is the section of the left and right sides, and the right is the section of the top and bottom sides. A side folded inward shows as a dashed line in the front view; a side folded outward shows as a wing outside it. For Type F the sections show the sheet at the end away from the glass with the walls standing toward the glass; the dashed line is the front of the BackPanel.
A type saved as D or E produces a panel without wings in RCW 5.4.3 or earlier. Please keep the PCs that share a drawing on the same version.

Save and Apply

ActionDescription
Add List Adds the current input values to the BackPanel type list. A duplicate name may prompt an overwrite confirmation.
Save Writes the current type list to BackPanelType_Data.dat in the folder that RCWFolder opens. Save to file if the same settings need to be reused later.
Remove from list Select a row in the list and press the Del key (several selected rows are removed at once). Click Save to write the change to the file.
Apply to Modeling BP1 ~ BP9 commands read the per-type thickness, color, code, and description values stored in this panel to create BackPanel models.

Related Commands

CommandDescription

BpNoAssigns numbers to created BackPanels.
BpListGenerates a BackPanel quantity list.
BpTableGenerates a BackPanel fabrication drawing table.
BpFdGenerates BackPanel fabrication drawings.
Caution: If you only click Add List without clicking Save, the type data may not be retained in the next working session.
