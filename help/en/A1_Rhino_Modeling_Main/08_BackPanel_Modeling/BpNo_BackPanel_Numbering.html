BpNo  —  BackPanel Numbering

BpNo

Automatically places number text on BackPanel solids created by BP1 ~ BP5. A sequential number is assigned at the center point of each BackPanel and used for drawing annotations and quantity tallying.

Purpose

Used to automatically place sequential number text at the center of each BackPanel solid for identification and reference. Numbers are used in drawing annotations and quantity tallying, and follow the BackPanel type code + sequential number format.

How to Use

  1. BackPanel solids must already be created with BP1 ~ BP5 commands.
  2. Type BpNo in the Rhino command line and press Enter.
  3. Executes immediately without any selection — number text is automatically placed at the center of each BackPanel.
