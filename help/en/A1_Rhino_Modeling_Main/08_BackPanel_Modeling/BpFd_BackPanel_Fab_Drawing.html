BpFd  —  Generate BackPanel Fabrication Drawing

BpFd

Automatically generates a fabrication drawing from selected BackPanel Solid objects. Automatically creates 2D lines and dimensions for front, back, side, and top views. The original 3D BackPanel objects are automatically deleted after the drawing is generated.

Purpose

Used to convert 3D BackPanel solids into 2D fabrication drawings with multi-view layout (front, back, side, top). Supports optional features (side views, section marks, ISO/unroll views) for comprehensive fabrication documentation. Automatically deletes source 3D objects after drawing generation to avoid duplication.

How to Use

  1. Type BpFd in the Rhino command line and press Enter.
  2. Set the output options Side_FabDwg_On, SectionLine_Mark_On, ISO_Dwg_On, etc. from the command options.
  3. Select the BackPanel group objects to generate drawings for and press Enter.
  4. Drawings are generated automatically in sequence for the number of selected objects. The command line shows progress as N / Total Working on [TypeName Fab_No].
  5. The original 3D objects for which drawings are completed are automatically deleted.

Example

Options

OptionResult when On
Side_FabDwg_On Creates additional fabrication drawing Views in the left and right side directions.
SectionLine_Mark_On Displays section position marks and A/B section labels on the front view, and adds corresponding marks on the section view.
ISO_Dwg_On Creates an additional auxiliary 2D drawing of the BackPanel in the ISO direction and displays ISO Dwg text.
UnRoll_Dwg_On Creates an additional unrolled flat pattern (UnRoll Dwg) of the BackPanel and annotates the overall dimensions.

Generated Drawing Content

Drawing ElementGeneration ConditionDescription
Front / Back 2D Always generated Writes width and height dimensions based on the BackPanel front shape, and also shows the back-direction Hidden lines.
Top / Right Section Always generated Creates top and right sections and writes section dimensions. Section marks are shown according to the SectionLine_Mark_On option.
Side FabDwg Side_FabDwg_On = On Creates additional Views in the left and right side directions.
Section Mark SectionLine_Mark_On = On Displays section position marks and A/B labels on the front view, and adds corresponding marks on the section view.
ISO Dwg ISO_Dwg_On = On Creates an additional ISO-direction auxiliary 2D drawing and displays ISO Dwg text.
UnRoll Dwg UnRoll_Dwg_On = On Creates the BackPanel flat pattern and overall dimensions.

Generated Layers

LayerContent
BPanel_FabMain BackPanel fabrication drawing 2D lines (white, Continuous line type)
BPanel_Fab_HiddenBack-face and hidden line 2D lines (Hidden line type)
BPanel_Fab_InsulationLines for displaying insulation/internal composition
DIMSDimension lines
Section_MarkSection position marks and A/B labels when SectionLine_Mark_On is On
TextAuxiliary drawing title text such as ISO Dwg, Unroll Dwg, etc.
