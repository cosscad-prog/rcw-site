Block Data Input

Block Data is used when inserting a Block into a Surface or subtracting the Block's shape from it. The Block to use and its placement method are specified in the Block selection field of the Pname panel.

Purpose

Used to define in advance how Blocks will be placed or subtracted in the section (how, how many, and where). Once you set Block-1 through Block-4 in the Pname panel, components are automatically placed or holes are generated with consistent rules during modeling, automating component placement.

How to Use

  1. Prepare the Block to be inserted or subtracted.
  2. Place it at the Section position where it will be applied.
  3. In Pname, select the Block to use from Block-1 through Block-4.
  4. Enter the Insert Type, reference, position, spacing, and quantity.

Example

Options

ItemDescription
Insert BlockInserts the selected Block at the specified position.
SubtractCuts the Surface by the Block shape and removes the Block.
Subtract & InsertCuts the Surface and also places the Block.
Subtract & Block InsertPerforms subtract and insert, and also uses the Block's property data.
Insert Block With MainInserts so the Block is represented in the Main group when printing fabrication drawings.

Placement Reference

ItemDescription
By BrepCalculates Block position based on the selected Surface.
By LineCalculates Block position based on the Wire Frame.
Top/LeftEnter position, spacing, and quantity from the top or left reference.
Bottom/RightEnter position, spacing, and quantity from the bottom or right reference.
Interval / QuantitySpecifies the repeat interval and count based on the total length.
