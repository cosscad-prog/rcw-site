Pname / PPI  —  InPut Data

Pname PPI

Pname is the command for entering Surface, Polyline, and Block information into a Section Profile. Profile name, unit weight, additional length, purpose, and Block Data are all managed in a single panel.

Purpose

Used to input and edit properties required for modeling (profile name, unit weight, additional length, purpose, Block Data, etc.) for Section elements (Surface, Polyline, Block) in a single panel. The values entered here become the reference data for Unit modeling (UMD) and list/drawing creation, so organizing this information immediately after creating the section is a critical step.

How to Use

  1. Select the Section element to enter data for.
  2. Run the Pname or PPI command.
  3. Enter Surface, Polyline, and Block values appropriate to the element type.
  4. Verify that the entered values are reflected in the list and modeling result.

Composite profiles  —  Combined mode

Open a section tied with ComP — a polyamide thermal-break assembly, typically — and the window opens in composite mode. A member list appears beside the name field with the member count next to it. The first entry is the composite; the indented entries are its members.

ModeWhat it edits
Composite
(first entry)		Composite name, Description, Unit Weight, Color Code, Material ID, Alloy,
and the shared items — Profile ID, Fab ID, Group ID and the whole Additional Length box.
Member
(indented entry)		That member's own name, Description, Unit Weight, Color Code, Material ID, Alloy.
Shared items must be identical across every member, so they are locked in member mode and edited once in composite mode. The Additional Length box takes a shared data heading while a composite is open, which is how you can tell.
Leave the unit weight blank and the sum of the members is used, following them whenever they change. Type a value and that value wins.
Machining (Block, Milling) belongs to the composite as a whole and is stored on one member only, which is why both tabs are read-only in member mode.
If you copied a section group, run SSP first. The copy carries the same composite tag as the original, so Pname will not open it as a composite and says so instead.

Tying and releasing are done with ComP and XcomP; see the ComP / XcomP page for details.

Additional Length  —  bar length and end pieces

The Additional Length box at the bottom of the panel decides how far the profile bar runs past its center line, and how many pieces sit at that end. The two rows are the two ends of the bar.

RowWhich end
Top/LeftTop end for a mullion, left end for a transom.
Bot/RightBottom end for a mullion, right end for a transom.
FieldDescription
StartHow far the bar runs past that end (mm). The center line end is pushed out by this much. Formulas such as 100+5 are accepted.
Length0 makes one bar from end to end. With a value, only a piece of that length is made at that end, leaving the middle empty - for brackets, sleeves and anything that only sits at the ends.
IntervalSpacing (mm) when several pieces are placed. Several comma separated values such as D100,D200 are read against the dummy points.
QuantityHow many to place. Fill in either interval or quantity and the other follows.
SymmetricPlaces the same spacing from the opposite end as well.
Changed in 5.1.3 — the Mullion and Transom fields became one Start field.
A section is either a mullion or a transom, never both, so only one of the two was ever in use. One value now applies whichever way the section is used. Existing drawings open unchanged; saving such a section merges its two old values into one.
A polyline section whose Profile ID is 0. Not Select and whose Start is 0 at both ends gets a default additional length of 50mm.

Selecting a curve locks the Block Insert and Milling tabs

When a Polyline, PolyCurve or Line is selected, the Block Insert and Milling tabs on the right go grey and accept no input. Both tabs exist for section surfaces; values entered on a curve do nothing during modelling.

Why it is blocked — a stray value later stops SSP.
Once a curve carries block information, copying or moving that curve leaves the recorded Block ID pointing outside its own group, and SSP halts with "the block cannot be found". Polylines usually share the same name, so the warning alone makes it very hard to tell which one is at fault.
To clean a polyline that already carries such values: select the curve with Pname and press Save at the bottom of the dialog. Saving a curve clears all four block slots and all four milling slots, and the command line reports what was cleared. (DBB and SDBB handle surfaces only, so they cannot clear a curve.)
Everything else on a curve — profile name, unit weight, description, IDs and additional length — is still entered and saved as before. Only the two tabs are locked.

Milling tab  —  cutting the bar

Cuts slots or grooves into a profile bar. Use the Milling tab next to Block Insert in the right-hand column; a profile can hold four entries, Mill 1 through Mill 4.

It used to take a separate solid, built and then subtracted, to put in a slot or a groove. One polyline drawn on the section is now enough - UMD does the cutting.
The two tabs are laid out alike. Block Insert and Milling keep their fields in the same places, so nothing moves when you switch tabs, and both read spacing and quantity by the same rule.
To see which polyline an entry holds, click the Mill 1-Mill 4 name field. A numbered dot appears at the center of that polyline - one at a time. It clears itself when you Save or close the window.
  1. Draw the cut shape as a closed polyline on the same section plane as the profile.
  2. On the Milling tab press Mill 1 and pick that polyline.
  3. Fill in the values below and press Save.
  4. Run UMD — the bar is cut to that shape.
ItemDescription
Cut Type2. Subtract Only — cut only. 3. Subtract & Show — cut, then keep a copy of each cutter on the Subtract_Block layer so you can see where they landed.
LocationArray reference. 1. By Brep — the actual ends of the bar solid. 2. By Line — the ends of the center line. The two differ when a bar end is cut at an angle.
LengthLength of one cutter along the bar axis (mm). A polyline is a section and has no length of its own, so it is extruded by this amount. Each array point sits at the middle of that length.
Top/LeftHow far outside the bar end the cutter at that end sits (mm). That end is the top for a mullion, the left for a transom. 0 puts it flush with the end; a negative value pulls it inward (-50 sits 50 mm inside the end).
SpacingAn upper limit on the spacing (mm). One cutter goes at each end first, and the run between them is divided into the fewest steps that keep each step at or under this value. So the actual spacing is always at or below what you enter, and equals it exactly when it divides evenly. Nothing is left over at the end. Fill this in and the Quantity box below follows on its own.
0.5 · 1/4 · 1/6 · 1/8 are read as center / symmetric placement, the same convention as blocks (0.5 = one at the center, the others = a symmetric pair).
Bot/RightThe same for the far end, negative values included.
QuantityLeave Spacing empty and fill this in instead, and the run is divided into that many cutters with the spacing worked out for you (both ends included). When Spacing holds a value the count comes from that, so this box is ignored. In short, fill in either one and the other follows.
Interval and quantity
on the Top/Left row		A separate group counted from the starting end. Used only when Spacing is empty.
Interval and quantity
on the Bot/Right row		The same, counted from the far end.
Spacing wins. When the Spacing box holds a value, the interval and quantity boxes on the Top/Left and Bot/Right rows are ignored even if they hold numbers. The first box on each of those rows (the Top/Left and Bot/Right allowance) still applies and shifts the start and the far limit.
This works the same way as "Equal spacing" on the Block Insert tab. On a 1250 mm run, entering 100 takes 13 steps to stay at or under 100, so you get 14 cutters spaced 96.15 mm. On a 1200 mm run, 200 divides evenly in 6 steps, so you get 7 cutters spaced exactly 200 mm. Either way there is always one cutter at each end.
The cutting polyline must be closed and planar. If it is open or non-planar no cutter is built — a warning is logged and the slot is skipped. The same applies when Length is 0.
