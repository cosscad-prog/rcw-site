FabG / XFabG  —  Main-Sub Set

FabG XFabG

Ties the main profile you pick and the sub profiles you want shown with it on the fabrication drawing into one set inside a section group.

When to use it

Use it when you want the sub profiles to appear as parts of the main profile on the main profile's fabrication drawing. The sub profiles are listed by FabBomTable.

The first profile you pick is the main; every profile picked after that is a sub. Any block attached to the main or to a sub is included as well.

When a group holds two or more main-sub sets, tie them into sets so they do not mix. Without the set mark a sub is found by axis (center line) alone, and each main takes the other set's subs as well.

How to use

  1. Type FabG in the Rhino command line and press Enter.
  2. Click one main profile section. Only the section you click is picked, not the whole group.
  3. Click the sub sections that belong to that main one by one, then press Enter. Besides section surfaces you can also pick polylines (for example, the cutter polyline that makes a bracket).
  4. The command line reports how many were written and the sub names — counted by reading the tags back.
  5. Run UMD → FabNo → FabTable → FDwg again, and the output follows the sets.
The section geometry is not touched. FabG only writes a set mark onto the sections. After changing marks, run modelling again for them to take effect.

Example

What FabG also takes care of

ItemBehavior
Main Group IDIf the main's Group ID is not 1. Main-Group, it is set to 1, because the fabrication drawing uses that value to pick the center line and the drawing's primary part. The command line says so when it changes.
Composite profiles (ComP)If the main or a sub is a composite member, every member of that composite gets the same mark. Clicking one member is enough.
Adding subs laterIf the main already has a set, that set is reused. Run the command again on the same main to add subs.
Sections from another setThey move to this set. The command line reports how many moved.

What appears on the fabrication drawing

  • The main's drawing shows only the subs of its own set, with their names and fabrication numbers.
  • The accessory table (FabBomTable) counts only the subs of that set.
  • Blocks carried by a sub (such as stud bolts) that remain in the model as blocks are located on the main's drawing and counted. Blocks that are only shown and do not remain in the model do not appear on the drawing.

XFabG  —  releasing a set

Run XFabG, pick the sections (or polylines) to release and press Enter; the set mark is cleared. Section names and data stay as they are.

  • Pick one composite member and all members of that composite are released together.
  • If sections of the same set remain in the drawing, it reports how many mains and subs are left. A sub whose set has no main attaches to nothing. Release the whole set, or deal with its main as well.

Cautions

If even one picked object cannot be tagged, nothing is written — a half-made set would only surface on the drawing. These cannot be tagged: an object with no section data, a section with an empty name (run Pname first for both), and a multi-face section.
Each rejected object gets a red mark (TextDot) on the No_Data layer (No_Data, No_Name, Multi_Face, Not_Section); running FabG again removes them.
If the main is also picked as a sub, it is left out. A member of the main's own composite picked as a sub stays a main.
Check the result with FabGList. It draws the mains and subs of each set and flags problems such as a missing main or missing subs in red.
