PolyLine Data Input

Polyline Data specifies the shape and method for subtracting from a Surface. Used at Mullion-Transom intersections, and wherever holes or cuts are needed.

Purpose

Used to specify the shape and method for subtracting (cutting out) from a Surface. By placing a Polyline at locations where a portion of the section must be removed (Mullion-Transom intersections, hole machining, cutting sections) and specifying the Subtracter type, that shape is automatically removed from the section during modeling.

How to Use

  1. Draw the Polyline to serve as the subtract reference.
  2. Use the same layer as the Surface to be cut.
  3. Specify the Material_ID or Subtracter type for the Polyline in Pname.

Example

Options

ItemDescription
4. SubtracterThe standard subtracter used to cut out the Mullion or Transom Surface shape.
5. Inter-SubtracterUsed to subtract only the area where Mullion and Transom subtracters intersect.
6. Sub-SubtracterUsed to re-cut the Subtracter itself or to create a protected area.
7. Milling-SubtracterUsed to directly machine a Surface at a specified location.
8. Bracket-InterUsed when creating M-Bracket or T-Bracket.

Caution

A standard Subtracter only cuts Surfaces on the same layer as the Polyline. However, Layer 0 can be used to target Surfaces on all layers.
