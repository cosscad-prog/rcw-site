RCW Section  —  section data in the Properties panel

A page inside Rhino's Properties panel. It is a tab, not a command, so there is nothing to run.

Purpose

Selecting an object is enough to see which member it is. It works for a section surface and for a polyline inside a section group alike - pick a single line and it tells you which profile it belongs to. The values can also be edited here.

How to Use

  1. Open Rhino's Properties panel (Properties command if it is not open).
  2. Select a section surface, a solid, or a curve.
    If it sits in a group, Alt + click to take just one object out of it - an ordinary click grabs the whole group, and editing is then locked. (See the Alt + click section below.)
  3. The RCW Section tab comes up on its own - there is nothing to click, even if you were looking at another tab. (It does not open the Properties panel for you. If the panel is closed, nothing appears until you open it.)
  4. To change a value, type it and press Enter, or move to another field.

Example

What is on the page

GroupContents
ObjectThe same rows Rhino's own Object page shows - Type (read only), Name, Description, Layer, Display Color.
Section DataMaterial_ID, Profile_ID, Fab_ID, Group_ID, Alloy_ID, read as what they mean rather than the stored number (1. Mullion). The lists are the ones Pname uses.
Add LengthTwo groups, Top / Left and Bot / Right, each with Start, Length, Interval, Quantity and Symmetric - the same values as one Additional Length row in Pname.
More details...Opens the Pname panel (Profile Manager) on that object, for the values this page does not carry: unit weight, Block, Milling.

Worth knowing

ItemDescription
Selecting a polylineThe values are read from the section in its group. The grey line at the bottom says where they came from, and edits are written there.
Changing NameThe object name and the profile name (P_name) change together, after a confirmation. Drawings and BOM already produced keep the old name.
When no tab appearsIf what you picked carries no section data, the tab does not appear at all. This is what stopped an empty tab from showing on any curve or surface. If it is a section and the tab is still missing, check that a section sits in the same group.
Several objects selectedThe first one is shown and editing is off, so nothing is changed while it is unclear where it would land.
Clicking a group puts you straight into this state - take one object out of it with Alt + click, below, and editing comes back.
Changing an IDModels and drawings already made do not change. They need SSP to register again and UMD to run again - the same as editing in Pname.
UndoObject attributes (Layer, Display Color, Name) undo normally, but section data does not.
The page reads in English whatever the UI language is: the values it shows (1. Alum. Profile and the rest) are English lists, and a half translated screen reads worse than either.
The page itself works in Rhino 7 as well. The icon on the Profile Manager panel tab, however, only appears in Rhino 8.

Alt + click  —  reach one object inside a group

Hold Alt and click an object in a viewport: that single object is selected and the Properties panel opens. A group stays intact.

Why it is needed: clicking a group picks up every object in it, and with several objects selected there is no telling which section an edit would land on, so editing is locked. Alt+click picks exactly one, so you can edit straight away.
Rhino's own gestures are untouched. Shift+click (add), Ctrl+click (remove) and Ctrl+Shift+click (sub-object) all behave as before. This acts only on a left click with Alt alone. Alt+clicking empty space clears the selection, as Rhino always did.
The tab switches by itself. Pick anything that carries section data - by Alt+click or by an ordinary click - and the panel moves to the RCW Section tab, much as picking a text object brings up the Text page.
If you choose the Object tab by hand, that choice holds until you next select something, so reading a dimension and then changing a layer is not interrupted.
How it differs from Ctrl+Shift+click: Rhino's sub-object selection makes you choose between an edge and a face when you click a surface. Alt+click works on whole objects only, so that extra step is gone.
