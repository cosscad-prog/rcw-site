Arc0

An Arc editing auxiliary command that normalises selected Arc objects to a reference radius or reference shape.

How to Use

  1. Type Arc0 in the Rhino command line and press Enter.
  2. Select the Arc or related curve to edit.
  3. Verify the updated shape.
