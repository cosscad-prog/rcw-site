BC11 ~ BC44  —  Copy Block Data

BC11BC12BC13BC14 BC21BC22BC23BC24 BC31BC32BC33BC34 BC41BC42BC43BC44

A 4×4 set of commands that copies Block Data from one Block slot to another within a Section. The first digit is the source Block number and the second digit is the destination Block number.

Purpose

Quickly copies Block Data settings from one Block to another position within a Section. By using pre-defined command names (BC11–BC44), repeated Block configurations can be applied efficiently without manual data entry for each position.

Command Number Rules

ItemDescription
First DigitSource Block number. Example: BC31 uses Block-3 data as the source.
Second DigitDestination Block number. Example: BC31 copies data to the Block-1 slot.
FormatBC + SourceNo + DestNo. Source and destination numbers range from 1 to 4.

How to Use

  1. Identify the source and destination Block numbers.
  2. Enter the corresponding command in the Rhino command line. Example: to copy Block-2 data to Block-4, type BC24.
  3. Select the reference or Section objects as prompted.
  4. Verify that the data in the destination Block slot has been copied or updated.
