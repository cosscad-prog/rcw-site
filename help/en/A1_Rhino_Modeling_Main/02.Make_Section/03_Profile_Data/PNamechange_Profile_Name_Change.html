PNamechange  —  Profile Name Change

PNamechange

Replaces hyphens (-) in the Profile name (P_name) of selected Surfaces with underscores (_) and prints the change list to the Rhino command line.

Purpose

Hyphens (-) in Profile names can cause problems in file names and data processing, so this command unifies naming conventions by replacing them with underscores (_). It updates both the Surface's UserData and object names. Objects without Section Data display an N_Error indicator.

How to Use

  1. Type PNamechange in the Rhino command line and press Enter.
  2. Select the Profile or related objects to rename.
  3. Enter the new name.
  4. Confirm the before/after names shown in the command line.

Result

ItemDescription
Changed DataProfile names with hyphens are replaced with underscores; UserData and object names are both updated.
Output MessageThe before and after names are displayed in the Rhino command line.
