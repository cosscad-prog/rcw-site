FabGList  —  FabG Set Check List

FabGList

Collects only the sections and polylines that carry a FabG set mark from the selected objects (grouped or not) and draws one cell per set, showing the shapes and names of its main and subs. Sets that are tied wrongly are flagged in red text. Use it to check the sets you made with FabG.

How to use

  1. Type FabGList in the Rhino command line and press Enter.
  2. Select the sections and polylines to check and press Enter. Objects in a group are selected with their group, and objects outside any group can be picked one by one; preselection works too. Objects without a set mark are left out of the list.
  3. The command line prints a summary: sections selected, objects with a set mark, sets, and sets with problems, followed by one line per set with its contents and problems.
  4. Click the point where the list is drawn.
Cell shape and layout are the same as ComPlist. Sets with the same name stack down one column, and each cell is grouped.

Example

What each cell shows

LineContent
FabGThe large text at the top — the first eight characters of the set number (FabG : 8f6dd754), to tell sets apart when a group holds more than one.
Group NameThe name of that section group (the unit name), or (no group).
MainThe number of main parts and each part. A composite counts as one part however many members it has, and only its name is shown (- OBUK-0003_Com); an ordinary section shows name [Layer].
SubThe number of sub parts and each part: a composite on one line, an ordinary section as name [Layer], a polyline with (polyline).
ShapeThe set's main and subs drawn in their actual arrangement, in the lower part of the cell.

Red lines  —  what is wrong and how to fix it

Problems are written on the DiesText layer (red) as lines starting with !!.

Red lineMeaning and fix
No Main - the subs attach to nothingA sub attaches only to the main of its own set. Pick a main and run FabG again, or release the remaining subs with XFabG.
No SubThe set ties nothing. Add subs (run FabG again on the same main) or release it.
Tag without a role (M/S)The mark is neither main nor sub, so it is used for neither. Run FabG on that object again.
Main xN - a set has one MainThere are two or more main parts (a composite counts as one). Release the set and tie it again with a single main.
[name] Group_ID=… (not 1. Main-Group - no center line on the fab drawing)The drawing does not take the center line from that main. Set Group ID to 1. Main-Group in Pname, or run FabG again (it sets this for you).
Composite [name]: Main (or Sub) on M of N membersOnly some members carry the mark, so results can change from run to run. Run FabG again on that composite (it writes to every member).
Not selected: N more in this group
(cell without a group: … outside any group)		The cell sees only part of the set. Select the whole group (or, without a group, the rest of the set) and run it again.
Copied sections: N carry another section's composite tagAppears only in cells without a group: copies of composite sections are mixed into the set. Run ComP on them again.

Cautions

Only single-face sections and polylines are read. Modelled parts (solids) are not counted. Objects outside any group are listed too.
In a cell without a group, copies of non-composite sections cannot be told apart (they carry no copy mark). Two identical mains are caught by the "Main xN" red line, but a copied sub only shows up as a higher count.
The shapes in the cells are copies with the section data removed. If the command line reports that copies still carry section data, delete this list before running UMD or PFList.
