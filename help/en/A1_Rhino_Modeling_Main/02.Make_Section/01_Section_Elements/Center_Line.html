Center Line  —  Section Elements

CT1

Center Line is the reference line for a Section Profile. The program recognises a line on the Center1 layer as the centerline.

Purpose

Used to define the centerline that serves as the reference for the placement and direction of section elements (Surface, Block, PolyLine). Since the program recognizes a line on the Center1 layer as the centerline, aligning the start and end direction ensures that section elements are oriented correctly.

How to Use

  1. Draw the line to be used as the Section reference.
  2. Use the CT1 command or layer settings to place the line on the Center1 layer.
  3. Verify the start and end direction, then place the Section elements alongside it.
