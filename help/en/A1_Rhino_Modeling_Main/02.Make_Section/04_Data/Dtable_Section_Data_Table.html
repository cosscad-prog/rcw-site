Dtable  —  Section Information Table

Dtable

Opens a window that collects the section data of the selected Section Surfaces into one table so it can be reviewed and edited together. Instead of opening each profile separately with Pname, you can compare and edit the name, weight, IDs, additional lengths and extrusion values of several sections in one grid.

How to Use

  1. Type Dtable in the Rhino command line and press Enter.
  2. Select the Section Surfaces to review and press Enter.
  3. The Section_Information_Table window opens with one row per selected section.
  4. Edit the values directly in the grid. Clicking a row shows a preview of that section on the left.
  5. Save All writes the edited values back to each section and closes the window. Close closes without saving.

Example

Always-Visible Columns

ColumnDescription
Profile NameProfile name. Used as the shape name in drawings and lists.
DescriptionProfile description.
Unit WeightUnit weight per meter. Used to calculate weight in material lists.
Color CodeSurface color code.

Clicking the Profile Name header sorts the rows by name. Saving matches each row to its section through a hidden object identifier rather than the displayed row order, so sorting before saving does not mix up the values.

Collapsible Column Groups

Because the grid has many columns, the remaining fields are grouped behind three toggle buttons below the preview. Pressing a button expands (▼) or collapses (▶) that group.

GroupColumns
Profile IDs
(expanded by default)		Material ID, Profile ID, Fab ID, Group ID, Alloy — the classification IDs of the member.
Additional LengthAdd.Len Top, Add.Len Bottom, Add.Len Left, Add.Len Right — additional length per direction.
ExtrusionExt Length / Ext Interval / Ext Qty / Equal, in two sets marked (T/L) and (B/R) for the top-left and bottom-right extrusion data.

Result

ItemDescription
SavingSave All writes every row back to its section. Each section that actually changed is reported in the command line as Saved data for [profile name].
Dimension styleThe dimension style in use before the command is restored when the command ends, including when the window is closed without saving.
Model geometryUnchanged. Only the data stored on the sections is updated.

Related Commands

CommandDescription
PnameEnters and edits the profile data of a single section. Dtable handles the same data for several sections at once.
PDlistOutputs section data as a list.
PPlistOutputs the profile list.
SSPSelects an existing Section Profile group.
Caution: if the selected objects carry no section data, the command reports The selected objects have no SectionCustomData. and does not open the window. Enter the section data with Pname first.
Caution: if an invalid value is found while saving, the window stays open instead of closing. Correct the reported value and press Save All again.
