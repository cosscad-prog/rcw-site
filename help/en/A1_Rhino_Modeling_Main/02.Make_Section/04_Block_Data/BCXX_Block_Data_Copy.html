BCXX  —  Copy Block Data by Number Input

BCXX

Copies Block Data based on a source/destination number combination entered by the user.

Purpose

Allows users to manually enter source and destination Block numbers for copying, providing flexibility when block numbers exceed 4 or when combinations not available in fixed commands (BC11–BC44) are needed.

How to Use

  1. Type BCXX in the Rhino command line and press Enter.
  2. Enter the number combination as prompted by the command line.
  3. Select the reference object and verify the copy result.

Result

ItemDescription
InputThe user enters the source/destination number combination directly.
Error ConditionIf the number format is incorrect, a Number Error message may appear.
