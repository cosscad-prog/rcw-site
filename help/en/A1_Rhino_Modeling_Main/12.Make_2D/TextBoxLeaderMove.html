TextBoxLeaderMove  —  Move Text Box with Leader

TextBoxLeaderMove

Moves a Fablist TypeB label text box to a new position.
The box (border, text rows, separator lines) moves to the new location, and the leader end point (box side) is automatically updated.
The leader start point (member midpoint) remains fixed.

Purpose

Use this command when Fablist TypeB mini-table labels overlap or need repositioning. Moving the text box with the standard Move command leaves the leader disconnected, but TextBoxLeaderMove automatically recalculates the leader end point to match the new box position.

How to Use

  1. Type TextBoxLeaderMove and press Enter.
  2. At the Select FabList type_B group object prompt, click any object in the text box group (border line, text, separator line, or leader).
  3. An orange preview (box outline + leader) appears, anchored to the box center. Click the new position.
  4. The box and text move; the leader end point is automatically updated to the nearest edge of the new box.
  5. Continue selecting other boxes, or press Enter to exit.

Example

Any object in the group (border Polyline, row TextEntity, separator Line, or Leader) can be clicked — all behave identically.

How It Works

ItemDescription
Move base pointCenter of the current box bbox. The box center moves to the clicked point.
Objects movedBorder Polyline, row TextEntities, separator Lines — all translated by the same vector.
Leader end updateRecalculated as the nearest point on the moved box edge to the fixed member midpoint.
Leader start pointMember midpoint — never changes.

Note

Only works on objects created by Fablist TypeB.
TextBoxLeaderMove requires the FablistGroupKey tag that is set when Fablist TypeB generates the labels. It cannot be used on manually created boxes or leaders, or on labels from older versions.
