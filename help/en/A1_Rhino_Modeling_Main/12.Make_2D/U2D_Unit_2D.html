U2D  —  Unit 2D

U2D

U2D is an integrated 2D command that simultaneously generates Section 2D and a Fablist for the selected Solid Unit.
Points are placed at section positions to create Cross Lines — up to 2 points are supported.

Purpose

Used to generate comprehensive Unit documentation in one operation: section views with dimensions and fabrication list. Supports up to 2 section reference points for multi-directional section generation.

How to Use

  1. Type U2D in the Rhino command line and press Enter.
  2. At the Select objects for Make2D prompt, select the Unit objects.
  3. Press Enter — Top/Right Sections and dimensions are generated.
  4. A Fablist for the selected Unit is created at the same time.
