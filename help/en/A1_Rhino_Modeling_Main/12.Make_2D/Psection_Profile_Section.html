Psection  —  Profile Section

Psection

Psection creates a section aligned to the direction of the selected Profile. Used to inspect individual Profile sections within a Unit.
      1. Profile Visual Lines are generated.
      2. Glass Lines and BackPanel are omitted so Profile lines are clearly visible.

Purpose

Used to inspect individual Profile sections aligned to the Profile's direction within a Unit. Generates clean section views focused on frame structure by omitting glass and back panel.

How to Use

  1. Type Psection in the Rhino command line and press Enter.
  2. Select the Profile or related 3D objects to section.
  3. Specify the section reference position.
  4. Verify the generated section curves.

Related Commands

Usection is used for section generation in each Profile direction within a Unit; S2d generates Unit-based Section 2D.
