S2d, Sec2d  —  Section 2D

S2d Sec2d

S2d and Sec2d generate Top/Right Sections and dimensions based on the View angle of the selected Solid Unit.
Uses the completed Solid Model to create 2D Sections:
      1. Profile Visual Lines and Block Lines are generated.
      2. If Glass or BackPanel exist, they are included.
      3. Dimensions are annotated along Center Lines (follows the current DimStyle).
      ▶ A line must exist at the section position.

Purpose

Used to generate section views (Top/Right) with automatic dimensioning for the completed Solid Unit. Includes all components (Profile, Block, Glass, BackPanel) and creates reference sections for fabrication documentation.

How to Use

  1. Type S2d or Sec2d in the Rhino command line and press Enter.
  2. At the Select objects for Make2D prompt, select the target 3D objects.
  3. Select the section reference line if required.
  4. Verify the generated Section curves and dimensions.

Example

Caution: Because the Section is created based on the selected Unit's View angle, models with complex orientations may not produce an accurate Section.
