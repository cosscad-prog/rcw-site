Flist, Fablist  —  Fabrication List

Flist Fablist

Flist and Fablist are identical commands that run the same function. They analyze selected Breps, standard Blocks, and NBlocks to create a per-Unit fabrication list with number annotations.
      1. Profile numbers are placed on the elevation.
      2. FabList is sorted in order: Aluminium Profile, Steel Profile, Accessory Profile, Block.
      3. Text size follows the current DimStyle.

Purpose

Used to write the fabrication list of the selected Unit together with the numbers shown on the elevation. Use it when you need a fabrication list sorted in the order aluminum Profile, steel Profile, accessory Profile, Block. It is the same command as Flist.

How to Use

  1. Type Flist or Fablist in the Rhino command line.
  2. Toggle the SubMaterial_No option On/Off if needed.
  3. Use the LabelType option to select the elevation number display method — TypeA (circle + number) or TypeB (mini table per line).
  4. Use LabelFontScale to adjust the label font size scale if needed (default 2.5).
  5. Set SaveAsDefault to On to save the current LabelType and LabelFontScale as defaults for future use.
  6. At the Select Brep, Block, NBlock objects for Fablist prompt, select the target objects.
  7. Press Enter — the selected objects are analyzed and the fabrication list is created.

Example

Options

OptionDescription
SubMaterial_NoWhen On, also generates accessory (Profile_ID 3) number annotations.
LabelTypeElevation number display method. TypeA = circle + number (default), TypeB = mini table per line.
LabelFontScaleLabel font size scale. Display size = FontHeight × this value × DimensionScale (default 2.5).
SaveAsDefaultWhen set to On, saves the current LabelType and LabelFontScale as defaults (System_Default.dat).

Label Display Method (TypeA / TypeB)

The overall fabrication list table is generated identically for both methods; only the labels displayed on the elevation differ.

MethodDescription
TypeAEach solid is marked with a circle + number connected by a leader. Corresponds 1:1 with the table NO.
TypeBSolids belonging to the same centerline (member) are grouped into a mini table showing ProfileName Fab# - Quantity per line, connected to the member's mid-point with a leader.
Users may prefer different methods. Run once with SaveAsDefault=On to have the saved method and font size automatically applied on subsequent FabList runs (saved per PC).

Output Content

ItemDescription
Unit NoUnit number read from the selected group. A warning is output if missing or multiple exist.
Fab NumbersReads data per object type (Frame, Glass, BackPanel, etc.) and places number annotations.
ListBuilds the fabrication list based on ProfileName, FabStr, Spec, Code, Add data, etc.
