MVOption  —  Model View Option

MVOption

MVOption is a global toggle command for controlling whether Mullion/Transom modeling results and subtract shapes are displayed in the viewport during modeling.

Purpose

Used to globally control the visibility of Mullion and Transom modeling results and their subtraction/machining verification shapes. Enables toggling display of results and verification shapes to optimize viewport clarity during modeling workflow.

How to Use

  1. Type MVOption in the Rhino command line and press Enter.
  2. Toggle the required items On/Off in the command options.
  3. Press Enter to exit — subsequent modeling routines will use those display settings.

Options

OptionResult when On
Mul_View_OnDisplays Mullion modeling results.
Mul_subtract_View_OnDisplays Mullion subtraction/machining verification shapes.
Trn_View_OnDisplays Transom modeling results.
Trn_subtract_View_OnDisplays Transom subtraction/machining verification shapes.

Related Commands

Used together with UMD to adjust display results before running the modeling command.
