DataView  —  Modeling Data Display Option

DataView

DataView is an auxiliary command for toggling the display of Mullion/Transom modeling data verification markers on or off.

Purpose

Used to turn on/off internal data verification display for Mullion/Transom models. Enables inspection of modeling results for correctness and cleanup of cluttered displays when verification is complete.

How to Use

  1. Type DataView in the Rhino command line and press Enter.
  2. Change the Mul_data_View and Trn_data_View options to the required state.
  3. Verify the data display status in the modeling result.

Options

OptionResult when On
Mul_data_ViewEnables Mullion-related data verification display.
Trn_data_ViewEnables Transom-related data verification display.

Related Commands

Used together with MVOption and StepView for modeling debug/review purposes.
