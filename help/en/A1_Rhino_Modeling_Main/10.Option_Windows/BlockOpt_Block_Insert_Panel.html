BlockOpt  —  Block Insert Panel

BlockOpt

BlockOpt reads .3dm Block files from the Blocks folder inside the folder RCWFolder opens, displays a list and preview in a dedicated panel, and inserts the selected Block into the current Rhino viewport.

Purpose

BlockOpt reads the .3dm Block files kept in Blocks, inside the folder that RCWFolder opens, shows them as a list with a preview in its own panel, and inserts the selected Block into the current Rhino viewport.

How to Use

  1. Run RCWFolder to open the folder and put the .3dm files holding your Blocks into Blocks.
  2. Type BlockOpt in the Rhino command line and press Enter.
  3. Select the file name and Block name in the left TreeView.
  4. Verify the shape in the right preview. Right-drag to orbit; double-click to reset the view.
  5. Click Insert, then specify the insertion position in the Rhino viewport.

Example

Panel Layout

ItemDescription

Panel Layout

ItemDescription
TreeViewShows Block names per .3dm file.
PreviewShows the Brep, Mesh, Surface and Curve shapes of the selected Block as a simple Shaded Wire view.
RefreshRe-reads the Block folder to update the list.
InsertAdds the Block definition to the current document and inserts an instance at the specified position.

Key Details

ItemDescription
BehaviorRunning the command opens the Block Insert Panel; if it is already open, the panel is closed.
Caution: If the Blocks folder is empty or its files hold no Block Definitions, the list may be empty.
