StractH  —  Horizontal Sheet Extract

StractH

StractH extracts Sheet/Panel models based on the horizontal direction.

Purpose

Used to explicitly extract sheet/panel data along the horizontal axis. Complements StractV for vertical extraction; use when direction control is required.

How to Use

  1. Prepare the model to extract in the horizontal direction.
  2. Type StractH in the Rhino command line and press Enter.
  3. Select the target objects as prompted.
  4. Verify that the extraction result is generated in the expected direction.

Related Commands

Stract currently runs the same horizontal extraction routine; StractV runs the vertical extraction routine.
