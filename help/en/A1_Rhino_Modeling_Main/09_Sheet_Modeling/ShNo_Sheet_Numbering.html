ShNo  —  Sheet Numbering

ShNo

Numbers the sheets made by Sht (SH-001, SH-002, …). Identical sheets get the same number, and the number is shown as text on each sheet.

Purpose

Use it to group identical sheets under one number for counting, and as the basis of the quantity list (ShList) and the fabrication drawings (ShTable, ShFd).

Workflow: WVector → SSP → ShMD → Sht → ShNo → ShList → ShTable → ShFd
The sheet commands rely on the S_Center1 line drawn in each section, on registered sections (SSP), and on a wireframe with direction data (WVector).

How to Use

  1. Type ShNo in the Rhino command line and press Enter.
  2. Select the sheets to number and press Enter. Press Enter without selecting anything to number every sheet in the document.
  3. A number is recorded on each sheet and the number text is placed at the middle of the panel face.

Example

What Makes Sheets Identical

Two sheets get the same number only when all of the following match. If any one differs, the numbers differ.

ItemDescription
ThicknessSheet thickness.
Edge typeFlat, Fold, Inside, or Outside, and the return length.
Fold depthDepth of the top, bottom, left, and right sides.
Shape of the panel faceWidth, height, and corner positions. Mirrored trapezoids get different numbers.
Holes in the returnDiameter, position, spacing, and count.
Attached profileProfile type, sides, placement (mitred, square, pieces) with the piece layout, and screw holes.

Rules

ItemDescription
OrderNumbers are assigned by thickness, then width, then height, smallest first.
FormatContinuous from SH-001. The sequence continues across thicknesses.
Number textPlaced on the Sheet_No layer and added to the group of the sheet.
Running againAfter adding or deleting sheets, run the command again to renumber. Existing number text is updated.
Table copiesCopies placed in the drawing by ShTable are not counted as sheets.

Related Commands

CommandDescription
ShtSheet modeling — run it before numbering.

ShTableSheet fabrication table — lays out one sheet per number in the drawing.
