Sht  —  Sheet Modeling

Sht

Pick panel faces (Sheet_XX or Glass_XX) and create folded sheet panels. Set the thickness, fold depth, and edge type (flat, fold, inside return, outside return), and optionally attach a profile or make screw holes on the back of the panel.

Purpose

Use it to model metal sheet panels (back pans, spandrel panels, and so on) that sit in a glass position. Size and fabrication data are recorded on each sheet, and numbering (ShNo), the quantity list (ShList), and the fabrication drawing (ShFd) are produced from those records.

Workflow: WVector → SSP → ShMD → Sht → ShNo → ShList → ShTable → ShFd
The sheet commands rely on the S_Center1 line drawn in each section, on registered sections (SSP), and on a wireframe with direction data (WVector).

How to Use

  1. Type Sht in the Rhino command line and press Enter.
  2. Select one or more panel faces (Sheet_XX, Glass_XX) and press Enter.
  3. Set the thickness, depth, edge type, and attached profile in the option window. You can still navigate the Rhino view and measure while the window is open.
  4. Click OK to create the sheets. Closing the window or clicking Cancel changes nothing.

Layout Rule (Pieces and Holes)

The start side (Fr. Start) is the left end of a horizontal side (top, bottom) and the top end of a vertical side (left, right), seen from outside the panel.

Edge Types

The figures below are section sketches of each edge type. To make the shape readable, the thickness is exaggerated and the width shortened (not to scale). The bottom is the visible face of the sheet.

A profile is attached only to sides that are folded once (Fold) or Flat. On sides with a return (Inside or Outside) the Attach Side box is disabled. Example: with Left and Top set to Fold and Right and Bottom set to Outside, the profile goes on the left and top sides and the screw holes are made in the returns of the right and bottom sides.
The wings of an outside return end square at the corners; the wings of an inside return meet at 45° in the corners. A corner where two different edge types meet is cut square. When a neighboring side has an inside return and the profile reaches the same depth as that return, a full-length profile is cut at the free end of the return (it becomes that much shorter, and the command line reports it). Pieces are not moved; if a piece runs into the return, the command line only shows a warning.
Sheets whose edge types or return lengths differ per side get different numbers from ShNo; the Edge column of ShList lists every side, for example T:Fold B:Out L:Fold R:Out, and the Return column reads like T:17 R:20. The sections, the unfold drawing, and the hole dimensions of ShFd follow the edge type of each side.

To give the options in the command line, use -Sht (for example Thickness, Depth, Edge, ProfileNo, Ends, Pieces, Holes). Per-side values use options named with Top, Bottom, Left, or Right at the end (for example EdgeTop, WingRight, HCountLeft).
