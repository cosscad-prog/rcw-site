Sht  —  Sheet Modeling

Sht

Pick panel faces (Sheet_XX or Glass_XX) and create folded sheet panels. Set the thickness, fold depth, and edge type (flat, fold, inside return, outside return), and optionally attach a profile or make screw holes on the back of the panel.

Purpose

Use it to model metal sheet panels (back pans, spandrel panels, and so on) that sit in a glass position. Size and fabrication data are recorded on each sheet, and numbering (ShNo), the quantity list (ShList), and the fabrication drawing (ShFd) are produced from those records.

Workflow: WVector → SSP → ShMD → Sht → ShNo → ShList → ShTable → ShFd
The sheet commands rely on the S_Center1 line drawn in each section, on registered sections (SSP), and on a wireframe with direction data (WVector).

How to Use

  1. Type Sht in the Rhino command line and press Enter.
  2. Select one or more panel faces (Sheet_XX, Glass_XX) and press Enter.
  3. Set the thickness, depth, edge type, and attached profile in the option window. You can still navigate the Rhino view and measure while the window is open.
  4. Click OK to create the sheets. Closing the window or clicking Cancel changes nothing.

Option Window

AreaItemDescription
ProfileList and previewChoose the profile to attach. (none) attaches nothing. The preview shows the section of the sheet and the profile.
SheetThicknessSheet thickness in mm. Enter the value you need, such as 1.2, 2, 3, or 4.
SheetDepthFold depth (outer dimension). From surface uses the length of the S_Center1 line of each side. Enter values lets you type Top, Bottom, Left, and Right.
SheetEdgeEdge type. Flat = flat plate with no fold, Fold = single fold, Inside = fold and return inward, Outside = fold and return outward.
SheetReturn lengthLength of the return (outer dimension, thickness included). Used with Inside and Outside.
SheetHole DistDistance of the screw holes from the free end of the outside return. Used with Outside only.
Attach profileSidesSides that receive a profile (Top, Bottom, Left, Right). All selects all four.
Attach profilePlacementFull length, mitred corners = full-length bars that meet at 45° in the corners.
Full length, square ends = full-length bars cut square at both ends. The vertical bars (left, right) run through and the horizontal bars (top, bottom) fit between them.
Pieces = several short pieces.
PiecesLength, Top, Pitch, Bottom, CountPiece length and layout. A margin (Top, Bottom, Left, Right) is measured from the corner to the end of the piece; Pitch is measured between piece centers.
With Pitch greater than 0, Count pieces are placed from Top (or Left) at that pitch. With Pitch 0, Count pieces are spread evenly between the two margins.
Screw holesMake screw holesMakes screw holes in the profile. With an outside return, the holes are made in the return.
Screw holesDiameter, Margin, Count / PitchHole diameter, margin from the end, and either the number of holes (Count) or the spacing (Pitch).

Edge Types

The figures below are section sketches of each edge type. To make the shape readable, the thickness is exaggerated and the width shortened (not to scale). The bottom is the visible face of the sheet.

With a return (Inside or Outside) no profile is attached. The wings of an outside return end square at the corners; the wings of an inside return meet at 45° in the corners.

Attached Profile

ItemDescription
Profile libraryRead from the 3dm files in %LOCALAPPDATA%\RCW_V5\5.0\Templates\SheetProfiles. One group in a file is one profile. Edit and save the file and the list is updated the next time the command runs.
Screw hole positionA line drawn on the Hole (or Hole_Center) layer inside the library group is the axis of the hole.
Attaching to a flat plateA profile can be attached to a Flat sheet as well. The position is the same as on a folded sheet (one thickness in from the edge).
LengthThe length of a bar is recorded as its longest side (a bar cut at 45° is longer on the outside).

Result

ItemDescription
SheetClosed solid on the Sheet_<thickness>T layer (for example, Sheet_3T).
Profile barsOn the Sheet_<thickness>T_Profile layer, in the same group as the sheet.
Panel faceThe selected Sheet_XX face is replaced by the sheet and does not remain.
UndoA single Undo restores the state before the sheets were made.
To give the options in the command line, use -Sht (for example Thickness, Depth, Edge, ProfileNo, Ends, Pieces, Holes).
