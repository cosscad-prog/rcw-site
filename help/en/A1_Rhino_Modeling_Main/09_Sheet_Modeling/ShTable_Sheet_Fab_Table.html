ShTable  —  Sheet Fabrication Table

ShTable

Lays out one representative sheet per number as a table on the drawing plane. One row is made per thickness and one cell per number, and a copy of the sheet (with its attached profiles) is placed face-on in the cell. The table is the base for the fabrication drawing (ShFd).

Purpose

Use it to prepare the area where the sheet fabrication drawings are drawn. It works by the same rules as BpTable.

Workflow: WVector → SSP → ShMD → Sht → ShNo → ShList → ShTable → ShFd
The sheet commands rely on the S_Center1 line drawn in each section, on registered sections (SSP), and on a wireframe with direction data (WVector).

How to Use

  1. Number the sheets with ShNo first.
  2. Type ShTable in the Rhino command line and press Enter.
  3. Select the sheets to include and press Enter. Press Enter without selecting anything to include every sheet in the document.
  4. Click the top-left corner of the table on screen. The table grows to the right and downward from that point.
  5. Run ShFd next to draw the fabrication drawing in each cell.

Example

Table Layout

ItemDescription
RowOne row per thickness. The first cell shows the thickness, such as Sheet 3T.
CellOne cell per number. The top-left shows the number, quantity (Qnt-), size, thickness, edge type, and area.
Representative sheetOne sheet of that number and its attached profiles are copied and laid face-on. The front face lies on the drawing plane.
Cell sizeSix times the largest width and height among the selected sheets, leaving room for the views of the fabrication drawing.
LayersCell text is placed on the Text and Profile_No_Qnt layers.
The copies in the table are not counted as sheets of the document. Running ShNo or ShList again does not increase the quantities.

Related Commands

CommandDescription
ShNoSheet numbering — run it before making the table.
ShFdSheet fabrication drawing — drawn around each representative sheet of the table.
BpTableBackPanel fabrication table — the same rules.
