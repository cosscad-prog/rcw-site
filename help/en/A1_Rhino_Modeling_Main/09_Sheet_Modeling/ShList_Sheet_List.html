ShList  —  Sheet Quantity List

ShList

Collects the numbered sheets by number and creates a quantity list. Below the sheet table, the attached profiles are listed by name and length. The table is drawn on screen and can also be saved as an Excel file.

Purpose

Use it to prepare order and production quantities for the sheets and the attached profiles. The table follows the same column order as BpList and GsList.

Workflow: WVector → SSP → ShMD → Sht → ShNo → ShList → ShTable → ShFd
The sheet commands rely on the S_Center1 line drawn in each section, on registered sections (SSP), and on a wireframe with direction data (WVector).

How to Use

  1. Number the sheets with ShNo first.
  2. Type ShList in the Rhino command line and press Enter.
  3. If you need an Excel file, set the Excel_File_On option to On in the command line.
  4. Select the sheets to list and press Enter. Press Enter without selecting anything to list every sheet in the document.
  5. Click the position of the table on screen.

Example

Sheet Table Columns

ColumnDescription
NORow number.
Unit_No, CodeKept so the columns line up with the other quantity lists. Sheets have no such record, so the cells show -.
Fab_NoSheet number (for example, SH-003).
QuantityNumber of sheets with that number.
Width, HeightWidth and height of the panel face (mm).
AreaWidth × height × quantity (m²). Folded parts are not included. The total row shows the overall area.
ThicknessSheet thickness (mm).
EdgeEdge type (Flat, Fold, Inside, Outside).
Depth T/B/L/RFold depth of the top, bottom, left, and right sides.
Return, HolesReturn length and the number of holes in the return.
ProfileName of the attached profile.

Profile Table Columns

ColumnDescription
Profile, MaterialProfile name and material number.
QuantityNumber of bars with the same name, length, and hole count (total over the selected sheets).
LengthBar length (mm), measured on the longest side — for a bar cut at 45° this is the outer length.
HolesNumber of screw holes in one bar.
Sheets without a number are left out, and the number left out is reported in the command line. The Excel file is written to the folder of the saved document, so save the document first.
