DWVector  —  Delete Wire Vector

DWVector

Deletes Wire Vector Dot/Text markers created by WVector.

How to Use

  1. Type DWVector in the Rhino command line and press Enter.
  2. Select the Wire Vector markers or related objects to delete.
  3. Confirm that the markers have been removed.
