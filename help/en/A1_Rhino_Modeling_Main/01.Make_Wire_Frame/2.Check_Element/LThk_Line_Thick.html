LThk  —  Thick Wireframe Lines

LThk

Gives the layers whose names start with M_ or T_ (M_Center, T_Center and so on) the Thick linetype (continuous, 3 px), so the wireframe lines show thick. Run it again to put the original linetypes back.

It is off at first. In a document where LThk is on, MC, MCL, TC and TCL also make the M_Center and T_Center layers they use thick. Turn it off and MC and TC stop doing so.

How to Use

  1. Run LThk. There is nothing to pick - every M_ and T_ layer in the document becomes thick.
  2. The command line shows how many layers changed.
  3. To go back, run LThk again. Each layer returns to the linetype it had before.

On and Off

ItemDescription
When it counts as onOn when at least one M_ or T_ layer uses the Thick linetype. New documents and documents made before are off.
LThk while offGives every M_ and T_ layer the Thick linetype, noting each layer's previous linetype on the layer. Creates the "Thick" linetype if it is missing, or resets it to continuous, 3 px.
LThk while onPuts the Thick layers back to the noted linetype. A layer with nothing noted (one MC or TC made thick from the start while it was on) goes to Continuous.
MC, MCL, TC, TCLOnly in a document where it is on, they give their layer the Thick linetype and set the picked lines to By Layer. In a document where it is off, they leave linetypes alone.
Saving and UndoThe layer linetypes are saved in the document. Undo puts them back.
Only lines whose linetype is By Layer become thick. Lines with their own linetype stay as they are, and the command line reports how many. The default Continuous linetype is never given a width - every other line using Continuous would become thick too.
Works in Rhino 8 or later only. Rhino 7 linetypes have no width, so in Rhino 7 LThk only shows a message and changes nothing. Reference layers (worksession, linked blocks) are not changed.
