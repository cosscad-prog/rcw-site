LineLayerDotText  —  Show Line Layer Names

LineLayerDotText

Shows the layer name of each picked curve as a dot at the middle of the curve. When editing a wireframe, you can see at a glance which layer a line is on.

Unlike WVector, it works on curves that are not grouped, and even on grouped curves only the curve you click is added.

How to Use

  1. Type LineLayerDotText in the Rhino command line and press Enter.
  2. Select the curves whose layer names you want to see and press Enter. You can also select them before running the command.
  3. The layer name appears at the middle of each selected curve.
  4. To show more curves, run LineLayerDotText again and select them. They are added to the curves already shown.
  5. To turn it off, run LineLayerDotText and press Enter without selecting anything, or click the Off option.

Result

ItemDescription
PositionMiddle of the curve length
TextLayer name of the curve (for a sublayer, only its own name)
Dot colorThe layer color, with black text on light colors and white text on dark colors
Layer changesIf you move the curve to another layer or rename the layer, the dot shows the new name right away without running the command again.
Moving curvesThe dot follows the curve.
Not shownDeleted curves, hidden curves and curves on layers that are off have no dot. The dot comes back when the curve is visible again.
The dots are drawn on screen only. No TextDot objects are added to the document, so nothing is saved to the file, printed, or recorded for Undo, and there is nothing to delete with DWVector.
Copies of a selected curve are not in the list. Select the new curves again to see their layer names. Opening another file clears the list.
