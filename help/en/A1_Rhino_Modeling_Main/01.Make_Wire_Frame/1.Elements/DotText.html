DotText  —  Wire Frame Element

Dot

DotText is a Dot object that displays the Unit number for the entire Wire Frame. It serves as reference information for recognising Unit numbers during fabrication drawing creation and quantity list generation.

How to Use

  1. Run the Dot command in the Rhino command line.
  2. Enter the text to be used as the Unit number.
  3. Place the DotText at the position in the Wire Frame where the Unit number should be identified.
