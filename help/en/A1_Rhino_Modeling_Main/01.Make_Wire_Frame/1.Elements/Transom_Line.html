Transom Line  —  Wire Frame Element

TC1 ~ TCXX

Transom Line defines the horizontal Transom centerline in a Wire Frame. Layers named T_Center1 through T_CenterXX are used to identify each Transom centerline.

Purpose

Used to organize horizontal component (Transom) centerlines in the T_Center layer system, preparing the subsequent section placement and Unit modeling (UMD) to correctly recognize the horizontal reference lines. When the Transom sequence number and left-to-right direction are properly aligned, the component sequence in the modeling result will be accurate.

How to Use

  1. Prepare the lines to be used as Transom centerlines in Rhino.
  2. Use the TC1 ~ TCXX commands to assign the selected lines to the corresponding T_Center layer.
  3. Verify that each Transom Line direction runs from left to right.
