SSC  —  Clear Section Selection State

SSC

Clears all Section Profile selection states saved by SSP.

How to Use

  1. Type SSC in the Rhino command line and press Enter.
  2. Confirm that the "Section Profile Selection Clear" message appears in the command line.
  3. Use SSP again to reselect the Section to work with if needed.

Result

ItemDescription
Cleared DataThe stored Section Profile selection list is emptied.
PurposeClears an incorrectly selected Section state and starts a new task.
