SSP  —  Select Section Profile Group

SSP

Selects a Section Profile group and saves the selected Section's Profile data and group information as the current working state.

Purpose

Used to designate a Section Profile group (a collection of multiple section elements) as the current target for work. By storing the selection state, subsequent modeling and data-input commands operate based on this selection. This is a preliminary step to confirm which Section to work with.

How to Use

  1. Type SSP in the Rhino command line and press Enter.
  2. Select the Section Profile group to work with.
  3. If needed, set the Check_Error option to On to inspect property errors at the same time.
  4. Once selected, subsequent modeling commands will reference the current Section information.

Result

Automatic Repair of Copied Groups

When a section group is copied, its section data comes along unchanged, so blocks, milling curves and composite tags keep pointing at the original group's objects. Modeled as is, the copy's holes and cuts appear at the original's place. SSP finds these in every selected group and switches them to the matching object inside the group. Each switch is reported on the command line.

TargetHow the match is found
BlockA block with the same name at the same direction and distance from the section (vector from the section bounding-box minimum to the insertion point).
Milling curveA closed curve in the group with the same length at the same direction and distance from the section center. Identical curves placed symmetrically on both sides are told apart by direction.
Composite tagThe copy gets a new composite number and is regrouped inside its own group.
Note: The reference position is taken from where the original block or curve sits now relative to its own section. If the original was deleted, the position saved by Pname/SSP is used (saved once the group has been through SSP). A group that was copied with rotation changes direction, so SSP tries once more by distance only and switches only when exactly one fits.
Warning tagMeaning and what to do
missingThe original is gone and the group has no match (or no position was saved). Pick it again in Pname.
positionThere are candidates with the right name/length but none at the same place — the group was scaled, or the curve/block was moved.
ambiguousMore than one candidate sits at the same place (e.g. rotated copy + symmetric positions). Pick it yourself in Pname.
