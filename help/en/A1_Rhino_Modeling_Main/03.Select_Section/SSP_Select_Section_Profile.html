SSP  —  Select Section Profile Group

SSP

Selects a Section Profile group and saves the selected Section's Profile data and group information as the current working state.

Purpose

Used to designate a Section Profile group (a collection of multiple section elements) as the current target for work. By storing the selection state, subsequent modeling and data-input commands operate based on this selection. This is a preliminary step to confirm which Section to work with.

How to Use

  1. Type SSP in the Rhino command line and press Enter.
  2. Select the Section Profile group to work with.
  3. If needed, set the Check_Error option to On to inspect property errors at the same time.
  4. Once selected, subsequent modeling commands will reference the current Section information.

Example

Result

ItemDescription
Saved DataThe selected Section Profile group information is stored in the internal selection list.
OptionWhen Check_Error is On, errors such as Profile_ID, MnT_ID, and Center1 Curve are inspected.
Error ConditionIf Unit_No or Center1 Curve is missing, an error message may appear in the command line.
