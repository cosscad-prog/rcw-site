CT0 ~ CT5, CTL  —  01_Layer_Making

CT0 ~ CT5CTL

Purpose

Create Center series layers for section reference lines or center lines, and align colors and Center Linetype by number.

A collection of commands to quickly generate Center series layers in AutoCAD / BricsCAD drawings.

Included Commands

CommandCreated LayerColor / Properties
CTLCreates CenterXX layer. Supports numeric and alphanumeric input.CAD Color Number (when numeric) / Center Linetype
CT0Creates Center0 layer.White Color / Center Linetype
CT1Creates Center1 layer.Color 1 [CAD Color Number] / Center Linetype
CT2Creates Center2 layer.Color 2 [CAD Color Number] / Center Linetype
CT3Creates Center3 layer.Color 3 [CAD Color Number] / Center Linetype
CT4Creates Center4 layer.Color 4 [CAD Color Number] / Center Linetype
CT5Creates Center5 layer.Color 5 [CAD Color Number] / Center Linetype

How to Use

  1. Enter the required command in the AutoCAD or BricsCAD command line and press Enter.
  2. Commands in *L format attach the numeric or alphanumeric input directly to the base layer name.
  3. When entering numbers, the number is used as the CAD Color Number. Numbers greater than 256 use the remainder after dividing by 256 as the Color Number.
  4. Verify the created layer name, color, and Linetype in the layer list.
