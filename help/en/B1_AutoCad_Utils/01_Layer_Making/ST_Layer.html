ST1 ~ ST9, STL  —  01_Layer_Making

ST1 ~ ST9STL

Purpose

Manage Steel-related center lines or reinforcement reference lines by dividing them into Steel series layers.

A collection of commands to quickly generate Steel series layers in AutoCAD / BricsCAD drawings.

Included Commands

CommandCreated LayerColor / Properties
STLCreates Steel XX layer. Supports numeric and alphanumeric input.CAD Color Number (when numeric)
ST1Creates Steel 1 layer.Color 1 [CAD Color Number]
ST2Creates Steel 2 layer.Color 2 [CAD Color Number]
ST3 ~ ST8Creates Steel 3 ~ Steel 8 layers in the same manner.CAD Color Number matching each command number
ST9Creates Steel 9 layer.Color 9 [CAD Color Number]

How to Use

  1. Enter the required command in the AutoCAD or BricsCAD command line and press Enter.
  2. Commands in *L format attach the numeric or alphanumeric input directly to the base layer name.
  3. When entering numbers, the number is used as the CAD Color Number. Numbers greater than 256 use the remainder after dividing by 256 as the Color Number.
  4. Verify the created layer name, color, and Linetype in the layer list.
