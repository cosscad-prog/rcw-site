Purpose

Quickly prepare T_Center layers for Transom center line work according to numbering and color standards.

A collection of commands to quickly generate T_Center series layers in AutoCAD / BricsCAD drawings.

Included Commands

CommandCreated LayerColor / Properties
TCLCreates T_CenterXX layer. Supports numeric and alphanumeric input.CAD Color Number (when numeric)
TC1Creates T_Center1 layer.Color 20 [CAD Color Number]
TC2Creates T_Center2 layer.Color 21 [CAD Color Number]
TC3 ~ TC13Creates T_Center3 ~ T_Center13 layers in the same manner.CAD Color Number assigned to each command code
TC20 ~ TC23Creates T_Center20 ~ T_Center23 layers.CAD Color Number assigned to each command code

How to Use

  1. Enter the required command in the AutoCAD or BricsCAD command line and press Enter.
  2. Commands in *L format attach the numeric or alphanumeric input directly to the base layer name.
  3. When entering numbers, the number is used as the CAD Color Number. Numbers greater than 256 use the remainder after dividing by 256 as the Color Number.
  4. Verify the created layer name, color, and Linetype in the layer list.
