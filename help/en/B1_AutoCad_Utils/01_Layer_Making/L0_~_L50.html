L0 ~ L50  —  01_Layer_Making

L0 ~ L50

Purpose

Quickly create general working layers using a numbering system to separate temporary lines, auxiliary lines, and review objects by color.

A collection of commands to quickly generate Layer 00 ~ Layer 50 series layers in AutoCAD / BricsCAD drawings.

Included Commands

CommandCreated LayerColor / Properties
L0Creates Layer 00 layer.Color 7 [CAD Color Number]
L1Creates Layer 01 layer.Color 1 [CAD Color Number]
L2Creates Layer 02 layer.Color 2 [CAD Color Number]
L3 ~ L49Creates Layer 03 ~ Layer 49 layers in the same manner with two-digit numbering.CAD Color Number matching each command number
L50Creates Layer 50 layer.Color 50 [CAD Color Number]

How to Use

  1. Enter the required command in the AutoCAD or BricsCAD command line and press Enter.
  2. Commands in *L format attach the numeric or alphanumeric input directly to the base layer name.
  3. When entering numbers, the number is used as the CAD Color Number. Numbers greater than 256 use the remainder after dividing by 256 as the Color Number.
  4. L0 creates Layer 00, L1 creates Layer 01, etc., using two-digit numbering.
  5. Verify the created layer name, color, and Linetype in the layer list.
