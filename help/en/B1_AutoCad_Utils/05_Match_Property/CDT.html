CDT  —  05_Match_Property

CDT

A text matching command that matches the content or text properties of a reference Text to another Text. Only the text content changes — layer, color and size stay as they are.

Purpose

Use to match the content or text properties of a reference Text to target Text and quickly unify drawing notations.

How to Use

  1. Enter CDT in the Rhino command line and press Enter.
  2. Select the target objects according to the command prompt.
  3. Press Enter to complete the command and verify the result in the Rhino display or command window.

Execution Example

Note: A command that matches the text string or Text properties of a reference Text to target Text. Used to organize drawing notation content in bulk.
