Y0, Z0  —  06_Move_Zero

Y0Z0

A collection of simple origin alignment commands that aligns selected objects to the 0 reference plane of a specified axis.

Purpose

Use to quickly align objects on different planes to a reference plane by setting specific coordinate values of selected objects (Lines, Points, etc.) to 0.

Command Summary

CommandCoordinate Set to 0Curve/Line ProcessingPoint/Text Processing
Y0Y = 0Project to XZ planeMove Y coordinate to 0 only
Z0Z = 0Project to XY planeMove Z coordinate to 0 only

How to Use

  1. Enter the required command (Y0 or Z0) in the AutoCAD or BricsCAD command line.
  2. Select the objects to align to the 0 reference plane.
  3. Press Enter and the selected objects will be aligned to the 0 reference of the corresponding axis.
Note: This document is organized using the same standards as Rhino's X0, Y0, Z0 documentation. Currently, only Y0 and Z0 commands are included in the AutoCAD / BricsCAD section.
