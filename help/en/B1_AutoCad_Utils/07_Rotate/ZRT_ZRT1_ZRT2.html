ZRT, ZRT1, ZRT2  —  07_Rotate

ZRT / ZRT1 / ZRT2

Used to rotate selected objects 90 degrees or 180 degrees aligned to the absolute coordinate Z-axis based on the object center.

Purpose

Rotates selected objects around the absolute coordinate Z-axis based on the object center. Used identically in AutoCAD / BricsCAD / Rhino, and used to quickly apply -90 degrees (ZRT), +90 degrees (ZRT1), and 180 degrees (ZRT2) rotation.

Included Commands

CommandFunctionRotation Axis
ZRTRotates the object clockwise around the absolute coordinate Z-axis based on the object center.Z-axis / -90°
ZRT1Rotates the object counter-clockwise around the absolute coordinate Z-axis based on the object center.Z-axis / +90°
ZRT2Rotates the object 180 degrees around the absolute coordinate Z-axis based on the object center.Z-axis / 180°

How to Use

  1. Enter the required command (ZRT, ZRT1, or ZRT2) in the Rhino command line and press Enter.
  2. Select the object to rotate.
  3. Press Enter to rotate the selected object around the Z-axis.

Execution Example

Note: ZRT/ZRT1/ZRT2 applies absolute Z-axis rotation based on the object center. It is safer to understand it based on the World coordinate axis rather than the current CPlane direction.
