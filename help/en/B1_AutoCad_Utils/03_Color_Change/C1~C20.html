C1~C20  —  Object Color Change

C1 ~ C20

A collection of commands to quickly change the Object Color of selected objects based on CAD Color Number.

Purpose

Use to change object display color while keeping the layer unchanged. Ideal for review marking, temporary emphasis, and color-based object categorization during drawing organization.

Command Summary

CommandAction
C1Changes selected object color to Color 1 [CAD Color Number].
C2Changes selected object color to Color 2 [CAD Color Number].
C3Changes selected object color to Color 3 [CAD Color Number].
C4 ~ C17Changes Object Color to the CAD Color Number matching the command number in the same manner.
C18Changes selected object color to Color 18 [CAD Color Number].
C19Changes selected object color to Color 19 [CAD Color Number].
C20Changes selected object color to Color 20 [CAD Color Number].

How to Use

  1. Enter the command for the desired color number from C1 to C20 in the AutoCAD or BricsCAD command line.
  2. Select the objects to change color.
  3. Press Enter to change the Object Color of selected objects to the specified number.
