CCL, CCN, CCS  —  Layer / Color Organization

CCLCCNCCS

A collection of auxiliary commands to quickly organize work status based on current layer, selected object's layer, and object color.

Purpose

Move selected objects to the current layer, set the current layer from selected object's layer, or change object color by CAD Color Number to quickly align object classification and display status during work.

Command Summary

CommandFunctionUsage Situation
CCLMove selected objects to current layerUse when gathering scattered objects to the current working layer.
CCSSet selected object's layer as current layerUse to set the reference object's layer as current layer for future object creation.
CCNChange selected object color to CAD Color NumberUse to quickly change object display color without moving layers.

How to Use

  1. Enter CCL, CCS, or CCN in the AutoCAD or BricsCAD command line.
  2. For CCL and CCS, select the reference object or objects to move as prompted.
  3. For CCN, enter the CAD Color Number first, then select objects to change color.
  4. After command completion, verify the Layer/Color result in the layer list and object properties.
