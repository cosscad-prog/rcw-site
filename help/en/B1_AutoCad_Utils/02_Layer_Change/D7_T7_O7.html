D7, T7, O7  —  Frequently-Used Layer Change

D7T7O7

A collection of layer change commands to quickly move selected objects to frequently-used default layers.

Purpose

Use to quickly organize scattered objects into frequently-used layers like Default, Text, OutLines during work to align drawing object classification.

Command Summary

CommandDestination LayerColorUsage Situation
D7DefaultWhiteUse to return temporary or unclassified objects to the default layer.
T7TextWhiteUse to gather drawing text, labels, and annotation objects to the Text layer.
O7OutLinesWhiteUse to organize outlines or print-ready profiles to the OutLines layer.

How to Use

  1. Enter D7, T7, or O7 in the AutoCAD or BricsCAD command line.
  2. Select the objects to move to the destination layer.
  3. Press Enter to move the selected objects to the specified layer.
