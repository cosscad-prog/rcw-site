HD  —  04_Layer_Control

HD

A drawing auxiliary command that changes the Linetype of selected Line objects to Hidden.

Purpose

Use to quickly create hidden lines that are visually distinct from visible lines by changing selected lines to hidden line representation during 2D drawing organization.

How to Use

  1. Enter HD in the Rhino command line and press Enter.
  2. Select the Line objects to change to Hidden Linetype.
  3. Press Enter to complete. The selected Line Linetype will change to Hidden.
Note: HD changes only the Linetype of selected objects to Hidden, not the layer. This applies uniformly regardless of which layer the objects are on. If the Hidden Linetype is not in the document, check the Linetype list first.
