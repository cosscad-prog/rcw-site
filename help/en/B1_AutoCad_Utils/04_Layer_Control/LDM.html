LDM  —  04_Layer_Control

LDM

A command that creates basic Layers and Annotation DimStyles required for initial modeling and drawing work at once.

Purpose

Use to quickly prepare basic Layers and DimStyles by DimScale that are frequently used in new files or initial work stages, and unify the standards for subsequent modeling, dimension, and text work.

How to Use

  1. Enter LDM in the Rhino command line and press Enter.
  2. When the command is executed, basic Layers and Annotation DimStyles are created.
  3. Verify the created items in the Rhino Layer panel and DimStyle/Annotation settings.
