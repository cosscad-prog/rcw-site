LayerList

A layer inspection command that displays the layers of all selected objects in a list.

Purpose

Use to quickly check which Layers the selected objects are scattered across and verify the Layer structure and object classification status before model cleanup.

How to Use

  1. Enter LayerList in the Rhino command line and press Enter.
  2. Select the objects to check their Layers.
  3. Press Enter and the Layers of all selected objects will be displayed as a list.

Execution Example

Difference from SSLayerList

CommandLayer List Target
LayerListDisplays the Layers of all selected objects.
SSLayerListDisplays only the Layers of Surface Objects among selected objects.
Note: Use LayerList when checking Layers of all selected objects regardless of object type. SSLayerList is more suitable when checking only Section Surface Layers.
