AD  —  04_Layer_Control

AD

A command that shows only the selected object's layer and related parent/child layers to organize the display.

Purpose

Use to show only the selected object's layer in complex models to focus on and verify only the necessary component families.

How to Use

  1. Enter AD in the Rhino command line and press Enter.
  2. Select the target object or layer if needed.
  3. Press Enter to complete the command and verify the result in the Rhino display or command window.
