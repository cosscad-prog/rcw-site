Mullion Modeling

MC1 ~ MC20 WVector SSP UMD

Procedure to create Mullion WireFrame, designate Layer and direction data, then model Mullion using the selected Section.

Basic Conditions

ItemDescription
Connection ConditionMullion WireFrame does not necessarily need to be connected to Transom Line.
LayerMullion Line must be on the M_Center Layer.
Direction PointMullion Line must have a direction point. If omitted, it is processed in the Y direction of absolute coordinates.

Step-by-Step Instructions

  1. Draw the line from bottom to top direction.
  2. Verify the line direction using the dir command or Direction icon in the main menu.
  3. If direction is incorrect, click the line repeatedly to change direction.
  4. Change the line's Layer using the MC1 ~ MC9 commands.
  5. Specify the direction point to the same Layer as the line. The direction point must be within 300 range from the line end point.
  6. Select the line and direction point to create a Group. A Group can be created with just one line.
  7. Run WVector and select the created Group to generate direction data for all lines.
  8. Select the Section to use with SSP.
  9. Run UMD and select the Wire Group to perform modeling.

Detailed Criteria

StepDescription
Direction PointOnly points on the same Layer within 300 range from the line end point are recognized as direction points.
Default DirectionIf there is no direction point on the same Layer within range, the line direction is automatically set to Y direction of absolute coordinates.
GroupModeling recognizes a Group as one window and performs operations by finding elements inside the Group.
Line DataWVector must be executed and saves connection information within the Group as line internal data.
SectionA Section matching the Layer must exist for UMD modeling to be executed.

Execution Example

Caution: If WVector is not executed, Line Data is not generated and connection information within the Group cannot be used.
