Profile Length Change

Additional Length Length / Spacing / Quantity

Feature to change the length of Solid Models like Mullion and Transom using Section Data values, or create multiple divided Profile Solids.

Purpose

Adjust Profile top/bottom or left/right length by changing length-related values in Section Data without directly editing the Solid Model. If needed, create divided Profile Solids by entering specific length, spacing, and quantity.

Adjusting Additional Length

  1. Enter the Additional Length value in Section Data.
  2. Adjust the length in top/bottom or left/right direction.
  3. + value increases length, - value decreases length.

Creating Divided Profiles

Using the Length, spacing, and quantity input fields, you can create multiple divided Profile Solids based on a single Line.

Input ExampleDescription
1/4 position, length 100Creates a Profile of length 100 at 1/4 position from both start and end points of the Transom Line. You can use fractions like 1/4, 1/6, etc.
From start point 200, length 100, spacing 400, quantity 2Creates 2 Profiles of length 100 at 400 spacing starting from 200 distance from Transom Line start point.
From end point 200, length 100, spacing 400, quantity 2Creates 2 Profiles of length 100 at 400 spacing starting from 200 distance from Transom Line end point.
Caution: Top and bottom conditions cannot be applied simultaneously.
Note: Related input items can be found in Rhino Curtainwall Modeling / Make Section / Input Data / Surface.
