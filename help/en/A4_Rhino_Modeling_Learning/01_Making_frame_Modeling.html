Frame Modeling Workflow Order

A step-by-step guide for first-time users — RCW Rhino Plugin

📋 Before You Start

  • The Wire Frame (Mullion/Transom reference lines) must be completed.
  • Section data (Profile, Block information) must be registered.
  • Each Unit group must be defined.
1
Run modeling
UMD Unit Frame modeling

Analyzes the Mullion/Transom reference lines of the Unit group selected in the Wire Frame and automatically generates the frame Solid and related Blocks.
This is the most central step and the basis for all subsequent work.

Frame Solid model and Blocks auto-generated
▶ UMD detailed help
2
Data check
CheckPfData ProfileData check

After running UMD, verifies that the generated frame's ProfileData is recorded correctly. Numbering and list creation in later steps only work properly if there are no data errors.

Outputs a list of error items — if no errors, proceed to the next step
▶ CheckPfData detailed help
3
Add data (optional)
AddBrkdata Add bracket data Optional

If there are brackets, records the additional data needed on those bracket objects. Projects without brackets skip this step.

Records data such as position and type on bracket objects
▶ AddBrkdata detailed help
4
Numbering
FabNo Assign fab numbers

Analyzes the modeled frame Breps/Blocks and automatically assigns fab numbers to the ProfileData. Identical Profiles share the same number, and this becomes the basis for later list and drawing work.

Assigns a unique fab number (FabNo) to each frame
▶ FabNo detailed help
5
Create list
Molist Create material list

Reads the ProfileData and Block information of the selected frames to generate a material quantity list. Used for quantity/weight aggregation and serves as the basis for ordering and process planning.

Frame material quantity table generated (inserted into the Rhino drawing)
▶ Molist detailed help

※ The two lists below are created alongside Molist as needed.

5-1
PMolist Profile material list Optional

A Profile-centric quantity/weight list. Used when calculating Profile unit prices or preparing purchase orders.

▶ PMolist detailed help
5-2
Cuttinglist Create cutting plan Optional

Aggregates by cut length and calculates stock-bar length and Loss to generate a cutting plan. Used as a factory cutting work order.

▶ Cuttinglist detailed help
6
Fab drawing
FabTable Create fab number table

Based on the fab numbers assigned in FabNo, creates a per-number quantity/length table. Used as the parts table of the fab drawing.

Per-fab-number quantity/length table generated
▶ FabTable detailed help
7
FDwg Auto-generate fab drawing

Analyzes the selected frame group objects and automatically generates the fabrication drawing (Fab Drawing). The DimStyle follows the style set in DsOpt, and the Profile information must be registered in the Fdds.dat file.

Per-frame fab drawing auto-output
▶ FDDS detailed help
Recommended order for first-time use: Proceed in the order 1 → 2 → 4 → 5 (Molist) → 6 → 7. If there are no data errors, you can briefly confirm CheckPfData (step 2) and move on. AddBrkdata, PMolist, and Cuttinglist are used optionally depending on project conditions.
