RCWFolder  —  Your Editable RCW Files

RCWFolder

Opens the one folder that holds every RCW file you are meant to edit: your data tables, your blocks, your drawing forms and the hatch pattern. You never need to know or type the path.

How to Use

  1. Type RCWFolder in the Rhino command line and press Enter.
  2. The folder opens in Windows Explorer.
  3. Edit the file you want. Blocks are in Blocks, drawing forms in Forms; everything else is in the folder itself.

What Is In The Folder

ItemWhat it is
Blocks\*.3dmThe blocks offered by the BlockOpt panel. Add your own 3dm files here and they appear in the list.
Forms\*.3dmFrame form templates you select with SFB or the Form button on the FDstyle panel.
Forms\*.dwgDrawing form sheets used by FDwgStyle.
RCW_Hatch.patThe hatch pattern used by the fabrication drawings.
*.dat, *.txtData tables: glass types, vent types, grill types, back panel types, die data, system defaults and the bar list.

Shared With AutoCAD and BricsCAD

RCWFolder exists under the same name in the RCW_V5 plug-ins for AutoCAD and BricsCAD. Whichever product you type it in, the same folder opens. Edit a file once and all three products use it. Adding the CAD plug-ins later will not split your settings.

FileCAD command that uses itRelationship to Rhino
System_Default.dat[D] on the DsOpt panel Shared. One file, separate keys: the values CAD writes start with CAD_, and saving never removes the keys Rhino wrote.
AutoScale.datFSC, NC4, SFB Shared. The same file Rhino's FSC reads.
LongBarList.datCuttinglist CAD only. Rhino never reads it.
barlist.txtUBarlist, Cuttinglist Same format. The name is not fixed - both products pick the file from a dialog - so one file can serve both.

Those four are all the CAD plug-ins read. Everything else here, including Blocks, Forms and RCW_Hatch.pat, is for Rhino only.

Your Edits Survive Updates

Installing a newer RCW release never overwrites a file you have edited. A file that a new release adds — a new block, for example — appears on its own, while everything you changed stays as you left it.

Do not edit anything inside the program installation folder under Program Files. Each release installs into a folder named after its version, so an edit made there is lost as soon as you update. The folder this command opens is the only place to work in.

Restoring The Installed Defaults

Because your files always win, a file you have broken stays broken. Use the restore option to put the shipped version back.

  1. Run RCWFolder and choose Restore.
  2. Choose what to restore: All, or just Data, Blocks, Forms or Hatch.
  3. The command lists the files that will change. Confirm with Yes.
ItemDescription
BackupYour current files are copied to a timestamped backup folder before anything is replaced. The command prints the location.
Your own filesBlocks and forms you added yourself are never touched. Restore puts the shipped files back; it does not empty the folder.
Model changesNone. The command does not modify the document.
Restore is a Rhino-only option. In the AutoCAD and BricsCAD plug-ins, RCWFolder only opens the folder and reports where each file is being read from.

Related Commands

CommandDescription
BlockOptInserts a block from the Blocks folder.
SFBSelects a frame form, either on screen or from a file in the Forms folder.
FDwgStyleBuilds a layout sheet from a drawing form DWG in the Forms folder.
Caution: a block or form already inserted into a model keeps the definition stored in that model. Editing the source file changes new insertions only; use Rhino's BlockManager to refresh a model you already made.
