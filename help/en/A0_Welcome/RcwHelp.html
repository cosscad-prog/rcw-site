RcwHelp  —  Open Help

RcwHelp

Opens the installed RCW help in your default web browser. This document is part of that help.

How to Use

  1. Type RcwHelp in the Rhino command line and press Enter.
  2. Your default web browser opens on the help start page.
  3. Expand a command group in the left navigation and select the command you need.

Which File Opens

The file that opens depends on the RCW display language.

Display languageFile opened
Koreanhelp\Help_index.html in the plug-in installation folder
Any other languagehelp\en\index.html in the plug-in installation folder (English help)

Result

ItemDescription
Help windowOpens in the default web browser rather than inside Rhino, so it can stay open beside your model.
Model changesNone. The command does not modify the document.

Related Commands

CommandDescription

RCWCustomerCodeSaves the customer code used to sign in to the customer page on this computer.
RCWVersionPrints the running build's version, edition, build date and loaded file path in the command line.
RCWUpdateChecks whether a newer version exists, and turns the startup check on or off.

Caution: if the help file cannot be found, the command prints the path it looked for and stops. Check that the help folder was installed with the plug-in.
