CD  —  Match Property

CD

A Match Property command to copy Rhino properties of a reference object to other objects.

Purpose

Copy Rhino properties of a reference object to target objects to quickly align Layers, colors, and display properties.

How to Use

  1. Type CD in the Rhino command line and press Enter.
  2. Select the target objects according to the command prompt.
  3. Press Enter to complete the command and verify the result in the Rhino display or command line.

Usage Example

Note: This copies the Rhino properties of the reference object to selected objects. It is used to match Layer, color, and display properties; the geometry itself is not changed.
