SSLayerList  —  Layer Control

SSLayerList

A Layer inspection command to view only the Layers of Surface Objects among selected objects as a list.

Purpose

Filter Layers based only on Surface Objects to verify the Surface Layer composition used in Section Objects.

How to Use

  1. Type SSLayerList in the Rhino command line and press Enter.
  2. Select the Section Objects or related objects whose Layer you want to verify.
  3. Press Enter to display only the Layers of Surface Objects among selected objects as a list.

Usage Example

Difference from LayerList

CommandLayer List Target
LayerListDisplays the Layers of all selected objects.
SSLayerListDisplays only the Layers of Surface objects among selected objects.
Note: This is useful for verifying which Surface Layers are included in a Section Object, as shown in the usage example. Non-Surface objects such as Lines, Text, and Blocks are excluded from the Layer List.
