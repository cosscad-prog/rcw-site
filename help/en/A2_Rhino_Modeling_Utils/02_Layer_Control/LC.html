LC  —  Layer Control

LC

A Layer control command to lock the Layer containing a selected object and prevent accidental editing.

Purpose

Lock the Layer containing the selected object to protect reference geometry from accidental editing.

How to Use

  1. Type LC in the Rhino command line and press Enter.
  2. Select the target object or Layer if required.
  3. Press Enter to complete the command and verify the result in the Rhino display or command line.

Related Layer Control Commands

CommandSummaryWhen to Use
ADShow selected object Layer onlyDisplay only the Layer of the selected object and its related parent/child Layers, hiding others to focus on the work target.
AFHide selected object LayerHide the Layer containing the selected object to quickly exclude finished components or interfering Layers.
LOShow all LayersRedisplay hidden Layers. Lock status is preserved, so locked Layers must be unlocked separately.

ALOShow all Layers + unlock allRestore all hidden/locked Layers at once to review the full model and return to an editable state.

Note: This locks the Layer containing the selected object. The current Layer is excluded from locking, so verify whether the Layer you want to lock is the current Layer.
