LayerList  —  Layer Control

LayerList

A Layer inspection command to view the Layers of all selected objects as a list.

Purpose

Quickly verify which Layers the selected objects are distributed across to inspect Layer composition and object classification before model organising.

How to Use

  1. Type LayerList in the Rhino command line and press Enter.
  2. Select the objects whose Layer list you want to view.
  3. Press Enter to display the Layers of all selected objects as a list.

Usage Example

Difference from SSLayerList

CommandLayer List Target
LayerListDisplays the Layers of all selected objects.
SSLayerListDisplays only the Layers of Surface objects among selected objects.
Note: Use LayerList to verify the Layers of all selected objects regardless of object type. Use SSLayerList when you only want to check Section Surface Layers.
