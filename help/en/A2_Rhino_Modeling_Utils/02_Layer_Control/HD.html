HD  —  Layer Control

HD

A drawing utility command to change the Linetype of selected Line objects to Hidden.

Purpose

In 2D drawing setup, change selected lines to hidden line representation to quickly distinguish hidden lines from visible lines.

How to Use

  1. Type HD in the Rhino command line and press Enter.
  2. Select the Line objects whose Linetype you want to change to Hidden.
  3. Press Enter to complete. The selected Lines will have their Linetype changed to Hidden.
Note: HD does not change the Layer — it only changes the Linetype of selected objects to Hidden. This applies the same way regardless of which Layer the object is on. If the Hidden Linetype does not exist in the document, verify the Linetype list first.
