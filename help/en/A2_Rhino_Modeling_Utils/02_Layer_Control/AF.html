AF  —  Layer Control

AF

A command to hide the Layer containing a selected object from the display.

Purpose

Hide the Layer containing the selected object to quickly exclude finished components or interfering Layers from the display.

How to Use

  1. Type AF in the Rhino command line and press Enter.
  2. Select the target object or Layer if required.
  3. Press Enter to complete the command and verify the result in the Rhino display or command line.
