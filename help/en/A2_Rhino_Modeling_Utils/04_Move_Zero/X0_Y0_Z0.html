X0, Y0, Z0  —  Move Zero

X0Y0Z0

A set of simple origin alignment commands to organise selected objects to the zero reference plane of a specified axis.

Purpose

Align specific coordinate values of Curves, Points, and Text to zero to quickly organise section lines, reference points, and text positions based on the origin.

Command Summary

CommandCoordinate Set to 0Curve ProcessingPoint/Text Processing
X0X = 0Project to YZ planeMove only X coordinate to 0
Y0Y = 0Project to XZ planeMove only Y coordinate to 0
Z0Z = 0Project to XY planeMove only Z coordinate to 0

How to Use

  1. Type the required command (X0, Y0, or Z0) in the Rhino command line.
  2. Select the Curve, Point, or Text objects to organise to the zero reference plane.
  3. Press Enter to organise the selected objects based on the zero reference of that axis.
Note: For Curves, the original object is deleted and replaced with a new projected Curve. For Points and Text, only the specified coordinate is moved to 0 while maintaining existing properties.
