7.XTC_Layer  —  Layer Making

XTC1 ~ XTC4 / XTCL

Purpose

Creates XT_Center series layers for distinguishing supplementary Transom / additional centreline work into numbered layers.

A set of commands for creating XT_Center series Layers.

Included Commands

CommandCreated LayerColor / Attributes
XTCLCreates an XT_CenterXX layer. Accepts numbers or characters.When a number is entered, applies the CAD Color Number; characters also accepted.
XTC1Creates the XT_Center1 layer.RGB(255,91,0)
XTC2Creates the XT_Center2 layer.RGB(255,121,0)
XTC3Creates the XT_Center3 layer.RGB(255,151,0)
XTC4Creates the XT_Center4 layer.RGB(255,181,0)

How to Use

  1. Type the required command in the Rhino command line and press Enter.
  2. The *L command appends the entered number or character directly after the base layer name to create the layer.
  3. When a number is entered, it is used as the CAD Color Number. Numbers greater than 256 use the remainder when divided by 256 as the Color Number.
  4. Check the Layer name, Color, and Linetype state in the Rhino Layer panel.
