1.AnP_Layer  —  Layer Making

ANP1 ~ ANP5 / ANPL

Purpose

Quickly creates AN_Point series point layers, preparing numbered layers and consistent colours needed for Anchor Point reference work.

A set of commands for creating AN_Point series Point Layers.

Included Commands

CommandCreated LayerColor / Attributes
ANPLCreates an AN_PointXX layer. Accepts numbers or characters.When a number is entered, applies the corresponding CAD Color Number; characters also accepted.
ANP1Creates the AN_Point1 layer.Color 1 [CAD Color Number]
ANP2Creates the AN_Point2 layer.Color 2 [CAD Color Number]
ANP3Creates the AN_Point3 layer.Color 3 [CAD Color Number]
ANP4Creates the AN_Point4 layer.Color 4 [CAD Color Number]
ANP5Creates the AN_Point5 layer.Color 5 [CAD Color Number]

How to Use

  1. Type the required command in the Rhino command line and press Enter.
  2. The *L command appends the entered number or character directly after the base layer name to create the layer.
  3. When a number is entered, it is used as the CAD Color Number. Numbers greater than 256 use the remainder when divided by 256 as the Color Number.
  4. Check the Layer name, Color, and Linetype state in the Rhino Layer panel.
