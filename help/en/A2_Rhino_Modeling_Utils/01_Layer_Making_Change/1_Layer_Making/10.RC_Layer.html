10.RC_Layer  —  Layer Making

RC1 ~ RC9 / RCL

Purpose

Creates R_Center series Layers with numbers to organise reference geometry for Rhino Curtainwall according to a standardised naming and colour scheme.

A set of commands for creating R_Center series Layers.

How to Use

  1. Type the required command in the Rhino command line and press Enter.
  2. Commands with the *L format create a Layer by appending the entered number or character directly after the base Layer name.
  3. When a number is entered, it is used as the CAD Color Number. Numbers greater than 256 use the remainder when divided by 256 as the Color Number.
  4. Check the Layer name, Color, and Linetype state in the Rhino Layer panel.
