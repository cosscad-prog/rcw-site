4.MC_Layer  —  Layer Making

MC1 ~ MC20 / MCL

Purpose

Creates M_Center series layers for distinguishing Mullion centrelines by number and organising reference lines for Wire Frame and Section work.

A set of commands for creating M_Center series Layers.

Included Commands

CommandCreated LayerColor / Attributes
MCLCreates an M_CenterXX layer. Accepts numbers or characters.When a number is entered, applies the CAD Color Number; characters also accepted.
MC1 ~ MC20Creates the M_Center1 ~ M_Center20 layers.Same CAD Color Number as the command number (e.g. MC13 → Color 13)

How to Use

  1. Type the required command in the Rhino command line and press Enter.
  2. The *L command appends the entered number or character directly after the base layer name to create the layer.
  3. When a number is entered, it is used as the CAD Color Number. Numbers greater than 256 use the remainder when divided by 256 as the Color Number.
  4. Check the Layer name, Color, and Linetype state in the Rhino Layer panel.
