11.SC_Layer  —  Layer Making

SC1 ~ SC5

Purpose

A set of commands for creating S_Center series layers, in the same way as GC1 ~ GC5 (G_Center).

They create the layer for the reference line drawn in a sheet section. The sheet commands (ShFace · Sht) read the S_Center1 line in the section group to set the sheet face position and the fold depth. See Making a Sheet Section for how to draw the line.

Included Commands

CommandCreated LayerColor / Attributes

SC4Creates the S_Center4 layer.RGB(255,38,0)
SC5Creates the S_Center5 layer.RGB(255,8,0)

How to Use

  1. Type the required command in the Rhino command line and press Enter.
  2. If the layer does not exist it is created; if it exists it becomes the current layer (same as GC1).
  3. Check the Layer name and Color in the Rhino Layer panel.

Key Details

ItemDescription
