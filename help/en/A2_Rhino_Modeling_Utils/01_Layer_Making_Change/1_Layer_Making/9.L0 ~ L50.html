9.L0 ~ L50  —  Layer Making

L0 ~ L50

A set of commands to create basic numbered Layers from Layer 00 to Layer 50.

Included Commands

CommandCreated LayerColour / Attributes
L0Creates Layer 00.Colour 7 [CAD Colour Number]
L1Creates Layer 01.Colour 1 [CAD Colour Number]
L2Creates Layer 02.Colour 2 [CAD Colour Number]
L3 ~ L47Creates Layer 03 ~ Layer 47 in the same manner.CAD Colour Number as specified in the command code
L48Creates Layer 48.Colour 48 [CAD Colour Number]
L49Creates Layer 49.Colour 49 [CAD Colour Number]
L50Creates Layer 50.Colour 50 [CAD Colour Number]
Note: Commands L0 and L1 create two-digit numbered Layers like Layer 00 and Layer 01. Each command applies the CAD Colour Number specified in the command code.

How to Use

  1. Type the required command in the Rhino command line and press Enter.
  2. Commands L0 and L1 create two-digit numbered Layers (e.g., Layer 00, Layer 01).
  3. Verify the Layer name, Colour, and Linetype in the Rhino Layer panel.
