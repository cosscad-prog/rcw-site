5.TC_Layer  —  Layer Making

TC1 ~ TC20 / TCL

Purpose

A set of commands for creating T_Center series Layers.

Included Commands

CommandCreated LayerColor / Attributes

TC10 ~ TC20Creates the T_Center10 ~ T_Center20 layers.Same CAD Color Number as the command number (e.g. TC13 → Color 13)

How to Use

  1. Type the required command in the Rhino command line and press Enter.
  2. The *L command appends the entered number or character directly after the base layer name to create the layer.
  3. When a number is entered, it is used as the CAD Color Number. Numbers greater than 256 use the remainder when divided by 256 as the Color Number.
  4. Check the Layer name, Color, and Linetype state in the Rhino Layer panel.
