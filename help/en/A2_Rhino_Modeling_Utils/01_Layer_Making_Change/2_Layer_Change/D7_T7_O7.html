D7, T7, O7  —  Common Layer Change

D7T7O7

A set of Layer change commands to quickly move selected objects to frequently-used base Layers.

Purpose

Quickly organise scattered objects during work by moving them to frequently-used Layers such as Default, Text, and OutLines to align the classification of modelling and drawing tasks.

Command Summary

CommandTarget LayerColorWhen to Use
D7DefaultWhiteUse when returning temporary or unclassified objects to the base Default Layer.
T7TextWhiteUse when collecting drawing text, annotations, and note objects to the Text Layer.
O7OutLinesWhiteUse when organising outlines and print-ready outline objects to the OutLines Layer.

How to Use

  1. Type the required command (D7, T7, or O7) in the Rhino command line.
  2. Select the objects to move to the target Layer.
  3. Press Enter to move the selected objects to the specified Layer.
Note: These three commands are designed to quickly move objects to predefined Layers. Understand them as commands that change the Layer of selected objects, not commands that change the current Layer.
