CCL, CCN, CCS  —  Layer/Color Organisation

CCLCCNCCS

A set of utility commands to quickly organise work based on the current Layer, the Layer of selected objects, and object color.

Purpose

Move selected objects to the current Layer, set the current Layer based on selected objects, or change object color by CAD Color Number to quickly align the classification and display state of working objects.

Command Summary

CommandFunctionWhen to Use
CCLMove selected objects to the current LayerUse when collecting scattered objects into the current working Layer.
CCSSet the Layer of selected objects as the current LayerUse when adopting the Layer of a reference object as the current Layer for subsequent object creation.
CCNChange selected object color to CAD Color NumberUse when changing object display color without moving Layers.

How to Use

  1. Type the required command (CCL, CCS, or CCN) in the Rhino command line.
  2. For CCL and CCS, select the reference objects or objects to move according to the command prompt.
  3. For CCN, enter the CAD Color Number, then select the objects to recolour.
  4. After the command completes, verify the Layer/Color result in the Layer panel and object properties.
Note: CCL moves objects to the current Layer, while CCS sets the current Layer based on selected objects. These commands work in opposite directions, so verify the current Layer and selection criteria before execution.
