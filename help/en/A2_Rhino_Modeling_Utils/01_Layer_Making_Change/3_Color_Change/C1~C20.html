C1~C20  —  Color Change

C1 ~ C20

A set of commands to change only the display color of selected objects using CAD Color Number.

Purpose

Used to quickly change object display color while keeping the Layer unchanged. Useful for review marking, temporary emphasis, and distinguishing objects by color during model cleanup.

Included Commands

CommandFunction
C1Changes the Color of selected objects to Color 1 [CAD Color Number].
C2Changes the Color of selected objects to Color 2 [CAD Color Number].
C3Changes the Color of selected objects to Color 3 [CAD Color Number].
C4 ~ C17Changes object color to the CAD Color Number matching the command number in the same manner.
C18Changes the Color of selected objects to Color 18 [CAD Color Number].
C19Changes the Color of selected objects to Color 19 [CAD Color Number].
C20Changes the Color of selected objects to Color 20 [CAD Color Number].
Warning: These commands operate independently of Layers. They change only the Color of selected objects and do not change the Layer.

How to Use

  1. Type the required command in the Rhino command line and press Enter.
  2. Select the objects whose Color you want to change.
  3. Press Enter to complete the Color Change for the selected objects.

Key Details

ItemDescription

Verifying Results

ItemDescription
object colorThe display color of selected objects is changed to the CAD Color Number matching the command number.
LayerThe Layer containing the object and the current Layer remain unchanged.
Note: C1~C20 quickly applies the specified CAD Color Number to selected objects. Since these commands do not change Layers, verify the Color Source in properties when returning objects to Layer Color.
