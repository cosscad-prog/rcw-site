TDF  —  Text

TDF

A command to move selected Text to the front of the together selected Solid Object. Used to bring Text to the front when it is inside or behind a Solid and not visible.

Purpose

Used to move Text hidden behind Solid or Brep to the front based on the current view, organizing text annotations to be visible in fabrication drawings or review screens.

How to Use

  1. Type TDF in the Rhino command line.
  2. Select both the Text and the Solid Object to use as reference.
  3. Finds the front boundary position of the Solid based on the current View and moves the selected Text to that position.

Usage Example

Key Details

ItemDescription
FunctionMoves selected Text to the front of the Solid.
Selection TargetMust select both Text Object and Brep/Solid Object together.
Front ReferenceIn Front View, moves Text to the front Y position of the Solid BoundingBox.
Top ReferenceIn Top View, moves Text to the top Z position of the Solid BoundingBox.
Note: Must select both Text and Brep together. Top/Front situation is determined by current CPlane normal. At Front reference, Text moves to minimum Y of Brep; at Top reference, Text moves to maximum Z position to appear in front of the model.
