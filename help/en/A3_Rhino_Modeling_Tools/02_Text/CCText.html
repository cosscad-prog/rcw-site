CCText

A command to continuously generate Circle Text with numbers inside circles. When you enter a starting number, the number increases by 1 each time you place a point.

Purpose

Used to quickly place visually distinct text markers by creating circular markers and text together, such as number plates, location markers, and fabrication diagram labels.

How to Use

  1. Type CCText in the Rhino command line.
  2. Enter the starting number. The default value is 1.
  3. Click on a position in the viewport to create a circled number at that location.
  4. Continue clicking on the next positions to sequentially increase the number.
  5. Press Enter or Cancel to finish the command.

FunctionCreates Circle Text with numbers.
Number IncrementEach click creates Text with the current number and automatically increments to the next number.
Text SizeUses the Text Size saved by the TTS command. If smaller than the current DimStyle TextHeight and DimensionScale, the DimStyle reference size takes priority.
Note: Circled number markers are created based on the current text size and selected position. To place multiple markers in the same style, it is recommended to match the DimStyle's TextHeight before running the command.
