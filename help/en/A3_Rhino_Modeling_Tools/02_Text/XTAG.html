XTAG

A utility command for text creation, alignment, resizing, and text list creation.

Purpose

Used to align text based on the X position of Text objects, neatly organizing the positions of drawing text or tags arranged vertically.

How to Use

  1. Enter XTAG in the Rhino command line and press Enter.
  2. Select the target object as prompted.
  3. Press Enter to complete the command and verify the result on the Rhino screen or command line.
Note: XTAG is an auxiliary command that aligns text based on the X position of Text objects. It only adjusts placement coordinates without changing text content, so verify the reference Text position before alignment.
