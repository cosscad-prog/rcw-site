Tlist  —  Text

Tlist

A command to create a quantity list by aggregating selected Text content by name. It collects identical Text strings, calculates quantities, and writes them in table form on the Rhino screen.

Purpose

Used to quickly review the quantity of identical annotations or check for missing annotations by writing selected Text strings as a list on the screen.

How to Use

  1. Type Tlist in the Rhino command line.
  2. Select the Text Annotations to create a list.
  3. Specify the position where the list will be placed according to the command prompt.
  4. A quantity list by name of the selected Text is created on the screen.

Note: Collects the selected Text strings as is and writes them as a list on the screen. Useful for checking quantities by duplicate names, but TextDot is not a target, so use Dotlist for DotText annotations.
