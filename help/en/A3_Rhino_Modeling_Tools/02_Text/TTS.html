TTS  —  Text

TTS

A command to store the standard size value for Text generated by RCW commands. This value is used by text creation commands such as CCText and Tlist.

Purpose

Used to adjust the size of selected Text at once and unify the size of drawing annotations. Suitable for organizing TextHeight before printing.

How to Use

  1. Type TTS in the Rhino command line.
  2. Enter the Text Size value to use at the Enter Text Size prompt.
  3. Press Enter to save the entered value as the Text Size for the current session.

Key Details

ItemDescription
FunctionSaves the TextSize variable with the entered value.
Default ValueThe currently saved Text Size is displayed as the default value in the prompt.
DimStyle ReferenceSome text creation commands compare the TTS value with the current DimStyle's TextHeight × DimensionScale value and use the larger value.

Commands Using This

CommandDescription
CCTextUsed for the Text size of circled numbers.
TlistUsed for the Table/Text size of Text quantity lists.
Other Text CommandsApplied to text creation commands within RCW that use TextSize_CurrentDim.
Note: Changing text size adjusts the height value of the TextEntity, not the content of the selected Text. When creating regular Text with DTT later, the current DimStyle text height also affects it.
