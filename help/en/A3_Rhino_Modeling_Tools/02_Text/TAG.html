TAG  —  Text

TAG

A command to align selected Text with single-line spacing. In Front View, it organizes by Z direction; in Top View, it organizes by Y direction.

Purpose

Used to neatly organize scattered Text objects according to a standard and arrange drawing annotations visually. Text content is maintained while only the placement is organized.

How to Use

  1. Run TAG in a View where you can select the Text Annotations to align.
  2. Select the Text objects to align.
  3. The selected Text objects are repositioned at regular intervals based on the lowest Text among them.

Usage Example

Key Details

ItemDescription
FunctionAligns selected Text Annotations based on position.
Alignment SpacingApplies approximately 1.6 times spacing based on the height of the first reference Text.
View ReferenceIn Front View, alignment is by Z direction; in Top View, alignment is by Y direction.
Note: Text alignment commands reposition objects without modifying their content. If annotation order is important, organize the reference Text and selection range before aligning.
