VB  —  View

VB

A command to set the construction plane (CPlane) of the current active viewport based on the start and end point directions of the selected Curve or Line.

Purpose

Used to quickly align the view direction or working reference based on the BoundingBox or arrangement state of the selected object, making model review and subsequent work convenient.

How to Use

  1. Type VB in the Rhino command line and press Enter.
  2. At the prompt "Select the line to use as the CPlane reference", select the reference Curve.
  3. The start point of the selected Curve becomes the CPlane origin, and the direction from the start point to the end point becomes the CPlane X-axis.

Operation Standards

ItemDescription
Selection TargetSelect a Curve object. Even if not a straight line, it can be selected, but the actual reference is the direction connecting the start and end points of the Curve.
CPlane OriginUses the start point (PointAtStart) of the selected Curve.
X-Axis ReferenceUses the unit vector from the start point to the end point (PointAtEnd) of the selected Curve.
Y-Axis ReferenceCalculates the direction perpendicular to the X-axis in Top View using the cross product of World Z-axis and X-axis (WorldZ x XAxis).
Z-Axis Parallel ExceptionIf the selected line is parallel to the World Z-axis and Y-axis cannot be calculated, the World Y-axis is substituted as the Y-axis.
Application ScopeChanges only the Construction Plane of the current active viewport.

Execution Result

ItemDescription
Processing ResultCPlane is applied to the active viewport with the start point of the selected Curve as the origin and the direction from start point to end point as the X-axis.
View ChangeDoes not change the screen View direction. Changes only the working plane and redraws the screen.
Command Line OutputOn success, CPlane origin, X-axis, and Y-axis information are output to the command line.
Caution: A Curve with identical start and end points cannot create a CPlane. Also, when a curve is selected, the direction connecting the start and end points is used as the X-axis, not the actual tangent of the curve.
