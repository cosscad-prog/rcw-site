CP  —  View

CP

A command to set the construction plane (CPlane) of the current active viewport based on the direction of the selected Surface.

Purpose

Used to align only the CPlane of the current viewport with the center and normal direction of the selected Surface. Suitable when you want to keep the View direction while attaching the working plane to the surface.

How to Use

  1. Type CP in the Rhino command line and press Enter.
  2. At the Select Surface Brep Objects prompt, select the Surface to be used as the reference.
  3. The CPlane of the active viewport is changed based on the center and normal direction of the selected Surface.

Operation Standards

ItemDescription
Selection TargetSelect Surface/Brep Face.
CPlane OriginUses the area centroid point (AreaMassProperties.Centroid) of the selected Surface.
CPlane DirectionFinds the closest UV position from the Surface center point and uses the Surface Normal at that position as the normal direction of the CPlane.
Application ScopeChanges only the Construction Plane of the current active viewport.
View ChangeDoes not change the screen View direction. Changes only the working plane.

Execution Result

ItemDescription
Processing ResultCPlane matching the selected Surface is applied to the active viewport and the screen is redrawn.
Grid SettingsWithin the command, CPlane Grid Line Count is set to 10 and Grid Spacing is set to 10.
Note: If Surface selection is canceled or Surface center/normal calculation fails, the default Plane value in the code may be used. For accurate results, select a valid Surface Face.
