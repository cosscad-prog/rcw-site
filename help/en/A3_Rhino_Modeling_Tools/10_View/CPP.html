CPP

A command to set the construction plane (CPlane) of the current active viewport using both the normal direction of the selected Surface and the direction of the selected Edge Line.

Purpose

Used as an auxiliary construction plane setting command when you need to establish a CPlane more clearly using the relationship between two Surfaces or reference objects. Used when a single Surface-based CP provides insufficient direction information.

How to Use

  1. Type CPP in the Rhino command line and press Enter.
  2. At the Select Surface Brep Objects prompt, select the Surface to be used as the reference for the CPlane's surface direction.
  3. At the Select Edge Line prompt, select the Edge to be used as the reference for the CPlane's origin and X-axis.
  4. The CPlane of the active viewport is changed based on the selected Surface and Edge.

Operation Standards

ItemDescription
Surface SelectionCalculates the area centroid of the selected Surface, and uses the Normal at the closest UV position to the centroid as the reference for the CPlane's Z direction.
Edge SelectionUses the start point of the selected Edge Curve as the CPlane origin.
X-Axis ReferenceUses the tangent direction at the start point of the selected Edge Curve as the CPlane X-axis.
Y-Axis ReferenceCalculates the Y-axis using the cross product of the Surface Normal direction and Edge X-axis direction (Z_Vec x X_Vec).
Application ScopeChanges only the Construction Plane of the current active viewport.
View ChangeDoes not change the screen View direction. Changes only the working plane.

Execution Result

ItemDescription
Processing ResultCPlane is applied to the active viewport with the start point of the selected Edge as the origin and the Edge direction as the X-axis.
Grid SettingsWithin the command, CPlane Grid Line Count is set to 10 and Grid Spacing is set to 10.
Note: Both Surface and Edge must be selected correctly to create the intended CPlane. Since the start point direction of the Edge determines the origin and X-axis, select the Edge in the opposite direction if an opposite direction is needed.
