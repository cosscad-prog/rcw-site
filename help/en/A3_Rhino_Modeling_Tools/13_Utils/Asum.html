Asum

Command to sum the area of planar faces in the selected Surface/Brep and write the total value as text on the drawing.

Purpose

Used to quickly verify area review values for panels, glass, back panels, etc., by summing the areas of selected Surface/Brep objects.

How to Use

  1. Type Asum in the Rhino command line and press Enter.
  2. At the Select Surface Object prompt, select one or more Brep/Surface objects to sum their areas.
  3. Click the location where you want to write the total text.
  4. The total area of the selected objects is written as two lines of text showing mm2 and M2.

Execution Example

Code-Based Operation

ItemDescription
Selection TargetSelects multiple ObjectType.Brep objects.
Calculation TargetOnly planar faces with IsPlanar property (based on current model tolerance) from each Brep are included in the area summation.
Area OutputTo the command line, area is output in Surface Area format by object number and face number.
Drawing TextBased on the selected point and aligned to the current CPlane, writes Total mm2 and Total M2 text.
LayerText is written to the Text layer. If the layer doesn't exist, it is created.
Text SizeObtained from Func.TextSize_CurrentDim() based on current Dimension/Text settings.
Note: Non-planar faces are excluded from the summation. If the total area of the entire Brep including curved surfaces is needed, results may differ from Rhino's default area calculation.
