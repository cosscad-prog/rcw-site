AWT

AWT

Command that calculates the aluminum unit weight of each picked section Surface and writes it straight into the Unit Weight field of Pname. It is the same value as the AL Weight that WT writes on the screen as text.

How to Use

  1. Type AWT in the Rhino command line and press Enter. You can also pick the sections first and then run it.
  2. At the Select section surfaces to write the aluminum unit weight prompt, pick the section Surfaces and press Enter. You can pick several at once.
  3. The command line shows AWT: name old -> new kg/m for each section, and the last line shows how many were written and how many were not.

Calculation Details

ItemDescription
Unit weightarea (mm²) * 2.71 * 0.001 kg/m, 3 decimal places (the same formula as the AL Weight of WT)
AreaThe actual (trimmed) area of the picked Surface Face. Holes are excluded.
UnitsIf the document unit is not mm, the area is converted to mm² first.

When Nothing Is Written

CaseCommand line message
A Surface never saved with Pnameno Pname record — save it with Pname first.
Material is Steel, Accessory or SubtracterReports the material, for example Material is 2. Steel, not aluminum, together with the aluminum value.
A section made of two or more facesShows the calculated value. Type it into Pname's Unit Weight field and press Save.
Already the same valueNot written; counted as already the same.

Code-Based Operation

ItemDescription
Material Not SelectWritten, with (Material = Not Select) at the end of the line.
Composite profileEach member gets its own unit weight. If the composite has its own unit weight set, that value is kept and reported.
Pname panelIf an open Pname panel shows that section (or its composite), its Unit Weight field is updated too.
UndoOne Undo restores all sections written in that run.
Note: Members that are already modeled keep their old unit weight (the same as saving with Pname). Model them again to update lists and tables. An open Dtable window holds the values from when it was opened, so reopen Dtable after AWT before saving there.
