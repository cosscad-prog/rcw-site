Acad_Join  —  joining the AutoCAD way

Acad_Join

Joins what you picked in one go - it does not ask for the next object one at a time the way Rhino's built-in Join does. It takes surfaces and polysurfaces as well as curves.

Purpose

Run Rhino's Join first and it asks you to pick one object, then pick the next. To anyone used to AutoCAD's JOIN, that is a detour. Acad_Join lets you sweep several up with a window or crossing and finish with Enter. Selecting first and then running the command works too.

How to Use

  1. Run Acad_Join. (prompt: Select curves, surfaces or polysurfaces to join)
  2. Pick what to join - one at a time, or with a window or crossing. At least two are needed.
  3. Press Enter.
You may also select first and then run Acad_Join.

Worth knowing

ItemDescription
Curves and surfaces together Curves do not join to surfaces, so each kind is joined among its own. If only one kind joins, only that one changes.
What it acceptsCurves, surfaces, polysurfaces and extrusions. An extrusion is converted to a Brep for the join - Rhino's own Join does the same at that point.
Result's propertiesTaken from the first object picked - its layer and colour. Same rule as Rhino's Join.
What has to meetCurve ends, or surface edges, must meet within the model tolerance.
Edges and facesNot join targets, so they cannot be picked.

When it does not work

What the command line saysWhat it means
Joining needs at least two objects of the same kind. You picked, say, one curve and one surface - only one of each kind.
No curve ends met within the model tolerance, so no curves were joined. The ends do not meet. Check the tolerance, or close the gap.
No surface edges met within the model tolerance, so no surfaces were joined. The surfaces' edges are not touching.
On success the command line says how many became how many - 5 curves joined into 1.
