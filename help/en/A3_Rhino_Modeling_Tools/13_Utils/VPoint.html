VPoint

VPoint

Command to display the Vertex positions of selected Solid/Brep objects as actual Point objects.

Purpose

Used to extract Brep vertex positions as Points and utilize them as dimension reference points, review points, and subsequent snap references.

How to Use

  1. Type VPoint in the Rhino command line and press Enter.
  2. At the Select Brep Object for All Vertex prompt, select one or more Brep objects to check vertices.
  3. Point objects are created at each Vertex location of the selected Brep.

Execution Example

Code-Based Operation

ItemDescription
Selection TargetSelects multiple ObjectType.Brep objects.
Vertex ExtractionIterates through the Vertices list of each Brep and retrieves BrepVertex.Location values.
Point CreationAdds a Rhino Point object at each Vertex location.
Command Line OutputOutputs the count of created Vertex Points as BrepVertex Count.
Caution: This is not a command that turns on control points for editing shape like Rhino's SolidPtOn. VPoint only creates Point objects to verify Vertex positions. Moving the created Points does not modify the original Solid/Brep shape.
