Erase  —  deleting the AutoCAD way

Erase

Deletes objects. It behaves like AutoCAD's ERASE: it takes what you pick whether you run the command first or select first.

Purpose

Anyone long used to AutoCAD types E, picks, and presses Enter. Rhino's Delete only works the other way round - pick first, then press it. Erase accepts both orders, so the habit does not have to change.

How to Use

OrderWhat happens
Command first
Erase → pick → Enter		 The prompt reads Select objects to delete. Pick them one by one, or sweep them up with a window or crossing. Enter deletes them.
Selection first
pick → Erase		 What is already selected is the target. There is nothing to pick again.

Worth knowing

ItemDescription
What it deletesEvery kind of object - curves, surfaces, solids, blocks, dimensions, text alike.
GroupsPicking something in a group takes the whole group.
Edges and facesCannot be picked. An edge or a face cannot be deleted on its own, so sub-object selection is turned off from the start.
UndoUndo brings them back, as with any Rhino deletion.
Pressing Enter with nothing selected does nothing and ends the command. Esc leaves it as well.
