VAD, VAF, VLO  —  Vision

VAD VAF VLO

Commands to directly toggle the Vision state of objects. Changes object display properties independently of Layer display state, hiding/showing objects without deletion.

Purpose

Used to control the display/hide state of selected objects, allowing you to keep only necessary objects during work or restore hidden objects to view.

Command Functions

CommandFunctionOperation
VADSelected Object Vision OnShows only selected objects and hides all unselected objects.
VAFSelected Object Vision OffHides only selected objects.
VLOAll Object Vision OnRestores the display properties of document objects, including hidden ones.

How to Use

  1. Run VAD and the "Select objects to keep visible" prompt appears. Select one or more objects to keep, and unselected objects are hidden.
  2. Run VAF and the "Select objects" prompt appears. Select one or more objects to hide, and their display properties are turned off.
  3. Run VLO without additional selection. Hidden objects' display properties are restored and the screen is refreshed.

Code-Based Operation

ItemDescription
VAD Selection MethodSelects one or more objects of all types (ObjectType.AnyObject) using GetObject. Saves selected object IDs, then iterates through all document objects and hides those not selected and not currently hidden using doc.Objects.Hide.
VAF Selection MethodClears all previous selection and selects new objects. PreSelect is disabled, so only newly selected objects are processed. Sets selected objects' Attributes.Visible value to false and saves changes.
VLO Restoration MethodGets the object list including Hidden, Locked, and Reference objects from ObjectEnumeratorSettings, then sets each object's Attributes.Visible value to true.
Relationship with LayerNot a command to turn Layers on or off. Changes object display/hide properties independently of Layer state.
Screen RefreshEach command redraws the Rhino View after processing.

Cautions

ItemDescription
No DeletionObjects are not deleted. Only their hidden state is changed.
VAD ResultHides all unselected objects, used to narrow the work scope and view specific objects only.
VAF ResultHides only selected objects, used to temporarily remove obstructing objects for a clean view.
VLO ResultRestores objects in Vision Off state to visibility. Includes hidden, locked, and reference objects in the enumeration.
Note: After running VAD, the number of hidden objects is output to the command line. Run VLO to view all objects again.
