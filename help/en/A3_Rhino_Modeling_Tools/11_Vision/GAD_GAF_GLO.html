GAD, GAF, GLO  —  Vision

GAD GAF GLO

Commands to toggle the Vision state of objects on a Group basis. Changes object display properties independently of Layer display state, hiding/showing objects without deletion.

Purpose

Used to hide or display objects by Group, allowing focused review of specific component groups in complex models. Adjusts object display properties without turning off Layers.

Command Functions

CommandFunctionOperation
GADSelected Group Object Vision OnShows only the selected Group and hides other Group objects.
GAFSelected Group Object Vision OffHides only objects belonging to the selected Group.
GLOAll Group Object Vision OnRestores the display properties of objects, including hidden ones.

How to Use

  1. Run GAD and the Select Group objects prompt appears. Select one or more Group objects to keep visible.
  2. Run GAF and the Select Group objects prompt appears. Select one or more Group objects to hide.
  3. Run GLO without additional selection. Hidden objects' display properties are restored and the screen is refreshed.

Code-Based Operation

ItemDescription
Group SelectionUses GroupSelect = true in GetObject. Previous selection is cleared before command execution, and PreSelect is disabled so only newly selected Groups are processed.
Group Index CollectionGets the first Group Index from Attributes.GetGroupList() of selected objects and creates a unique list of selected Groups.
GAD ProcessingIterates through all Groups in the document. Sets Visible = true for objects in selected Groups and Visible = false for objects in unselected Groups.
GAF ProcessingFor each selected Group Index, finds Group objects with doc.Objects.FindByGroup(index) and sets their Visible value to false.
GLO ProcessingGets the document object list including Hidden, Locked, and Reference objects, then sets each object's Visible value to true.
Relationship with LayerNot a command to turn Layers on or off. Changes object display/hide properties independently of Layer state.
Screen RefreshEach command redraws the Rhino View after processing.

Cautions

ItemDescription
No DeletionObjects are not deleted. Only their hidden state is changed.
GAD ResultHides unselected Group objects, used to view a specific Group only.
GAF ResultAll objects belonging to the selected Group are hidden. Does not hide only some objects within a Group.
GLO ResultReferenced as Group Object Vision On, but the current code implementation restores display properties of document objects overall without Group filtering.
Note: GAD/GAF operates based on objects belonging to Groups. Selecting objects without Groups will not include them in the selected Group list, potentially producing unexpected results.
