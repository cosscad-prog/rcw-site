FSC  —  16_Stretch

FSC

A Drawing Shortening command that automatically compresses a selected Rhino drawing area only along the CPlane X (U) direction.
It analyzes the dimension-point layout, shrinks only the long spans by ratio, and keeps the dimension values at their original measurements after shortening.

Purpose

When the actual geometry length exceeds the length that fits the form, only the spans longer than a reference value are selectively compressed to display the drawing shorter. Geometry, dimensions, text, points, etc. are moved/transformed together to reduce the X-direction length of the drawing.

Workflow

OrderStepDescription
1Drag-select areaAfter running the command, drag the drawing area to compress with the mouse. The drag rectangle is computed against the current view's CPlane.
2Auto-collect objectsCollects objects that overlap or sit inside the selection window. Locked/hidden/deleted objects are excluded.
3Profile recognitionReads the drawing number from the Text on layers starting with Profile, and looks up the min_ds value in AutoScale.dat by the first word.
4Collect dimension pointsUses the smallest U coordinate of NC_BottomPoint as the left reference, and collects the U coordinates of LinearDimension endpoints and Point objects.
5Analyze spansClassifies only spans where the distance between consecutive dimension points is larger than min_ds as compression targets.
6Enter target distanceShows the current total width and the minimum achievable width, then prompts for the target compression distance. Pressing Enter alone uses the minimum achievable width.
7Lock dimensionsLinearDimensions larger than min_ds have their current measured value converted to fixed text, so the original dimension is shown even after compression.
8Per-span stretchStarting from the rightmost span, pulls the control points/objects to the right of each compression span's center along the CPlane X direction.

Prerequisites

ItemDescription
NC_BottomPoint layer PointThe left reference U coordinate of the drawing. If absent, the left U coordinate of the drag selection window is used as the reference.
LinearDimensionThe basis for collecting the dimension endpoints of the spans to compress. At least 2 dimension points are required.
Profile* layer TextReads the drawing number to find the per-profile min_ds in AutoScale.dat.
AutoScale.dat in the RCWFolder folderThe file of per-profile compression reference values. If it is missing or the profile is not found, the default min_ds=100 is used.

How to Use

  1. Confirm that LinearDimensions and the needed reference Points are placed in the drawing.
  2. Type FSC in the Rhino command line and press Enter.
  3. When the "FSC: Drag to select the drawing area to compress." message appears, drag the drawing area to compress with the mouse.
  4. The selected objects are highlighted, and the dimension-point and compression-target span information is printed in the command line.
  5. At the "Target compression distance" prompt, enter the desired final width. Pressing Enter alone applies the minimum achievable width.
  6. The drawing is automatically compressed along the CPlane X direction, and the number of compressed spans and the total shortened distance are printed in the command line.

Key Details

ItemDescription
Selection methodObjects are auto-collected by a mouse drag window, not the standard Rhino selection prompt. Right-click or Esc cancels.
Compression directionCompresses along the XAxis direction of the current view's CPlane. This may differ from the model world X axis.
Compression basisOnly spans longer than the min_ds read from AutoScale.dat are compressed. The default is 100.
Minimum span sizeA compression-target span keeps a minimum length of 30.
Target distance correctionIf the entered target distance is smaller than the minimum achievable width, it is corrected to the minimum. If it is greater than or equal to the current width, no compression is performed.
Dimension lockLinearDimensions larger than min_ds are converted to backtick (`) fixed text and keep their original measured value.
Curve handlingAmong NURBS control points, only those to the right of the compression reference line are moved.
Brep handlingThe object is moved when the entire Brep is to the right of the compression reference line.
Annotation handlingFor a LinearDimension, if only one endpoint is to the right of the reference line, only that endpoint moves; if both are, the whole dimension moves.
EnvironmentRhino

AutoScale.dat Reference

ItemDescription
File locationAutoScale.dat in the RCWFolder folder
Profile nameUses the first word of the Profile* layer Text. The first word is up to the - or a space.
Columns usedIn a tab-separated row, [0] is the profile name and [1] is used as min_ds.
DefaultIf the file is missing or the profile is not found, min_ds=100 is used.

Result

ItemDescription
Drawing compressionThe target spans are shrunk by ratio along the CPlane X direction.
Dimension preservationThe dimensions of long spans are locked to their original measured values, so the actual dimension is shown even after shortening.
Command-line outputThe dimension-point count, total width, minimum achievable width, per-span compression distance, and total shortened distance are printed.
Note: The Rhino version behaves differently from the AutoCAD help's excluded-span selection, MinFabdist auto value, and NC data table move features. Based on the current code, processing centers on the drag selection area, min_ds, and the target compression distance input.
Caution: If there are not enough LinearDimensions or Point references inside the selection range, it does not run and shows a Not enough dimension points message. Since the compression direction depends on the current CPlane, check the CPlane direction before running.
