SST  —  16_Stretch

SST

A stretch command built to behave like AutoCAD STRETCH inside Rhino.
It moves the control points or objects inside the dragged window by the vector from the base point to the to-point, stretching or shrinking the geometry.

Purpose

Used to select part of a drawing and move endpoints, dimension endpoints, block insertion points, points, etc., while keeping the unselected parts in place and deforming curves and dimensions. In particular, it is for performing AutoCAD's Crossing-Window-based Stretch within Rhino on 2D drawings.

Selection Method

Drag directionBehavior
Drag to the rightWindow selection. Only objects whose BoundingBox fits entirely inside the selection window are selected. Shown on screen as a blue window.
Drag to the leftCrossing selection. Objects whose BoundingBox overlaps the selection window are selected. Shown on screen as a green window.
Right-click or EscCancels the command.

Workflow

OrderStepDescription
1Define drag windowDrag the Stretch target area with the mouse. The selection window is computed in U/V coordinates against the current view's CPlane.
2Collect objectsExcludes locked, hidden, and deleted objects and collects objects matching the Window or Crossing condition.
3Extract control pointsFinds Curve control points, Brep Vertices, Points, Block insertion points, LinearDimension endpoints, etc. inside the selection window.
4Highlight selectionPre-highlights the selected objects in yellow.
5Enter base pointSpecify the move base point at the "Base point" prompt.
6Enter to-pointSpecify the point to move to at the "To point" prompt. A yellow DynamicDraw preview is shown while moving.
7Modify objectsMoves the inside-window control points or the whole object according to per-object-type rules.
8Clean upClears the selection and runs _PointsOff to turn off any remaining control-point display.

How to Use

  1. Type SST in the Rhino command line and press Enter.
  2. When the "Drag to define the Crossing Window. (Esc: cancel)" message appears, drag the area to Stretch.
  3. Dragging to the right selects only fully-enclosed objects; dragging to the left also selects crossing objects.
  4. Pick the base point at the "Base point" prompt.
  5. Pick the destination at the "To point" prompt.
  6. The control points or objects inside the selection window are moved by the base-to-target vector, and the number of modified objects is printed in the command line.

Per-Object-Type Handling

Object typeHandling
CurveConverted to a NURBS Curve, then only the control points inside the selection window are moved. Control points outside the window are kept as-is.
BrepMoves the entire Brep only when its BoundingBox fits entirely inside the selection window. It does not move only some Vertices.
BlockIf the Block Instance's insertion point is inside the selection window, the whole block is moved.
PointMoved entirely when its BoundingBox fits entirely inside the selection window.
HatchMoved entirely when its BoundingBox fits entirely inside the selection window.
LinearDimensionEvaluates the two ExtensionLine endpoints individually. If only one endpoint is inside the window, only that endpoint moves; if both are inside, the whole dimension moves.
Other AnnotationMoved entirely when its BoundingBox fits entirely inside the selection window.

Key Details

ItemDescription
Coordinate basisThe selection window and inside-test are computed against the current viewport's CPlane.
Move amountUses the 3D vector from the base point to the to-point directly.
PreviewWhile entering the to-point, the Curve deformation result and the fully-enclosed object move result are shown in yellow.
Zero moveIf the base point and to-point are the same so the move amount is 0, no object is modified.
ResultOn completion, the message SST done: n objects modified. is printed.
EnvironmentRhino

Differences from AutoCAD Stretch

ItemDescription
Selection inputUses the command's own mouse drag window, not the standard Rhino selection prompt.
Curve handlingA selected Curve is deformed based on NURBS control points. Depending on the curve type, the control-point deformation result may look different from the original shape.
Brep handlingA Brep is not partially Stretched; it is only moved entirely when fully enclosed.
Block handlingMoved entirely based on the insertion point. The geometry inside the block is not partially Stretched.
Note: SST runs only if there is at least one control point inside the selection window. Even if objects are selected, it does not run when there is no movable control point or base point inside the window.
Caution: The selection-window test is CPlane-based. If the drawing orientation and CPlane direction do not match, unexpected objects may be selected or deformed. Check the working view and CPlane before running.
