WebV

WebV

Command to convert the selected Rhino model to GLB for viewing in a Web Browser and automatically open the local WebViewer.

Purpose

Used to open the current model or exported web viewer results on a local web server and verify the 3D state in a browser.

How to Use

  1. Type WebV in the Rhino command line and press Enter.
  2. At the Select objects to view in WebViewer (custom GLB) prompt, select objects to view in the web viewer.
  3. At the Polygon reduce ratio (0.5~1.0, Enter=original) prompt, enter the reduce ratio. Pressing only Enter uses the original ratio 1.0.
  4. The selected model is converted to GLB data, and the browser opens at http://localhost:8765/glb.

Execution Example

Code-Based Operation

ItemDescription
Selection TargetCan select ObjectType.AnyObject, and also allows group selection with GroupSelect = true. SubObject selection is not used.
Reduce RatioCan input from 0.5 to 1.0. Default is 1.0. Smaller values reduce polygons to make web display data lighter.
GLB ConversionRhinoMeshExporterGLB converts selected objects to Progressive GLB chunks by layer. Uses render mesh cache, smooth normal, color/layer/block color inheritance, and mesh quantization.
Transmission MethodConverted GLB chunks are registered on the local HTTP server and transmitted with gzip compression on browser request.
Local ServerWebViewerServer runs on localhost:8765. /glb provides Viewer HTML, and /model/count and /model/{index} provide GLB chunks.
Browser LaunchAfter conversion, opens the default browser and navigates to http://localhost:8765/glb.

Web Viewer Basic Operations

OperationDescription
OrbitWith the Orbit button selected in the top toolbar, drag the right mouse button to rotate the model.
PanWith the Pan button selected in the top toolbar, drag the right mouse button to pan the view.
ZoomRoll the mouse wheel to zoom in/out. Camera moves based on mouse position.
ResetThe Reset button in the top toolbar resets the camera direction to initial Isometric state and fits the entire model to the screen.
FitThe Fit button in the top toolbar executes Zoom Extents to fit the entire current model in view.
HelpClicking the Help button in the top toolbar opens an operation shortcut guide panel within the WebViewer.

Zoom Window Usage

  1. Press keyboard W on the browser screen.
  2. Then press Space or Enter to activate Zoom Window mode and the cursor changes to a crosshair.
  3. Drag the left mouse button to define a rectangle over the area you want to zoom in.
  4. Release the mouse button to zoom to the center of the defined area.
  5. Press Esc to cancel during the process.

Display Options

OptionDescription
ShadedToggles shaded display of the model on/off.
GhostConverts the model to semi-transparent display to easily check internal or rear objects.
GridToggles reference grid display on/off.
SectionToggles Section Cut on/off. Can adjust X/Y/Z cutting axis and cutting position in Panel.
SaveSaves the current WebViewer model as a standalone executable web file.
PanelOpens and closes the right Display Control panel. Drag the panel top to move its position.

Display Control Panel

ItemDescription

AmbientAdjusts the Ambient Light intensity of the scene.
ProjectionSwitches between Persp and Ortho projection modes. Default is Ortho.
ExplodeUses slider to separate model elements and check assembly relationships.
Section CutSelects X/Y/Z axis and adjusts cutting position with slider. Cutting results are visible when toolbar Section is enabled.

Execution Result

ItemDescription
Command Line OutputOutputs number of selected objects, conversion time, number of GLB chunks, total size, and browser URL.
Web ViewerA WebViewer opens in the browser where you can rotate, zoom in/out, and verify the selected model.
File SavingWebV is a command to view immediately in a web browser. For exporting as a web file, use the ToWebFile command.
Note: WebV converts selected objects to temporary GLB data and displays it on a local server. It does not upload to an external internet server and uses the localhost address on the current PC.
