ToWebFile

ToWebFile

Command to save the selected Rhino model as a single HTML file with embedded GLB data. The saved HTML file can be opened in a Web Browser by double-clicking without Rhino, and can be shared with other users to share the model.

Purpose

Used to export the selected model as a web-viewable file and HTML viewer format to create external reviews or 3D previews for sharing.

How to Use

  1. Type ToWebFile in the Rhino command line and press Enter.
  2. At the ToWeb: Select objects to save as HTML prompt, select objects to export to HTML.
  3. At the Polygon reduce ratio (0.1~1.0, Enter=original) prompt, enter the reduce ratio. Pressing only Enter uses the original ratio 1.0.
  4. At the Use KHR_mesh_quantization compression? (Y/N, Enter=N) prompt, select the compression option. Default is N.
  5. In the save dialog, specify the HTML filename and location.
  6. After saving is complete, the generated HTML file opens immediately in the default browser.

Execution Example

Code-Based Operation

ItemDescription
Selection TargetCan select ObjectType.AnyObject, and also allows group selection with GroupSelect = true. SubObject selection is not used.
Reduce RatioCan input from 0.1 to 1.0. Smaller values reduce polygons to decrease file size, but may simplify the shape.
QuantizationEntering Y or YES uses KHR_mesh_quantization compression. Default is not used.
GLB ConversionRhinoMeshExporterGLB converts selected objects to GLB. Includes color, layer, block color inheritance, and text conversion data for WebViewer display.
HTML SavingConverts GLB binary to Base64 data and embeds it in HTML as EMBEDDED_GLB variable. For large models, streams 3MB units to reduce memory burden.
Default Save LocationIf Rhino document is saved, uses the same folder and filename as defaults. If no document path exists, uses desktop and rhino-model.html as defaults.

Difference from WebV

CommandDifference
WebVConverts selected model to temporary GLB and views directly in the localhost:8765 WebViewer on the current PC. Not intended for file saving.
ToWebFileSaves a standalone HTML file with embedded GLB. The saved HTML can be opened by double-clicking and can be shared with other users.

Using Saved HTML

  1. Double-click the saved .html file.
  2. Rhino Web Viewer opens in the browser and loads the embedded model.
  3. Since the model data is included in the file, no separate GLB file or local server is needed.
  4. When sharing with other users, only pass the generated HTML file.

Web Viewer Basic Operations

OperationDescription
OrbitWith the Orbit button selected in the top toolbar, drag the right mouse button to rotate the model.
PanWith the Pan button selected in the top toolbar, drag the right mouse button to pan the view.
ZoomRoll the mouse wheel to zoom in/out.
ResetResets camera direction to initial Isometric state and fits the entire model to the screen.
FitExecutes Zoom Extents to fit the entire current model in view.
HelpOpens an operation shortcut guide panel within the WebViewer.

Zoom Window Usage

  1. Press keyboard W on the browser screen.
  2. Then press Space or Enter to activate Zoom Window mode.
  3. Drag the left mouse button to define a rectangle over the area you want to zoom in.
  4. Release the mouse button to zoom to the center of the defined area.
  5. Press Esc to cancel during the process.
