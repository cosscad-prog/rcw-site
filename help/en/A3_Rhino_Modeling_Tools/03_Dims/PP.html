PP

A command to create one Point in the Dim_Points Layer at a location specified by the mouse.

Purpose

Used to supplement automatic dimension reference points by adding Dim_Points layer Points at user-specified locations. Suitable for adding arbitrary reference points not captured by HPP.

How to Use

  1. Type PP in the Rhino command line.
  2. Click the dimension reference point position at the Click for new point prompt.
  3. Dim_Points Layer Point is created at the clicked location.

Key Details

ItemDescription
FunctionDirectly creates Dim_Points Layer Point.
Usage PurposePrepares dimension reference points to be used when executing DST, DSR, DSL, DSB.
Fabrication Drawing UsageAdding points in advance at necessary locations when creating fabrication drawings such as FDwg makes dimension creation convenient.
Note: To automatically generate multiple points, use HPP which reads endpoints, nodes, and center points of objects.
