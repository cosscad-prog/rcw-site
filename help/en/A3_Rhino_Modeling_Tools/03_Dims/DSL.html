DSL  —  Dims

DSL

A command to create Linear Dimension in the Left direction by selecting Points in the Dim_Points Layer.

Purpose

Used to automatically generate left direction dimensions using reference points prepared in the Dim_Points layer. Quickly organizes left-based width, spacing, and cumulative dimensions.

How to Use

  1. Prepare Dim_Points Points using PP or HPP.
  2. Run DSL and select the Point objects to use for dimensions.
  3. Left direction dimensions are created based on the leftmost X position among the selected Points.

Usage Example

Key Details

ItemDescription
DirectionLeft direction
Target PointsOnly Points in the Dim_Points Layer are used.
Spacing OptionsUses First Dist, Dim Gap, and Left Max settings from DsOpt.
Creation LayerDimensions are created in the DIMS Layer.
Warning: If the selected Point's Layer is not Dim_Points, it will not be used as a dimension reference point.
