HPP  —  Dims

HPP

A command to automatically create Dim_Points Layer Points at key positions of selected Lines, Polylines, Circles, and Arcs.

Purpose

Used to automatically create Dim_Points layer Points at endpoints, nodes, and center points of selected objects—positions necessary for dimensions. It prepares reference points before executing directional automatic dimension commands.

How to Use

  1. Type HPP in the Rhino command line.
  2. Select objects to create dimension reference points.
  3. Dim_Points are created at endpoints, nodes, and center points depending on object type.

Usage Example

Creation Criteria

ObjectCreation Position
LineCreates Dim_Points at start and end points.
PolyLineCreates Dim_Points at each Node position.
CircleCreates Dim_Points at the center of the circle.
ArcCreates Dim_Points at the center of the Arc.

Key Details

ItemDescription
Usage PurposeQuickly prepares dimension reference points to be used in DST, DSR, DSL, DSB.
Fabrication Drawing UsageUseful for adding dimension points in advance needed for fabrication drawing creation such as FDwg.
Note: Use PP when adding a single Point at a desired arbitrary location.
