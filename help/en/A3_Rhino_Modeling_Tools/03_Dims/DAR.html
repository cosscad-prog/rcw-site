DAR  —  Dims

DAR

A command to create general linear dimensions by calling Rhino's Linear Dimension input. It is a dimension command with the same nature as DR in code comments.

Purpose

Used when a user directly specifies two points and a dimension position to create a Linear Dimension. Suitable for temporary measurements or manual correction dimensions when automatic dimension reference points are not available.

How to Use

  1. Type DAR in the Rhino command line.
  2. Specify the first point, second point, and dimension line position using the Rhino Linear Dimension method.
  3. Linear Dimension is created at the specified location.
