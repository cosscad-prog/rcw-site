InterPt

A command to create Points at the intersections between selected Surfaces and Lines.

Purpose

ItemDescription
Intersection CheckMarks the intersection locations between Surfaces and Lines with Points.
Reference Point CreationCreates intersection reference points for subsequent modeling or review work.
Review SupportLets you directly check where Lines actually intersect Surfaces in the viewport.

How to Use

  1. Type InterPt in the Rhino command line and press Enter.
  2. Select the Surfaces where intersection locations will be found.
  3. Select the Lines that intersect the Surfaces.
  4. Check the Points created at the Surface and Line intersection locations in the Rhino viewport.

Usage Example

Key Details

ItemDescription
Target ObjectSurfaces and Lines
Created ObjectPoints at the locations where Surfaces and Lines intersect

Execution Results

ItemDescription
ResultPoints are created at the intersection locations of the selected Surfaces and Lines.
Confirmation LocationCheck the Point objects at the Surface and Line intersection locations in the Rhino viewport.
Note: Select the Curves first, then select the Surface/Brep in the next step. Intersection points are created on the Surface_inter_Pt layer, so check that layer's visibility if the results are not displayed.
