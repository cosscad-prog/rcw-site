SSinter  —  InterLine

SSinter

A command to create Lines at the intersections between selected Surface/Brep objects.

Purpose

ItemDescription
Intersection Line CheckDisplays the locations where two Surfaces or Breps intersect as Lines.
Reference Line CreationCreates reference lines for Surface joints, cutting locations, or subsequent modeling work.
Review SupportLets you directly check the actual intersection locations of two surfaces in the Rhino viewport.

How to Use

  1. Type SSinter in the Rhino command line and press Enter.
  2. Select the first Surface or Brep set for creating intersection Lines.
  3. Select the second Surface or Brep set.
  4. Check the Lines created at the locations where the two object sets intersect in the Rhino viewport.

Usage Example

Key Details

ItemDescription
Target ObjectTwo intersecting Surface or Brep sets
Created ObjectLines at the locations where two Surfaces or Breps intersect

Execution Results

ItemDescription
ResultLines are created at the intersection locations of the selected Surface or Brep sets.
Confirmation LocationCheck the Line objects at the Surface or Brep intersection locations in the Rhino viewport.
Note: Select the first Surface/Brep set and the second Surface/Brep set separately, then the command calculates Brep-Brep intersection lines for every combination. The created lines are placed on the Surface_inter_Line layer.
