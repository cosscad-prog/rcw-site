SSAngle  —  Angle

SSAngle

A command to display normal vectors of 2 selected Surfaces and calculate the angle between them in the Text panel.

Purpose

Used to calculate the angle between two planar Surfaces and display a midway direction arrow to visually verify junction angles or inclination relationships.

How to Use

  1. Type SSAngle in the Rhino command line and press Enter.
  2. Select the first Surface to check the angle.
  3. Select the second Surface.
  4. Check the normal vector display in the Rhino viewport and the calculated angle in the Text panel.

Usage Example

Key Details

ItemDescription
Measurement TargetTwo Surfaces selected by the user
Display ContentDisplays normal vectors of each Surface on screen and outputs the calculated angle value in the Text panel.

Execution Results

ItemDescription
ResultCalculates the angle based on the normal vectors of the two selected Surfaces.
Confirmation LocationCheck the normal vector display in the Rhino viewport and the angle value in the Text panel.
Note: An angle arrow is created only if both selected faces are planar and a shared or intersecting Edge can be found. The normal of the first face is reversed in internal calculations, so the displayed intermediate direction may vary depending on selection order.
