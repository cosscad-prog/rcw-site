SSAngle2  —  Angle

SSAngle2

A command to calculate and display the angle between two Surfaces on the intersection line (interLine) where they meet.

Purpose

Used to write the angle value between two planar Surfaces as Text at the common Edge location, leaving angle information directly on the model.

How to Use

  1. Type SSAngle2 in the Rhino command line and press Enter.
  2. Select the first Surface to check the angle.
  3. Select the second Surface.
  4. Check the angle value displayed at the intersection line location of the two Surfaces.

Usage Example

Key Details

ItemDescription
Measurement TargetTwo Surfaces selected by the user
Display ContentDisplays the calculated angle value on the intersection line (interLine) of the two Surfaces.

Execution Results

ItemDescription
ResultWrites the angle value at the intersection line location of the two selected Surfaces.
Confirmation LocationCheck the angle Text displayed around the intersection line of the two Surfaces in the Rhino viewport.
Note: The angle Text is written at the midpoint of the common Edge of two Surfaces, and the text size uses the TextHeight of the current DimStyle. If no common Edge is found, neither the angle value is calculated nor the Text is created.
