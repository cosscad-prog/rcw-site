RDoT  —  DotText

RDoT

A command to repeatedly create DotText with sequential integer numbering.

Purpose

ItemDescription
Repeated CreationCreates DotText objects with sequential integer numbering repeatedly.
Start NumberSpecify the starting number in the options to establish the numbering system.
Number PlacementUsed when quickly placing sequential numbered DotText at multiple locations.

How to Use

  1. Type RDoT in the Rhino command line and press Enter.
  2. Specify the starting number in the options.
  3. Specify the locations where DotText will be placed in order.
  4. Verify the repeatedly created integer DotText in the Rhino viewport.

Usage Example

Key Details

ItemDescription
InputStarting number and DotText placement locations
Created ObjectsSequential integer DotText

Execution Result

ItemDescription
Processing ResultSequential integer DotText is repeatedly created starting from the specified start number.
Verification LocationVerify the created DotText numbers in the Rhino viewport.
Note: Each click creates TextDot that repeats from 1 to Repeat_Number. The number counter is maintained during command execution, and resets to 1 when it exceeds the repeat count.
