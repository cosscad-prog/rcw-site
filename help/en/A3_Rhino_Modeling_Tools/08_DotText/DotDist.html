DotDist  —  DotText

DotDist

A command to calculate the distance between selected integer DotText objects.

Purpose

ItemDescription
Distance CalculationCalculates the distance between selected integer DotText objects.
Display SizeThe size of the result text can be adjusted using the TTS command.
Review AssistanceUsed when verifying the spacing between DotText reference points.

How to Use

  1. Type DotDist in the Rhino command line and press Enter.
  2. Select the integer DotText objects to use for distance calculation.
  3. Complete the selection.
  4. Verify the distance calculation results in the Rhino viewport.

Usage Example

Key Details

ItemDescription
Target ObjectsDotText objects with integer values
OutputDistance values between selected DotText objects

Execution Result

ItemDescription
Processing ResultDistance between selected DotText objects is calculated.
Verification LocationVerify the distance text displayed in the Rhino viewport.
Note: When DotText character values are sequential numbers like 1, 2, the distance between those number pairs is calculated. Pairs with distance less than or equal to 0.5 are excluded, and the result table is written to the Text layer at the specified location.
