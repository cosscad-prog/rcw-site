OffsetSrfPlane

A command that creates a Plane Surface from the selected Surface's Plane and moves it in the opposite Normal direction by a specified distance.

Purpose

ItemDescription
Offset PlaneCreates an Offset Plane Surface based on the selected Surface's Plane.
SrfPlane ExtensionSimilar to SrfPlane, but includes the ability to move in the opposite Normal direction by a specified distance.
Cutting Reference PlanePrimarily used to create a cutting reference plane displaced from the original Surface when cutting specific Solids.

How to Use

  1. Enter OffsetSrfPlane in the Rhino command line and press Enter.
  2. Select the Surface to use as the Plane reference.
  3. Enter the Offset distance as prompted.
  4. Verify the Plane Surface moved in the opposite Normal direction.

Execution Example

Key Details

ItemDescription
InputReference Surface and Offset distance
Created ObjectPlane Surface moved in the opposite Normal direction

Execution Result

ItemDescription
Processing ResultThe Plane based on the selected Surface is created and moved in the opposite Normal direction by the specified distance.
Confirmation LocationVerify the Offset Plane Surface created on the Rhino screen.
Note: First attempts to Offset the selected face in the opposite Normal direction, then retries in the reverse direction if the Normal direction is incorrect. The resulting Plane is created larger than the original BoundingBox (2x) for adequate use as a cutting reference plane.
