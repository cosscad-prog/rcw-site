SrfPlane

A command that creates a Plane Surface based on the Plane direction of the selected Surface.

Purpose

ItemDescription
Surface-based PlaneCreates a new Plane Surface based on the Plane direction of the selected Surface.
Difference from CSrfCSrf copies the exact shape of the selected Surface, but SrfPlane creates the Plane face of the selected Surface.
Cutting Reference PlanePrimarily used to create a Plane Surface reference for cutting specific Solids.

How to Use

  1. Enter SrfPlane in the Rhino command line and press Enter.
  2. Select the Surface to use as the Plane reference.
  3. Verify the Plane Surface to be created based on the selected Surface direction.
  4. Confirm the created Plane Surface on the Rhino screen.

Execution Example

Key Details

ItemDescription
InputSurface from which to extract Plane direction
Created ObjectPlane Surface created based on the selected Surface's Plane direction

Execution Result

ItemDescription
Processing ResultA Plane Surface following the selected Surface's Plane direction is created.
Confirmation LocationVerify the newly created Plane Surface on the Rhino screen.
Note: Creates a Plane from the center point and Normal of the selected Surface, and generates a Plane Surface slightly larger than the original Brep BoundingBox. Results are most predictable when using a planar face as reference rather than a curved surface.
