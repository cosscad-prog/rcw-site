3PPlane

A command that creates a 4-sided Plane Surface based on 3 selected Points.

Purpose

ItemDescription
Plane CreationDefines Plane direction with 3 Points and creates a 4-sided Plane Surface.
Difference from 3PSrfSimilar to 3PSrf, but creates a 4-sided surface instead of a triangular one.
Cutting Reference PlanePrimarily used to create a Plane Surface reference for cutting specific Solids.

How to Use

  1. Enter 3PPlane in the Rhino command line and press Enter.
  2. Specify 3 reference Points in order to create the Plane Surface.
  3. Verify the Plane direction defined by the 3 specified Points.
  4. Confirm the created 4-sided Plane Surface on the Rhino screen.

Execution Example

Key Details

ItemDescription
Input3 Points that define the Plane direction
Created Object4-sided Plane Surface based on the specified Plane

Execution Result

ItemDescription
Processing ResultA 4-sided Plane Surface is created aligned with the direction defined by the 3 Points.
Confirmation LocationVerify the newly created Plane Surface object on the Rhino screen.
Note: Creates a triangular plane Face with 3 points on the Surf layer. Since the Plane direction is determined by the order of point selection, maintain consistent point selection order when using this as a reference plane for subsequent Offset or Vector operations.
