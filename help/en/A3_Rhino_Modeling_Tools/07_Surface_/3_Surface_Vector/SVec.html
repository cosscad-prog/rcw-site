SVec

A command that forcibly assigns X/Y/Z direction Vector information to the selected Surface.

Purpose

ItemDescription
Directionality AssignmentStores desired X/Y/Z direction Vector information on the selected Surface.
FabTable PreparationSupplements surface directionality needed for FabTable creation when using external Modeling data.
Flat Panel Direction OrganizationUsed to forcibly organize the direction of flat panels like Glass Panels and BackPanels.

How to Use

  1. Enter SVec in the Rhino command line and press Enter.
  2. Select the Surface to which to assign Vector information.
  3. Specify the direction as prompted.
  4. Verify the assigned Surface Vector direction on the Rhino screen.

Execution Example

Key Details

ItemDescription
Target ObjectSurface to which to assign Vector information
Color ReferenceRed: X axis direction, Blue: Y axis direction, Green: Z axis direction

Execution Result

ItemDescription
Processing ResultDirection Vector information is assigned to the selected Surface.
Confirmation LocationVerify the Vector display and internal direction information of the Surface on the Rhino screen.
Note: Specifies the X direction by clicking an additional point from the face center, and saves the face Normal as the Z direction. The Y direction is calculated as the Cross Product of Z and X, so incorrectly specifying the X direction point can also affect subsequent Fab/Panel direction interpretation.
