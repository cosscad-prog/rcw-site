CSrf

A command that copies the selected Surface face and creates it as a new Surface object.

Purpose

ItemDescription
Surface CopyCopies the selected Surface face as a separate Brep Surface.
Face SeparationUsed to separate only the required face from an existing object for use as a reference in subsequent operations.
Layer OrganizationThe copied Surface is placed on the Surf layer.

How to Use

  1. Enter CSrf in the Rhino command line and press Enter.
  2. Select the Surface to copy.
  3. Select multiple Surfaces and press Enter to complete the selection.
  4. Confirm the copied Surface object created on the Surf layer.

Execution Example

Key Details

ItemDescription

Created ObjectCopied Surface Brep object

Execution Result

ItemDescription
Processing ResultThe selected Surface face is copied and created as a new Surface object.
Confirmation LocationVerify the copied Surface object on the Rhino screen and on the Surf layer.
Note: Copies the Face of the selected Brep using DuplicateFace(false) and places the new object on the Surf layer. Since the original Solid is not modified, it is convenient to extract only the reference face for use in subsequent Trim or Plane operations.
