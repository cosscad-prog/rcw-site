4PSrf  —  Surface

4PSrf

A command to create a planar Surface from the boundary defined by four user-specified Points.

Purpose

ItemDescription
Point-Based SurfaceCreates a rectangular or four-point planar Surface by directly specifying four Points.
Temporary Face CreationUsed to create a Surface for review or later work when only four corner locations are available.
Planar ConditionCreates a closed boundary Curve from the four specified Points and converts it into a Planar Brep.

How to Use

  1. Type 4PSrf in the Rhino command line and press Enter.
  2. Specify the first Point for the Surface.
  3. Specify the second, third, and fourth Points in order.
  4. Check the Surface created inside the closed boundary formed by connecting the four Points.

Key Details

ItemDescription
InputFour Points specified in the viewport
Created ObjectSurface created from a closed boundary formed by connecting the four Points

Execution Results

ItemDescription
ResultA planar Surface is created using the four specified Points as the boundary.
Confirmation LocationCheck the newly created Surface object in the Rhino viewport.
Note: The command connects the four Points in order to create a closed boundary and then creates a Planar Brep. If the four Points are not coplanar or are picked in a twisted order, Can Not Make Planar Surface may appear.
