3PSrf

A command that creates a planar Surface using 3 user-specified Points as boundaries.

Purpose

ItemDescription
Point-based SurfaceCreates a triangular planar Surface by directly specifying 3 Points.
Temporary Surface CreationUsed to quickly create a Surface for review or subsequent operations when only reference points are available.
Planar ConditionCreates a closed boundary Curve from the specified 3 Points and converts it to a Planar Brep.

How to Use

  1. Enter 3PSrf in the Rhino command line and press Enter.
  2. Specify the starting Point for the Surface.
  3. Specify the second and third Points in order.
  4. Confirm the Surface created within the triangular boundary formed by the three Points.

Execution Example

Key Details

ItemDescription
Input3 Points specified on screen
Created ObjectSurface generated with a closed boundary connecting the 3 Points

Execution Result

ItemDescription
Processing ResultA planar Surface is created with the 3 specified Points as boundaries.
Confirmation LocationVerify the newly created Surface object on the Rhino screen.
Note: Creates a triangular boundary connecting the three points, then generates a planar Surface using CreatePlanarBreps. If the three points are nearly collinear or cannot form a planar boundary, the Surface will not be created.
