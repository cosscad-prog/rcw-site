3CSrf

A command that creates a planar Surface using 3 selected Curves as boundaries.

Purpose

ItemDescription
Curve-based SurfaceCombines 3 Curves to create a closed boundary and generates a Surface.
Layer-based FilterOnly Curves on the same layer as the first selected object are used as Surface creation targets.
Boundary CorrectionIf the combined Curve is not closed, it closes based on tolerance and creates a Planar Brep.

How to Use

  1. Enter 3CSrf in the Rhino command line and press Enter.
  2. Select Curve objects to use as Surface boundaries.
  3. Ensure that 3 Curves on the same layer are included in the selection targets.
  4. Complete the selection to confirm the Surface created by combining the 3 Curves into a closed boundary.

Execution Example

Key Details

ItemDescription
Input3 Curves to use as Surface boundaries
Created ObjectSurface generated by converting 3 Curves to a closed boundary

Execution Result

ItemDescription
Processing ResultA planar Surface is created within the boundary of the 3 selected Curves.
Confirmation LocationVerify the created Surface object inside the Curve boundary on the Rhino screen.
Note: Only Curves on the same layer as the first selected Curve are used, and the Surface is created only when exactly 3 Curves are selected. Open boundaries are closed based on tolerance and converted to a Planar Brep.
