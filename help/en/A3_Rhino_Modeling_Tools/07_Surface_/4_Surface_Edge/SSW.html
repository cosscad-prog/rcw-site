SSW

A command that extracts the Edge Lines of the selected Surface and groups them.

Purpose

ItemDescription
Edge ExtractionExtracts the Edge Lines of the selected Surface.
Difference from ExtractWireframeLike Rhino's built-in ExtractWireframe, creates Edge Lines, but extracts based on faces and groups the result.
Partial Face ProcessingUsed when extracting edges based on a specific face of a Solid.

How to Use

  1. Enter SSW in the Rhino command line and press Enter.
  2. Select the Surface from which to extract edges.
  3. Complete the selection.
  4. Verify the extracted Edge Lines and Group status.

Execution Example

Key Details

ItemDescription
Target ObjectSurface from which to extract edges
Created ObjectGroup of Line objects extracted from Surface edges

Execution Result

ItemDescription
Processing ResultEdge Lines are extracted from the selected Surface and organized in a Group.
Confirmation LocationVerify extracted Edge Lines and Group status on the Rhino screen.
Note: First generates all Edge Curves from the selected Surface, then attempts to Join them. If they form a closed PolyCurve, individual Edge Curves are deleted and only the closed boundary remains, useful for obtaining face outlines as a single object.
