NBlock  —  Block

NBlock NamedBlock

A command to create a Block from selected Objects based on internal Text names. When using the same shape and specification Curtainwall Units repeatedly, managing them as a single Block instead of continuously copying Groups reduces work time and file size.

Purpose

ItemDescription
Block CreationCreates a Block from a Unit after modeling and FabNo organization is complete.
Repeated Unit ManagementUnits of the same size and shape can be created as Blocks and repeatedly placed.
Subsequent List OperationsPrepares Block data for creating Molist, Cuttinglist, and Fblist. Fblist uses a single selected Block.

How to Use

  1. Type NBlock in the Rhino command line and press Enter.
  2. Select Objects to create as Blocks.
  3. If there is Text in the selected Objects, the first Text excluding excluded Texts is used as the Block name.
  4. If there is no Text to use in the selected Objects, enter a new name and specify the Text position on the screen.
  5. If it is a new Block name, specify the Insert Point to create the Block.
  6. If a Block with the same name already exists, the existing Block Definition is updated and the existing placed Instance is recreated in the same position and rotation state.

Usage Example

Key Details

ItemDescription
Block NameUses Text from inside the selected Object. Characters that cannot be used in names / \ : * ? " < > | are replaced with _.
Reference PointFinds the Block reference point at the location where the start points of M_Center and T_Center type Lines coincide. If the reference point cannot be found automatically, the user specifies it directly.
Existing Block HandlingIf a Block with the same name already exists, the Definition is updated with the new shape and the existing Instance is repositioned based on the original Transform.

Cautions

Caution: NBlock must include one M_Center Line. Insert Point is based on the start point of the Mullion Center Line.
Note: Text starting with GS, VT, BP, or GR are not used as Block names. Closed Polylines/PolyCurves in the same group as those Texts may also be excluded from Block targets.
Note: If a Block with the same name was deleted but the Definition remains in Rhino, clean it up with Purge, or Insert the existing Block to check the status before running again.

Execution Result

ItemDescription
Processing ResultSelected Objects are created as Blocks with Text names, or existing Blocks with the same name are updated.
Verification LocationCheck the created Block Instance, Block Insert Point, and Block name Text in the Rhino viewport.
Note: If a block with the same name already exists, the existing definition is deleted and the existing instance in the same location is recreated with the new definition. Since the reference point is found where the start points of Mullion/Transom center lines meet, related center line layers must be selected together for accurate insertion reference.
