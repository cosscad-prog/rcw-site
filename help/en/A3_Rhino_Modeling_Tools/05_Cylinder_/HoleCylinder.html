HoleCylinder

A command to create a new Cylinder with adjusted diameter and length at the Hole location if the selected Solid Object has a Hole.

Purpose

ItemDescription
Hole DetectionCreates a Cylinder based on the Hole location of the selected Solid Object.
Diameter ChangeUsed to change the existing Hole diameter or recreate a processing reference Cylinder.
Length AdjustmentGenerates a Cylinder of required length at each Hole location to be used as a reference for subsequent modeling.

How to Use

  1. Type HoleCylinder in the Rhino command line and press Enter.
  2. Select a Solid Object that includes Holes.
  3. Enter the required values for Cylinder creation following the command prompt.
  4. Check the diameter and length of the Cylinder created at the Hole location in the Rhino viewport.

Usage Example

Key Details

ItemDescription
Target ObjectSolid Object that includes Holes
Created ObjectNew Cylinder created at the Hole location

Execution Results

ItemDescription
ResultA Cylinder with adjusted diameter and length is created at the Hole location of the selected Solid Object.
Confirmation LocationCheck the Cylinder object created at the Hole location in the Rhino viewport.
Note: Creates a separate Cylinder Brep by reading the axis and center of the cylindrical Face. The Cylinder_Diameter and Cylinder_Length options are the size of the display cylinder to be created, not a direct copy of the original hole radius.
