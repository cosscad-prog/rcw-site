HoleLine  —  Cylinder

HoleLine

A command to create a Center Line for each Hole if the selected Solid Object has Holes.

Purpose

ItemDescription
Hole DetectionFinds a Center Line based on the Hole location of the selected Solid Object.
Center Line CreationCreates a Line indicating the central direction of each Hole.
Subsequent ReferenceCan be used to verify Hole location, create machining reference lines, and review before and after Cylinder creation.

How to Use

  1. Type HoleLine in the Rhino command line and press Enter.
  2. Select a Solid Object that includes Holes.
  3. Complete the selection following the command prompt.
  4. Check the Center Lines created at each Hole center in the Rhino viewport.

Usage Example

Key Details

ItemDescription
Target ObjectSolid Object that includes Holes
Created ObjectCenter Line passing through the Hole center

Execution Results

ItemDescription
ResultA Center Line is created for each Hole of the selected Solid Object.
Confirmation LocationCheck the Line object passing through the Hole center in the Rhino viewport.
Note: Only processes Faces recognized as cylindrical Faces within the selected Brep. When centers overlap within 0.2, such as on both sides of a cylindrical Face of the same Hole, only one center line is created to prevent duplication.
