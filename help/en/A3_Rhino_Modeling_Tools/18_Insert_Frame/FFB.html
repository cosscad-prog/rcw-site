FFB  —  18_Insert_Frame

FFB

A command that measures the size of selected Rhino drawing objects and inserts the Frame Form block saved with SFB into the drawing at an automatic scale.
It automatically fills the Form placeholders with the drawing number, quantity, scale, panel size, pad size, and length text.

Purpose

When you select 2D drawing objects, it measures the overall drawing size against the current CPlane and computes the scale and insertion position so that the Frame Form chosen in SFB wraps around the drawing. Since it automatically fills the Form text placeholders with the drawing and size information, repetitive frame insertion work can be handled quickly.

Workflow

OrderStepDescription
1Select drawing objectsSelect the drawing objects to wrap with the Frame Form. Annotation, Curve, Brep, Hatch, and Point can be selected.
2Recognize drawing number/quantityReads the Text on layers starting with Profile. Text starting with Qnt- is used as the quantity; the first other text is used as the drawing number.
3Recognize size infoReads panel/pad W,H values from PSize_WH layer text, and the length value from Steel 7 layer text.
4Measure drawing sizeComputes the BoundingBox of the selected objects, excluding text and Annotation, against the current CPlane.
5Auto-compute scaleCompares the drawing size with the Frame Form's inner area to derive the optimal scale at which the Form wraps the drawing.
6Insert Frame FormInserts the Form block on the Form-Frame layer at the computed scale and position.
7Place polylines/textCopies the polylines and text saved by SFB with the same move/scale transform as the Form and updates their contents.

SFB → FFB Workflow

CommandRoleDescription
SFBSelect/save Frame FormSelects the Form block, text placeholders, and polylines and saves them to memory.
FFBInsert Frame FormSelects drawing objects to measure the size, and inserts the Form saved by SFB at an automatic scale.

How to Use

  1. Run SFB first to select the Frame Form block to use.
  2. Type FFB in the Rhino command line and press Enter.
  3. At the "FFB: Select drawing content (objects)" prompt, select all drawing objects to wrap with the Frame Form.
    To auto-fill the drawing number, quantity, and size values, the related text objects must also be included in the selection.
  4. Press Enter to insert the Frame Form at the automatic scale/position, with the text placeholders filled with actual values.
  5. The drawing number, quantity, and computed scale are printed in the command line.

Key Details

ItemDescription
PrerequisiteSFB must be run first so the Frame Form block is saved in memory.
Selection targetSelect the drawing objects together with the Text objects needed for auto-fill. The selection filter is Annotation, Curve, Brep, Hatch, Point.
Size-measure exclusionTextEntity and AnnotationBase are excluded from the drawing-size BoundingBox calculation.
Scale calculationAutomatically determines the optimal scale by comparing the drawing width/height with the Frame Form inner area.
Insertion layerThe Form block is inserted on the Form-Frame layer. If the layer is missing, it is auto-created in yellow.
Text replacementReplaces the drawing number, quantity, scale, panel W/H, pad W/H, and length placeholders with the actual values read from the drawing.
View moveAfter insertion, zooms the view to the BoundingBox of the newly added objects.
EnvironmentRhino

Input Text Reference

ItemDescription
Drawing numberUses the first ordinary text on a layer starting with Profile.
QuantityUses the trailing value of text starting with Qnt- on a layer starting with Profile.
Panel W/HSorts PSize_WH layer text by position and extracts the panel size values.
Pad W/HSorts PSize_WH layer text by position and extracts the pad size values.
LengthUses the first text value on the Steel 7 layer.

Result

ItemDescription
Frame Form block insertionThe Frame Form block is placed on the Form-Frame layer at a scale matching the drawing size.
Polyline placementThe boundary polyline saved in SFB is copied/placed with the same transform as the Form.
Auto text fillThe drawing number, quantity, scale, panel/pad size, and length are automatically filled in at the corresponding text positions of the Form.
Note: FFB uses Frame Form information registered from SFB (screen selection) or the FDstyle panel's [Drawing Template] (external 3DM files). The registered template information is saved together with the current document (.3dm) and auto-restored when reopened, so there is no need to re-register on the same file. (If no template has been registered, no Form will be inserted.)
Hidden templates insert normally: Template instances registered from external 3DM files are hidden on the screen, but the templates (block, polylines, text) inserted via FFB appear normally visible.
Caution: If the needed Text objects are not included in the drawing selection range, the Form may be inserted with its drawing-number/quantity/size fields left empty.
