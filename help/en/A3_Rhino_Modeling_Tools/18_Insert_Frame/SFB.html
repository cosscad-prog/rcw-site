SFB  —  18_Insert_Frame

SFB

A Rhino command that selects a Frame Form block and saves it to memory.
Afterwards, when FFB runs, it auto-inserts this Frame Form into the selected drawing at a matching scale and position.

Purpose

By pre-selecting a company-specific frame form block, FFB later automatically computes the scale matching the drawing size and inserts the Frame Form. SFB only handles Form selection and saves the selected block, text placeholder, and polyline information to the current Rhino session's memory.

Required Components Inside the Frame Form

ComponentRole
Block InstanceThe drawing form block body. Must be included in the SFB selection range.
2 Points (inside the block definition)The min/max reference points of the inner area where the drawing goes. If absent, the whole block BoundingBox is used as the reference.
Text — DWG_NO, DWG-NO, DWGNOThe drawing-number placeholder. FFB replaces it with the drawing name text.
Text — Scale layer or content SCALEThe scale placeholder. FFB replaces it with the auto-computed scale string (1 / N).
Text — Qnt layer or content QNTThe quantity placeholder. FFB replaces it with the quantity text read from the drawing.
Text — SIZE_W, SIZE_H, PAD_W, PAD_H, LENGTHPlaceholders to auto-fill with panel size, pad size, and length values.
PolylineCurveThe frame boundary polyline. A closed polyline is saved first, and FFB copies and places it together with the Form.

How to Use

  1. Confirm that the Frame Form block, text placeholders, and polyline are placed in the Rhino file.
  2. Type SFB in the Rhino command line and press Enter.
  3. At the "SFB: Select the Frame Form (including block, polyline, text)" prompt, select the Form block, text, and polyline all together and press Enter.
  4. The selected Frame Form information is saved to memory. Afterwards, insert the Frame Form into the drawing with FFB.

Registering Templates from External 3DM Files (FDstyle Panel [Drawing Template] Button)

In addition to SFB where you select directly on screen, you can also register pre-made external 3DM template files via the [Drawing Template] button in the FDstyle panel. The same Frame Form mechanism applies; only the template source differs.

StepAction
File selectionWhen you select a template 3DM file in the file dialog, it is imported into the current document.
Pre-checkChecks whether the imported template's block name conflicts with existing templates, alerting you if there is an issue.
Auto-unique namingIf block names overlap, unique names are automatically assigned, so different templates (e.g., for Profile_A, Profile_B) don't mix.
Display isolationRegistered template instances are hidden so they don't clutter the viewport. (Inserted templates display normally)
Note: Templates registered from external files are also saved with the document (.3dm) and auto-restored when reopened. Multiple different template files can coexist, each with its own unique name.

EnvironmentRhino
Note: SFB saves Frame Form information only; it does not insert new objects into the drawing. The actual Frame Form insertion is performed with FFB (or the [Insert Template] button in the FDstyle panel). Template information is saved together with the current document (.3dm) and auto-restored when reopened — no need to re-register on the same file. (However, if the registered template object is deleted, re-registration is needed.)
Caution: If the needed text placeholders are missing inside the Frame Form block, those items are not filled when FFB runs.
