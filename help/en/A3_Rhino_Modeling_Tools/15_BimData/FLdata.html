FLdata

Command to input floor information and role-based schedule data into selected Group or Block objects.

Purpose

Used to verify or edit BIM/Floor-related data stored in selected objects, and manage model objects together with floor/zone/attribute information.

How to Use

  1. Type FLdata in the Rhino command line and press Enter.
  2. At the Select objects to set BIM data (Group/Block) prompt, select one or more objects to apply data.
  3. In the BIM Data Input dialog, enter floor information and schedule information.
  4. Click OK to save the BIM data to the UserString of the selected objects.

Execution Example

Input Data

ItemDescription
Floor NumberSaved as RCW_Floor. Positive numbers displayed as nF, 0 as Ground, negative as BnF.
Reference HeightSaved as RCW_Elevation. Enter the reference height (mm) of the floor.
ManagerEnter Manager role planned start/end, actual start/end, and progress rate.
DesignerEnter Designer role planned start/end, actual start/end, and progress rate.
ProductionEnter Production role planned start/end, actual start/end, and progress rate.
InstallationEnter Installation role planned start/end, actual start/end, and progress rate.

Code-Based Operation

ItemDescription
Selection TargetSelects ObjectType.AnyObject and also allows Group selection with GroupSelect = true. SubObject selection is not used.
Load Existing ValuesReads existing UserString from the first selected object and uses it as initial values in the input dialog.
Object SavingInput values are saved to Attributes UserString of all selected objects. Empty values delete the corresponding UserString.
Document Backup SaveIf floor number and Block/object display name exist, schedule data is also dual-saved in doc.Strings. After block regeneration, can be restored in FLOpt if the same floor+name.
Save KeyFloor saved as RCW_Floor, reference height as RCW_Elevation, schedule as RCW_Sched_{Role}_{Field} format.
Note: FLdata is a command for inputting/saving data. To verify and modify input data by floor and block, use the FLOpt panel.
