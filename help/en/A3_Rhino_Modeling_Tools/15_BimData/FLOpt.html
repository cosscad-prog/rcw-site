FLOpt

Command to open the Floor Data panel that organizes and displays floor data and schedule data entered via FLdata by floor/Block unit. In the panel, you can control display state and double-click Block rows to modify BIM data.

Purpose

Used to set basic options needed for BIM/Floor data input and management, and to organize data entry standards before FLData work.

How to Use

  1. Type FLOpt in the Rhino command line and press Enter.
  2. The Floor Data panel opens and scans objects with RCW_Floor UserString in the current document.
  3. Use the Refresh button at the top to re-read the data.
  4. Click the role buttons at the top (Manager, Designer, Production, Installation) to switch the schedule role to display.
  5. Double-click a Block row to open the BIM Data Input dialog for objects with that floor+Block name.

Panel Composition

ItemDescription
OnIcon column to toggle display/lock state of floor or Block.
Floor / Reference HeightFloor rows display floor number and reference height. Block rows display Block/object display name.
QtyFloor rows show total object count for that floor, Block rows show object count for that floor+Block name.
ProgressDisplays progress status based on currently selected role as a colored box.
Planned CompletionDisplays planned completion date of the currently selected role. Floor rows show the latest date among child Blocks as representative value.
Actual CompletionDisplays actual completion date of the currently selected role. Floor rows show the latest date among child Blocks as representative value.

Progress Status Colors

StatusCriteria
GreyDisplayed as Not Started if the selected role has no planned start date.
YellowDisplayed as In Progress if there is a planned start date.
GreenDisplayed as Done if there is an actual completion date and that date is today or earlier.

Code-Based Operation

ItemDescription
Panel ExecutionFLOpt command opens the FLPanelControl.PanelId panel.
Data ScanClassifies objects with RCW_Floor UserString by floor, excluding deleted/hidden objects from the document.
Block NameBlock Instance uses Instance Definition name as display name, regular objects use object name.
Schedule RestorePrioritizes object UserString value, and if empty, restores from backup data of floor+Block name stored in doc.Strings.
Double-Click EditDouble-clicking a Block row collects objects with the same floor number and display name and edits them with Dlg_BimData.
On/Off ToggleClicking the On column locks/unlocks objects in that floor or Block. Controls objects in lock state without hiding or deleting them.
Panel CloseWhen the panel closes, FLOpt unlocks objects it locked and reinitializes internal Off state.
Note: FLOpt is a panel for viewing/organizing/modifying input data. To initially input BIM data in new objects, use FLdata first.
