License / Version

RCWMachineCode RCWLicense RCWCustomerCode RCWVersion RCWUpdate

These are not drawing commands. They handle installation, activation and version, and never change your model or drawing. They are grouped in one document because they belong together.

What this page covers

NameWhat it does
RCWMachineCodeShows this workstation's machine code and copies it to the clipboard. You need it to request a license.
RCWLicenseImports the license file (.lic) you received, and reports the current license status.
RCWCustomerCodeSaves the customer code from your e-mail on this computer, once. From then on RCWVersion keeps showing it back to you.
RCWVersionShows the version, edition, build date and file path of the build that is actually running - and the saved customer code.
RCWUpdateChecks whether a newer version exists, and turns the startup check on or off.
Customer codeThe code you use to sign in to the customer page; it arrives by e-mail. See Two different codes below.

Activating for the first time (Core / Standard)

  1. Start Rhino. With no license file present, the machine code is printed in the command line and copied to the clipboard automatically. If you missed it, run RCWMachineCode.
  2. Open the customer page rcw-site.vercel.app/customer and sign in with your customer code.
  3. Paste the machine code from step 1 into the machine code field in the license box, then press [Request license].
  4. Within about a minute a [Download license] button appears in the same place. The page updates itself — no refresh needed.
  5. Save the downloaded .lic file somewhere safe.
  6. Run RCWLicense in Rhino and select that .lic file.
  7. Confirm the success message and restart Rhino.
  8. After the import, Rhino asks whether to save your customer code. Paste in the code you signed in with at step 2 — you can then find it again even if the e-mail is lost. To do it later: RCWCustomerCode.
Do not copy the license file into the Program Files folder by hand. It must be imported with the RCWLicense command.

Two different codes — do not mix them up

NameLooks likeWhere it comes from, what it is for
Customer code
(license code)		RCW-XXXX-XXXX-XXXX Arrives by e-mail. Used to sign in to the customer page. One per person; it does not change when you change computers.
Machine codeRCW5-CO-… (Core)
RCW5-ST-… (Standard)		 Produced by Rhino. Used to request a license after signing in. Different on every computer.
A failed sign-in is almost always the two codes swapped. The sign-in box takes the customer code starting with RCW-; the machine code starting with RCW5- goes into the license box after you are signed in.
If you cannot remember the customer code, run RCWVersion - it is there once you have saved it.

RCWMachineCode — read the machine code

Prints the machine code in the command line and copies it to the clipboard, ready to paste into the customer page.

ItemDescription
When you need itWhen requesting your first license, and again when you change computers or the machine code changes.
How the value is formedDerived from a value Windows assigns to that computer. The same computer always gives the same code.
Edition markerCO and ST stand for Core and Standard. A different edition produces a different code.
Where to send itOnly to the customer page or to the person who issues licenses.
If the code cannot be produced, the command reports that the Windows MachineGuid is unavailable and fails. Send us a screenshot if that happens.

RCWLicense — import the license file

  1. The command first prints the current license status on one line.
  2. A file dialog opens. Select the .lic file you downloaded.
  3. The status is printed again after the import. On success: "RCW license file imported."
  4. If no customer code is saved yet, you are asked for it once here. Paste it, or press Enter to skip.
  5. Restart Rhino to apply it.
ItemDescription
File typeOne *.lic file. Multiple selection is not allowed.
CancellingYou may cancel the file dialog. An existing license is left untouched.
If it fails"was not imported" usually means the file belongs to another computer or has expired. Send us the status line printed just above it.
InternetNot required. The license is verified offline from the file's signature.
The customer code questionAsked only when the import succeeded and no code is saved yet. Whatever you do there — skip it, mistype it — the result of the import is unchanged.

RCWCustomerCode — save the customer code

The customer code exists only in the e-mail you were sent. It is not inside the license file and it appears nowhere on screen. Months later, when you change computers or want the installer again, that e-mail is often gone. Save the code once, the way you import the license file once.

The first place to save it is RCWLicense, which asks for it right after importing the licence. This command is for saving it later, or changing or removing it.

  1. Run RCWCustomerCode. If a code is already saved it is shown first and copied to the clipboard.
  2. The command line asks for the code. Paste it and press Enter.
  3. A confirmation appears. From then on it is part of what RCWVersion prints.
ActionResult
Press Enter aloneChanges nothing. Use this when you only wanted to look.
Paste a new codeReplaces the saved one.
Remove optionDeletes the saved code. The code itself is not cancelled - only this computer's note of it.
ItemDescription
What it acceptsWith or without hyphens, upper or lower case. It is stored in upper case.
What it acceptsCodes starting with RCW-. Codes starting with V5KO- are still accepted too, as they are on the customer page.
What it rejectsAny other prefix, and fewer than 8 or more than 40 letters and digits. A rejected entry leaves the saved code untouched.
If you paste the machine codeIt is refused, with the reason. RCW5-CO-… and RCW5-ST-… are machine codes, not customer codes - one character apart, and the most common mix-up.
Where it is keptNext to the license file. It survives a reinstall, and it is not in the folder you open and edit, so it is unlikely to be deleted by accident.
InternetNot used. Nothing is asked of any server to check the code - only its shape is checked.
This code is the key that signs you in to the customer page. Once saved it sits in a file on this computer, so on a Windows account shared with other people you may prefer not to save it. Remove in RCWCustomerCode deletes it at any time.

RCWVersion — which build is running

The first thing we need for any support request. It prints two lines.

RCW V5 5.1.2 Standard net48 build 2026-08-14 C:\Program Files\...\RCW_V5.rhp Customer code: RCW-1A2B-3C4D-5E6F
ValueMeaning
5.1.2Version number. A suffix such as -trial identifies the kind of build.
StandardEdition — Core, Standard or Internal; evaluation builds also show Trial.
net48The .NET flavour in use. Rhino 8 may show a different value depending on its setting.
build …The date that build was made.
Second lineThe file that was actually loaded. This line answers the question when an older build is still lying around.
Third lineThe customer code saved with RCWCustomerCode. If none is saved, a note telling you to save one appears instead.
The same line is printed once when Rhino starts, so you can scroll up to it without running the command.

RCWUpdate — check for a new version

It only tells you. It never downloads or installs anything.

ActionResult
EnterChecks now. If you are current it says so; if a newer version exists it names both versions and asks whether to open the download page.
AutoCheckTurns the startup check on or off. With it off, nothing is checked at all.

The automatic check behaves like this:

ItemDescription
How oftenOnce a day, quietly, after Rhino has finished starting. It never holds up startup.
What is sentNothing. It reads one version list file from the web site. Machine code, license and drawings are never sent anywhere.
On failureIt says nothing — no warnings behind a firewall or on an isolated network. Run RCWUpdate yourself if you want the reason; asked directly, it always answers.
Repeat promptsThe dialog is not shown twice for the same version. The command-line note stays.
Installing requires closing Rhino — the plug-in file is locked while Rhino runs.

Changing computers or reinstalling

SituationWhat to do
Reinstalling on the same computerThe machine code is unchanged, so import your existing .lic again with RCWLicense.
Reinstalling to change the help languageInstall again from the same file with the other language, then import the same .lic again.
New computer / changed machine codeA new license is required. Request it on the customer page; it is issued after a check.
A colleague at the same companyA license covers one computer. Each person needs their own.

Trial builds need no license file

Core Trial runs the Core command set for 90 days, Standard Trial the full set for 30 days. The period starts at the first successful run, and reinstalling under the same Windows account does not reset that date. The two periods are independent of each other.

Trial builds do not contain RCWMachineCode, RCWLicense or RCWCustomerCode, because they use neither a license file nor a customer code. RCWVersion and RCWUpdate are present in trial builds as well.

If something goes wrong

SymptomWhat to check
Cannot remember the customer codeRun RCWVersion. It is on the last line once you have saved it; if you never did, look for the e-mail.
Cannot sign in to the customer pageWhether you entered the customer code starting with RCW-. RCW5- is not a sign-in code.
License imported but nothing changedWhether you restarted Rhino.
A command is reported as unknownCheck the edition with RCWVersion. Trial builds have no license commands, and Core does not include Standard-only commands.
A fix seems to have no effectLook at the second line of RCWVersion — an older build in another folder may be the one loaded.

When contacting support, include both lines of RCWVersion, your Rhino version, your Windows user name and the error message or a screenshot.
