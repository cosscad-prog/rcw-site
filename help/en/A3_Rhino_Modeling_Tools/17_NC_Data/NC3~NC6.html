NC3 / NC4 / NC5 / NC6  —  17_NC_Data

NC3  NC4  NC5  NC6

A command that reads hole information from selected Rhino geometry and automatically generates an NC machining hole data table.
NC3~NC6 differ only in the origin reference corner (top-left / bottom-left / top-right / bottom-right); the rest of the behavior is identical.

Purpose

Collects the hole dimensions and circular/slot shapes placed in the drawing and converts each hole's X/Y coordinates (relative distance from the origin) and diameter information into an NC data table. By choosing the origin reference corner among NC3~NC6, you can generate a table that matches the machine's origin setting.

Origin Position by Command

CommandOrigin referenceDescription
NC3Left-TopUses the minimum U, maximum V coordinate of the selected group area as the origin.
NC4Left-BottomUses the minimum U, minimum V coordinate of the selected group area as the origin.
NC5Right-TopUses the maximum U, maximum V coordinate of the selected group area as the origin.
NC6Right-BottomUses the maximum U, minimum V coordinate of the selected group area as the origin.

How to Use

  1. Confirm that hole dimensions or hole shapes are prepared in the drawing.
  2. Type the command matching the origin reference (NC3 / NC4 / NC5 / NC6) in the Rhino command line.
  3. At the "NCn: Select objects (Gap = whether to include the X_Gap column)" prompt, select the needed objects.
  4. To include the X_Gap column, switch the command option to Gap=Yes before selecting. The default is No.
  5. Press Enter to complete the selection.
  6. A marker is created at the origin position, and the NC hole data table is output to the right of the selection area.

Key Details

ItemDescription
Selection targetAnnotation, Curve, Point, Brep, and Hatch can be selected. SubObject selection is not used.
Coordinate basisComputes U/V coordinates against the current active view's CPlane.
Group separationIf there are Points on the NC_BottomPoint or NC_TopPoint layer, groups are split per reference point. Otherwise groups are built from the curve extents of Cut_Curve, then Shape_Curve/Shape_Hidden/Dim_Curve/Dim_Sub layers.
Hole data sourceRecognizes RadialDimensions or circular Curves on the Hole_Dia layer, and slot Curves/dimension text on the Slot_Hole_Dia layer.
Minimum hole sizeHoles smaller than diameter 3.0 are excluded.
Countersink holesIf two ordinary holes of different diameters share the same center, they are classified as countersink holes in CS1, CS2 format.
SlotsIf on the Slot_Hole_Dia layer or the dimension text is in Ø10-20LG format, it is classified as a slot in SL1, SL2 format.
X_Gap optionWhen Gap=Yes, adds a column for the X distance between adjacent holes. The first hole's X_Gap is the X distance from the origin to the first hole.
Table positionCreates the table 100 to the right of each group's maximum U coordinate.
Text sizeUses the TextHeight and DimensionScale of the current Rhino DimensionStyle. If the value is too small, 3.5 is used.
LayerThe generated origin marker and table are placed on the NC_Data layer. If the layer is missing, it is auto-created in orange.
EnvironmentRhino

Table Output Order

CategoryDescription
CS holesCountersink holes are output first. Numbered CS1, CS2 in order.
Slot holesSlots are output second. Numbered SL1, SL2 in order.
Normal holesOrdinary circular holes are output last. Numbered 1, 2 in order.
X sortNC3/NC4 sort by ascending X; NC5/NC6 sort by descending X.

Result

ItemDescription
Origin markerA Point and 3 concentric circles are created at the specified corner of the selected group extent.
Hole numbersHole number text is created next to each hole position.
Hole data tableEach hole's position number, Dia, X, Y, and (if selected) X_Gap values are output as drawing text and a rectangular table.
LayerAll generated elements are placed on the NC_Data layer.
Note: The Rhino version uses, based on the current code, fixed defaults of Hole Min=3.0 and NC data Dist=100.0. This behaves differently from the DsOpt setting items in the AutoCAD help.
Caution: If hole objects are not on the Hole_Dia or Slot_Hole_Dia layer, they are not recognized as hole data. If the needed objects are not included in the selection range, the table may not be generated.
