FSC  —  05_Drawing_Shortening

FSC

A command that automatically reduces 2D drawing in X-axis direction only (Drawing Shortening) to compress it to match form size.
Automatically reads profile-specific settings from AutoScale.dat and applies shortening reference dimensions, target dimensions, and excluded sections.
AutoCAD / BricsCAD only — not available in Rhino.

Purpose

When actual shape dimensions exceed the maximum length that fits in form size, selectively compress only sections meeting specified criteria to reduce drawing to match form size. Dimension text is converted to fixed actual-size dimensions so original dimensions display even after compression.

Operation Flow

StepStageDescription
1Object SelectionSelect entire drawing (shape, dimensions, text, NC Points, etc.). All objects can be selected without filtering.
2Profile RecognitionReads drawing number text from selected MText, using first word before - or space as profile name. Loads configuration data for that profile from AutoScale.dat.
3Range MeasurementCalculates total drawing width (Max_distance) from X coordinates of NC_BottomPoint layer Point (left reference) and NC_TopPoint layer Point (right reference).
4Execution Condition CheckIf current width (Max_distance) is less than target dimension (MinFabdist), shortening is not executed.
5Dimension Fixed ConversionConverts RotatedDimension in sections meeting or exceeding shortening reference (min_ds) to fixed actual-size text dimensions.
6Excluded Section SelectionIf excute=1 in AutoScale.dat: Select dimension objects in sections not to shorten at "Select excluded section Entity" prompt.
7Minimum Value InputIf Min_excute=1 in AutoScale.dat: Directly enter target minimum width (previous input displays as default).
8Per-Section StretchPulls right from center point of each dimension section meeting shortening criteria along X-axis, compressing proportionally.
9NC Data Table MovementMoves objects (NC data table) on right of maximum drawing X in NC4_data / NC3_data layers leftward by total reduction distance.

AutoScale.dat Settings

ColumnItemDefault ValueDescription
[0]Name—Profile name. Must match first word of drawing number for automatic application.
[1]Shortening Reference (min_ds)250Only sections meeting or exceeding this value are targets for shortening. (Example: 250 = compress only if section length ≥ 250)
[2]Total Shortening Dimension (MinFabdist)300Target total width of drawing after shortening.
[3]Excluded Section Selection (excute)1If 1, displays excluded section selection prompt. If 0, skips.
[4]Minimum Value Input (Min_excute)1If 1, displays direct minimum width input prompt. If 0, uses MinFabdist as-is.

Preparation

ItemDescription
NC_BottomPoint Layer PointLeft reference point (minimum X value). If absent, replaced with entire shape range.
NC_TopPoint Layer PointRight reference point (maximum X value). If absent, replaced with entire shape range.
AutoScale.datProfile-specific shortening parameter file. If absent or profile name not found, defaults used (min_ds=250, MinFabdist=300).
Drawing Number MTextSelection range must include drawing number MText for profile to be automatically recognized.

How to Use

  1. Verify that parameters for the profile are correctly entered in AutoScale.dat.
  2. Verify that NC_BottomPoint / NC_TopPoint layer Points are placed on drawing.
  3. Enter FSC in command line and press Enter.
  4. At "Select Entity" prompt, select entire drawing including shapes, dimensions, drawing number text, and NC Points, then press Enter.
  5. (If excute=1) At "Select excluded section Entity" prompt, select dimension objects in sections not to shorten and press Enter. If none, press Enter only.
  6. (If Min_excute=1) Enter target minimum width. Pressing Enter only uses previous input or AutoScale.dat's MinFabdist.
  7. Drawing is automatically compressed in X-axis direction, and command window outputs Maximum_distance / Minimum_distance / ratio / actual movement distance.

Execution Example

Execution Result

ItemDescription
Drawing CompressionEach section meeting or exceeding shortening criteria is pulled proportionally along X-axis.
Dimension FixedDimensions in compressed sections are converted to fixed actual-size text, displaying original dimensions even after compression.
NC Table MovementNC data table on NC4_data / NC3_data layers is automatically moved leftward by total reduction distance.
Note: If current drawing width (Max_distance) is already less than or equal to AutoScale.dat's MinFabdist, shortening will not execute and "Not Working" message displays.
Sections below shortening criteria (min_ds) are not compressed, and minimum post-compression size (Min_s=30) is guaranteed.
Caution: FSC is not available in Rhino (AutoCAD / BricsCAD only).
If selection range does not include drawing number MText, AutoScale.dat profile cannot be recognized and defaults are used.
If NC_BottomPoint / NC_TopPoint layer Points are absent, drawing range calculation may be inaccurate.
