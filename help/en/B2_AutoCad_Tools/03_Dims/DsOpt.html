DsOpt

A command that displays an option panel for setting variables used in dimension commands such as DST / DSB / DSL / DSR / DSA / DAA.
No object selection is required — a dockable panel (PaletteSet) appears on the screen in AutoCAD.

Purpose

Preset dimension line distances, intervals, angle distances, and NC data-related variables in the panel before executing dimension commands. Set values are immediately applied to all subsequent dimension commands.

How to Use

  1. Enter DsOpt in the command line and press Enter.
  2. The Dim Panel panel appears on the AutoCAD screen.
  3. Modifying any item value is immediately reflected in the dimension command variables.
  4. To close the panel, click the × in the upper right corner of the panel or use the HIDEDimPanel command.

Execution Example

Note: When panel values are changed, they are immediately applied to subsequently executed DST, DSB, DSL, DSR, DSA, DAA commands. Always verify values before executing dimension commands.
