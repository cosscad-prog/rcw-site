HPP  —  03_Dims

HPP

A command that automatically extracts characteristic points from selected entities (Line, PolyLine, Circle, Arc) and creates Points on the Dim_Points layer.
Use to quickly place reference Points before executing DST / DSB / DSL / DSR / DSA dimension commands.

Purpose

Automatically extract dimension reference points (endpoints, center points, nodes) from shape entities without clicking individually, creating Points on the Dim_Points layer. Quickly create multiple dimension reference points in complex drawings all at once.

Point Creation Location by Entity Type

Selected EntityPoint Creation Location
Line2 Points at start point (StartPoint) and end point (EndPoint)
PolyLinePoints created at each vertex (Node) location
Circle1 Point at circle center (Center)
Arc1 Point at arc center (Center)

How to Use

  1. Enter HPP in the command line and press Enter.
  2. Follow the "Select Entity" prompt and select entities to extract dimension reference points.
    (Can select mixed Line, PolyLine, Circle, Arc)
  3. Press Enter to complete.
  4. Points on Dim_Points layer are created at each characteristic point location of selected entities.
  5. Subsequently select created Points with dimension commands like DST / DSB to add dimensions.
