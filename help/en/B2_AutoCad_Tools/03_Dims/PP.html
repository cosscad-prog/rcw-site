PP  —  03_Dims

PP

A command that creates 1 Point on the Dim_Points layer at the clicked location on screen.
Does not use object selection — places Points at desired locations through direct clicking (Pick Point).

Purpose

Use to directly place Dim_Points layer Points at desired locations for use as reference in DST / DSB / DSL / DSR / DSA dimension commands. Unlike HPP which automatically extracts from entities, PP directly specifies desired locations.

How to Use

  1. Enter PP in the command line and press Enter.
  2. Follow the "Select Point location" prompt and click on the screen where to place the Point.
  3. A Dim_Points layer Point is created at the clicked location.
  4. Subsequently select the created Point with dimension commands like DST / DSB to add dimensions.
