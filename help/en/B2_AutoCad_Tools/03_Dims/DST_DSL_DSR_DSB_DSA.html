DST / DSB / DSL / DSR / DSA  —  03_Dims

DST  DSB  DSL  DSR  DSA

A command that automatically adds dimensions in a specified direction when you select Point objects on the Dim_Points layer, using variables configured in DsOpt.

Purpose

Based on Dim_Points layer Points pre-positioned with PP or HPP at key locations on the drawing shape, automatically add consistent dimensions in desired directions (Top / Bottom / Left / Right / all 4 sides simultaneously). Complete drawings much faster than manually creating dimensions one by one.

Command List

CommandAction
DSTAdd horizontal dimension at object Top.
DSBAdd horizontal dimension at object Bottom.
DSLAdd vertical dimension at object Left.
DSRAdd vertical dimension at object Right.
DSAAdd dimensions to all 4 sides (Top / Bottom / Left / Right) simultaneously.

How to Use

  1. Execute DsOpt to set dimension variables (First Dist, Dim Gap, etc.).
  2. Use PP or HPP to place dimension reference Points (Dim_Points layer).
  3. Enter the command for desired direction (DST / DSB / DSL / DSR / DSA) in the command line.
  4. Follow the prompt "Select POINT" to select Point object(s) to use as dimension reference.
  5. Press Enter to complete — dimensions are automatically added in the specified direction.

Execution Example

Dimension VariablesReferences First Dist, Dim Gap, Top/Left/Right/Bottom Max settings in DsOpt panel.
LayerDimensions are created on the Dims layer.

DSA Additional Requirements

ItemDescription
NC_BottomPointPoints on NC_BottomPoint layer are required when executing DSA.
NC_TopPointPoints on NC_TopPoint layer are required when executing DSA.
If Not MetIf Points on these layers are absent, DSA dimensions may not be added correctly.

Execution Result

ItemDescription
Created DimensionsDimensions are automatically added in the specified direction based on selected Points' positions.
Dimension Line DistanceUses First Dist (first dimension line) and Dim Gap (dimension line spacing) setting values.
LayerCreated dimensions are placed on the Dims layer.
Note: Points that serve as dimension reference must be on the Dim_Points layer. Execute PP (create Point at click location) or HPP (automatically create Points based on entities) first.
Caution: Variables configured in DsOpt directly affect dimension line position and size. Verify First Dist and Dim Gap values before adding dimensions.
