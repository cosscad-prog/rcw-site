DAA  —  03_Dims

DAA

A command that automatically adds the angle dimension between two lines when you select 2 Lines at different angles.
Uses the DsOpt Angle Dist setting value as the dimension position distance. Any Line object can be selected regardless of layer.

Purpose

Use to accurately mark the angle between two lines on a drawing. Quickly add angle information to locations where inclined members, bent sections, or slope dimensions are needed.

How to Use

  1. Check and adjust the Angle Dist value in DsOpt if needed.
  2. Enter DAA in the command line and press Enter.
  3. Select 2 Line objects to add angle dimension and press Enter.
  4. Angle dimension is automatically added between the two lines.

Execution Result

ItemDescription
Created DimensionThe angle between the two selected Lines is displayed as an arc dimension.
Dimension PositionThe arc is drawn at a distance from the intersection point equal to the Angle Dist setting.
LayerCreated dimensions are placed on the Dims layer.
Note: The two Lines must actually intersect or their extensions must intersect for the angle dimension to be added correctly. If two parallel lines are selected, no angle dimension can be created.
