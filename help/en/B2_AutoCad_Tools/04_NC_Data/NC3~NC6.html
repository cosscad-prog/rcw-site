NC3 / NC4 / NC5 / NC6  —  04_NC_Data

NC3  NC4  NC5  NC6

A command that reads DiametricDimension (diameter dimension) objects from selected shapes and automatically creates an NC machining hole data table on the drawing.
NC3~NC6 differ only in origin-based corner (top-left/bottom-left/top-right/bottom-right), with identical operations otherwise.
AutoCAD / BricsCAD only — not available in Rhino.

Purpose

Automatically collect diameter dimensions (DiametricDimension) from drawing and convert each hole's X/Y coordinates (relative distance from origin) and diameter information into NC data table. Choose origin-based corner from NC3~NC6 to create table matching the machining machine's origin settings.

Command-Specific Origin Location

CommandOrigin ReferenceDescription
NC3Top-LeftUses minimum X and maximum Z(Y) coordinates of selected shape area as origin.
NC4Bottom-LeftUses minimum X and minimum Z(Y) coordinates of selected shape area as origin.
NC5Top-RightUses maximum X and maximum Z(Y) coordinates of selected shape area as origin.
NC6Bottom-RightUses maximum X and minimum Z(Y) coordinates of selected shape area as origin.

How to Use

  1. Execute DsOpt to check and adjust Hole Min / Hole Max, Slot Hole Dist, NC data Dist values if needed.
  2. Verify that DiametricDimension (diameter dimension) is present on drawing. Table will not be created without it.
  3. Enter the command matching origin reference (NC3 / NC4 / NC5 / NC6) in the command line.
  4. At the "Select objects Include X_Gap Data ? [Yes/No] <...>:" prompt, select necessary objects.
    To change X_Gap Data inclusion, enter Yes or No from keyboard before selection.
  5. Press Enter to complete the selection.
  6. Marker (3 concentric circles) is created at origin location, and NC hole data table is output on drawing to the right of selected area.

Key Details

ItemDescription
Selection TargetSelect any objects without filter. Internally extracts shape range from Line/PolyLine on Shape_Curve / Shape_Hidden / Dim_Curve / Dim_Sub layers, and reads hole data from DiametricDimension.
Hole Data SourceRecognizes only DiametricDimension (diameter dimension) objects. Does not read regular Circle or Arc.
Hole FilterOnly diameters within DsOpt's Hole Min / Hole Max value range are included in table.
Slot HoleClassifies hole pairs with spacing matching DsOpt's Slot Hole Dist (4 values) as slot holes.
X_Gap OptionWhen selected, toggle X_Gap Data (X distance between adjacent holes) inclusion with [Yes/No] keyword. Previous selection value is maintained as default.
Origin MarkerPoint on NC_Data layer and concentric circles (diameters 5 / 12 / 13) are automatically created at calculated origin location.
Table LocationTable is created to the right by NC_data_Dist (default 100) from maximum X of selected area.
Text SizeUses current AutoCAD TEXTSIZE system variable (minimum 3, maximum 50).
LayerOrigin marker and table text are created on NC_Data layer (color 40).
Multiple Area SupportIf selected entities include multiple Z-separated areas (maximum 4), tables are created separately for each area.
Applicable EnvironmentAutoCAD / BricsCAD (Rhino not supported)

Execution Result

ItemDescription
Origin MarkerPoint + concentric circles (diameters 5 / 12 / 13) are created at specified corner of selected shape area.
Hole Data TableEach hole's X/Y coordinates (from origin), diameter, and slot hole status are output as drawing text.
LayerAll created elements are placed on NC_Data layer (color 40).
Note: Hole data source must be DiametricDimension (diameter dimension) objects. Circle or Arc selection directly will not be recognized as holes. Origin location is automatically calculated from Line/PolyLine range on Shape_Curve / Shape_Hidden / Dim_Curve / Dim_Sub layers.
Caution: NC3~NC6 are not available in Rhino (AutoCAD / BricsCAD only). Holes outside DsOpt's Hole Min/Max range will not be included in table, so verify range before executing command.
