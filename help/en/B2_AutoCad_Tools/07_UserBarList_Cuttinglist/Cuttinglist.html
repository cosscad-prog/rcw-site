Cuttinglist

A command that reads layer (profile name) and length (cutting dimension) of selected Line objects and automatically generates Cutting List and Long Bar List both as drawing and Excel file.
Processes in one workflow: Line filtering → bar mode switching → cutting optimization → drawing output and Excel save.

Purpose

When each profile member in AutoCAD drawing is represented as Line, uses layer name as profile name and line length as cutting dimension to automatically calculate cutting list by member and required bar quantity.

Line Data Reading Rules

Line PropertyUsage
Layer NameUsed as profile (member) name. When bar mode is User, searches bar file by this name.
Line LengthUsed as cutting dimension (mm, converted to integer). Decimal places are truncated.

Bar Mode (Auto / User)

ModeDescription
Auto (default)Applies built-in bar list (3000~6500mm, 100mm intervals) identically to all profiles.
UserSelects .txt file saved with UserBarlist from file open dialog. Uses bar list matching profile name, or uses defaults (3000, 4000, 5000, 6000, 6500) if no match.

Operation Flow

StepStageDescription
1Mode SelectionAt "Current Barlist <Auto/User>: Enter Key [Auto / User]:" prompt, enter A or U to switch bar mode. Pressing Enter only keeps previous mode.
2Line SelectionAt "Select one or more lines:" prompt, select cutting dimension Lines. Only Line objects are filtered, other entities are ignored.
3User File Selection(User mode) Select .txt saved with UserBarlist from file open dialog.
4Length ValidationIf any Line has cutting dimension of max bar value - 35mm or greater, displays warning and stops processing.
5Cutting OptimizationSorts and aggregates by profile/length, then optimally distributes cutting dimensions to each bar specification, calculating required bar quantity, loss length, and remaining length.
6Excel File Name InputAt "Enter Excel File Name:" prompt, input Excel file name to save.
7Drawing Output Location SelectionAt "Select TList position:" prompt, click drawing location to place table.
8Result OutputOutputs Cutting List and Long Bar List as text in drawing and also saves as Excel file.

How to Use

  1. Draw profile members as Line. Ensure layer name = profile name, line length = cutting dimension (mm).
  2. (If using User mode) Save bar data in advance with UserBarlist.
  3. Enter Cuttinglist in command line and press Enter.
  4. At "[Auto / User]:" prompt, select mode. Pressing Enter only keeps previous mode.
  5. Select cutting dimension Lines and press Enter.
  6. (User mode) Select bar data .txt file from file open dialog.
  7. After cutting length validation passes, input Excel file name.
  8. Click drawing location to place table.
  9. Cutting List and Long Bar List are output to drawing and Excel file is saved.

Key Details

ItemDescription
Selection FilterRecognizes LINE objects only. PolyLine, Circle, etc. are ignored even if selected.
Auto Bar Range3000mm ~ 6500mm, 100mm intervals (36 specifications)
Cutting Length LimitIf cutting dimension is max bar value - 35mm or greater, displays warning and stops.
Drawing Output Content① Cutting List (cutting dimension, quantity, bar assignment, loss, remaining) ② Long Bar List (bar length, quantity) output in order.
Excel OutputCutting List and Long Bar List are saved as Excel file.
Text SizeUses current AutoCAD TEXTSIZE system variable.
Applicable EnvironmentAutoCAD / BricsCAD

Execution Result

ItemDescription
Cutting List (Drawing)Cutting dimension, quantity, used bar assignment, loss, and remaining for each profile are output as drawing text.
Long Bar List (Drawing)Required bar length and quantity for each profile are output below Cutting List.
Excel FileCutting List and Long Bar List are saved in Excel file with input name.
Note: Partial selection is also possible. If only some Lines are selected instead of entire drawing, cutting list is calculated only for selected range.
In User mode, if no item matches profile name, default bar (3000, 4000, 5000, 6000, 6500) is applied.
Caution: If any Line has cutting dimension of max bar value - 35mm or greater, processing stops. The layer name and length of that Line is displayed in command window, so verify and correct.
