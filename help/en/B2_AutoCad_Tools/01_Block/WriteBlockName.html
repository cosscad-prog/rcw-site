WriteBlockName  —  01_Block

WriteBlockName

A command that displays the names of selected Block objects as text at the Block's Insert Point location. Use when you want to directly verify the names of Block instances placed on the drawing in the display.

Purpose

In drawings with multiple Block types mixed together, directly mark the definition name of each Block at the insertion point location to enable quick visual identification. Useful for Block inspection, drawing organization, and pre-verification before quantity confirmation.

How to Use

  1. Enter WriteBlockName in the AutoCAD or BricsCAD command line and press Enter.
  2. Select the Block objects to label and press Enter.
  3. Block name text is created at the Insert Point location of each Block.

Execution Example

Key Details

ItemDescription
Selection TargetProcesses only Block Reference objects. Other entities such as Lines, Text, and dimensions are ignored even if selected.
Text LocationCreates name text at each Block's Insert Point location.
Text AlignmentInserted with MiddleCenter (center alignment).
Applicable EnvironmentAutoCAD / BricsCAD

Execution Result

ItemDescription
Generated TextThe definition name (Block Name) of the selected Block Reference is created as text at the Insert Point.
Text LocationPositioned at the Block's Insert Point location with MiddleCenter alignment.
Note: Objects that are not Block References (Lines, Text, dimensions, etc.) are not processed even if selected. You must select Block instances inserted in the drawing.
Caution: The generated text is added as a separate Text entity. If you move or delete the Block afterward, the text does not automatically follow it.
