BB1 ~ BB8  —  01_Block

BB1  BB2  BB3  BB4  BB5  BB6  BB7  BB8

A command that inserts the Block corresponding to a number from the Block list saved by SSBlock at the location of a Point or Line entity selected on the screen.
If no object is selected, it is replaced with a direct click (Pick Point), and the inserted Block does not explode and maintains Block Reference status.

Purpose

Use to repeatedly place Blocks at precise locations based on Point objects (DBPoint) or Line endpoints already placed in the drawing. Since the insertion point is automatically extracted from existing shapes without manually entering coordinates, it is suitable for quickly placing the same Block at multiple locations.

Insertion Location Determination Method

Selected ObjectInsertion Location Determination Method
DBPoint (Point object)Uses the Point's Position directly as the insertion point.
Line (Line object)Collects StartPoints / EndPoints of all selected Lines and uses the point with the smallest Z value (lowest) and among those, the smallest X value (leftmost) as the insertion point.
No object selected / OtherReplaced with direct click (Pick Point).

How to Use

  1. First, use SSBlock command to select Block objects in order and save them to memory.
    The selection order becomes the number (number 1, number 2, …).
  2. Enter the command corresponding to the number to insert (BB1 ~ BB8) in the AutoCAD or BricsCAD command line and press Enter.
  3. Select Point or Line objects to use as the insertion location reference and press Enter.
    — If you select a DBPoint, it will be inserted at that point location.
    — If you select a Line, the lowest-leftmost endpoint is used as the insertion point.
    — If you do not select an object, it switches to direct click (Pick Point).
  4. The Block is inserted at the specified location as a Block Reference.

Note: The command does not work if no Block is saved by SSBlock or if there is no Block corresponding to the specified number. First run SSBlock to register Blocks before using this command.
Caution: Use B1~B8 if you need exploding after insertion. Since BB1~BB8 maintains Block Reference status, subsequent content modifications must be done through Block editing (REFEDIT or BEDIT).
