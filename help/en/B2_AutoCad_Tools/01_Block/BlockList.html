BlockList

A command that creates a list by calculating the name and quantity of selected Block objects.

Purpose

Use to quickly check how many Block instances of each type are in the selected drawing and keep block shape samples and quantity lists on the same screen. Useful when reviewing repeated parts or Block composition for processing.

How to Use

  1. Enter BlockList in the AutoCAD or BricsCAD command line and press Enter.
  2. Select the target objects according to the command prompt.
  3. Press Enter to complete the command and verify the result in the AutoCAD / BricsCAD display or command window.
