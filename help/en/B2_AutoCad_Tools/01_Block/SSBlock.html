SSBlock

A command that selects Block objects to be used in B1~B8 / BB1~BB8 commands and saves them to memory.
The selection order becomes the number — the first selected Block is number 1 (B1/BB1), the second is number 2 (B2/BB2), …

Purpose

A preparation command that registers Block objects to be used before inserting Blocks. Multiple types of Blocks can be managed by number, and the registered Blocks can then be quickly placed using B1~B8 (Explode insertion) or BB1~BB8 (Block Reference insertion) commands.

How to Use

  1. Enter SSBlock in the AutoCAD or BricsCAD command line and press Enter.
  2. Select Block objects to be used for insertion in order.
    The first selected Block becomes number 1, the second becomes number 2.
  3. Press Enter to complete the selection.
  4. Verify the selected Block names in the command window.
  5. Subsequently insert registered Blocks using B1~B8 or BB1~BB8 commands.

Execution Example

Key Details

ItemDescription
Selection TargetRecognizes only Block Reference objects. Other entities such as Lines, Text, and dimensions are ignored even if selected.
Save MethodSaves the names (Definition Names) of selected Blocks in order to memory (BlockNameList).
NumberingNumbers are assigned in selection order. First selection = number 1, second = number 2, …, maximum number 8.
Command Window OutputThe name of each selected Block is output to the command window.
Applicable EnvironmentAutoCAD / BricsCAD

Execution Result

ItemDescription
Saved ListSelected Block names are saved in order to BlockNameList.
Command Window OutputEach Block's name is output to the command window so you can verify the registration.
Next StepInsert registered Blocks using B1~B8 or BB1~BB8 commands.
Caution: If you run SSBlock again, the previously saved list will be completely overwritten. If you need the existing registration, verify it before re-running.
Note: Objects that are not Block References (Lines, Text, dimensions, etc.) will not be added to the list even if selected. You must select Block instances inserted in the drawing.
