B1 ~ B8  —  01_Block

B1  B2  B3  B4  B5  B6  B7  B8

A command that inserts the Block corresponding to a number from the Block list saved by SSBlock at a Pick Point (directly clicked) location, and immediately explodes it into individual entities.
▶ After insertion, the Block status is released and it is converted into individual objects rather than remaining a Block.

Purpose

Use to quickly place a Block of desired number (1~8) from those previously registered with SSBlock at a specific location on the screen. Since it explodes immediately upon insertion, it is suitable for tasks where Block definition is not maintained and components (lines, circles, etc.) need to be edited directly.

How to Use

  1. First, use SSBlock command to select Block objects in order and save them to memory.
    The selection order becomes the number (number 1, number 2, …).
  2. Enter the command corresponding to the number to insert (B1 ~ B8) in the AutoCAD or BricsCAD command line and press Enter.
  3. Click on the screen to select the insertion location according to the command prompt "Select location:".
  4. The Block is inserted at the clicked location and immediately exploded into individual objects.

ExplodeDecomposed immediately upon insertion — remains as individual entities, not Block Reference
Caution: Since it explodes after insertion, the original Block definition is not affected, but the inserted objects cannot be re-edited as a Block. Use BB1~BB8 if you want to insert while maintaining Block status.
Note: The command does not work if no Block is saved by SSBlock or if there is no Block corresponding to the specified number. First run SSBlock to register Blocks before using this command.
