FFB  —  06_Insert_Form

FFB

A command that measures the size of selected drawing and inserts Form block saved with SFB at automatic scale to match drawing.
Automatically fills drawing name, quantity, and scale text into Form placeholders.
AutoCAD / BricsCAD only — not available in Rhino.

Purpose

When 2D drawing objects are selected, automatically measures entire drawing size (width, height) and calculates scale and insertion position so Form selected in SFB wraps around drawing. Automatically fills drawing name, quantity, and scale values into Form text placeholders, completing drawing template without manual entry.

Operation Flow

StepStageDescription
1Drawing Object SelectionSelect all objects in drawing to be wrapped with Form (no filtering).
2Drawing Name & Quantity RecognitionAutomatically reads drawing number text and Qnt layer text from selected MText/DBText.
3Size MeasurementCalculates total drawing width (Length) and height (Height) using GeometricExtents of all entities except MText, MLeader, and Spline.
4Scale Automatic CalculationCompares drawing size with internal dimensions of Form block saved in SFB and calculates optimal scale for Form to wrap drawing.
5Form Block InsertionInserts Form block on Form-Frame layer with calculated scale and position.
6Polyline Copy & PlacementCopies Polyline saved in SFB and applies identical movement and scale transformation as Form.
7Text Placeholder FillingReplaces drawing number text with drawing name / Qnt text with quantity / Scale text with scale string in 1 / N format.

SFB → FFB Workflow

CommandRoleDescription
SFBForm Selection & SaveSelects Form block, text placeholders, and Polyline and saves them in static variables.
FFBForm InsertionSelects drawing objects, measures size, and inserts Form saved in SFB at automatic scale.

How to Use

  1. Execute SFB first to select Form block to use.
  2. Enter FFB in command line and press Enter.
  3. At "Select Object" prompt, select all objects in drawing to be wrapped with Form.
    (Selection range must include drawing number MText and Qnt layer text.)
  4. Press Enter to insert Form at automatic scale and position, with text placeholders filled with actual values.
  5. Calculated scale (Frame Scale : 1 / N) is output in command window.

Execution Example

Key Details

ItemDescription
PrerequisiteMust execute SFB first so Form block is saved in memory.
Selection TargetSelect all drawing objects without filtering. Drawing number MText and Qnt layer text must be included for automatic filling.
Size Measurement ExcludedMText, MLeader, and Spline are excluded from size measurement. Arc is measured using StartPoint/EndPoint.
Scale CalculationAutomatically determines optimal scale by comparing drawing width/height with Form block internal dimensions.
Insertion LayerForm block is inserted on Form-Frame layer (color 1).
Text ReplacementCopies drawing number, Scale, and Qnt text ObjectID saved in SFB and changes content to actual values read from drawing.
Applicable EnvironmentAutoCAD / BricsCAD (Rhino not supported)

Execution Result

ItemDescription
Form Block InsertionForm block is placed on Form-Frame layer at scale matching drawing size.
Polyline PlacementBoundary Polyline saved in SFB is copied and placed with identical transformation as Form.
Text Auto-FillingDrawing number, quantity, and scale (1 / N) are automatically filled at corresponding text positions in Form.
Note: FFB uses Form information saved in SFB. If FFB is executed without running SFB first, Form will not be inserted. If a new session is started, must re-execute SFB before FFB.
Caution: FFB is not available in Rhino (AutoCAD / BricsCAD only).
If drawing selection range does not include drawing number MText and Qnt layer text, Form's drawing number and quantity fields will be inserted empty.
