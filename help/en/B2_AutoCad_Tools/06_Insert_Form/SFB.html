SFB  —  06_Insert_Form

SFB

A command that selects drawing template (Form) block and saves it in memory.
When FFB command is executed later, Form is automatically inserted at scale and position matching drawing based on this reference.
AutoCAD / BricsCAD only — not available in Rhino.

Purpose

By pre-selecting company-specific drawing template (Form) block, FFB automatically calculates scale matching drawing size and inserts Form. SFB only handles Form selection and saves ObjectID of selected block, text placeholders, and polyline in static variables.

Required Form Components

ComponentRole
BlockReference (Form Block)Drawing template block body. Must be included in SFB selection range.
MText/DBText — Scale Layer
or text with content "Scale"		Scale notation placeholder. FFB replaces with automatically calculated scale string (1 / N).
MText/DBText — Qnt Layer
or text with content "Qnt"		Quantity notation placeholder. FFB replaces with quantity text read from drawing.
Other MText/DBTextDrawing number notation placeholder. FFB replaces with drawing name text.
PolylineBoundary polyline for AutoPlot. FFB copies and places with Form.

How to Use

  1. Verify that drawing file has company Form block, text placeholders (Scale, Qnt, drawing number), and Polyline placed.
  2. Enter SFB in command line and press Enter.
  3. At "Select Frame-form!" prompt, select all Form block, text, and Polyline together and press Enter.
  4. Selected Form information is saved in memory. Subsequently, insert Form into drawing with FFB.

Execution Example

Key Details

ItemDescription
Selection TargetSelect Form block, text placeholders (drawing number, Scale, Qnt), and Polyline together.
Saved ContentSaves block name, block position, Scale/Qnt/drawing number text ObjectID, and Polyline ObjectID in static variables.
AutoScale.datAfter selection is complete, reads AutoScale.dat and loads profile data into memory.
Layer Auto-CreationIf WS-PLOT-1 (color 1) and Qnt (color 0) layers do not exist, they are automatically created.
Applicable EnvironmentAutoCAD / BricsCAD (Rhino not supported)
Note: SFB saves Form information only in memory and does not insert anything in drawing. Actual Form insertion is performed with FFB. When session ends, saved information is reset, so after starting new session, must execute SFB first before executing FFB.
Caution: SFB is not available in Rhino (AutoCAD / BricsCAD only).
If Form block does not have Scale / Qnt / drawing number text, those items will not be filled when FFB is executed.
