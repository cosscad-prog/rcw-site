TAG  —  02_Text

TAG

A command that evenly aligns selected Text objects vertically based on the position of the first text.
X values are also unified to match the first text. Use XTAG to align while maintaining individual X values.

Purpose

Use to align scattered Text objects at regular intervals in the vertical direction. The position of the first selected text becomes the reference point, and the remaining texts are aligned downward at intervals of text height (Height × 1.6).

How to Use

  1. Enter TAG in the command line and press Enter.
  2. Select the Text objects to align. (The first selected text becomes the reference.)
  3. Press Enter to complete the selection.
  4. The selected texts are vertically aligned based on the position of the first text.
