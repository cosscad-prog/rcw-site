TTS  —  02_Text

TTS

A command that changes the AutoCAD system variable TEXTSIZE.
No object selection is required — it works by displaying the current value and accepting a new value. Set this before executing commands like CCText that are affected by text size.

Purpose

A shortcut command to quickly change the AutoCAD TEXTSIZE system variable. Since text-related commands like CCText (circled text creation) reference this value, setting it to the appropriate size beforehand ensures consistent text sizes throughout the work.

How to Use

  1. Enter TTS in the command line and press Enter.
  2. The current TEXTSIZE value is displayed in the command window.
    Example: "Enter TEXTSIZE [Current: 5]"
  3. Enter the desired new text size (positive integer) and press Enter.
  4. Verify the changed value in the command window.

Key Details

ItemDescription
OperationDisplays the current TEXTSIZE value in the command window and accepts a new value to change it.
Object SelectionNone — operates with numeric input only.
Input RestrictionOnly positive integers can be entered (0 and negative values are not allowed).
Application ScopeApplies to the entire AutoCAD session. The default size of subsequently created text is changed.
Applicable EnvironmentAutoCAD / BricsCAD

Execution Result

ItemDescription
Change ResultThe AutoCAD system variable TEXTSIZE is changed to the entered value.
Command Window OutputThe applied value after change is displayed in the command window.
Note: TTS sets the size referenced when creating circled text with CCText. After changing the size and executing CCText, the new size is immediately applied.
