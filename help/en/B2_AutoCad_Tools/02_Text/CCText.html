CCText

A command that continuously creates circled text numbers with sequential numbering from a specified starting number (Circle + number text) at each clicked location.
Text size follows the AutoCAD system variable TEXTSIZE, which is adjusted in advance using the TTS command.

Purpose

Use to quickly place circled serial numbers such as part numbers or detail numbers in multiple locations on the drawing. When a starting number is specified, the number automatically increases with each click, making it suitable for assigning consecutive numbers to multiple locations.

How to Use

  1. If text size adjustment is needed, first set TEXTSIZE using the TTS command.
  2. Enter CCText in the command line and press Enter.
  3. Enter the starting number (integer 1 or greater) at the "Enter Start number :" prompt and press Enter.
  4. Click to place the circled text at desired locations according to the "Pick Point" prompt.
    The number increases by 1 with each click, generating circled text.
  5. Press ESC or Enter to terminate the command.
