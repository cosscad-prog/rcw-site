XTAG

A command that evenly aligns selected Text objects vertically while maintaining each text's individual X value.
Operates the same way as TAG, but differs in that it does not unify X values to the first text.

Purpose

Use to equalize vertical spacing while keeping texts' horizontal positions (X values) unchanged. For example, when you want to align only the vertical positions of texts that are slightly offset horizontally.

How to Use

  1. Enter XTAG in the command line and press Enter.
  2. Select Text objects to align. (The first selected text becomes the Y/Z reference.)
  3. Press Enter to complete the selection.
  4. Selected texts are vertically aligned while maintaining their individual X values.

Key Details

ItemDescription
Selection TargetRecognizes only TEXT, MTEXT, and DBText objects. Other entities are automatically filtered.
Reference PositionAligns based on the Y/Z position of the first selected text.
X Value HandlingEach text's X value is individually maintained (unchanged).
Alignment SpacingUses the first text's Height × 1.6 as the spacing interval.
Alignment DirectionAligns in the Z-axis direction in Front View (XZ plane), and in the Y-axis direction in Top View (XY plane).
Applicable EnvironmentAutoCAD / BricsCAD
