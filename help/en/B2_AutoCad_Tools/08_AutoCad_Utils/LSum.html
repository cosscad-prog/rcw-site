LSum

A command that recognizes only Line objects from selected objects, calculates length total by layer name, and outputs as table in drawing.

Purpose

Use when automatically aggregating total length of Lines separated by layer. When member types are distinguished by layer, can quickly check total length by type and insert as table in drawing.

How to Use

  1. Enter LSum in command line and press Enter.
  2. At "Select Entity" prompt, select Lines to aggregate length and press Enter.
  3. Length total by layer is immediately output in command window.
  4. At "Select TList position:" prompt, click drawing location to place table.
  5. Length total table by layer is created at selected location.

Execution Example

Key Details

ItemDescription
Selection TargetSelects without filtering but processes only Line objects. Other entities like PolyLine, Arc are ignored.
Aggregation BasisGroups by Line layer name and sums length (mm, 1 decimal place).
SortingSorts by layer name ascending, then by length ascending within same layer, then aggregates.
Command Window OutputImmediately outputs in format {LayerName} : {Total mm} in command window.
Drawing TableIf 2+ layers, draws table with NO / LayerName / Length (mm) header + rows + Total row. If 1 layer, draws simple 2-column table.
Text SizeUses current TEXTSIZE system variable (replaced with 10 if below minimum).
Applicable EnvironmentAutoCAD / BricsCAD

Execution Result

ItemDescription
Command WindowLength total by layer is displayed in format {LayerName} : {Total} mm.
Drawing TableTable with NO / LayerName / Length (mm) + Total row is created at clicked location.
Note: Entities other than Line (PolyLine, Arc, Circle, etc.) are not included in results even if selected. To get length total of PolyLine, cannot use this command instead of ASum. Explode (EXPLODE) PolyLine into Lines and then use LSum.
