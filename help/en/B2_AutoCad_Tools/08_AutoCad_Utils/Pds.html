Pds

A command that aligns display direction of all Point objects in drawing to current view direction in batch.
Without need for user to select objects, automatically finds and processes all Points in drawing.

Purpose

Use when Points placed in drawing (e.g., Dim_Points, NC_BottomPoint, etc.) after view direction change are drawn based on previous view direction and do not display correctly on screen. On command execution, updates Normal vector of all Points in batch to current view direction (ViewDirection).

How to Use

  1. Set view direction to desired state.
  2. Enter Pds in command line and press Enter.
  3. All Points in drawing are automatically processed without separate selection.
  4. Verify number of Points processed in command window.

Execution Example

Key Details

ItemDescription
Object Selection MethodNo user selection. Automatically collects all Point (DBPoint) objects in drawing using SelectAll.
Processing ContentChanges Normal vector of each Point to ViewDirection of current view.
System Variable ChangeSets PDMODE = 35 (X mark + circle), PDsize = 1.
Repeated ExecutionInternally repeats identical processing twice for stable application.
Output MessageAfter processing completion, "Point N objects changed." and "Re_Draw_Point_and_Overkill completed." are output in command window.
Applicable EnvironmentAutoCAD / BricsCAD

PDMODE 35 Display Format

System VariableDescription
PDMODE = 35Displays Point as overlapping X mark and circle (3 + 32 = 35).
PDsize = 1Sets Point display size to 1 in screen pixel units.

Execution Result

ItemDescription
Point Normal UpdateNormal vector of all DBPoints in drawing is changed to current view direction.
PDMODE / PDsize ChangePoint display format is set to X+circle (PDMODE=35), size 1 (PDsize=1).
Command Window OutputNumber of processed Points and completion message are output.
Note: Pds applies to all Points in drawing. Be aware that even if you want to process only Points on specific layer, all are changed without distinction.
Since PDMODE and PDsize system variables are changed, if different Point display format was previously used, same format will apply to subsequent Point creation.
