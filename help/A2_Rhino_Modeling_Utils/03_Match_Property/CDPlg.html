CDPlg

기준 단면의 Additional Length 상자만 다른 단면들에 복사하는 명령입니다. 그 상자의 다섯 칸(Start · Length · 간격 · 수량 · 대칭)이 함께 넘어가고, 대상의 Profile 이름·단중·ID·Block 데이터는 그대로 둡니다.

사용 목적

여러 단면의 추가길이를 한 값으로 맞출 때 사용합니다. CDP는 단면 데이터를 통째로 복사하므로 Profile 이름과 단중까지 기준 객체 것으로 바뀌지만, CDPlg는 Additional Length 상자만 건드립니다. 단면마다 Pname 창을 열어 손으로 고치던 작업을 한 번에 끝냅니다.

사용 방법

  1. Rhino 명령창에 CDPlg를 입력하고 Enter를 누릅니다.
  2. 기준이 될 단면 하나를 선택합니다(Surface 또는 PolyCurve).
  3. 대상 단면들을 선택합니다. 여러 개를 한 번에 고를 수 있습니다.
  4. Enter를 누르면 복사가 끝나고, 명령창에 옮긴 값과 대상 개수가 표시됩니다.
참고: 대상은 기준 객체와 같은 종류만 고를 수 있습니다. 기준이 Surface면 Surface만, PolyCurve면 PolyCurve만 대상이 됩니다(CDP와 같은 규칙).

멀리언과 트랜섬 사이에도 값이 그대로 갑니다

추가길이는 저장될 때 네 칸으로 나뉘고, 멀리언과 트랜섬이 서로 다른 칸을 읽습니다. CDPlg는 저장 칸을 그대로 베끼지 않고 화면에 보이는 두 값(Top/Left, Bot/Right)으로 옮기므로, 기준이 멀리언이고 대상이 트랜섬이어도(또는 그 반대라도) 값이 제대로 전달됩니다.

화면 값멀리언이 읽는 칸트랜섬이 읽는 칸
Top / LeftAdditional_Length_Data_0Additional_Length_Data_2
Bot / RightAdditional_Length_Data_1Additional_Length_Data_3

예를 들어 기준 멀리언의 추가길이가 Top/Left 100, Bot/Right 50이면, 트랜섬 대상에도 100과 50이 들어갑니다.

참고: 100-5처럼 수식으로 넣은 값도 계산되지 않고 글자 그대로 복사됩니다.

실행 결과

명령창에 무엇을 얼마에 옮겼는지 표시됩니다.

  • CDPlg: 추가길이 상자 전체(Start·Length·간격·수량·대칭)를 대상 8개에 옮겼습니다. Start = Top/Left 100, Bot/Right 50.
  • 단면 데이터가 없던 대상이 있었다면 그 개수도 함께 알려 줍니다.
참고: 옮겨진 값이 함께 표시되므로, 0, 0이 나왔다면 기준 객체를 잘못 고른 것입니다. 그 자리에서 바로 알아챌 수 있습니다.

주의할 점

기준 객체에 단면 데이터가 없으면 중단됩니다. 옮길 추가길이가 없으므로 대상을 고르기 전에 멈추고, 대상의 값은 건드리지 않습니다.
대상에 단면 데이터가 없으면 새로 만들면서 기본값을 함께 채웁니다. Profile 이름 D_000, 단중 1.0, 비고 No_Data, 나머지 숫자 칸은 0 — Pname이 새 단면에 보여 주는 것과 같은 값입니다. 이것은 임시 이름일 뿐입니다. 그 객체를 단면으로 쓸 계획이라면 Pname으로 실제 Profile 이름과 단중·ID를 반드시 입력하십시오. 단면 데이터가 생겼기 때문에 SSP 사전검사와 UMD는 이 객체를 정상으로 보고 통과시킵니다 — 두 명령은 데이터가 있는지만 보고 이름이 임시값인지는 가리지 않습니다.
기준 객체의 짝이 어긋난 옛 도면에서는 부재 갈래를 따릅니다. 멀리언 칸과 트랜섬 칸에 서로 다른 값이 들어 있는 옛 데이터라면, 기준 객체가 멀리언인지 트랜섬인지에 따라 옮겨지는 값이 달라집니다. 결과 메시지의 값을 확인하십시오.
