X0, Y0, Z0  —  Move Zero

X0Y0Z0

선택한 객체를 지정 축의 0 기준면으로 정리하는 단순 원점 정렬 명령 모음입니다.

사용 목적

Curve, Point, Text의 특정 좌표값을 0으로 맞춰 단면선, 기준점, 문자 위치를 원점 기준으로 빠르게 정리할 때 사용합니다.

명령어 정리

명령어0으로 맞추는 좌표Curve 처리Point/Text 처리
X0X = 0YZ 평면으로 투영X 좌표만 0으로 이동
Y0Y = 0XZ 평면으로 투영Y 좌표만 0으로 이동
Z0Z = 0XY 평면으로 투영Z 좌표만 0으로 이동

사용 방법

  1. Rhino 명령창에 X0, Y0, Z0 중 필요한 명령을 입력합니다.
  2. 0 기준면으로 정리할 Curve, Point, Text 객체를 선택합니다.
  3. Enter를 누르면 선택 객체가 해당 축의 0 기준으로 정리됩니다.
참고: Curve는 기존 객체를 삭제하고 투영된 새 Curve로 대체됩니다. Point와 Text는 기존 속성을 유지한 채 해당 좌표만 0으로 이동합니다.
