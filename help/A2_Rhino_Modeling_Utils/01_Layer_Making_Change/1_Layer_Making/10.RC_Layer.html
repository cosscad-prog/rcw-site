10.RC_Layer  —  01_Layer_Making_Change

RC1 ~ RC9 / RCL

R_Center 계열 Layer를 만드는 명령 모음입니다.

사용 목적

RC 계열 레이어를 번호별로 생성해 Rhino Curtainwall 관련 기준 객체를 정해진 이름과 색상 체계로 분류할 때 사용합니다.

포함 명령어

명령어생성 LayerColor / 속성
RCLR_CenterXX Layer를 만듭니다. 숫자, 문자 입력이 가능합니다.숫자 입력 시 해당 CAD Color Number, 문자 입력 가능
RC1R_Center1 Layer를 만듭니다.41번 Color [CAD Color Number]
RC2R_Center2 Layer를 만듭니다.41번 Color [CAD Color Number]
RC3R_Center3 Layer를 만듭니다.41번 Color [CAD Color Number]
RC4R_Center4 Layer를 만듭니다.41번 Color [CAD Color Number]
RC5R_Center5 Layer를 만듭니다.41번 Color [CAD Color Number]
RC6R_Center6 Layer를 만듭니다.41번 Color [CAD Color Number]
RC7R_Center7 Layer를 만듭니다.41번 Color [CAD Color Number]
RC8R_Center8 Layer를 만듭니다.41번 Color [CAD Color Number]
RC9R_Center9 Layer를 만듭니다.41번 Color [CAD Color Number]

사용 방법

  1. Rhino 명령창에 필요한 명령어를 입력하고 Enter를 누릅니다.
  2. *L 형식의 명령은 입력한 숫자 또는 문자를 기준 Layer 이름 뒤에 바로 붙여 Layer를 만듭니다.
  3. 숫자를 입력하는 경우 해당 숫자를 CAD Color Number로 사용합니다. 256보다 큰 숫자는 코드에서 256으로 나눈 나머지 값을 Color Number로 사용합니다.
  4. Rhino 레이어 패널에서 Layer 이름, Color, Linetype 상태를 확인합니다.
