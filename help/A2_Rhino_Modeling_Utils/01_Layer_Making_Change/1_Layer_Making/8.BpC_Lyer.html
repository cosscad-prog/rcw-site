8.BpC_Lyer  —  01_Layer_Making_Change

BpC1 / BpC2 / BpCL

BackPanel 및 BP_Center 계열 Layer를 만드는 명령 모음입니다.

사용 목적

Bp_Center 계열 레이어를 생성해 BackPanel 기준선을 정해진 이름과 색상으로 분류할 때 사용합니다.

포함 명령어

명령어생성 LayerColor / 속성
BpCLBackPanel Layer를 만듭니다.RGB(210,170,128)
BpC1BP_Center1 Layer를 만듭니다.RGB(210,110,180)
BpC2BP_Center2 Layer를 만듭니다.RGB(210,90,180)

사용 방법

  1. Rhino 명령창에 필요한 명령어를 입력하고 Enter를 누릅니다.
  2. BpCL은 BackPanel Layer를 만들고, BpC1, BpC2는 BP_Center 뒤에 숫자를 바로 붙인 Layer를 만듭니다.
  3. Rhino 레이어 패널에서 Layer 이름, Color, Linetype 상태를 확인합니다.

주요 내용

항목설명
레이어 계열BackPanel, BP_Center
대상 명령BpC1, BpC2, BpCL

실행 결과 확인

항목설명
Layer 이름생성된 Layer 이름이 표의 생성 Layer와 일치하는지 확인합니다.
Layer ColorColor / 속성 열의 CAD Color Number 또는 RGB 값이 적용되었는지 확인합니다.
명령창명령 실행 후 표시되는 안내 또는 완료 메시지를 확인합니다.
