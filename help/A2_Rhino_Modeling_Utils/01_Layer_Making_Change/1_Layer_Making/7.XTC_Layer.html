7.XTC_Layer  —  01_Layer_Making_Change

XTC1 ~ XTC4 / XTCL

XT_Center 계열 Layer를 만드는 명령 모음입니다.

사용 목적

XT_Center 계열 레이어를 생성해 보조 Transom/추가 중심선 작업을 번호별 레이어로 구분할 때 사용합니다.

포함 명령어

명령어생성 LayerColor / 속성
XTCLXT_CenterXX Layer를 만듭니다. 숫자, 문자 입력이 가능합니다. 입력 대신 단면 group 을 고르면 그 이름에서 XTC 를 뗀 나머지를 씁니다(XTC3 → XT_Center3).숫자 입력 시 해당 CAD Color Number, 문자 입력 가능
XTC1XT_Center1 Layer를 만듭니다.RGB(255,91,0)
XTC2XT_Center2 Layer를 만듭니다.RGB(255,121,0)
XTC3XT_Center3 Layer를 만듭니다.RGB(255,151,0)
XTC4XT_Center4 Layer를 만듭니다.RGB(255,181,0)

사용 방법

  1. Rhino 명령창에 필요한 명령어를 입력하고 Enter를 누릅니다.
  2. *L 형식의 명령은 입력한 숫자 또는 문자를 기준 Layer 이름 뒤에 바로 붙여 Layer를 만듭니다.
  3. 숫자를 입력하는 경우 해당 숫자를 CAD Color Number로 사용합니다. 256보다 큰 숫자는 코드에서 256으로 나눈 나머지 값을 Color Number로 사용합니다.
  4. XTCL 은 이름을 묻는 자리에서 단면 group 의 객체(이름 글자 · 선 · 면 아무것이나)를 클릭해도 됩니다. group 이름이 XTC3 면 XT_Center3 를 만들고, 명령창에 단면 group "XTC3" -> 레이어 XT_Center3 가 표시됩니다. 이 레이어의 선은 Xtract 명령 에서 바로 그 단면 group 을 찾습니다. XT_Center1 ~ XT_Center9 가 되는 group 만 고를 수 있습니다(XT_Center 선을 읽는 명령이 그것만 받습니다). Enter 만 누르면 지난 값을 씁니다.
  5. Rhino 레이어 패널에서 Layer 이름, Color, Linetype 상태를 확인합니다.

참고: XTCL은 입력값을 XT_Center 뒤에 바로 붙여 새 레이어를 만듭니다. 숫자 입력 시 해당 CAD Color Number가 적용되므로, 보조 중심선 번호와 색상을 함께 맞추기 좋습니다.
단면 group 을 골랐는데 아래의 경우면 알림만 남기고 아무것도 바꾸지 않고 멈춥니다: 고른 객체가 group 에 없음 · group 에 이름 글자가 없음 · 이름 글자가 둘 이상 · 이름이 XTC 로 시작하지 않음(예 ATC_M3a — 이 선은 단면을 못 찾습니다) · 레이어 이름으로 쓸 수 없는 글자 · XT_Center1 ~ XT_Center9 가 아님.
