1.AnP_Layer  —  01_Layer_Making_Change

ANP1 ~ ANP5 / ANPL

AN_Point 계열 Point Layer를 만드는 명령 모음입니다.

사용 목적

AN_Point 계열 포인트 레이어를 빠르게 만들고, Anchor Point 기준점 작업에 필요한 번호별 레이어와 색상을 일관되게 준비할 때 사용합니다.

포함 명령어

명령어생성 LayerColor / 속성
ANPLAN_PointXX Layer를 만듭니다. 숫자, 문자 입력이 가능합니다.숫자 입력 시 해당 CAD Color Number, 문자 입력 가능
ANP1AN_Point1 Layer를 만듭니다.1번 Color [CAD Color Number]
ANP2AN_Point2 Layer를 만듭니다.2번 Color [CAD Color Number]
ANP3AN_Point3 Layer를 만듭니다.3번 Color [CAD Color Number]
ANP4AN_Point4 Layer를 만듭니다.4번 Color [CAD Color Number]
ANP5AN_Point5 Layer를 만듭니다.5번 Color [CAD Color Number]

사용 방법

  1. Rhino 명령창에 필요한 명령어를 입력하고 Enter를 누릅니다.
  2. *L 형식의 명령은 입력한 숫자 또는 문자를 기준 Layer 이름 뒤에 바로 붙여 Layer를 만듭니다.
  3. 숫자를 입력하는 경우 해당 숫자를 CAD Color Number로 사용합니다. 256보다 큰 숫자는 코드에서 256으로 나눈 나머지 값을 Color Number로 사용합니다.
  4. Rhino 레이어 패널에서 Layer 이름, Color, Linetype 상태를 확인합니다.

실행 결과 확인

항목설명
Layer 이름생성된 Layer 이름이 표의 생성 Layer와 일치하는지 확인합니다.
Layer ColorColor / 속성 열의 CAD Color Number 또는 RGB 값이 적용되었는지 확인합니다.
명령창명령 실행 후 표시되는 안내 또는 완료 메시지를 확인합니다.
참고: ANPL은 입력값을 AN_Point 뒤에 바로 붙여 새 레이어를 만듭니다. 숫자 입력 시 해당 CAD Color Number가 적용되므로, 번호 체계를 맞춰 입력하는 것이 좋습니다.
