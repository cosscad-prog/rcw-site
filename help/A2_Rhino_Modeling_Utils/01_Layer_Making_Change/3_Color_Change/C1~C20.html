C1~C20  —  01_Layer_Making_Change

C1 ~ C20

선택한 Object의 표시 Color만 CAD Color Number 기준으로 변경하는 명령 모음입니다.

사용 목적

Layer는 그대로 유지하면서 객체 표시 색상만 즉시 변경할 때 사용합니다. 검토 표시, 임시 강조, 모델 정리 과정에서 객체를 색상별로 구분하기 좋습니다.

포함 명령어

명령어기능
C1선택한 Object의 Color를 1번 Color [CAD Color Number]로 변경합니다.
C2선택한 Object의 Color를 2번 Color [CAD Color Number]로 변경합니다.
C3선택한 Object의 Color를 3번 Color [CAD Color Number]로 변경합니다.
C4 ~ C17같은 방식으로 명령어 번호와 같은 CAD Color Number로 Object Color를 변경합니다.
C18선택한 Object의 Color를 18번 Color [CAD Color Number]로 변경합니다.
C19선택한 Object의 Color를 19번 Color [CAD Color Number]로 변경합니다.
C20선택한 Object의 Color를 20번 Color [CAD Color Number]로 변경합니다.
주의: 이 명령은 Layer와 상관없이 작동합니다. 선택한 Object의 Color만 변경하며 Layer는 변경하지 않습니다.

사용 방법

  1. Rhino 명령창에 필요한 명령어를 입력하고 Enter를 누릅니다.
  2. Color를 변경할 Object를 선택합니다.
  3. Enter를 눌러 선택한 Object의 표시 Color 변경을 완료합니다.

항목설명

실행 결과 확인

항목설명

참고: C1~C20은 선택 객체에 지정 번호의 CAD 색상을 빠르게 적용합니다. 레이어를 바꾸는 명령이 아니므로, 객체를 레이어 색상으로 되돌릴 때는 속성의 Color Source를 함께 확인하십시오.
