D7, T7, O7  —  자주 쓰는 Layer 변경

D7T7O7

선택 객체를 자주 사용하는 기본 Layer로 빠르게 보내는 레이어 변경 명령 모음입니다.

사용 목적

작업 중 흩어진 객체를 Default, Text, OutLines 같은 자주 쓰는 Layer로 즉시 정리해 모델링과 도면 작업의 분류를 빠르게 맞출 때 사용합니다.

명령어 정리

명령어이동 LayerColor사용 상황
D7DefaultWhite임시 객체나 분류 전 객체를 기본 Layer로 되돌릴 때 사용합니다.
T7TextWhite도면 문자, 표기, 주석 객체를 Text Layer로 모을 때 사용합니다.
O7OutLinesWhite외곽선이나 출력용 윤곽선을 OutLines Layer로 정리할 때 사용합니다.

사용 방법

  1. Rhino 명령창에 D7, T7, O7 중 필요한 명령을 입력합니다.
  2. 해당 Layer로 보낼 객체를 선택합니다.
  3. Enter를 누르면 선택 객체가 지정 Layer로 이동합니다.
참고: 세 명령은 객체를 빠르게 정해진 Layer로 보내는 용도입니다. 현재 Layer를 바꾸는 명령이 아니라 선택 객체의 Layer를 변경하는 명령으로 이해하면 됩니다.
