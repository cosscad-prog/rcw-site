System Default  —  사용자 기본값 저장

RCW의 여러 기능 기본값을 System_Default.dat 한 파일에 저장합니다. 이 파일은 설치 PC 단위로 보관되므로, 사용자(PC)마다 다른 기본값을 가질 수 있습니다. 각 기능은 실행 시 이 파일을 읽어 저장된 기본값을 자동으로 적용합니다.

저장 파일

항목내용
위치RCW 데이터 폴더의 System_Default.dat. 전체 경로는 저장할 때 명령창에 찍힙니다 — 그 줄을 복사하면 파일을 바로 찾을 수 있습니다.
형식key=value 한 줄에 하나. # 로 시작하는 줄은 주석.
공유여러 기능이 같은 파일을 공유합니다. 저장 시 자기 항목만 갱신하고 다른 기능의 값은 보존합니다.
편집필요하면 메모장 등으로 직접 열어 값을 수정할 수 있습니다(재빌드 불필요).

현재 저장되는 항목

기능저장 내용
DdOptDrawing 옵션 패널의 체크박스·입력값(View/거리/치수/모델 표시 등) 전체.
DsOpt현재 DimStyle 이름과 배수값(First·Gap·Angle·LnR), 그리고 Top/Bottom/Left/Right Max 체크 상태.
Fablist라벨 방식(Fablist_LabelType = A/B)과 라벨 글자 배율(Fablist_LabelFontScale).
참고: 저장 항목은 앞으로 다른 기능까지 확장될 수 있습니다. (현재는 DdOpt·DsOpt·Fablist 기준)

저장 방법

기능방법
DdOpt패널 위쪽의 작은 D 버튼을 누릅니다.
DsOptApply 버튼 아래의 작은 D 버튼을 누릅니다.
Fablist명령 실행 중 옵션 SaveAsDefault 를 On으로 두고 객체 선택을 마치면, 현재 LabelType·LabelFontScale 가 기본값으로 저장됩니다.
눌렀는지 어떻게 아나 — 버튼이 파랗게 바뀝니다. 저장한 뒤 값을 하나라도 다시 바꾸면 원래 색으로 돌아옵니다. 그래서 지금 화면 값이 기본값과 같은지 버튼 색만 보고 알 수 있습니다. 저장한 파일의 전체 경로는 명령창에 함께 찍힙니다.

적용

  1. 해당 기능을 실행하면 System_Default.dat의 저장값을 자동으로 읽어 적용합니다.
  2. 저장된 값이 없으면 현재(코드) 기본값을 사용하고, 없는 항목은 자동으로 시드(기록)됩니다.
  3. 사용자(PC)마다 다른 파일이므로, 사람마다 선호하는 기본값으로 항상 동작하게 만들 수 있습니다.
주의: 이 파일은 설치 PC 단위 설정입니다. 다른 PC로 같은 기본값을 옮기려면 파일을 복사해야 합니다.
