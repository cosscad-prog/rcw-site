LC  —  02_Layer_Control

LC

선택 객체가 속한 레이어를 잠가 실수 편집을 막는 레이어 제어 명령입니다.

사용 목적

선택 객체가 속한 레이어를 잠가, 기준 객체를 보이게 유지하면서 실수로 편집되지 않게 보호할 때 사용합니다.

사용 방법

  1. Rhino 명령창에 LC를 입력하고 Enter를 누릅니다.
  2. 필요한 경우 대상 객체나 레이어를 선택합니다.
  3. Enter를 눌러 명령을 완료하고 Rhino 화면 또는 명령창 결과를 확인합니다.

관련 Layer 제어 명령

명령어동작 요약사용 상황
AD선택 객체 Layer만 켜기선택한 객체가 속한 Layer와 관련 상위/하위 Layer만 보이게 하고 나머지는 숨겨 작업 대상을 집중해서 볼 때 사용합니다.
AF선택 객체 Layer 끄기선택한 객체가 속한 Layer를 화면에서 숨겨, 확인이 끝난 부재나 방해되는 Layer를 빠르게 제외할 때 사용합니다.
LO전체 Layer 켜기숨겨진 Layer를 다시 표시합니다. 잠금 상태는 유지되므로 잠긴 Layer는 별도로 해제해야 합니다.
ADF선택 객체 Layer만 편집 가능선택 객체가 속한 Layer만 작업 가능하게 남기고 다른 Layer를 잠가 특정 부재군 작업에 집중할 때 사용합니다.
ALO전체 Layer 켜기 + 잠금 해제숨김/잠금 처리된 Layer를 한 번에 복구해 전체 모델을 다시 확인하고 편집 가능한 상태로 돌릴 때 사용합니다.
LC선택 객체 Layer 잠금선택한 객체가 속한 Layer를 잠가 기준 객체를 보이게 유지하면서 실수로 편집되지 않게 보호할 때 사용합니다.
참고: 선택 객체가 속한 레이어를 잠급니다. 현재 레이어는 잠금 대상에서 제외되므로, 잠그려는 레이어가 Current Layer인지 확인하십시오.
