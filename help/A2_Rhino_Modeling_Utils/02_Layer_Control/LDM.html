LDM

초기 모델링과 도면 작업에 필요한 기본 Layer와 Annotation DimStyle을 한 번에 생성하는 세팅 명령입니다.

사용 목적

새 파일 또는 초기 작업 단계에서 자주 쓰는 기본 Layer와 DimScale별 DimStyle을 빠르게 준비해, 이후 모델링/치수/문자 작업의 기준을 통일할 때 사용합니다.

사용 방법

  1. Rhino 명령창에 LDM를 입력하고 Enter를 누릅니다.
  2. 명령이 실행되면 기본 Layer와 Annotation DimStyle이 생성됩니다.
  3. Rhino의 Layer 패널과 DimStyle/Annotation 설정에서 생성된 항목을 확인합니다.
