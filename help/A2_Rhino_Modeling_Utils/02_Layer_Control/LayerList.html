LayerList

선택한 모든 객체가 속한 Layer를 목록으로 확인하는 레이어 점검 명령입니다.

사용 목적

선택한 객체 전체가 어떤 Layer들에 분산되어 있는지 빠르게 확인해, 모델 정리 전 Layer 구성과 객체 분류 상태를 점검할 때 사용합니다.

사용 방법

  1. Rhino 명령창에 LayerList를 입력하고 Enter를 누릅니다.
  2. Layer 목록을 확인할 객체들을 선택합니다.
  3. Enter를 누르면 선택한 모든 Object의 Layer가 List로 표시됩니다.

실행 예시

SSLayerList와 차이

명령어Layer List 대상
LayerList선택한 모든 Object의 Layer를 표시합니다.
SSLayerList선택한 Object 중 Surface Object의 Layer만 표시합니다.
참고: 객체 종류와 관계없이 선택된 전체 Object의 Layer를 확인할 때는 LayerList를 사용합니다. Section Surface Layer만 확인하려면 SSLayerList가 더 적합합니다.
