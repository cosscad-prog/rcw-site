SSLayerList

선택한 객체 중 Surface Object가 속한 Layer만 목록으로 확인하는 레이어 점검 명령입니다.

사용 목적

선택 범위 안에서 Surface Object만 기준으로 Layer를 추려, Section Object에 사용된 Surface Layer 구성을 확인할 때 사용합니다.

사용 방법

  1. Rhino 명령창에 SSLayerList를 입력하고 Enter를 누릅니다.
  2. Layer를 확인할 Section Object 또는 관련 객체들을 선택합니다.
  3. Enter를 누르면 선택한 Object 중 Surface Object의 Layer만 List로 표시됩니다.

실행 예시

LayerList와 차이

명령어Layer List 대상
LayerList선택한 모든 Object의 Layer를 표시합니다.
SSLayerList선택한 Object 중 Surface Object의 Layer만 표시합니다.
참고: 실행 예시처럼 Section Object에 어떤 Surface Layer가 포함되어 있는지 확인할 때 유용합니다. Line, Text, Block 등 Surface가 아닌 객체는 Layer List 대상에서 제외됩니다.
