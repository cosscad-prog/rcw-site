HD  —  02_Layer_Control

HD

선택한 Line 객체의 Linetype을 Hidden으로 변경하는 도면 보조 명령입니다.

사용 목적

2D 도면 정리 과정에서 선택한 선을 숨은선 표현으로 바꿔, 보이는 선과 구분되는 Hidden Line을 빠르게 만들 때 사용합니다.

사용 방법

  1. Rhino 명령창에 HD를 입력하고 Enter를 누릅니다.
  2. Linetype을 Hidden으로 바꿀 Line 객체를 선택합니다.
  3. Enter를 눌러 완료하면 선택한 Line의 Linetype이 Hidden으로 변경됩니다.
참고: HD는 Layer를 변경하지 않고 선택 객체의 Linetype만 Hidden으로 바꿉니다. 따라서 객체가 어느 Layer에 있든 같은 방식으로 적용되며, Hidden Linetype이 문서에 없으면 먼저 Linetype 목록을 확인하는 것이 좋습니다.
