R45  —  Right View 45도 가공

Fab_ID = 5.R45

Profile 기준 Right View에서 Profile 상하 끝을 45도로 절단 가공하는 Fab ID 설정입니다.

사용 목적

Profile의 Right View 기준으로 상단 또는 하단 끝단에 45도 절단 가공이 필요할 때 사용합니다. 지정된 Profile 방향을 기준으로 절단 각도를 적용하여 끝단 형상을 가공합니다.

적용 기준

  1. 가공할 Profile의 Fab ID를 5.R45로 지정합니다.
  2. Profile 기준 Right View 방향을 확인합니다.
  3. Profile의 상하 끝단에 45도 절단 가공을 적용합니다.
  4. 가공 후 절단 방향과 끝단 형상이 의도한 Right View 기준과 맞는지 확인합니다.
