Frame Modeling 진행 순서

처음 사용자를 위한 단계별 가이드 — RCW Rhino Plugin

📋 시작 전 준비사항

  • Wire Frame(Mullion·Transom 기준선)이 완성되어 있어야 합니다.
  • Section 데이터(Profile, Block 정보)가 등록되어 있어야 합니다.
  • 각 Unit 그룹이 정의되어 있어야 합니다.
1
모델링 실행
UMD Unit Frame 모델링

Wire Frame에서 선택한 Unit 그룹의 Mullion·Transom 기준선을 분석하여 프레임 Solid와 관련 Block을 자동으로 생성합니다.
가장 핵심이 되는 단계로, 모든 후속 작업의 기반이 됩니다.

프레임 Solid 모델 및 Block 자동 생성
▶ UMD 상세 도움말
2
데이터 검사
CheckPfData ProfileData 검사

UMD 실행 후 생성된 프레임의 ProfileData가 올바르게 기록되었는지 확인합니다. 이후 단계에서 번호 부여나 리스트 작성이 제대로 되려면 데이터 오류가 없어야 합니다.

오류 항목 목록 출력 — 오류 없으면 다음 단계 진행
▶ CheckPfData 상세 도움말
3
데이터 추가 (선택)
AddBrkdata 브라켓 데이터 추가 선택

Bracket이 있는 경우, 해당 브라켓 객체에 필요한 데이터를 추가 기록합니다. 브라켓이 없는 프로젝트는 이 단계를 건너뜁니다.

브라켓 객체에 위치·타입 등 데이터 기록
▶ AddBrkdata 상세 도움말
4
번호 부여
FabNo 제작 번호 부여

모델링된 프레임 Brep·Block을 분석하여 ProfileData에 제작 번호를 자동으로 부여합니다. 동일한 Profile은 같은 번호를 공유하며, 이후 리스트·도면 작업의 기준이 됩니다.

각 프레임에 고유 제작 번호(FabNo) 할당
▶ FabNo 상세 도움말
5
리스트 작성
Molist 자재 리스트 작성

선택한 프레임의 ProfileData와 Block 정보를 읽어 자재 수량 리스트를 생성합니다. 수량·중량 집계에 사용하며, 발주 및 공정 계획의 기초 자료가 됩니다.

프레임 자재 수량표 생성 (Rhino 도면에 삽입)
▶ Molist 상세 도움말

※ 아래 두 리스트는 필요에 따라 Molist와 병행하여 작성합니다.

5-1
PMolist Profile 자재 리스트 선택

Profile 중심의 수량·중량 리스트. Profile 단가 계산이나 발주서 작성 시 활용합니다.

▶ PMolist 상세 도움말
5-2
Cuttinglist 절단 계획표 작성 선택

절단 길이별로 집계하고 장바 길이·Loss를 계산하여 절단 계획표를 생성합니다. 공장 절단 작업 지시서로 사용됩니다.

▶ Cuttinglist 상세 도움말
6
제작 도면
FabTable 제작 번호 테이블 작성

FabNo에서 부여된 제작 번호를 기반으로 번호별 수량·길이 테이블을 작성합니다. 제작 도면의 부품 표로 활용됩니다.

제작 번호별 수량·길이 테이블 생성
▶ FabTable 상세 도움말
7
FDwg 제작 가공도 자동 생성

선택한 프레임 그룹 객체를 분석하여 제작 가공도(Fab Drawing)를 자동으로 생성합니다. DimStyle은 DsOpt에 설정된 스타일을 따르며, Fdds.dat 파일에 Profile 정보가 등록되어 있어야 합니다.

프레임별 제작 가공도 자동 출력
▶ FDDS 상세 도움말
처음 사용 시 권장 순서: 단계 1 → 2 → 4 → 5(Molist) → 6 → 7 순서로 진행하세요. 데이터 오류가 없으면 CheckPfData(2단계)는 간략히 확인 후 넘어가도 됩니다. AddBrkdata·PMolist·Cuttinglist는 프로젝트 조건에 따라 선택적으로 사용합니다.

순서명령어역할필수/선택

5-2Cuttinglist절단 계획표 작성선택
