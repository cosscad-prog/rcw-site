Mullion Modeling  —  Mullion 만들기

MC1 ~ MC20 WVector SSP UMD

Mullion WireFrame을 작성하고, Layer와 방향 데이터를 지정한 뒤 선택한 Section으로 Mullion을 모델링하는 절차입니다.

기본 조건

항목설명
연결 조건Mullion WireFrame은 Transom Line과 반드시 연결되어 있을 필요는 없습니다.
LayerMullion Line은 M_Center Layer여야 합니다.
방향점Mullion Line은 방향점이 있어야 합니다. 생략된 경우 절대좌표 기준 Y 방향으로 처리됩니다.

따라하기

  1. 라인을 아래에서 위 방향으로 그립니다.
  2. dir 명령 또는 기본 메뉴의 Direction 아이콘으로 라인 방향을 확인합니다.
  3. 방향이 맞지 않으면 선을 반복 클릭하여 방향을 바꿉니다.
  4. MC1 ~ MC9 명령으로 라인의 Layer를 변경합니다.
  5. 방향점도 선과 같은 Layer로 지정합니다. 방향점은 라인 끝점에서 300 범위 안에 있어야 합니다.
  6. 라인과 방향점을 선택하여 Group을 만듭니다. 선이 하나만 있어도 Group을 만들 수 있습니다.
  7. WVector를 실행하고 만든 Group을 선택하여 모든 라인에 방향 데이터를 생성합니다.
  8. SSP로 사용할 Section을 선택합니다.
  9. UMD를 실행하고 Wire Group을 선택하여 모델링합니다.

세부 기준

단계설명
방향점라인 끝점에서 300 범위 안의 같은 Layer 점만 방향점으로 인식합니다.
기본 방향범위 안에 같은 Layer의 방향점이 없으면 절대좌표 Y 방향으로 라인 방향을 자동 설정합니다.
Group모델링은 Group을 하나의 창으로 인식하고, Group 내부의 요소를 찾아 수행합니다.
Line DataWVector는 반드시 실행해야 하며, Group 안에서 연결되는 정보를 라인 내부 데이터로 저장합니다.
Section해당 Layer에 맞는 Section이 있어야 UMD 모델링이 실행됩니다.

실행 예시

주의: WVector를 실행하지 않으면 Line Data가 생성되지 않아 Group 내부 연결 정보를 사용할 수 없습니다.
