MakeTemp  —  Temp Profile

MakeTemp

Fab ID가 2.Temp인 보조 Profile을 작성하여 모델링 완료 후 삭제되도록 지정하는 명령입니다.

사용 목적

선택한 Surface의 모델링이 완료된 후, 형상의 최대 길이를 기준으로 Screw Block 위치가 결정됩니다. Bracket 형상이 길어지면 Screw Block이 원하는 위치에 정렬되지 않을 수 있으므로, Bracket 앞에 작은 보조 Profile을 만들어 기준 길이를 조정할 때 사용합니다.

사용 방법

  1. Rhino 명령창에 MakeTemp를 입력하고 Enter를 누릅니다.
  2. Bracket 앞쪽에 Screw Block 정렬 기준이 될 작은 보조 Profile을 작성합니다.
  3. 보조 Profile의 Fab ID를 2.Temp로 지정합니다.
  4. 작성한 보조 Profile에 Screw Block을 연결합니다.
  5. 모델링 완료 후 2.Temp Profile이 삭제되는지 확인합니다.
