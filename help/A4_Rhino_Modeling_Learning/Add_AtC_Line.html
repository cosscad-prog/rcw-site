AtC Line  —  AT_Center Layer 추가

ATC1 ~ ATCXX

특정 위치에 AT_Center Layer를 추가하여 Attach Profile 위치를 별도로 지정하는 기능입니다.

사용 목적

같은 Mullion Line 또는 Transom Line 위에 서로 다른 위치의 Attach Profile이 배치되어야 할 때 사용합니다. 선택한 선을 AT_Center 계열 Layer로 만들어 Attach Profile 기준선으로 활용합니다.

사용 방법

  1. Layer 이름을 AT_Center 또는 AT_CenterXX 형식으로 준비합니다.
  2. Rhino 명령창에 ATC1 ~ ATCXX 형식의 명령을 입력합니다.
  3. AT_Center로 만들 선을 선택합니다.
  4. 선이 Mullion Line 또는 Transom Line 위에 겹치도록 배치되어 있는지 확인합니다.

배치 기준

항목설명
Mullion Line 위해당 Mullion Line의 방향 Point를 따릅니다.
Transom Line 위해당 Transom Line의 방향 Point를 따릅니다.
길이 기준선의 길이로 Section Profile의 길이를 조절할 수 있습니다.

실행 예시

주의: AT_Center 선은 Mullion Line 또는 Transom Line 위에 겹치도록 배열해야 합니다.
