F45  —  Front View 45도 가공

Fab_ID = 4.F45

모델링 Front View 기준으로 두 선의 중간 각도를 찾아 45도 방향 가공을 적용하는 Fab ID 설정입니다.

사용 목적

Glass 두께 변경 등으로 Adapter와 같은 부재에 선택적인 45도 가공이 필요할 때 사용합니다. Mullion Line과 Transom Line이 만나는 면을 기준으로 절단 각도를 계산하여 가공합니다.

적용 기준

  1. 가공할 부재의 Fab ID를 4.F45로 지정합니다.
  2. Model Front View 기준에서 Mullion Line과 Transom Line이 만나는 면을 확인합니다.
  3. 두 선 사이의 중간 각도를 기준으로 절단 각도를 산정합니다.
  4. 직각이 아닌 경우에도 두 선의 중간 각도를 유지하여 가공합니다.
