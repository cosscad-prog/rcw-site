R-Dist  —  상·하부 나란한 경사 가공

Fab_ID = 6.R-Dist

부재의 위 끝과 아래 끝을 서로 나란한 경사로 절단하는 Fab ID 설정입니다. 경사는 각도가 아니라 거리값(높이 차이, mm)으로 정합니다.

사용 목적

sleeve 처럼 위·아래 끝이 같은 방향으로 조금 기울어야 하는 부재에 사용합니다. 5.R45 는 위·아래가 마주 보는 45도 경사(사다리꼴)이고, 6.R-Dist 는 위·아래가 나란한 경사(평행사변형)입니다.

거리값의 뜻

항목설명
아래 끝깊이 한쪽의 가장 낮은 모서리에서 시작해, 반대쪽 끝에서 거리값만큼 올라갑니다.
위 끝아래 끝과 나란하게, 반대쪽의 가장 높은 모서리에서 시작해 거리값만큼 내려갑니다.
전체 길이바뀌지 않습니다. 한쪽 모서리만 거리값만큼 짧아집니다.
깊이그 부재 자신의 크기로 잽니다(센터라인의 방향 기록 쪽 폭). 같은 거리값이라도 깊이가 다른 부재는 각도가 다릅니다 — 깊이 100 에 10 이면 약 5.7도, 깊이 50 에 10 이면 약 11.3도.
음수-10 처럼 넣으면 반대 방향으로 기웁니다.
계산식5+5 같은 식도 쓸 수 있습니다.

적용 기준

  1. Pname 창에서 가공할 단면의 Fab ID 를 6. R-Dist 로 고릅니다.
  2. Fab ID 콤보 바로 오른쪽 칸에 거리값을 넣습니다. 이 칸은 6번일 때만 켜집니다.
  3. 저장한 뒤 UMD 로 모델링합니다.
  4. 기운 방향이 반대이면 거리값의 부호를 바꿉니다.

Rhino Properties 패널의 RCW Section 탭에서도 같은 자리(Fab_ID 오른쪽 칸)에서 고칠 수 있습니다.

참고: Fab ID 를 다른 번호로 바꿔도 넣어 둔 거리값은 지워지지 않고 칸만 꺼집니다. 다시 6번으로 돌아오면 그 값이 그대로 나옵니다.
주의:
  • 6번인데 거리값이 비었거나 0 이면 Pname 이 저장을 막습니다. 다른 길(Dtable 등)로 6번이 된 단면에 값이 없으면 모델링이 자르지 않고 "Fab_ID 6 (R-Dist): … 의 끝을 자르지 못했습니다" 로 알립니다.
  • 다른 부재와 겹치는 끝은 모델링 뒤 단계가 겹친 만큼 다시 잘라 냅니다. 겹침이 거리값보다 크면 경사가 최종 부재에 남지 않습니다.
  • 단면 group 에서 압출되는 부재에만 적용됩니다. 블록으로 끼우는 부속은 Fab ID 를 읽지 않습니다.
