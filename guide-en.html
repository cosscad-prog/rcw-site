Installation & Activation Guide

Core · Standard · Trial | From installation to local help

Before you begin: There is one installer, RCW5.exe. You choose the Rhino version (7 or 8) and the edition during setup. For the full version (Core or Standard) keep the customer code from your welcome email (it starts with RCW-) at hand. The language is chosen during setup too; Korean and English are both in the one file. Close Rhino before installation. For the full version this guide opens automatically when installation finishes.

1. Install

A warning may appear during installation — this is expected.
“Windows protected your PC” (blue screen) → click More info, then Run anyway
Antivirus scan dialog → wait for the scan to finish, then choose the option that allows the file to run (the button name differs by product: Allow / Run anyway / Add to exceptions / Trust this program)
The installer does not yet carry a code-signing certificate, which is why these appear. It does not indicate a problem with the file. If it still will not install, contact us with the name of your antivirus.
  1. Run RCW5.exe and approve Windows administrator access if requested.
  2. Choose the Rhino version — Rhino 7 or Rhino 8. A version not installed on this PC cannot be chosen. RCW is installed into one Rhino at a time.
  3. Choose the edition.
    • Full version — enter your customer code; it decides Core or Standard. Hyphens, spaces and lower case do not matter.
    • Trial — choose Core Trial or Standard Trial. No code is needed.
  4. Finish setup. If Rhino is open, setup asks to close it and reopens it afterwards.
  5. Start Rhino. The trial period is counted from this first successful load.
CorePerpetual commercial edition with the Core command scope
StandardPerpetual commercial edition with the full general command scope
Core Trial90-day evaluation using the Core command scope; no license file is required.
Standard Trial30-day evaluation using the full command scope; no license file is required.
If something comes up
“This customer code could not be confirmed” — check the code. If you enter the machine code (RCW5-) by mistake, setup tells you so.
No internet connection — if this PC already has a license, setup installs that edition. On a PC installing for the first time, connect to the internet and run setup again. Trials install without internet.
An earlier RCW is installed — the new setup takes it over and cleans it up, so only RCW5 remains in the Control Panel. Your license, customer code and settings stay as they are.

2. Activate Core / Standard

Get your license yourself on the customer page — no need to contact us. If this PC already has a license (reinstall or update), you can skip this.

  1. When Rhino first starts without a license file, it automatically displays and copies the machine code, then opens this guide. You can also run RCWMachineCode manually.
  2. Go to www.beimptech.com/rcw/customer and enter the customer code you were sent (it starts with RCW-).
  3. In the License section further down the page, paste the machine code from step 1 into the Machine code field and press [Request license].
  4. A [Download license] button appears in the same place, usually within a minute. The page updates by itself — no need to refresh.
  5. Save the downloaded license file (.lic) in a safe location.
  6. Run RCWLicense in Rhino and select that .lic file.
  7. Confirm the success message and restart Rhino.
Two codes — do not mix them up.
Customer code — RCW-... · sent to you by email. Use it during setup and to sign in to the customer page. It does not expire, so the same code stays with you even after you change PCs. The code you enter during setup is saved, and RCWVersion shows it at any time.
Machine code — RCW5-CO-... or RCW5-ST-... · shown by Rhino. Use it to request the license once signed in.
Important: Do not manually copy a license file into Program Files. Always import it with RCWLicense. One license is issued per PC. A new license must be issued after replacing the PC or changing the machine code; request it on the customer page and we will confirm it with you.

3. Trial

  • Core Trial runs for 90 days with the Core command scope; Standard Trial runs for 30 days with the full command scope.
  • The period begins at the first successful load and keeps that start date when reinstalled under the same Windows user account.
  • The two periods are counted separately — using up the 90 days of Core Trial leaves the 30 days of Standard Trial untouched.
  • After Trial, purchase Core or Standard and follow the activation procedure above.

4. Help and support

  • Run RcwHelp in Rhino to open the installed local help.
  • To change the help language, run RCW5.exe again and pick the other language. Your license and customer code stay as they are.
  • RCW sends information once when setup finishes (installed version, Rhino version, edition, and the customer code for the full version) and once a day when RCW starts (a random install number, version, edition, Rhino version and language). It does not send the machine code, the license file or drawing content. The daily report stops when you turn off the update notice with RCWUpdate.
  • For support, include the RCWVersion output, Rhino version, Windows user name, error text, and a screenshot when available.
